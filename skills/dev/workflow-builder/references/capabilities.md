# 能力发现、Skill 选择与接入

## 发现

先读目标项目规则和 SKILLS_INDEX.md（如有），从本机总入口进入相关分类，读取少量候选 SKILL.md、必要脚本和来源。结合当前会话的系统／插件清单与工具定义，不把磁盘历史缓存当成可用插件。

按目标产物、输入、实际执行能力、约束与依赖比较，名称相似不代表覆盖。Skill 提供方法和模板，CLI／插件／MCP 提供执行，Agent 提供职责，不必互相替代。领域技能只分配给需要它的节点。

## 缺口驱动检索

写明缺少的能力。服务插件先查可用插件目录；需要新 Skill、MCP 或 SDK 时检索官方文档和源仓库。通常比较至多三个合格候选，覆盖不足再扩大；找到足够合适的就停止，避免无边界“全网最佳”。

记录来源、版本／提交、检查日期、平台支持、维护证据、许可、费用、安装成本和选择理由。匹配用户已选工具，优先本机现有方案；未经要求不购买、不开会员、不增加收费服务。

安装时调用可用的 skill-library-management 或遵循目标库管理规则：检查同名及独立修改，保留完整资源和来源，更新所属索引及客户端入口。第三方 Skill 不混入 Builder 自身源码包或标为原创；生成的业务工作流按下节要求携带其运行依赖，并保留来源。不要清理用途相似的其他资源。

## Skill 随工作流完整交付

本机技能库和互联网是选型来源，不是交付后的隐含运行路径。对新建、改造或外部导入的工作流，实际使用的领域 Skill 都完整复制到 `WORKFLOW_DIR/skills/<skill-name>/`；没有使用 Skill 的流程无需创建空目录。只参与构建的三个规划伙伴不自动成为运行依赖。

保留 SKILL.md、脚本、references/、assets/、来源、版本与许可等完整包内容，保留执行权限；凭据、个人配置、缓存、虚拟环境和运行历史不作为技能源码交付。不能只复制 SKILL.md、摘录提示词或建立指向共享库的软链接。核对实际许可证允许本次随包分发；限制不兼容时选择可分发替代，不能以外部本机引用冒充完整交付。

检查 Skill 的相对引用、硬编码绝对路径、脚本导入、子 Skill 与上级套件共享资料。必要依赖递归纳入工作流并更新本地引用；同名不同版本须使用明确目录标识和绑定，不覆盖混用。包内必要文件不得通过软链接逃逸到本机库；保留原始来源与修改记录。模板、脚本和资源使用包内副本；宿主工具、模型服务及 MCP 是另行声明的环境依赖，不因复制 Skill 就自动可用。

在 workflow.yaml 中用 `skills/<skill-name>/SKILL.md` 等相对文件路径绑定 resource，并分配给实际节点；resources.lock.json 记录包内位置、原始来源、版本／提交、许可、完整文件清单及摘要，原始绝对路径只能作为溯源信息，不能用来执行。适配器须实际加载所需指令、按包内目录解析关联文件和调用脚本；不依赖客户端自动发现 skills/。

首版 Runtime 的 resource.paths 接受文件而非目录；kind=skill 中的文件会作为文本传入 job.resources，不能把整个目录或二进制素材放入该文本列表。完整包仍保留在 skills/ 下，业务适配器按项目目录和已加载文档位置访问脚本与素材。Runtime 不自动遍历所有 Skill 文件；Builder 生成的完整性验证须核对锁文件中的清单与摘要，必要支持文件须通过声明资源、执行／验收命令或实际校验纳入变更检测，不能仅检查 SKILL.md 存在。

交付前将工作流复制到新的绝对路径，在隔离环境中禁用原始工作流与构建机器技能库路径，通过包内入口完成样例、检查实际消费的包内 Skill 和支持资源。隔离仅作用于测试环境，不擅自改动用户真实技能库；扫描残留路径只是辅助，不能代替执行证据。接收者按 README 安装声明依赖、配置自己的模型／MCP 凭据；记录真实验证范围，不宣称复制文件即可携带外部连接。

## 连接证据

优先现有插件、CLI、MCP；足够时不新装连接。依据工具实际动作核对账户、目标资源、权限、参数与版本。OAuth 或账户选择必须通过真实支持的途径，不能伪造已授权状态。

状态分开记录：发现、安装、配置、认证、所需操作验证、受阻。读取测试只证明对应读取范围，不能推断写入或另一账户可用。

随包 Runtime 的 tool／model 资源要求只读 probe 命令，返回 {"ok":true} 作为所需操作的探测结果；需要业务专用适配器完成真实 API 检查。环境变量存在不能代替连接验证。

resources.lock.json 和 workflow.yaml 保存非敏感身份引用、资源版本与配置需求，不存实际密钥。输出日志可能包含服务返回，应避免打印凭据；默认 runs/、outputs/ 不入 Git。

权限或工具仅绑定当前会话时，在新的 Runtime 会话重新验证。用户需参与 OAuth、重载客户端或提供必要账户信息时，只暂停依赖该动作的部分，并给出具体恢复操作。已有授权不重复申请；不能完成时交付真实缺口，不虚报连接成功。
