# image 项目技能索引

技能数量：8

[返回项目总索引](../../SKILLS_INDEX.md)

## 什么时候查本分类

视觉创意指导、图片生成、角色与多视角场景资产、服装妆造及 JSON 提示词。

## 技能入口

- [json-prompt-system](json-prompt-system/SKILL.md) — 生成对镜自拍、前置自拍、他拍与时尚大片的完整生图提示词，支持仅输出动作 JSON，参考图规则按任务编写；v3.1.0。
- [Character Design（character-design）](character-design/SKILL.md) — 完成角色参考板、服装造型与状态裂变；v1.7.0，五模式各五模板；新增可扩充的文字预设模块，含“正常人体比例3D动画预设”；宫格3:4、独立全身9:16横向三视。
- [codex-imagegen](codex-imagegen/SKILL.md) — 供其他 Agent 通过本机已登录的 Codex CLI 调用生图与图片编辑能力。

## Midjourney 执行

- [midjourney-generate](midjourney-generate/SKILL.md) — 判断 MJ 任务并通过 Apilio 执行生成、变体、放大、编辑、状态恢复及下载交付。

## RunningHub 图片编辑

- [RH Krea2（rh-krea2）](rh-krea2/SKILL.md) — 直连RunningHub单参考图编辑，固定截图底模与双LoRA 0.4，默认约1K/1张、可选比例，支持参考强度、共享并发与任务恢复；v1.0.0。

- [RH-Qwen Image 2.1（rh-qwen-image-2-1）](rh-qwen-image-2-1/SKILL.md) — 直接调用 RunningHub Qwen 全能无限版 V2，固定底模与双 LoRA、默认 Plus，支持文生图、多图编辑与任务恢复；v3.0.1。

## Google Flow 执行

- [flow-image](flow-image/SKILL.md) — 通过现有 Chrome 使用 Flow Nano Banana 2.1 生图、多参考图与重叠生成；流量异常刷新重试，默认交付 Flow 2K 下载；v1.2.4。

## 场景资产设计

- [场景资产设计（scene-asset-design）](scene-asset-design/SKILL.md) — 从参考拆解、空间规划到四向场景原图、连续性验收与标注拼板，支持设计、提示词和完整资产制作。
