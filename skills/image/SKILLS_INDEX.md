# image 项目技能索引

技能数量：6

[返回项目总索引](../../SKILLS_INDEX.md)

## 什么时候查本分类

视觉创意指导、图片生成、角色资产、服装妆造及 JSON 提示词。

## 技能入口

- [json-prompt-system](json-prompt-system/SKILL.md) — 生成或还原自拍、生活照、电商服装与试穿的分层 JSON 图像提示词；含角色、服装、环境三块，按有无参考图决定写全或只写一致性；v2.1.0。
- [Character Design（character-design）](character-design/SKILL.md) — 区分真人模板、自定义3D与AAA写实建模风格，完成角色参考板、服装造型与状态裂变；当前 v1.6.0。
- [codex-imagegen](codex-imagegen/SKILL.md) — 供其他 Agent 通过本机已登录的 Codex CLI 调用生图与图片编辑能力。

## Midjourney 执行

- [midjourney-generate](midjourney-generate/SKILL.md) — 判断 MJ 任务并通过 Apilio 执行生成、变体、放大、编辑、状态恢复及下载交付。

## RunningHub 图片编辑

- [RH-Qwen Image 2.1（rh-qwen-image-2-1）](rh-qwen-image-2-1/SKILL.md) — 直接调用 RunningHub Qwen Unlimited Edition，固定双 LoRA、默认 Ultra，完成多图编辑与任务恢复；v2.0.1。

## Google Flow 执行

- [flow-image](flow-image/SKILL.md) — 通过 Chrome DevTools CLI 常驻会话使用 Flow Nano Banana 2.1 文生图、多参考图编辑与重叠生成及参考图复用；v1.2.1。
