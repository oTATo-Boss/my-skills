# Calibration Example: 极夜花冠

This is a structure example, not a default aesthetic.

Inside `{{ }}`, define a named look, intended body, complete garment inventory, real construction, exact accessory count, and view invariants. For example:

- asymmetrical high-neck velvet mini dress with a concealed corsetry base;
- seven fixed smoke-black organza petals, each boned and attached to named shoulder/back/waist seams;
- one articulated metal shoulder piece with padded interior support;
- one pair of over-knee leather boots with fixed zipper and heel construction;
- one right ear cuff and one left wrist band;
- an explicit final sentence freezing all quantities, sides, materials, lengths, and wearing relationships across four views.

The useful pattern is exact structural ownership. Do not reuse its black floral styling unless the user requests it.
