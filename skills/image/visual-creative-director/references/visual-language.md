# Visual Language｜从抽象气质到具体视觉

## 建立「看见后能记住」的方向
创作之前先回答三个问题：观众第一眼会看哪里？五秒后记住什么？这个项目与同类作品的区别能否用一句话说清？

把视觉方向拆成五个可控制的选择：
1. **主视觉机制**：是什么引起注意——表面折射、比例反常、材质冲突、色彩切割、极端留白、身体运动、空间错位、特殊物体的行为？
2. **构图与形体**：先建立最易辨认的轮廓和主要质量块，再考虑微小细节；明确主次、对齐、倾斜轴线和负空间的作用。
3. **色彩与材料**：选择主色关系而不是堆砌色名。至少有一个材料对照（如高光硬金属×吸光织物），让色彩和材料在同一光环境下互相证明。
4. **光线与尺度**：光是对空间和物体的解释。知道光来自哪里、照亮什么、留下什么阴影；用熟悉的参照物建立尺度感。
5. **情绪与行为**：让视觉元素表现心理状态，例如克制、锋利、松弛、俏皮、压迫、神秘。情绪应由姿态、距离、节奏、光线传达。

## 抽象词如何变成可执行设计
| 用户表达 | 可能的视觉决策（根据上下文选，而非全部叠加） |
|---|---|
| 高级 | 大轮廓干净；材料有主次；环境与主体有明确距离；精确的细节落点；摄影与光源可信 |
| 性感 | 服装开口和身体线条之间的设计关系；自信、松弛的动作；有意图的视线；与人物性格一致的造型 |
| 韩系 | 由具体子风格决定妆发、廓形和街景细节；可以甜、酷、锋利或极简，不能只靠国别标签 |
| 多巴胺 | 活跃的色彩关系、可识别的色块、快速情绪转换；用中性色或材质留白承担视觉秩序 |
| 电影感 | 空间真实、受控构图、光有来源、表演有状态、镜头选择有意图、物理连续性可靠 |
| 超现实 | 一条清晰的现实规则被改变，其余可感知的材质、空间和反应仍自洽 |
| 设计感 | 独特的形体/功能决定、重复出现的视觉母题、比例与材料统一且理由充分 |

## 主张与反差
- 先决定作品的**主要气质**，再添加一个能增强它的反差：浪漫×工业、自然×几何、复古×高科技等。
- 反差不是强行拼贴。需要有一个共同变量将两方连接，例如同一材质、光照条件、结构节奏或人物行为。
- 当用户要求“独特”，优先创造一个与目标绑定的标志性场面，而不是增加更多装饰。
- 当用户要求“参考 X 的质感”，识别其摄影、色彩、构图、材质等实现机制，再转译到当前主题。

## 层级与视觉节奏
- 第一层：主体和最重要动作/信息；第二层：空间与人物关系；第三层：材质、纹理、装饰。
- 每个画面只需少数高权重视觉元素；若全部元素同等抢眼，降低非核心要素的对比度或复杂度。
- 将细节放在会被看见的地方：近景才可见的装饰需要真实的近景；远景中的细节主要贡献轮廓和色块。
- 根据媒介决定信息密度：小屏封面关注缩略图识别；电影关注画面持续观看；网页关注可扫读和操作。

## 快速原创性检验
问自己：把品牌、角色和地点替换成任意其他名称，这个方案还会完全一样吗？如果会，说明创意依赖通用风格词。改动**核心视觉机制**或主体与环境的关系，而非再增添形容词。
