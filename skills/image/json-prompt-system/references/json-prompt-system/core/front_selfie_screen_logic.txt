front_selfie_screen_logic

本文件只服务 `front-camera-selfie`。
目标是让前置自拍不再只是“近景 + 看屏幕”，而是能写出女生面对屏幕确认自己好看的真实自拍状态。

一. 前置自拍灵魂
- 前置自拍的核心是屏幕意识：她不是面对镜子，也不是被外部拍摄者捕捉，而是在屏幕里确认自己。
- 画面要像“她看到了这个角度不错，于是停在这一秒”，不是机械地对着镜头摆动作。
- 自我确认感必须落到视线、嘴角、下巴、头部角度和身体靠近前方视角的关系。
- 近距离亲密感来自取景距离、画面裁切、面部边缘、肩颈和身体前景，不来自可见取景实体。

二. 画外前置视角成立方式
- 画面默认不出现取景实体。
- 前置视角必须在画面外成立，且只能选择一种主要成立方式：
- 手臂前伸：可见手臂或肩臂透视支持自拍关系。
- 固定视角：画面外的前方视角稳定，人物迎向屏幕，双手可自由参与姿势。
- 定时自拍：人物已经摆好姿势，画外前方视角定时拍下这一秒。
- 支撑视角：前方视角由生活支撑点稳定，但不写具体道具款式。
- 如果双手都在姿势里，不要为了前置自拍硬造持机手；写“无可见持机手，定时自拍或画外前置视角成立”。

三. 屏幕意识写法
- 视线：落在屏幕里的自己、镜头旁一点、屏幕下沿或略偏离镜头；不能写看镜中自己。
- 眼睑：半垂、轻抬、轻挑、放松睁开、短暂停住，必须和气质一致。
- 嘴部：轻抿、微张、嘴角压住、浅笑未完全展开、轻轻收住，不写空泛“有镜头表现力表情”。
- 下巴与头部：下巴轻收、头轻偏、脸略靠近前方屏幕，颈部顺着肩线拉出角度。
- 表情可以是主动摆出来的可爱、轻松镜头感、冷淡或慵懒，但必须像她正在屏幕里管理自己。

四. 近距离姿势母题
- 前置自拍常用母题：托脸停住、拨发停住、手指停下巴边、抱膝靠近、侧躺抬眼、靠枕斜靠、桌边前倾、床面半撑、双手整理边界。
- 每次只选一个主动作母题，其他动作只能辅助它成立。
- 卧姿、侧躺、靠姿、坐姿必须先写主支撑点，再写手部和表情。
- 双手都参与姿势时，必须分别写清两只手的停点和手腕方向；不要再写持机手。
- 构图要顺着前置裁切：脸、肩颈、上身轮廓、腰线、近处膝部/手臂/肩线前景，而不是强行远距离全身。

五. 参考图转译
- 上传图片在 FRONT 锁定下只是姿势、构图、表情、曲线和支撑关系参考，不是重新判 mode 的证据。
- 如果参考图不是前置自拍，也要保留主姿势、构图比例、身体曲线和关键手部动作，再翻译成画外前置视角成立。
- 不能因为原图像他拍就写外部拍摄者；不能因为原图没有完整拍摄关系就判定无法生成。
- 如果参考图双手都可见并参与姿势，优先保留双手动作，用定时自拍或画外前置视角解释拍摄关系。
- 换环境任务中，可以按 front-camera-selfie 规则写生活场景、支撑点和光线氛围，但不复刻原图环境陈设。

六. 失败判定
- 强行生成持机手，导致参考图双手姿势丢失，FAIL。
- 把画外前置视角或定时自拍误判为不成立，FAIL。
- 把卧姿、靠姿、抱膝、侧躺写成普通近景半身自拍，FAIL。
- 只写“看屏幕 / 表情自然 / 可爱有镜头表现力”，没有眼睑、视线、嘴角、唇部、下巴和头部角度，FAIL。
- 出现镜子、对镜、镜中、镜面构图、可见取景实体、第三视角他拍、外部拍摄者，FAIL。

七. 一句话标准
- 前置自拍要像“她面对画外屏幕确认自己这一秒很好看”，取景关系成立、表情有生命力、姿势有支撑、曲线顺着近距离构图自然出现。
