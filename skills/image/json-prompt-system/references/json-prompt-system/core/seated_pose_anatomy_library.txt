seated_pose_anatomy_library

本文件用于稳定生成坐姿，尤其是 M 字鸭子坐、跪坐、盘腿、侧坐、交叠腿和地面坐姿。
坐姿必须写成骨骼路径和构图要求，不能只写中文姿势名。

一. 核心原则
- 坐姿先锁下盘，再写上身，再写手部，再写表情。
- 如果坐姿是用户需求核心，构图必须给下盘足够空间。
- 复杂坐姿不得写成近景半身、胸像或只到大腿上方；必须让骨盆、双膝和关键小腿方向入画。
- 坐姿缺少承重点时视为失败。

二. M 字鸭子坐固定拆解
M 字鸭子坐必须同时写清：
- 骨盆坐地，主要重量落在骨盆和大腿根部。
- 双膝向左右两侧打开，膝盖不是向前并拢。
- 两条小腿分别折向身体两侧，形成左右两个折角。
- 脚踝/脚背落在臀侧附近，不要让脚踝反向扭曲。
- 大腿与小腿形成左右两个明显折角，从正面或略俯视能读出 M 形下盘。
- 上半身可以前倾，但不能让下盘被裁掉。

三. M 字鸭子坐构图要求
- 画面必须至少包含腰部、骨盆、双膝、小腿折向。
- 若用户同时要求上半身前倾和 M 字鸭子坐，优先中全身或全身坐姿构图。
- 前置自拍也必须拉远到能看见骨盆、双膝和小腿折向，不得默认近景半身。
- 如果只看到脸、上身和大腿上方，M 字鸭子坐必定失败。

四. 其他坐姿简表
- 跪坐：骨盆落在脚跟或小腿上，双膝向前或轻开，小腿在身体下方。
- 盘腿：双膝向左右打开，两条小腿交叠在身体前方，脚踝靠近对侧膝部。
- 侧坐：骨盆坐地，双腿向同一侧折叠，身体上半身用一侧手或腰腹维持平衡。
- 交叠腿坐姿：一条腿高位跨过画面或压在另一条腿前方，另一条腿提供低位支撑。
- 地面坐姿：必须写清骨盆、支撑手、膝盖、脚踝至少三个承重或方向点。

五. 坐姿质量门
- M 字鸭子坐缺少双膝外开、小腿折向两侧、骨盆坐地任一项，即 FAIL。
- 复杂坐姿被半身裁掉，即 FAIL。
- 膝盖、脚踝、小腿方向反人体，即 FAIL。
- 上半身前倾导致下盘不可见，即 FAIL。

六. 一句话标准
- 坐姿不是姿势名，而是骨盆、膝盖、小腿、脚踝和构图一起成立。
