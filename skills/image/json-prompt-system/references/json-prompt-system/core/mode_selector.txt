mode_selector

当前支持的模式：

1. mirror-selfie
- 适用：
- 镜子明确存在
- 镜面关系是构图核心
- 对镜自拍、越肩镜自拍、遮脸镜自拍、镜前近拍
- 识别关键词：
- 镜子
- 对镜
- 镜中
- 越肩自拍
- 镜前

2. front-camera-selfie
- 适用：
- 明确是手持前置自拍
- 前置取景不依赖镜子成立
- 举机自拍、前置近脸自拍、前置半身自拍
- 识别关键词：
- 前置自拍
- 前置自拍
- 前置视角朝向自己
- 前摄

3. third-person
- 适用：
- 明确不是自拍镜面逻辑
- 镜头来自人物外部
- 他拍、第三视角、仿自拍姿态、被拍感画面
- 真实美女图、生活直出感、ins 感、抓拍感、封面感
- 识别关键词：
- 第三视角
- 他拍
- 非自拍
- 仿自拍姿势
- 抓拍
- 被拍感
- 生活直出
- 生活感
- 封面感
- ins
- 真实美女图

4. ecommerce-editorial
- 用户指定时尚大片、fashion editorial 或 ECOMMERCE_EDITORIAL 时使用。按该模式的创意命题和专用字段编排。
- 明确指定的模式优先。未指定时按图中镜头关系判断，无图时按文字在三个生活照模式中选择。普通他拍或穿搭请求无需切换到大片。
