third_person_capture_logic

本文件只服务 `third-person`。
目标是让他拍不再只是“外部镜头 + 生活直出参数 + 动作说明”，而是能写出真实外部拍摄者捕捉到的女性照片。

一. 他拍灵魂
- 他拍的核心是外部拍摄者存在感：镜头来自人物之外，人物正在被别人拍到。
- 画面要像“有人刚好用外部镜头拍到她这一秒”，不是她自己在镜子或屏幕里管理自己。
- 被拍反应必须落到视线来向、嘴角、下巴、头部角度、身体停顿和环境接触。
- 小广角直出镜头真实感来自外部机位、景别、人物占比、深景深和轻微数码质感，不来自可见取景实体。

二. 4 类他拍瞬间
- 被叫住回头：身体原本朝向别处，头和视线晚半拍回到外部镜头。
- 走动中停住：脚步、肩线、手部仍保留移动惯性，像刚被拍摄者喊停。
- 靠住 / 坐下时被拍：身体与墙、桌边、床面、台面或座面有真实承重，动作还没完全摆稳。
- 主动配合镜头的半摆拍：她知道自己被拍，故意配合但不演过头，给一个好看的角度。

三. 被拍表情写法
- 视线来向：刚从别处扫回来、略过镜头边缘、短暂停在拍摄者身上、看见镜头后停住。
- 眼睑：轻抬、半垂、慢半拍睁开、眼尾压住、眼神带一点确认或反应。
- 嘴部：嘴角刚收住、浅笑未完全展开、轻抿、微张停住、单侧嘴角轻动。
- 下巴与头部：下巴轻收或轻抬，头部轻偏、回看角度不过度，颈肩线跟随镜头方向。
- 表情可以是被拍到的自然瞬间，也可以是主动摆出的半摆拍表情；都必须像她正在回应外部拍摄者。

四. 姿势与场景支撑
- 他拍动作必须有环境支撑：靠墙、靠桌、倚坐、坐下前后、走近停住、回头、手从脸侧 / 发边 / 衣物边界放下。
- 身体曲线顺着外部机位成立：低机位拉腿，轻俯视做头肩关系，斜切裁切压出身体线，前后层次轻牵肩胯错位。
- 手部动作要像刚停在那里，不像摆件；必须写清手腕方向、手指停点、接触面或边界牵引。
- 场景不是背景板，必须给身体承重、动线、停顿来源或拍摄者站位提供理由。
- 若参考图是局部近景、上身近景裁切、上半身裁切或无完整环境的第三视角图，不得因为缺少完整场景支撑而拒绝；此时“支撑”可以来自身体姿态、手部牵引、画面裁切和外部近距离取景机位。
- 局部他拍的外部拍摄者位置可以用最小锚点成立：近距离侧前方、略高位俯拍、略低位仰拍或贴近身体侧面的小广角直出镜头；不需要追问完整场景。
- 可见范围只有上身时，只写可见人体链条：头颈、肩线、上身结构、手臂、手腕、手指、衣物边界；不要强制补完整下盘。

五. 参考图转译
- 上传图片在 PORTRAIT 锁定下只是姿势、构图、表情、曲线和手部动作参考，不是重新判 mode 的证据。
- 如果参考图是自拍、对镜或前置图，也要保留主姿势、构图比例、身体曲线、表情强度和关键手部动作，再翻译成外部拍摄者视角。
- 不复制可见取景实体、镜子、自拍持机逻辑；不因参考图是自拍而切换 mode。
- 如果原图魅力来自可见取景实体遮挡或镜面关系，只能抽象成遮挡边界、脸部半遮、视线压低、外部镜头偏侧捕捉。
- 如果原图双手都参与姿势，优先保留双手动作；不要为了解释拍摄关系写持机自拍。

六. 失败判定
- 只写摄影参数，没有被拍关系、被拍反应和人物停顿来源，FAIL。
- 人物像摆拍假人：身体站死、手像摆件、表情空木，FAIL。
- 有图反推时参考图姿势被泛化成普通站姿或普通他拍，FAIL。
- 有图反推时把可用的第三视角局部图判成信息不足，要求补完整下盘、完整环境或完整摄影者关系，FAIL。
- 禁止自拍持机：把外部他拍写成手持自拍、前置自拍或自我拍摄逻辑，FAIL。
- 把自拍图直接写成自拍、前置自拍、对镜自拍或持机自拍，FAIL。
- 外部镜头位置不成立：不知道拍摄者在哪里、为什么这个景别能拍到，FAIL。
- 出现镜子、对镜、镜中、镜面构图、前置自拍、持机自拍、可见取景实体作为拍摄主体，FAIL。

七. 一句话标准
- 他拍要像“外部拍摄者用外部镜头真的抓到了她好看的这一秒”，镜头位置成立、被拍反应有生命力、身体有支撑、曲线顺着外部机位自然出现。
