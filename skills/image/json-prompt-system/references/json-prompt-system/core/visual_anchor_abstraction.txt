visual_anchor_abstraction

本文件用于把参考图里可见的服装、穿戴、配饰、道具、图案和颜色信息，抽象成动作变量层。
JSON Prompt 的职责是写姿势、表情、构图、裁切、镜头方位和动作关系，不负责复制服装、配饰或商品外观文本。

一. 全 mode 硬禁原则
- 最终 JSON 不得出现任何服装款式、颜色、材质、图案、品牌、风格或配饰具体名。
- 禁写范围覆盖所有字段：表情、眼神、焦点区域、头部状态、动作名称、视觉关键词、核心主色调、点缀色彩、氛围描述、负面限制、展示重点、细节保留等。
- 不能把服装/配饰信息藏进色彩字段，例如“黑色服装”“浅色外层”“服装主色调”“配饰点缀色”。
- 不能因为参考图有某件衣物、眼部穿戴、头部穿戴或装饰物，就让结果图生成同类物件。
- 电商 mode 也不复述具体商品款式、颜色、图案、材质名称；只写参考图锁定、结构边界、开口厚度、遮挡限制、展示关系和镜头裁切。
- 必须区分“信息硬禁”和“动作力度保留”：不得削弱明确牵引动作，边界方向、手指受力和可见范围必须写清。

二. 禁写信息类型
- 头部/眼部穿戴：任何帽类、帽檐、眼镜类、墨镜类、发饰类。
- 上下装与外层：任何上衣、外套、裙、裤、袜、鞋、披挂、制服、泳装、内衣等具体名。
- 配饰道具：项链、戒指、耳环、链条、吊坠、包、手机壳图案、贴纸、品牌标识等具体名。
- 外观属性：颜色、材质、纹理、印花、图案、风格、年代、品牌、商品名、服装主色调。
- 组合描述：任何“某颜色 + 某服装/配饰”“某材质 + 某款式”“某服装压住主体轮廓”的表达。

三. 允许的中性变量
- 上方边界遮挡眼神。
- 面部上半区被上方遮挡边界压住。
- 一侧肩部边界下移，肩颈线条露出。
- 衣物上方边界下移。
- 衣物边界、上方边界、下摆边界、腰线边界、腿部边界。
- 手指钩住边界、向上/向下/向前下方牵引、边界明显位移。
- 两指钩住上方边界向边界方向轻整理。
- 遮挡关系、贴合关系、牵引方向、受力停点、可见范围。
- 上身中心线、上身轮廓线条、腰胯线、肩颈线条由身体角度、裁切和边界关系带出。

四. 错误转写与正确转写
- 错误：墨镜遮住大部分眼神。
- 正确：上方面部边界遮住大部分眼神，视线从遮挡下方压出来。
- 错误：帽檐压住上半张脸。
- 正确：上方遮挡边界压住上半张脸，头部略低并靠近画面边缘。
- 错误：黑色服装和浅色外层共同构成主色调。
- 正确：色彩只写环境/背景或整体手机成像色温，不把人物衣物纳入色彩总结。
- 错误：外套滑落露出肩颈。
- 正确：一侧肩部边界下移，肩颈线条露出，肩线形成不对称。
- 错误：手机壳图案成为视觉焦点。
- 正确：只写遮挡边界、持机位置或设备画外关系；不写图案。

五. 有图还原执行
- 先识别可见服装/配饰/道具造成的作用：遮挡眼神、压住脸部、露出肩颈、压住腰线、分割腿部比例、制造遮挡私密感。
- 再转成中性动作变量：头低、上方边界、肩部边界、腰线边界、腿部边界、遮挡边界、持机/画外设备关系。
- 如果服装/配饰/道具不是动作成立的必要原因，直接舍弃，不要转写。
- 最终 JSON 只能写动作、构图、裁切、镜头方位、表情和边界互动；不得命名原图服装/配饰/颜色。

六. 一句话标准
- 看得见服装和配饰，不等于写进动作 JSON；只保留它对人物姿势、表情、边界、裁切和镜头关系造成的中性影响。
