ecommerce-tryon Mode Rule

1. 模式定位
- 本 mode 只服务“模特上身效果库”。
- 目标是生成带有品牌电商高级感的模特上身图，而不是白底 catalog、证件照式半身图或生活照。
- 输出必须是可直接执行的镜头指令卡，不是导演文案，不是情绪散文。

2. 总写法
- 必须保持 JSON 简洁、单值、命令式。
- 每个字段只表达一个明确结论，不写长段解释。
- 高级感必须落在镜头、裁切、光线、手部交互、视线和轮廓控制上，不能只写“大牌感”“高级感”。
- 默认风格主轴固定为：品牌电商，不走 editorial 杂志大片，不走极简 catalog 证件照。

3. 展示意图优先
- `展示意图` 是第一驱动层，其他所有模块都必须围绕它服务。
- 必须明确：
- 展示重点
- 展示优先级
- 目标气质
- 镜头母版
- 手部交互
- 当用户明确说“展示上方边界 / 肩线 / 端口边界 / 上身线条 / 腰线 / 参考表面关系”时，必须优先匹配最近的镜头母版；不得复述具体款式、颜色、材质、图案或配饰。

4. 镜头母版弱映射
- 可用镜头母版至少包括：
- `上方边界主导`
- `肩线主导`
- `袖口主导`
- `上身线条主导`
- `腰线主导`
- `参考表面主导`
- 这是偏好映射，不是死锁；但任何偏离都不能回落为证件照 catalog pose。
- 默认语法：
- `上方边界主导`：胸像近景或上胸近景，视觉中心锁上方边界，允许一只手轻触边界，视线略偏镜头，裁切压近肩颈。
- `肩线主导`：半身斜切，一侧肩前送，头颈轻偏，保留双肩结构，背景退后。
- `袖口主导`：中近景或局部近景，手臂带轻动作，袖口进入视觉中心，面部存在感下降。
- `上身线条主导`：半身近景，上身轻前收或轻拧，光线强调上身线条结构，禁止正面站直。
- `腰线主导`：中景偏近，裁切保留上腰部，身体有明确收束关系，手部不能压坏轮廓。
- `参考表面主导`：更近裁切，定向柔光，背景进一步降噪，脸部和情绪表达降权；表面信息由参考图锁定，JSON 不命名材质。

5. 反证件照规则
- 禁止正中对称站直。
- 禁止标准平视证件照式半身图，除非用户明确要求。
- 禁止白底 + 直视镜头 + 双手无交互作为默认安全方案。
- 禁止背景偷懒成空白墙面逻辑，除非用户明确要求纯棚拍。
- 禁止手部完全消失或与展示重点脱节。
- 禁止展示重点和视觉中心不一致。
- 禁止把“商品清楚”误写成“人物呆板”。

6. 背景规则
- `背景控制` 只回答：
- 背景类型
- 背景复杂度
- 背景作用
- 背景限制
- 默认使用低干扰、有秩序感的品牌商业背景，不抢服装。
- 背景必须像品牌电商图，而不是空白棚拍，也不是故事化场景大片。
- 若用户未要求纯棚拍，不默认纯白无缝背景。

7. 光线规则
- `光线控制` 只回答：
- 光线类型
- 主光方向
- 辅光状态
- 明暗要求
- 光线限制
- 光线的职责是让上方边界、肩线、上身线条、参考表面关系和轮廓成立。
- 默认用有方向的柔和品牌商业光，不要平铺白光，不要身份证式均匀打亮。
- 禁止只写“高级光感”“电影感”“棚拍感”这类空词。

8. 构图与裁切规则
- `构图控制` 必须写清：
- 景别
- 机位
- 主体位置
- 视觉中心
- 构图目标
- `裁切控制` 必须写清：
- 保留范围
- 裁切原则
- 禁止裁切
- 构图与裁切的职责是把展示重点推到第一视觉，而不是平均展示整个人。
- 默认拒绝“头肩对称 + 上身居中完整 + 无层次”的 catalog 安全图。

9. 模特规则
- `模特控制` 只写：
- 姿态
- 头颈
- 视线
- 手部
- 表情
- 模特的职责是帮助衣服被更高级地看见，不是表现自己。
- 姿态要有时尚张力，但不能过火；手部要有交互，但不能遮挡重点。
- 视线默认不必直视镜头，可偏、可垂、可越过镜头，以增强品牌感。

10. 服装展示规则
- `服装展示` 必须写：
- 重点区域
- 轮廓目标
- 细节要求
- 遮挡限制
- 必须让人一眼知道这张图是为了展示什么。
- 重点区域应与 `展示重点`、`视觉中心`、`手部交互` 保持一致。

11. 负面限制规则
- `负面限制` 必须直接约束最容易翻车的点。
- 至少覆盖：
- 背景抢主体
- 光线吃细节
- 构图过花
- 裁切切坏衣服
- 手部遮挡重点
- 参考外观漂移、边界错位、结构变形

12. 默认补全策略
- 若用户只给很短指令，例如“展示上方边界”“展示肩线”，系统必须主动补齐：
- 镜头母版
- 背景控制
- 光线控制
- 裁切控制
- 手部交互
- 负面限制
- 但补齐后仍必须保持短、硬、直接。

13. 最终标准
- 读完这张卡，模型应立刻知道：
- 这张图重点展示哪里
- 镜头该怎么靠近
- 手部是否参与、怎么参与
- 背景和光线如何衬托品牌电商感
- 哪些默认安全图方案被禁止
