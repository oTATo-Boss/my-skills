ecommerce-tryon Mode Workflow

一. 总原则
- 先定展示重点，再选镜头母版，再补背景和光线，再收束构图、裁切、手部和负面限制。
- 不从人物情绪起手。
- 不从品牌故事起手。
- 不写长段解释，只写短指令。

二. 纯原创流程

步骤1：确认任务类型
- 这是模特上身品牌电商图
- 不是生活照
- 不是自拍
- 不是普通动作设计
- 不是纯服装渲染

步骤2：先写展示意图
- 先定展示重点
- 再定展示优先级
- 再定目标气质
- 再定镜头母版
- 最后定手部交互
- 这是全卡的第一驱动层

步骤3：按展示重点匹配镜头母版
- 领口 -> 优先 `领口主导`
- 肩线 -> 优先 `肩线主导`
- 袖口 -> 优先 `袖口主导`
- 上身线条 -> 优先 `上身线条主导`
- 腰线 -> 优先 `腰线主导`
- 面料纹理 -> 优先 `面料纹理主导`
- 允许偏离，但不能回到 catalog 安全图

步骤4：写背景控制
- 先定背景类型
- 再定背景复杂度
- 再定背景作用
- 再定背景限制
- 默认是低干扰品牌商业背景，不是纯白证件照墙面

步骤5：写光线控制
- 先定光线类型
- 再定主光方向
- 再定辅光状态
- 再定明暗要求
- 最后定光线限制
- 光线必须服务展示重点，而不是平均照亮整个人

步骤6：写构图控制
- 先定景别
- 再定机位
- 再定主体位置
- 再定视觉中心
- 最后定构图目标
- 构图要把展示重点推到第一眼，不允许平均分配注意力

步骤7：写裁切控制
- 先定保留范围
- 再定裁切原则
- 再定禁止裁切
- 裁切必须和镜头母版一致，不能把关键结构切坏

步骤8：写模特控制
- 只定姿态、头颈、视线、手部、表情
- 先保证服装展示，再补时尚感
- 手部要么明确参与展示，要么明确避让重点，不能失语

步骤9：写服装展示
- 写重点区域
- 写轮廓目标
- 写细节要求
- 写遮挡限制
- 重点区域必须和视觉中心保持一致

步骤10：写负面限制
- 优先写最常见翻车项：
- 证件照式构图
- 白底安全图
- 手部失踪
- 视觉中心跑偏
- 遮挡重点
- 改款改色改材质

三. 最终检查
- 是否先写了展示意图，而不是先写背景或模特
- 是否选了合适的镜头母版
- 是否高级感已经落在镜头、裁切、手部交互、视线和光线
- 是否没有回落为白底半身直视 catalog pose
- 是否展示重点、视觉中心、手部交互三者一致
