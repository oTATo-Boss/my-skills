third-person Mode Quality Gate

硬性失败条件（任一命中即 FAIL）
- Schema 不符合当前 mode 模板，或混入其他 mode 的顶层结构。
- mode 判断错误：镜面自拍、前置自拍或电商展示任务被写成 third-person。
- 在站点锁定 PORTRAIT 时，输出镜子、镜中、对镜、镜面构图或镜前关系。
- 在站点锁定 PORTRAIT 时，输出前置自拍、持机自拍、自我拍摄逻辑，或可见取景实体作为拍摄主体。
- 最终 JSON 输出污染：出现 `core/`、`mode_`、文件名、路径、规则名、README 或“参考某文件”等 agent 工作说明。
- 越权写入模特身份、人物外形、皮肤或材质审美；场景、环境、光线必须只服务真实生活直出他拍成立。
- 写入背景虚化、浅景深、bokeh、人像模式焦外、单反/全画幅审美、专业后期、HDR 光晕、电影感分层调色或作品级修背景。
- 最终 JSON 出现任何具体服装、穿戴、配饰、鞋包、道具款式、颜色、材质、图案、品牌或商品名，导致服装参考图被污染。
- 在表情、焦点区域、头部状态、视觉关键词、核心色彩、点缀色彩或氛围字段写入服装/配饰信息。
- 表情只剩冷淡、有镜头表现力、可爱等标签，没有眼睑、视线、嘴部、下巴/头部角度；或表情空木、过度假笑。
- 无图原创没有被拍瞬间母题，只是普通站姿或自拍动作外壳。
- 只剩摄影参数，没有外部拍摄者位置、拍摄动机、被拍反应或人物停顿来源。
- 人物像摆拍假人：身体站死、手像摆件、表情空木，或者半摆拍过度营业。
- 有图反推时参考图姿势、构图、曲线、表情或手部动作被泛化成普通站姿 / 普通他拍。
- 有图反推时把可用的第三视角局部图、上半身近景或上身近景裁切图误判为信息不足，返回 draft:null 或要求用户补图。
- 把自拍图、对镜图或前置图直接写成自拍逻辑，而不是转译为外部拍摄者视角。
- 外部镜头位置不成立：不知道拍摄者在哪里、为什么这个景别能拍到、人物为什么刚好被拍到。
- 侧身/半转身出现极限扭转、手臂穿体、多手、重心不明或外部镜头位置不成立。
- 对近景 / 局部裁切图强行要求完整下盘、完整腿部、完整场景或完整承重关系，导致拒绝生成或废话追问。
- 用户要求上方裁头、下方延伸到腿部、上身近景构图、衣物边界牵引时，不得因目标判断或裁切不完整直接失败。
- 字段冗长复述、重复锚点、只剩氛围词或规则解释腔，导致输出不再是高密度照片动作 JSON。
- 压缩后丢失被拍瞬间母题、表情强度、身体结构、摄影构图或关键手部动作。

一. 核心标准
- 最终结果必须像真实生活直出他拍美女图。
- 必须先像一张真实会留下来的照片，再像一个动作。
- 必须有构图设计，但不能有作品集摆拍感。

二. 结构检查
- 是否包含以下模块：
- `场景基础`
- `周边环境与空间`
- `光影与色彩表现`
- `整体氛围与情绪传达`
- `动态动作库`
- `角色位置与构图模块`
- `生活直出成像约束`
- 是否明确没有 `服装还原模块`

三. 摄影师检查
- 是否体现了 `photographer_skill.txt` 的摄影师判断
- 是否体现了外部拍摄者位置、拍摄动机和被拍者反应
- 是否先定照片任务，再定动作
- 是否写出了构图法则、景别、机位、人物位置与画面占比
- 如果只剩动作说明，没有摄影决策，视为不合格

四. 反 AI 感检查
- 是否仍像 AI 摆拍
- 是否头部太正、肩线太平、手部像摆件
- 是否表情自然却仍发呆
- 是否所有元素都过于平均、过于安全、过于规整
- 是否像“一个好看的假人”而不是“真实被拍到的美女”

五. 反刻板构图检查
- 是否默认中轴对称
- 是否默认正面平视
- 是否默认人物站桩
- 是否人物画面位置过于居中平均
- 是否构图缺乏引导线、前后层次、偏移或裁切设计

六. 生活直出质感检查
- 是否用具体参数或成像结果写出了生活直出质感
- 是否明确是 24mm / 26mm 小广角直出逻辑、小底深景深、轻颗粒、轻锐化等方向
- 是否仍偷懒写成一句“生活直出拍摄”
- 是否错误混入：
- 单反
- 全画幅
- 大光圈
- 奶油焦外
- bokeh
- 前景虚化

七. 生活直出模块检查
- 生活直出模块是否仍然存在，但被弱化为生活直出控制
- `景深效果` 是否明确关闭
- 是否没有 强风格调色、HDR 光晕、色差特效、重滤镜
- 是否没有把高级感交给后期去伪造

八. 场景与人物同步成立检查
- 场景是否具体真实
- 光线是否来自环境
- 动作是否与场景接触、支撑、空间方向统一
- 表情是否像被拍到的一瞬，不是摆给镜头
- 视线是否有来向：发现镜头、刚从别处扫回来、知道自己被拍或半摆拍配合
- 是否既好看，又像真的存在于那个场景里
- 是否读懂并还原了原图/任务里的女性气质、拍照情绪、展示目的、身体曲线和微表情动作
- 是否避免为了更有魅力而硬塞撑扶、回头、顶胯、拉衣或开放式构图

八.1 参考图转译检查
- PORTRAIT 锁定下，参考图原始拍摄方式是否没有推翻当前 mode
- 自拍 / 对镜 / 前置图是否被翻译为外部拍摄者视角，而不是保留可见取景实体、镜子或持机自拍逻辑
- 是否保留参考图主姿势、构图比例、身体曲线、表情强度和关键手部动作
- 若原图魅力来自可见取景实体遮挡或镜面关系，是否抽象成遮挡边界、脸部半遮、视线压低、外部镜头偏侧捕捉
- 若原图已经是第三视角或无完整取景关系的局部他拍，是否直接分析可见动作，而不是反复解释缺少完整动作信息
- 对局部近景图，是否只检查可见人体链条和裁切目的，并对缺失下盘/环境做最小补全

九. 一句话标准
- third-person 的最终目标不是“从外部拍到一个动作”，而是“像有人用外部镜头真的拍到了一张构图有设计、人物又真实好看的美女图”。
