third-person Mode Rule

1. 模式定位
- 本 mode 处理第三视角、他拍感、被拍感、抓拍感、仿自拍姿态任务。
- 核心目标是生成“真实生活直出他拍美女图”，不是单反浅景深人像、不是影棚样片、不是 AI 海报、也不是普通站姿说明图。
- 画面必须先像一张真实好看的生活直出照片，再像一个动作。
- 本 mode 必须参考 `core/third_person_capture_logic.txt`：他拍的灵魂是外部拍摄者存在感、被拍者反应、被捕捉的一秒、环境中的身体支撑和小广角直出镜头真实感。

2. 结构原则
- third-person 采用完整照片设计结构，不再沿用自拍动作卡的极简骨架。
- 顶层结构固定为：
- `场景基础`
- `周边环境与空间`
- `光影与色彩表现`
- `整体氛围与情绪传达`
- `动态动作库`
- `角色位置与构图模块`
- `生活直出成像约束`
- 禁止回退成旧的九段式动作说明卡。
- 禁止加入服装还原模块、人物身份设定、脸部精修设定。

3. 摄影师指导层
- 本 mode 必须同时参考 `modes/third-person/photographer_skill.txt`。
- 该文件提供：
- 真实生活直出他拍摄影原则
- 构图设计库
- 生活直出参数语言库
- 人物自然度规则
- 常见失败图谱
- 写作时优先让摄影师 skill 提供“镜头怎么拍”，再让动作字段补“人怎么停”。

4. 反 AI 感与反刻板构图规则
- 禁止默认中轴对称、正面平视、人物站桩。
- 禁止“动作成立但照片不成立”。
- 禁止“表情自然”被写成“发呆、空、木、无差别冷脸”。
- 禁止只写“高级感 / 氛围感 / 封面感”而不落实到机位、构图、视线、动作节奏。
- 禁止“人物在画面中心平均摊开、背景退成说明板”的安全构图。
- 构图必须被设计过，但仍像随手拍出来的真实瞬间。

5. 生活直出质感规则
- 必须写具体生活直出成像参数或结果，不允许只写一句“生活直出拍摄”。
- 优先可用的具体表达：
- 24mm 或 26mm 小广角直出逻辑
- 小底传感器深景深
- 轻微边缘锐化
- 暗部轻微亮度噪点或彩色噪点
- 社交媒体压缩后的细腻颗粒感
- 局部高光不过曝但有轻微数码溢出边缘
- 禁止出现：
- 单反
- 全画幅
- 大光圈定焦
- 奶油焦外
- bokeh
- 人像模式级虚化
- 前景虚化层次
- 背景虚化托主体

6. 场景与空间规则
- 场景必须具体、真实、可停留，不允许抽象空背景。
- `场景基础` 负责时间、天气、季节、地点。
- `周边环境与空间` 负责可见空间、材质、道具、纵深和压迫感。
- 背景不是装饰，而是让人物成立、让构图更有层次的支撑系统。
- 场景必须像真的有人会在那里，不像 AI 拼贴背景板。

7. 光影与色彩规则
- 光源必须来自真实环境，而不是摄影棚概念词。
- 光影要写清：光从哪来、阴影如何落、环境/背景色彩倾向是什么、空间里有哪些非服装来源的色彩跳点。
- 色彩不得来自人物服装、穿戴或配饰；不得写“服装颜色构成主色调”“配饰点缀色”等。
- 光影的职责是让人物更真实、更好看、更像被外部镜头抓到的一瞬。
- 禁止空泛写“高级光感”“电影光影”“影棚质感”。
- 禁止用光影掩盖结构问题或人物假感。

8. 动态动作库规则
- `动态动作库` 是人物动作与神态的主干。
- `镜头语言` 必须回答：
- 相机为什么在这个位置
- 机位为什么成立
- 景别与构图为什么不是安全图
- 镜头特征如何体现小广角直出镜头而非专业相机
- `人物动作骨架` 必须回答：
- 人为什么会这样停住
- 重心为什么成立
- 双手为什么停在这里
- 动作如何带来真实的身体连锁
- `人物表情神态` 必须优先用叙事触发式写法，不允许退回参数校准式呆板脸。
- 被拍关系必须成立：写清外部拍摄者大概在人物哪一侧、为什么这个距离能拍到、人物是刚发现镜头、被叫住、走动中停住，还是主动配合镜头的半摆拍。

9. 角色位置与构图模块规则
- 这是本 mode 的核心层，专门用来打掉“证件照式站姿构图”。
- 必须明确：
- 构图法则
- 引导线
- 留白比例
- 景别
- 机位高度
- 焦距感
- 人物在画面中的 X/Y/Z 位置
- 人物画面占比
- 身体朝向、头部转向、视线焦点
- 构图必须优先服务“真实感 + 设计感”，而不是平均、平铺、无风险。
- 允许偏移、压迫式裁切、低机位、轻俯视、斜切和前后景层次，但都必须看起来像生活取景拍得到。

10. 生活直出成像约束规则
- 该模块保留，但只允许服务“生活原相机直出感”。
- 允许：
- 轻度亮度/对比度/饱和度/白平衡描述
- 极轻颗粒感
- 极轻边缘锐化痕迹
- 很弱的镜头边缘边缘压暗
- 禁止：
- 景深效果
- 胶片预设感过重
- 强风格调色
- HDR 光晕
- 色差特效
- 任何明显“作品化后期”的语法
- `景深效果` 字段必须显式禁用，不允许被 agent 填成有效景深控制。

11. 真实美女图标准
- “真实美女图”不是只让人物好看。
- 必须同时满足：
- 人物像真的会出现在这个环境里
- 构图有设计，但不装
- 表情和动作像被拍到，不像摆给镜头
- 生活直出成像质感具体可感
- 没有影楼感、AI 精修感、单反焦外感

11.1 女性魅力与被拍气质还原
- 本 mode 必须参考 `core/women_selfie_presentation_logic.txt`。
- 同时参考 `core/third_person_capture_logic.txt`、`core/visual_anchor_abstraction.txt`、`core/expression_intensity_logic.txt`、`core/original_pose_invention_logic.txt`、`core/anatomy_pose_sanity.txt`、`core/expressive_pose_translation.txt`、`core/seated_pose_anatomy_library.txt`、`core/output_density_control.txt`。
- third-person 要读懂被拍者的气质、拍照情绪和镜头捕捉到的女性魅力；不是只把人物放进构图。
- 曲线感必须和摄影构图一起成立：斜切、偏移、低机位、轻俯视、前后层次都要服务原图/任务里的身体线条和气质。
- 微表情可以是被拍到的瞬间，也可以是主动摆出的表情管理；必须具体写眼睑、视线、嘴角、下巴和头部角度。
- 表情必须写出她和外部镜头的关系：发现镜头、刚从别处扫回来、知道自己被拍、故意配合但不演过头；不能只写“看镜头”。
- 以图还原时，必须尽量完美还原原图里女性的气质、拍照情绪、目的、身体曲线和微表情，而不是泛化成一个普通他拍动作。
- 禁止为了增强魅力硬塞不属于当前视图的撑扶、回头、顶胯、拉衣或开放式构图。
- 若参考图本身就是第三视角或他拍近景，必须直接分析并产出草稿；不得因为没有完整拍摄关系、没有完整腿部、没有完整环境或只看到上半身局部而返回 draft:null。
- 局部裁切图也可以成立：只锁定当前可见裁切内的上身、手部、衣物边界、上身轮廓、肩颈、头部/画面边缘关系；缺失的下盘和环境只做最小合理补全，不要把它当作失败原因。
- 用户要求“改为上裁头下延伸腿部”等裁切变化时，理解为构图裁切重写：上方可切到下巴/嘴部/颈部或头部边缘，下方可延伸到大腿/腿部边界；保留原图主动作和上身边界牵引。

11.2 服饰中立、表情强度、被拍动作与人体检查
- 有图还原时，不得把任何具体服装、穿戴、配饰、颜色、材质、图案、品牌或道具款式写进最终 JSON；只能写上方边界、衣物边界、腰线边界、腿部边界、遮挡关系和边界牵引等动作变量。
- 服装/配饰信息不得出现在表情、焦点区域、头部状态、视觉关键词、核心色彩或点缀色彩字段；他拍只写外部镜头、裁切、被拍瞬间、表情和边界互动。
- 表情必须选择清晰强度档位：克制、轻松镜头感、甜/娇俏、自信强表达；并落到眼睑、视线、嘴部、下巴/头部角度，不得只写“冷淡、有镜头表现力、可爱”。
- 无图原创不能套自拍动作；必须转成被拍瞬间，例如刚回头、刚靠住、刚走近、刚把手从脸侧放下、刚转身停住、被叫住抬眼。
- third-person 人体检查优先服务外部镜头成立：人物为什么停在这个位置、手从哪里来、重心落在哪里、上身结构与骨盆方向差是否可执行，禁止极限扭转、手臂穿体和多手。
- 如果画面是上半身或上身近景，不要求完整重心、承重腿或完整下盘；只检查可见部分的人体连贯性，如头颈/肩/上身结构/手臂/手腕/手指路径是否成立。
- 用户明确要求边界整理、上提、拽住、露出上身轮廓或上身中心线时，不得以“服饰中立”或保守化为由删除动作；写成非款式化的边界牵引：手指钩住/托住/向上或向下带住衣物边界，上身中心线/上身轮廓线条可见。
- 最终 JSON 必须按输出密度控制压缩：每个字段只写自己的职责，用短锚点保留视图构图、被拍瞬间母题、表情强度、身体结构、手部动作或衣物边界；不得用长段复述替代摄影和动作决策。

11.3 参考图转译与自拍污染处理
- 如果站点锁定 PORTRAIT，上传图的原始拍摄方式不能推翻当前 mode；只提取姿势、构图、曲线、表情、手部动作和支撑关系。
- 如果参考图是自拍图、对镜图或前置图，只能翻译成外部拍摄者视角；不得复制镜子、可见取景实体、持机自拍、前置取景关系或看屏幕语义。
- 若原图主魅力来自可见取景实体遮挡或镜面关系，只能抽象为遮挡边界、脸部半遮、视线压低、外部镜头偏侧捕捉。
- 若原图双手都参与姿势，优先保留双手动作；他拍不需要持机手解释拍摄关系。
- 若参考图已经没有自拍取景关系且视角来自人物外部，直接按 third-person 处理，不要反复质疑“是不是他拍”。
- 参考图缺失的信息按当前 mode 最小补全即可：外部拍摄者位置用“近距离侧前方/略高位/略低位小广角直出镜头”这种短锚点，不需要追问完整场景、景别或腿部动作。

12. 最终检查
- 是否像真实生活直出他拍，而不是 AI 摆拍
- 是否没有虚化逻辑和相机味
- 是否构图被设计过，但不显得做作
- 是否人物不呆、不木、不对称过度完美
- 是否第三视角、场景、动作、表情和生活直出质感全部同步成立
