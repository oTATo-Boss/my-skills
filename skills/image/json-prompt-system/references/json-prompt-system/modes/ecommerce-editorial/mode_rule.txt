ecommerce-editorial Mode Rule

1. 模式定位
- 本 mode 处理杂志内页、品牌广告、时装故事、创意棚拍、街头直闪、复古胶片、极简视觉和实验时尚等时尚大片任务。
- 它不是固定风格，也不是常规白背景电商上身图；目标是根据用户文字与参考图，为每个任务建立一套独立、统一、可执行的视觉命题。
- 人物身份、身材、服装、配饰和商品外观由参考图与外层提示词负责，本 JSON 只负责目标画面、创意方向、摄影策略、模特表现和保护限制。

2. 固定结构
- 顶层只能是 `时尚大片`。
- 内部字段固定为：`动作名称`、`画面内容`、`大片类型与创意命题`、`核心视觉优先级`、`场景与主体关系`、`灯光与色彩策略`、`镜头与构图策略`、`模特表现`、`服装与身份保护`、`成像与后期策略`、`负面限制`。
- 禁止增加效果 ID、版本号、风格编号、功能开关、参数母版、LUT 路径或渲染器式伪参数。

3. 画面内容
- `画面内容` 是整份效果卡的整体语义锚点，用一段连贯自然语言说明最终画面里有什么、人物在做什么、重点商品位于哪里、元素如何分布以及画面停在哪个瞬间。
- 可以写人物数量、景别范围、动作、场景、道具功能、前中后景、空间关系和事件瞬间。
- 不得写模特的五官、脸型、年龄、种族、肤色、发型、发色、身高、体重、身材数据或其他具体形象。
- 不得写任何服装相关描述，包括服装种类、颜色、材质、版型、图案、穿搭、鞋包和配饰；需要出现商品时只写 `重点商品`、`手持商品` 或 `展示商品`。
- 不写灯光参数、镜头参数、调色、颗粒或后期手段，这些信息分别进入后续专属字段。
- 不写分析过程，不写“高级感、大片感、奢华感”等空泛评价。

4. 创意命题与视觉优先级
- `大片类型与创意命题` 必须先确定本次属于哪类大片，再用一句清楚的命题说明它要表达什么。
- 类型可以变化，不默认电影感、胶片感、硬光、直闪、极简或复古。
- `核心视觉优先级` 必须明确第一、第二、第三注意力落点，并说明背景或次要元素如何退让。
- 每张图只选择最有效的二至三个主要视觉手段，不为填字段堆叠风格标签。

5. 场景、灯光与摄影
- `场景与主体关系` 写具体可见的环境、主体在空间中的位置、支撑关系和背景参与方式，不重复画面事件。
- `灯光与色彩策略` 写光源类型、方向、软硬、明暗组织和色彩秩序；允许专业时尚摄影语言，但必须服务当前创意命题。
- `镜头与构图策略` 写画幅、景别、焦距感、机位、主体位置、裁切、留白、前后景和视觉动线。
- 时尚大片允许深景深、浅景深、直闪、影棚布光、运动模糊、胶片或数码介质等不同选择，但只能在任务确实需要时使用，不得形成固定审美模板。

6. 模特表现
- `模特表现` 只写姿态、动作、重心、头部方向、视线、表情、手部和动作节奏。
- 表现必须与创意命题和镜头关系一致，既可以克制静止，也可以夸张、动态或戏剧化，但人体结构、承重和手部交互必须成立。
- 不得通过改变人物长相、体型或服装设计来制造美感。

7. 服装与身份保护
- 本字段只写保护要求，不复述参考图中的具体人物形象或具体服装外观。
- 不复述具体服装款式、颜色、材质、图案、品牌、配饰或商品名。
- 必须要求人物身份、面部辨识、身体比例、服装、配饰和重点商品遵循参考素材。
- 可以写需要保护的关系类型，例如轮廓、比例、结构、纹理、图案位置、五金位置和穿着受力；不得重新命名或描述它们的具体样式。

8. 成像与后期
- `成像与后期策略` 根据本次创意选择摄影介质、清晰度、颗粒、锐度、对比、色彩处理和允许的后期程度。
- 后期必须强化已经成立的画面关系，不能用磨皮、液化、抠图、光晕或复杂特效掩盖错误人体、错误透视、错误光源和商品变形。
- 禁止默认套用统一电影色、复古黄调、青橙调、重颗粒或浅景深。

9. 负面限制
- 只列本次任务最容易发生的高风险问题，通常 5–8 条。
- 优先限制身份漂移、服装与商品变形、错误人体、错误透视、无依据元素、风格跑偏和过度后期。
- 不重复正向字段已经写清的普通要求，不使用空泛的 `不要不好看`。

10. 输出密度
- 使用直接、专业、自然的中文，每个字段只承担自己的职责。
- 常规成品建议约 2200–3600 字符，硬上限 4000 字符；复杂不等于冗长，不得靠重复摄影原理或同义形容词凑长度。
