ecommerce-editorial Mode Workflow

一. 确认输入用途
- 用户显式指定时尚大片或站点锁定 `ECOMMERCE_EDITORIAL` 时，只使用本 mode。
- 有图时先判断图片是创意参考、构图参考还是仅人物/服装/商品素材；没有额外说明时，将其视为可转译的视觉参考，但不把人物形象和服装外观写进 JSON。
- 无图时根据用户主题、商品展示目的和期望气质原创一套完整视觉方案。

二. 先写整体语义锚点
- 用 `画面内容` 把最终画面组织成一段可直接用于生图的自然语言。
- 只保留人物数量、景别、动作、场景、重点商品位置、空间关系和瞬间状态。
- 删除人物具体形象、任何服装描述、灯光参数、镜头参数和后期语言。

三. 确定创意命题
- 选择最适合当前素材和任务的大片类型。
- 用一个清楚命题统一画面，不并列多个互相竞争的风格。
- 排出第一、第二、第三视觉优先级；如果没有重点商品，就把人物表现或空间关系放在更高优先级。

四. 分配摄影职责
- `场景与主体关系`：地点、空间、支撑、背景参与方式。
- `灯光与色彩策略`：光源、软硬、方向、亮暗和色彩秩序。
- `镜头与构图策略`：画幅、景别、机位、焦距感、主体位置、裁切、留白和视觉动线。
- 各字段不得复述 `画面内容`，而要补足它没有承担的执行细节。

五. 设计模特表现
- 让姿态、重心、视线、表情、手部和动作节奏共同服务创意命题。
- 有图还原时保留原图最有辨识度的动作关系，并修正明显的关节、承重和交互问题。
- 不写人物长相、身材数据或具体服装，不用改变身份和体型制造美感。

六. 写保护与成像策略
- `服装与身份保护` 只写参考锁定、结构保护和交互边界，不复述具体外观。
- `成像与后期策略` 根据本次命题选择介质和处理方式；没有明确需要时保持克制，不自动添加胶片、电影色、重颗粒或浅景深。

七. 写负面限制并输出
- 选出 5–8 个最可能破坏本次成片的问题。
- 按模板输出纯 JSON，并控制在 4000 字符以内。
