front-camera-selfie Mode Workflow

1. 先确认这不是镜面自拍
- 没有镜子作为必要视角来源
- 画外前置视角直接朝向人物自己

2. 先判断前置自拍是否成立
- 画外前置视角是否在人物前方
- 画外前置视角是否略高于眼平、眼平或贴近面部常见区域
- 前置视角关系由哪种方式成立：手臂前伸、固定视角、定时自拍、支撑视角或近距离前方视角
- 是否默认应让画面只保留视角关系
- 如果参考图双手都在做姿势，不要强行指定持机手；把画外前置视角放在画面外
- 同时参考 `core/front_selfie_screen_logic.txt`，先确认这是屏幕意识自拍，不是镜面自拍或他拍

3. 先确定构图距离
- 优先判断是：
- 近距离胸像特写
- 中近景半身
- 近景脸部与肩颈
- 如果构图太远，优先收近，而不是继续写完整下半身
- 如果是中距离，必须让前景关系成立，不能像普通第三视角站拍

4. 再拆动作母题
- 是拢发
- 托腮
- 扶后颈
- 轻拉发丝
- 轻扶脸侧
- 还是别的近距离前置动作

5. 再写前置自拍的成立参数
- 画外前置视角位置
- 入镜边界
- 手臂透视；若无可见持机手，则写“无可见持机手，定时自拍或画外前置视角成立”
- 头部如何迎向画外前置视角
- 眼神是看镜头还是更像看屏幕中的自己

6. 再写空间成立控制
- 先找主支撑点
- 再找辅助接触点
- 再找前景关系
- 再说明为什么这张图会被看成前置自拍而不是第三视角拍摄

7. 再补场景与氛围
- 判断是否需要生活场景支撑
- 判断人物是否与支撑面、倚靠点、坐姿或躺姿形成真实关系
- 判断是否需要补光线氛围，让画面更像真实前置自拍成片
- 这些内容统一写进 `画面氛围控制`

8. 再补表情
- 避免只写“直视镜头”
- 优先写：
- 半聚焦
- 轻专注
- 自然微张
- 很浅笑意
- 自我观察感
- 必须落到眼睑、视线落点、嘴角/唇部、下巴和头偏角；表情要像在屏幕里确认自己，而不是看镜子或看外部拍摄者

9. 再补局部细节
- 如果动作涉及发丝、嘴角、下巴边缘、脸侧或后颈
- 把这些内容写进 `局部细节`
- 不要把这些特征塞进通用体态字段里导致模板发散

10. 进行美照质量检查
- 这张图是否像真实女生会拍、会留、会发的自拍
- 是否具有生活感和环境依托
- 是否不是动作说明图
- 是否人物自然、不呆、不木、不像 mannequin

11. 最终检查
- 是否没有可见取景实体
- 手臂延伸、固定视角或定时自拍逻辑是否至少一种成立
- 构图是否足够近，像真实前置自拍
- 眼神是否像看画外前置视角而不是看镜子
- 是否有屏幕意识和自我确认感，而不是普通摆拍脸
- 表情是否自然，不呆不僵
- 场景是否帮助自拍成立，而不是悬空或空白
- 中距离是否有前景关系与支撑关系
- 主支撑点与辅助接触点是否区分清楚
- 画面是否既成立又好看
