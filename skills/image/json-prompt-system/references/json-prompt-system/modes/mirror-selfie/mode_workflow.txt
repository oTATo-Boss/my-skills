mirror-selfie Mode Workflow

一. 原创流程补充
1. 先确认镜子是否是必要元素
2. 再确认持机手位置与镜中构图是否成立
3. 再确认身体与镜面的关系：
- 正对镜
- 轻侧对镜
- 背对镜但回看
- 越肩对镜
4. 再写动作主轴
5. 再检查持机手与非持机手是否都像真实镜前自拍动作，而不是摆件
6. 再补镜中眼神落点、嘴角轻微变化、头部小偏差和肩线小误差
7. 最后补镜中截帧感

二. 图片还原流程补充
1. 先判断镜子是不是主要视角来源
2. 判断手机是否为自拍设备
3. 判断画面属于：
- 正面镜自拍
- 侧身镜自拍
- 背身镜自拍
- 越肩镜自拍
4. 再拆解持机手、非持机手、肩颈关系、回看逻辑
5. 再拆镜中眼神落点、表情轻重、头肩微误差
6. 最后再转写 JSON

三. 最终检查
- 镜子是否仍然是必要元素
- 持机手是否成立
- 回看逻辑是否成立
- 身体朝向和镜中画面是否一致
- 是否没有混入前置自拍或第三视角逻辑
- 持机手是否自然，不像任务性举机
- 非持机手是否和动作母题相关，不像硬摆 pose
- 眼神和微表情是否像在镜中确认自己，而不是演给镜头看
- 站姿是否有小幅不对称与停顿感
- 是否已经对照 `mode_quality_gate.txt` 做最终质量收口
