# 基础角色与三类画风

## 写实模板入口

真人通用、美女、帅哥按[真人模式选型](realistic-routes.md)选择；通用3D与AAA按目标画风选择。角色设计固定五个模式，每个模式都具备肖像、头部四视、半身、全身三视、综合宫格五个模板，入口见[统一模板表](templates.md)。真人通用的四个基础建档模板与已认可的写实宫格板同属 `realistic-base/`，不能拆为两种角色模式。基础建档沿用该模式的普通T恤、长裤、鞋子要求；综合板按原模板结尾填入人物与完整服装设计。下文快速/分阶段只是同一模式内的执行方式，各模式的原审美、肤质、体型、服装与画风保持。

## 输入和续作

从用户要求、剧本、人物小传、性格、外貌与现有文件中提取影响视觉的内容：身份、年龄感、五官、体型、发型、固有特征、目标画风与用途。性格转为可见的气质依据，不用强烈表情替代中性身份参考。基础阶段不加入临时伤口、泪痕或剧情服装。

查看可访问的实际图片，把结论写入已有项目记录：可复用、需修正、缺少、待核验。已有肖像只缺全身时补全身；已有合格综合板只需要造型时进入裂变，不重新建角。文件无法查看就标待核验，不以名字声称合格。

无图时可由特征描述生成。用户要求参考具体人物时，使用实际提供或明确选定的素材；需要检索时记录实际来源和外貌职责，不把未获取的图片写成模型输入。融合只发生于首次长相设计，结果须形成一个统一的新角色。确认之后，已定正面肖像是身份依据，不再让原始多个人物参与后续重融合。

## 快速路径：一次生成完整角色板

适用于要求较少、允许同时形成长相与造型的任务，也适用于用户已选好参考、只需直接生成整板的请求。选择写实、通用CG或AAA的综合模板，填写`快速整板生成`模式；人物、服装、发型、妆造和特征用实际参考图与文字共同控制。无图可用文字，不虚构素材。

先说明每份参考的职责：已确认人物参考锁身份，服装参考只提供款式与穿戴关系，风格参考控制表现，文字补充需要的造型和特征。只有首次设计且明确允许融合时才融脸；已有身份不因走快速路径而变成新人物。

直接调用生图得到同时有面部、半身和全身的最终参考板，不先制作中间视图，不要求先画样衣或换回基础打底服。直接着装造型任务要求的最终服装、妆造和特征可在这一步一起出现；贴身衣物基础任务仍保留基础衣物。沿用用户指定的布局、画幅和数量；没有另行要求时，五套角色综合模板均采用3:4竖版，上方头部四视（0°/45°/90°/180°）、下方左侧半身、右侧全身正面／侧面／背面三视。此规格用于快速整板生成；后续独立阶段与已有源图拼接按各自规格执行。

直接验收身份、各视图服装与状态、质感和完整性。候选不自动等于已确认基础身份；需后续裂变或长期锁定时，先明确采用哪个结果。一板已满足任务就停止，不再反向补做全套中间资产。若有生成缺陷，保持原提示词、参考、参数和规格重抽，不因单次失败改设计或自动切换分阶段流程；连续失败达到任务预算或尝试上限时交付现有结果与缺陷，等待下一步指示。

## 分阶段：阶段及参考职责

| 阶段 | 输出 | 依据与停止条件 |
|---|---|---|
| 长相确定 | 1:1正面面部肖像 | 文字或明确外貌参考；五官、肤色、年龄感、发型与质感可辨；等待用户确认 |
| 头部扩展 | 16:9的0°/45°/90°/180°头部四视图 | 已确认正面肖像；不依赖尚未制作的全身图 |
| 体型确定 | 3:4正面半身 | 肖像与已有头部视图；确定肩颈、躯干、腰胯比例，不重设脸 |
| 全身扩展 | 所有画风统一9:16竖版画布，正面/侧面/背面横向三视 | 肖像、已有头部与半身；补下半身和鞋履，不反向改变已定信息 |
| 综合参考板 | 三张整图自然拼接，尺寸由源图决定 | 已验收头部条带、半身整图、全身整图；不拆分视图，按等高横拼再等宽竖拼 |

写实、通用CG与AAA全身三视图均在一张9:16竖版画布上，从左至右横向排列正面、90°侧面、180°背面。方向以角色自身左右为准。所有角度维持同一打底服装、同一体型和中性姿态，允许变化的是观察方向。

## 只交付一张全身资产，缺陷按原条件重抽

所有画风的一张9:16全身三视图整图就是完整产物，不再分别生成三个全身视角，统一使用所选路线的独立全身模板。完成后在项目已有记录中绑定该文件、实际尺寸、验收状态及生成任务引用（如有）；进入整板阶段只读取它，不提交第二次全身生成。若规格或边缘出错，沿用同一提示词、参考与9:16目标重抽，不自行改为横版、修改提示词或重排人物。合格图只留一张作为本阶段采用版本，候选可保留诊断；这不限制为同一资产重试的次数，实际尝试仍受任务预算与授权约束。

头部条带保留原宽高；半身与全身等高横拼，再将下方组合等比缩放到头部原宽，紧接头部下方。不固定分辨率，也不裁切源图。详见[整图拼接](board-composition.md)。

## 分阶段各路线的模板数量

模板入口见[统一模板表](templates.md)。真人通用、美女、帅哥、通用3D、AAA CG均各有五个模板：肖像、头部四视、半身、全身三视、综合宫格。分阶段时先用同一模式的肖像、head-four、half、body-three建立源图，最终按三张完整源图拼接；快速整板时用该模式的board直接生成。综合模板不承担缺失头部或全身的视角补齐，也不要求已有合格源图再次生图。

AAA使用五个独立模板：肖像、头部四视图、半身、全身三视图、综合。肖像确认后使用head-four扩展头部角度，随后制作半身与body-three（9:16横向三视），再按三张整图拼接；不再通过综合模板的头部补齐模式生成头部。

五个角色模式使用相同的五模板结构并遵守相同的信息依赖，面部、体型和完整全身信息均须齐备。

## 风格与质量

- 写实：真实摄影、自然肤质与发丝、可信服装结构；避免磨皮、油腻高光或滤镜改脸。
- 通用CG：依据用户指定画风或风格参考决定比例、建模和材质语言。卡通、黏土、树脂等是可能的指定风格，不能被一律改成写实或AAA。
- AAA：固定3A大作高质量精细化写实角色建模风格，保留清晰三维模型体积、雕刻与CG渲染质感；可信解剖、PBR/SSS皮肤和材质、细致毛发与清楚结构；不把身份照片变成真人摄影，也不被卡通服装参考带偏。

身份参考管长相，风格参考管表现；新图不得改变原有风格。所有必要结构都要能读清，不能用景深或强阴影掩盖面部、服装或身体细节。未知背面是设计补充，不声称从正面照片“还原了真实背面”；按已有结构推导并检验自洽。
