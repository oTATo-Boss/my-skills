# 写实角色的四套模板

先选角色资产类型，再选快速整板或分阶段；性别不自动等于审美路线。女性角色不一定走美女版，男性角色不一定走帅哥版。

| 目标 | 模板目录 | 调用边界 |
|---|---|---|
| 通用角色的身份与体型基础资产 | `assets/templates/realistic-base/` | 默认基础路线；普通T恤、长裤和鞋子，保留设定的性别、年龄、肤色与体型，不强制美女或帅哥审美 |
| 明确要求美女／高颜值成年女性 | `assets/templates/beauty/` | 恢复整体重写前的五份女模特模板；仅服装改为纯白色基础款合身短袖T恤和黑色基础款运动短裤（裤长至大腿中部），原审美、摄影与肤质保持；宫格板采用3:4头部四视＋左半身＋右侧全身三视 |
| 明确要求帅哥／高颜值成年男性 | `assets/templates/handsome/` | 从通用基础服装版派生，强制高颜值帅气脸型与完美身材，穿黑色短裤；具体脸型、精瘦或健壮等体型风格不固定，确认后保持一致 |
| 直接生成真人宫格板（默认宫格入口） | `assets/templates/realistic/board.txt` | 写实角色宫格板；3:4竖版，上方头部四视、下方左半身、右侧全身三视。结尾填写人物与完整服装设计，支持无参考图纯文生图；不走分阶段或拼接 |

四套真人快速宫格板均采用3:4竖版：上方0°/45°/90°/180°头部四视，下方左侧正面半身，右侧全身正面／侧面／背面三视；通用基础服装、美女与帅哥的衣物和审美要求分别沿用各自模板。

“快速”只决定是否拆阶段；通用基础服装版快速输出仍穿普通T恤、长裤和鞋子，美女、帅哥版按各自模板穿着。直接生成真人宫格板时默认采用写实角色宫格板；明确选择基础建档或美女／帅哥专用时，沿用对应模板的穿着。已有合格资产直接复用。

## 五个阶段的入口

通用基础服装、美女、帅哥三套各有 `portrait.txt`、`head-four.txt`、`half.txt`、`body-three.txt`、`board.txt`；原写实仅有 `board.txt`，具体链接见[模板表](templates.md)。基础流程仍为肖像确认 → 头部扩展 → 半身体型 → 全身 → 拼板。新基础版和帅哥版的分阶段规格仍为1:1／16:9／3:4／9:16；全身只需一张三视图，最终拼接用三张完整源图。

## 美女版当前调用规则

当前五模板以整体重写前的原女模特备份为基础，服装段采用以下定稿原文；审美、摄影、肤质与布光保持，不沿用1.4.0整体改写。2026-11-10仅综合宫格板排版改为下述3:4格式，其他四个阶段模板不变。

穿纯白色基础款合身短袖T恤，搭配黑色基础款运动短裤，裤长至大腿中部。柔软棉质面料，剪裁简洁自然，呈现清晰协调的身体比例与日常休闲感。

原文既有阶段冲突仍按之前已记录的调用适配处理，保存实际提交的完整提示词：无参考图时用文字首次设计，不虚构图片；头部四视结尾按本阶段头部输出理解；全身三视统一正面／侧面／背面，从左至右，一张9:16；美女综合宫格板上方头部四视采用0°正面／45°斜侧／90°侧面／180°背面，独立头部阶段仍按其模板执行。填写或修复原有占位符，不把参考图要求冒充已上传事实。这些历史适配不是本次新增的摄影或审美改写。

美女快速综合板默认3:4竖版，上方头部四视条带，下方左侧正面半身，右侧全身正面／侧面／背面三视；取景须完整保留头顶、手部与脚底。已有分阶段源图时仍直接按三张整图拼接，不为适配快速板重做源图。随机缺陷沿用实际输入原条件重抽，服务拒绝单独记录。

## 写实角色宫格板

直接生成真人宫格板时默认使用 `realistic/board.txt`。将人物、体型、实际参考图及职责、完整服装造型、妆发、特征、保持与修改项、画幅布局填入结尾 `{{输入具体角色设定}}`。没有参考图时明确写纯文生图；服装必须具体到各件衣物、鞋履、配饰、颜色、材质、穿法与跨视图一致的结构。未指定款式时先按角色身份与用途设计完整穿搭，然后一次生成整板；不要求额外样衣阶段。布局与真实摄影要求沿用认可版本，人物和服装按当前任务填写。

[城市通勤完整示例](../assets/examples/realistic-board-city-commute.txt)保留本次实际成功提示词，包含苔绿夹克、米白针织衫、炭灰长裤和深棕皮靴，作为填写参考；不能将示例人物和穿搭自动带入其他角色。

需要分阶段或固定普通基础服装时使用通用基础服装版；贴身衣物受限但允许普通服装替代时，也进入通用基础服装版，记录改用原因与新提示词。只有任务同时允许一步生成完整设计图时，才选无默认服装的快速综合板；不得仅因某个源图生成失败就擅自改变制作路径。严格固定服装仍按服装模块与用户已指定的确认边界执行。
