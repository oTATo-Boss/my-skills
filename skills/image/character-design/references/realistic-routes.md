# 写实角色的四套模板

先选角色资产类型，再选快速整板或分阶段；性别不自动等于审美路线。女性角色不一定走美女版，男性角色不一定走帅哥版。

| 目标 | 模板目录 | 调用边界 |
|---|---|---|
| 通用角色的身份与体型基础资产 | `assets/templates/realistic-base/` | 默认基础路线；普通T恤、长裤和鞋子，保留设定的性别、年龄、肤色与体型，不强制美女或帅哥审美 |
| 明确要求美女／高颜值成年女性 | `assets/templates/beauty/` | 恢复整体重写前的五份女模特模板；仅服装改为纯白色基础款合身短袖T恤和黑色基础款运动短裤（裤长至大腿中部），原审美、摄影、肤质和构图保持 |
| 明确要求帅哥／高颜值成年男性 | `assets/templates/handsome/` | 从通用基础服装版派生，强制高颜值帅气脸型与完美身材，穿黑色短裤；具体脸型、精瘦或健壮等体型风格不固定，确认后保持一致 |
| 直接一步到位生成角色设计图 | `assets/templates/realistic/board.txt` | 仅保留快速综合板；无默认服装，结合实际参考图与结尾插槽中的设计信息／提示词要求生成，不走分阶段或拼接 |

“快速”只决定是否拆阶段；通用基础服装版快速输出仍穿普通T恤、长裤和鞋子，美女、帅哥版按各自模板穿着。要求直接完成最终服装时才选原写实模板，不因为一步生成就自动替换为着装版。已有合格资产直接复用。

## 五个阶段的入口

通用基础服装、美女、帅哥三套各有 `portrait.txt`、`head-four.txt`、`half.txt`、`body-three.txt`、`board.txt`；原写实仅有 `board.txt`，具体链接见[模板表](templates.md)。基础流程仍为肖像确认 → 头部扩展 → 半身体型 → 全身 → 拼板。新基础版和帅哥版的分阶段规格仍为1:1／16:9／3:4／9:16；全身只需一张三视图，最终拼接用三张完整源图。

## 美女版当前调用规则

当前五模板恢复自整体重写前的原女模特备份，仅服装段采用以下定稿原文；其余审美、摄影、肤质、布光与构图保持，不沿用1.4.0整体改写。

穿纯白色基础款合身短袖T恤，搭配黑色基础款运动短裤，裤长至大腿中部。柔软棉质面料，剪裁简洁自然，呈现清晰协调的身体比例与日常休闲感。

原文既有阶段冲突仍按之前已记录的调用适配处理，保存实际提交的完整提示词：无参考图时用文字首次设计，不虚构图片；头部四视结尾按本阶段头部输出理解；全身三视统一正面／侧面／背面，从左至右，一张9:16；横版宫格的头部角度名称对应0°正面／90°左侧／180°背面／270°右侧。填写或修复原有占位符，不把参考图要求冒充已上传事实。这些历史适配不是本次新增的摄影或审美改写。

美女快速综合板默认16:9，左半身、右上头部四视、右下全身四视；已有分阶段源图时直接按整图拼接，不为快速板的四视布局重做全身。随机缺陷沿用实际输入原条件重抽，服务拒绝单独记录。

## 一步到位快速综合板

仅在直接生成完整角色设计图时使用 `realistic/board.txt`，将人物、体型、实际参考图及职责、服装造型、妆发、特征、保持与修改项、画幅布局等设计信息／提示词要求填入结尾 `{{输入具体角色设定}}` 插槽。插槽与实际参考图共同控制本次设计，不从通用基础服装版继承T恤、裤子、鞋子，也不预设任何其他服装。

需要分阶段或固定普通基础服装时使用通用基础服装版；贴身衣物受限但允许普通服装替代时，也进入通用基础服装版，记录改用原因与新提示词。只有任务同时允许一步生成完整设计图时，才选无默认服装的快速综合板；不得仅因某个源图生成失败就擅自改变制作路径。严格固定服装仍按服装模块与用户已指定的确认边界执行。
