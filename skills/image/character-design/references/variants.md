# 剧情状态与角色裂变

## 选择编辑目标

新增造型从已确认基础板派生；同一服装的状态变化从该服装的已确认造型板派生。基础板始终保留，不能把带伤、湿衣版本覆盖为新的基础身份。

每次记录角色、造型、状态、适用剧情、来源版本和本次改变。若从现有状态继续改变，只继承剧情需要的内容；需从湿透恢复干燥时，优先复用该造型的干净版，而非多次编辑“擦除”伤损造成细节退化。

## 明确修改与保持

[状态模板](../assets/templates/outfit/state.txt)分别填写：

- **改变**：伤口位置、朝向、大小、颜色与阶段；泪痕、红眼、表情；衣物破损、污渍或湿润的区域与程度；指定纹身、发型和妆容。
- **保持**：面部身份、骨相、年龄感、基础肤色、身高体型、未指定的服装结构、原视角与排版。
- **对应**：以角色自身左右描述单侧特征，明确哪些视角可见；背面看不到面部伤口时不得为凑一致强行复制伤口。

用户指定的哭泣、开心等状态允许改变表情，但不能改五官身份。仅做表情或伤口时不强迫换衣，不额外要求服装参考。新设计的妆造在应用前遵守造型确认节点；已明确指定的剧情状态按要求执行和验收，不新增逐图审批。

保持原版面，各视图表示同一时刻、同一套造型与同一状态。若某状态无法通过静态图表达，记录其动作要求交视频制作方，不在本技能生成具体剧情镜头。

## 版本与停止

采用项目现有命名；没有约定时可用 `角色ID/基础或造型ID/状态ID/v001`。新文件和记录不能覆盖已存在版本。版本关系是来源说明，不要求建立额外数据库。

每个请求状态得到可用参考板即停止；失败则交付候选及已知缺陷，不用未审查图充当已确认资产。
