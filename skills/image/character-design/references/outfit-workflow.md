# 服装、妆造与换装模块

先识别原创设计、已有款式、原穿搭提取、仅妆造四种任务。不把每次换装都变成服装重设计，也不把普通短视频强制升级为造型资产工程。

## 原创设计

读取[设计方法](design-brief.md)，把风格词转成具体款式、结构、材质、层次、闭合、承重、配饰数量和穿戴方式。用[四视图模板](../assets/four-view-template.txt)生成16:9空气假人样衣，顺序为正面/背面/左侧/右侧；只展示同一套设计，不出现可见人体或假人外壳。

抽象表达必须落实到可制作结构，保留原技能对真实材料、重力、接触和固定部件数量的判断。需要校准设计块结构时再读[原案例](example-filled-design.md)，不照搬案例审美。版本化保留候选，针对具体缺陷调整，不无上限抽卡。

服装、妆造方案须在应用到角色前确认；可以确认设计文字或已生成样衣。已有明确确认的设计不重复询问。用户只要设计或提示词时完成该范围即停。

## 已有款式与穿搭提取

用户明确采用的服装图可直接作为造型依据，无须再画一次样衣。有多件服装时说明各件来源、叠穿和配饰关系；缺少关键背面或穿法时只补该缺口。

需要将原穿搭整理成独立服装资产时，用[提取模板](../assets/templates/outfit/extract.txt)，只去人物、整理背景并补足视角；原款式、道具、配饰、数量和穿戴关系保持。提取不等于原创设计。缺失视角只能按已有结构推导，不伪称已知原版。

## 应用到角色

读取[换装要求](character-try-on.md)和需要时的[妆造方法](makeup-styling.md)。使用[固定换装模板](../assets/character-styling-template.txt)，填写风格、保留/不保留妆造及本次变化字段：

- 图1为角色基础板，锁定身份、体型、布局与各视图。
- 图2为已确认服装，锁定结构、材质、层次、穿法和配饰；没有服装变化时不要求图2。
- 图3～N只控制标明的局部细节，不贡献人物身份。
- 用户明确修改的发型、表情与状态可覆盖对应基础项；其他内容继承图1。

换装后的第一产物仍是原排版的角色资产，不进入新动作或剧情构图。全板所有相关面板都要换装，面部区域可见的领口、饰品和妆造也须一致。

## 画风与返修

服装参考决定设计，不覆盖角色画风。写实使用自然摄影质感；通用CG使用角色的指定材质和渲染语言；AAA维持写实CG。不能把所有风格都验收为“看起来像手机拍摄”。

沿用[服装与换装返修](review-and-repair.md)的方法：确定主问题、保留通过部分、作最小修订。个别随机手脚缺陷可在授权范围内重试一次；同类问题重复出现时修正控制条件，不无限追加批次。
