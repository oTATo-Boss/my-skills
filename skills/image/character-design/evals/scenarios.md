# 场景走查与验收要求

这是维护用场景，不是每次制作的必读清单。下表是预期决策；不能声称已执行独立Agent或实际生图测试。

| 输入场景 | 预期执行与停止点 | 错误信号 |
|---|---|---|
| 要求宽松、参考人物和服装加文字，直接要最终角色板 | 综合模板快速模式一次生成；不要求先肖像或样衣；按实际图验收 | 套用两处中间审批、强制打底服、自动补中间资产 |
| 无图片，仅人物小传，要求分阶段定稿的写实角色 | 文字生成1:1肖像，等待确认，再扩展四视头、半身、三视全身和拼板 | 强制找明星图、未经确认直接完成整套 |
| 多个外貌参考，新角色已确认肖像 | 后续只使用已定身份扩展，原多人物参考不继续融脸 | 全身扩展又重新融合换脸 |
| 已有合格基础板，普通短视频造型宽松 | 复用交接，不生新首帧或强制服装裂变 | 自动生成双人卧室构图 |
| 只有头部图，需完整角色参考 | 补半身体型与全身、拼板；头部资料不是完整交付 | 用白底大头照代替综合板 |
| 通用黏土CG角色 | 复用三模板，综合模板分别补头部/全身，保留黏土材质 | 强制毛孔、AAA或真人手机照片 |
| AAA角色 | 使用五个AAA模板，独立head-four补头部；全身9:16四宫格 | 仍用综合板头部补齐、头部阶段混入整板 |
| 原创复杂服装 | 明确结构、配件数量、承重点，确认设计/样衣后上装 | 把幻想效果当服装结构、擅自应用未确认造型 |
| 用户明确选定款式或已有确认服装 | 直接参考应用；只有缺口才补，提取原穿搭不重新设计 | 强制再做原创样衣或混入模特脸 |
| 同一服装从干净到湿透、受伤 | 从该造型已确认版本派生，保留布局和服装结构，按自身左右应用伤口 | 从错误造型派生、每个视图伤口都在屏幕左边 |
| 仅改变哭泣表情，无换装 | 状态模板只改表情和泪痕，面部身份保持，不要求服装图 | 固定表情规则覆盖请求或额外换衣 |
| 基础源图已通过，只需排版 | 脚本等比拼接和回执，源图不重绘 | 为了4K整板重抽、放大声称新增细节 |

实施验收：检查上述路径的模板与职责是否实际可达；脚本以合成测试图片验证尺寸、面板对应、比例、裁切、缺项、重叠、上采样警告和防覆盖。语义走查不等于模型实际执行效果。

## 2026-10-29 · 真实拼接失败回归

- 用户反馈固定分区造成大块白边，并要求全身三视图只生成一张9:16。实际目录的第二次全身生成是为修复外侧手臂裁边而改成3:2横图；新规则禁止为拼接自动改变规格并重抽，生成缺陷沿用原提示词、参考与9:16目标重抽，不擅自改横图或改提示词。
- 新任务仅传入头部、半身、全身三张完整图片。头部原尺寸不变，下方等高横拼后整体等宽缩小，最终尺寸由源图形成，不拆裁视角。
- 新增整图回归测试覆盖无额外白缝、源图边缘完整、源文件不变、头部像素不变、实际1672×941/1086×1448/941×1672输入得到1672×2215、异常输入与防覆盖。原分格模式及其测试仅用于历史显式配置兼容，不作为新任务路径。

- 用户进一步明确：一张是最终采用资产数量，不是抽卡次数上限。随机缺陷使用完全相同的生成条件重抽；不得自动变更提示词、设计、画幅、裁切或流程。
