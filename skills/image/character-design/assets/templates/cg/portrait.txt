# 任务目标：生成高质量3D/CG角色（全性别通用正面面部肖像版）

# 执行背景
基于多重参考图与下方“角色设定”文本描述，生成商业级3D/CG角色面部肖像基础设定图，用于面部身份锁定、发型妆容和后续建模与动画的视觉参考；不包含实际绑定或三维模型数据。

## 本次阶段与参考职责

基础资产按“确定正面肖像 → 扩展头部角度 → 确定半身体型 → 扩展全身视角 → 拼接综合参考板”的信息顺序建立；只执行本模板对应阶段，不凭空要求尚未生成的下游图片。不同风格可在同一模板内补足角度，不强制新增模板。

基础资产统一采用能清楚辨认体型的简洁打底服装，款式、颜色与覆盖范围按角色设定，各视图一致；不默认加入剧情服装、伤口、泪痕、纹身、强烈情绪或装饰配件。已确定的固有特征按角色设定保留。裂变时以基础角色参考板锁定身份、体型和原排版，只改变明确指定的服装、妆造、表情或状态，并使其在各视图中一致；未经指定的特征保持原样。

## 1. 风格基调与CG渲染质感

* 核心原则：本提示词不预设固定3D画风、不强制固定渲染器、不固定写实程度。最终画面的整体艺术风格、CG渲染语言、材质表现、角色比例、光影逻辑、色彩倾向和完成度，必须继承已明确指定的风格参考或角色设定，不混用其他参考的画风。
* 参考图画风优先级：用户明确指定的3D/CG风格与风格参考是画风依据；角色身份图和服装图只承担各自职责，不因混入真人照片而覆盖已定3D风格。无风格参考时按角色设定确定3D表现。若参考图是写实CG，则生成写实CG；若参考图是半写实3D，则生成半写实3D；若参考图是卡通3D、手办感、潮玩感、黏土感、树脂感、二次元3D、游戏CG、影视CG、低多边形、风格化建模或其他特殊3D风格，则完整继承该风格。
* 质量下限：无论参考图属于哪种3D/CG风格，都必须保持商业级角色资产完成度，包括稳定头骨结构、清晰面部识别、干净材质边缘、统一灯光环境、稳定五官比例和可用于后续角色一致性制作的面部资产展示效果。
* 面部材质：根据参考图风格决定皮肤表现方式。若参考图偏写实CG，则保留毛孔、肤色层次、次表面散射、细微高光、眼周细节、唇部纹理和自然面部细节；若参考图偏卡通/手办/潮玩/二次元3D，则继承参考图中的简化皮肤、柔滑材质、塑料/树脂/黏土/动画化表面或风格化肤色处理。
* 头发材质：根据参考图风格决定头发表现方式。若参考图为写实CG，则使用真实 Groom Hair 毛发系统，发丝边缘清楚、层次自然；若参考图为风格化3D，则继承其发片结构、块面发束、雕塑感发丝、卡通高光、模型化头发处理或对应的风格化发型语言。
* 眼睛材质：根据参考图风格决定眼睛表现方式。若参考图为写实CG，则呈现真实角膜、虹膜纹理、泪膜高光、眼白厚度与眼睑包裹关系；若参考图为风格化3D，则继承其眼睛比例、虹膜画法、高光形状、玻璃感、玩具感或二次元化眼球表现。
* 模型质量：必须保持高完成度3D角色头像资产标准，但不强制固定为AAA游戏、影视数字人、虚幻引擎、Octane、Arnold、V-Ray或超写实PBR风格。所有技术质感服务于指定的3D画风，不覆盖它。
* 成像要求：high-quality 3D character portrait render, CG character head-and-shoulders asset, clean character model presentation, sharp facial structure, stable identity, coherent hair material, coherent eye material, commercial-grade 3D/CG finish, style inherited from reference images.

## 2. 背景与光影设定

纯白或近白无缝背景，柔和均匀的资产展示光线，必要的轻微接触阴影。保证头发、浅色衣物和身体轮廓可辨；各视图曝光、色温和材质响应一致。无复杂环境、无剧情化布光，不用强轮廓光或大片阴影遮住身份与结构。

## 3. 人物设计与参考职责

* 首次设计：可以仅凭角色设定生成，无参考图时不虚构输入；也可按用户明确指定的外貌参考与融合要求形成一个统一的新角色，不把多位参考人物分别画入成品。
* 已确定身份后的复用：指定的已定正面肖像或基础角色板决定面部身份，不再重新融合长相；只执行明确提出的修改。
* 服装、发型、风格参考各司其职，不把服装模特的脸或身材带入角色。未提供的参考不作为必需输入。
* 本阶段输出一位角色的一张正面肖像，锁定五官、骨相、年龄感、肤色和发型；后续视图继承该结果。

## 4. 排版与构图标准

* 1:1正方形，单人正面head-and-shoulders肖像；居中、平视、自然中性表情，完整保留头顶和发型，肩颈与少量上胸可见。
* 五官、皮肤或相应风格的表面细节清楚；避免夸张广角、遮脸发丝、过曝、强阴影、美颜式改脸与过度景深。
* 干净白底，不添加剧情环境、文字、Logo、水印或额外人物。
