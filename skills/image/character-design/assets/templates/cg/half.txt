# 任务目标：生成高质量3D/CG角色（全性别通用正面半身版）

# 执行背景
基于多重参考图与下方“角色设定”文本描述，生成商业级3D/CG角色正面半身基础设定图，用于后续角色一致性、换装、建模与动画开发的视觉参考；本图本身不包含可绑定的三维模型数据。

## 本次阶段与参考职责

基础资产按“确定正面肖像 → 扩展头部角度 → 确定半身体型 → 扩展全身视角 → 拼接综合参考板”的信息顺序建立；只执行本模板对应阶段，不凭空要求尚未生成的下游图片。不同风格可在同一模板内补足角度，不强制新增模板。

基础资产统一采用能清楚辨认体型的简洁打底服装，款式、颜色与覆盖范围按角色设定，各视图一致；不默认加入剧情服装、伤口、泪痕、纹身、强烈情绪或装饰配件。已确定的固有特征按角色设定保留。裂变时以基础角色参考板锁定身份、体型和原排版，只改变明确指定的服装、妆造、表情或状态，并使其在各视图中一致；未经指定的特征保持原样。

## 1. 风格基调与CG渲染质感

* 核心原则：本提示词不预设固定3D画风、不强制固定渲染器、不固定写实程度。最终画面的整体艺术风格、CG渲染语言、材质表现、角色比例、光影逻辑、色彩倾向和完成度，必须继承已明确指定的风格参考或角色设定，不混用其他参考的画风。
* 参考图画风优先级：用户明确指定的3D/CG风格与风格参考是画风依据；角色身份图和服装图只承担各自职责，不因混入真人照片而覆盖已定3D风格。无风格参考时按角色设定确定3D表现。若参考图是写实CG，则生成写实CG；若参考图是半写实3D，则生成半写实3D；若参考图是卡通3D、手办感、潮玩感、黏土感、树脂感、二次元3D、游戏CG、影视CG、低多边形、风格化建模或其他特殊3D风格，则完整继承该风格。
* 质量下限：无论参考图属于哪种3D/CG风格，都必须保持商业级角色资产完成度，包括稳定角色结构、清晰面部识别、合理上半身比例、干净材质边缘、清楚服装结构、统一灯光环境和可用于后续角色一致性制作的资产展示效果。
* 角色皮肤：根据参考图风格决定皮肤表现方式。若参考图偏写实CG，则保留毛孔、肤色层次、次表面散射、微弱油脂高光、真实皮肤起伏和自然细节；若参考图偏卡通/手办/潮玩/二次元3D，则继承参考图中的简化皮肤、柔滑材质、塑料/树脂/黏土/动画化表面或风格化肤色处理。
* 头发材质：根据参考图风格决定头发表现方式。若参考图为写实CG，则使用真实 Groom Hair 毛发系统，发丝边缘清楚、层次自然；若参考图为风格化3D，则继承其发片结构、块面发束、雕塑感发丝、卡通高光、模型化头发处理或对应的风格化发型语言。
* 眼睛材质：根据参考图风格决定眼睛表现方式。若参考图为写实CG，则呈现真实角膜、虹膜纹理、泪膜高光、眼白厚度与眼睑包裹关系；若参考图为风格化3D，则继承其眼睛比例、虹膜画法、高光形状、玻璃感、玩具感或二次元化眼球表现。
* 服装材质：服装必须以3D/CG资产方式呈现，清楚展示版型、领口、肩部结构、胸前结构、腰腹结构、面料厚度、缝线、褶皱、垂坠、反射或粗糙度。材质表现必须服从参考图风格，不能被统一套成真人照片质感。
* 模型质量：必须保持高完成度3D角色半身资产标准，但不强制固定为AAA游戏、影视数字人、虚幻引擎、Octane、Arnold、V-Ray或超写实PBR风格。所有技术质感服务于指定的3D画风，不覆盖它。
* 成像要求：high-quality 3D character waist-up render, CG character bust asset, clean character model presentation, stable identity, coherent body proportion, coherent clothing material, commercial-grade 3D/CG finish, style inherited from reference images.

## 2. 背景与光影设定

纯白或近白无缝背景，柔和均匀的资产展示光线，必要的轻微接触阴影。保证头发、浅色衣物和身体轮廓可辨；各视图曝光、色温和材质响应一致。无复杂环境、无剧情化布光，不用强轮廓光或大片阴影遮住身份与结构。

## 3. 已定身份与半身体型

* 输入为已定正面肖像与已有头部四视图；没有独立头部四视图的路线可用已定肖像直接扩展，不要求尚不存在的图片。
* 正面肖像决定面部身份，头部四视图补充侧向结构与发型；两者冲突时先核对并修正，不借半身扩展重新设计脸。
* 角色设定补充尚未确定的肩宽、颈长、胸腔、腰腹与身体比例。服装参考只决定明确采用的服装，不提供人物身份和体型。
* 保持基础打底造型及已有视觉风格。裂变时按明确要求修改，不把半身图误当作完整全身依据。

## 4. 排版与构图标准

* 3:4竖版，单人正面waist-up半身图，完整保留头顶，下缘位于肚脐下方至胯骨上方；不能变成大腿以上的四分之三身照。
* 人物直立、正对镜头、自然中性表情；肩颈、胸腔、腰腹、上臂轮廓清楚，双臂自然下垂并略离躯干。
* 不靠夸张透视、动态姿势、遮挡或服装褶皱改变体型；与前序肖像保持同一身份、发型和打底造型。
* 干净白底，不添加文字、Logo、水印、剧情环境或额外人物。
