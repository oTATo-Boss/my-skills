# 任务目标：生成AAA写实CG角色视觉档案底图（全性别通用全身四视图版）
# 执行背景：基于多重参考图与下方“角色设定” 文本描述，生成一张商业级3D角色全身四视图基础设定图，用于角色一致性、换装及后续建模与动画的视觉参考，不包含实际绑定或三维模型数据。

## 本次阶段与参考职责

基础资产按“确定正面肖像 → 扩展头部角度 → 确定半身体型 → 扩展全身视角 → 拼接综合参考板”的信息顺序建立；只执行本模板对应阶段，不凭空要求尚未生成的下游图片。不同风格可在同一模板内补足角度，不强制新增模板。

基础资产统一采用能清楚辨认体型的简洁打底服装，款式、颜色与覆盖范围按角色设定，各视图一致；不默认加入剧情服装、伤口、泪痕、纹身、强烈情绪或装饰配件。已确定的固有特征按角色设定保留。裂变时以基础角色参考板锁定身份、体型和原排版，只改变明确指定的服装、妆造、表情或状态，并使其在各视图中一致；未经指定的特征保持原样。

头发采用高密度独立发丝级渲染，具有真实发根、发束层次、碎发、绒毛与透光效果，拒绝块状塑料头发。

### 渲染

自然曝光，真实镜头解析力；资产参考图中各必要视图、五官与服装均清晰，不用景深虚化或光学柔化掩盖细节。

## 2. 背景与光影设定

纯白或近白无缝背景，柔和均匀的资产展示光线，必要的轻微接触阴影。保证头发、浅色衣物和身体轮廓可辨；各视图曝光、色温和材质响应一致。无复杂环境、无剧情化布光，不用强轮廓光或大片阴影遮住身份与结构。

## 3. 身份、体型与全身扩展

* 输入为已定正面肖像、已有头部四视图与已定正面半身图；没有独立头部四视图的路线使用已定肖像和半身图，不强制增加模板。
* 正面肖像锁定面部身份，头部视图补充头部结构，半身图锁定肩颈、躯干、腰胯与基础穿着；下半身比例依据角色设定补全，不反向改变已定面部和体型。
* 各视图保持同一角色、同一身高、同一套服装、同一状态；只改变观察方向。单侧配件、伤口、图案等按角色自身左右对应，禁止镜像复制冒充另一侧。
* 服装与细节参考只承担指定职责，不继承参考模特的脸、身材、姿势或背景。

## 4. 排版与构图标准

本图是独立的全身四视图补充资产，不能替代含面部近景与半身信息的综合参考板。AAA综合参考板可直接使用这里的四个全身视图；其排布为2×2，输出9:16，视图顺序保持不变。
* 画幅比例：9:16竖屏。
* 构图布局：标准2×2四宫格 Character Turnaround Sheet，仅生成4个完整全身角色视图。
* 禁止生成肖像、半身、局部特写、材质特写、道具拆解、表情图或任何额外视图。
* 四个宫格尺寸完全一致，人物大小、头顶高度、脚底基线、身体比例和占画比例统一。

### 四宫格视图
1. 左上｜0°正面全身
   * 角色完全正对镜头，保持标准自然站姿。
   * 从头顶到脚底完整入画。
   * 清晰展示正面五官、身体比例、服装正面结构、配饰与鞋履。

2. 右上｜90°左侧全身
   * 角色相对于正面严格旋转90°。
   * 保持与正面完全相同的站姿、重心和肢体状态。
   * 清晰展示头部侧面、身体厚度、胸腰臀轮廓、服装侧面结构与鞋履轮廓。

3. 左下｜180°背面全身
   * 角色完全背对镜头。
   * 保持与其他视图完全相同的标准站姿。
   * 清晰展示后脑与发型背面、肩背结构、服装背面结构、腿部与鞋履背面。

4. 右下｜270°右侧全身
   * 角色从正面向另一方向严格旋转90°，形成与左侧视图对应的另一侧全身视图。
   * 保持完全相同的站姿、重心和身体比例。
   * 清晰展示另一侧身体轮廓、服装结构、配饰及左右不对称设计细节。

### 四视图一致性
* 四个视图必须理解为同一个3D角色资产围绕垂直轴旋转得到的标准Turnaround，而不是重新生成4个相似人物。
* 严格锁定同一头部模型、五官、头骨、发型、身体模型、身高、肩宽、胸腰臀比例、四肢长度、手脚大小、服装结构、配饰、材质和颜色。
* 角色全程保持相同站姿、表情、手臂位置、腿部状态和身体重心，仅观察方向发生变化。
* 若服装、发型或配饰存在左右不对称设计，必须在左侧视图、右侧视图、正面和背面中保持正确的空间对应关系，禁止镜像错误、左右互换或细节随机变化。
* 四个视图均必须从头顶至脚底完整入画，禁止裁切头发、手部、服装下摆、腿部、鞋履或外延配饰。

### 镜头与资产展示规范
* 采用标准角色资产展示视角，弱化透视畸变，接近正交投影视觉效果。
* 禁止广角、夸张透视、俯拍、仰拍、动态机位、景深虚化或电影化构图。
* 镜头高度、焦距逻辑、人物距离与画面尺度在四个宫格中完全一致。
* 纯白无缝背景，2×2等尺寸规则宫格，间距统一，排版极简、整洁、专业。
* 不添加文字、标题、参数、边框装饰、UI、Logo、水印或任何额外设计元素。
* 最终呈现为：9:16竖版 AAA 3D Character Turnaround Sheet，2×2四宫格，正面 / 左侧 / 背面 / 右侧，仅完整全身四视图。
