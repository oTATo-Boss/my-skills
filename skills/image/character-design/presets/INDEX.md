# 预设

预设是可复用的文字风格模块，与角色模式、构图模板和人物设计分开维护。只读取本次选用的文件；新增预设不增加角色模式或基础模板数量。

## 调用

1. 用户点名预设或明确选择其风格后，读取对应文件；按本次产物选择原有角色模板。未指定预设时，继续沿用原画风选型，不自动套用本列表首项。
2. 把预设文件中“风格提示词”的完整内容填入模板的风格字段，不能只写预设名称或缩写成“正常比例、轻度风格化”。本预设使用通用3D模板的 `{{3D/CG动画风格与视觉质感控制}}`；人物、服装、实际参考职责等其他字段按本次要求填写。有身份或产品实拍参考时，明确它们不覆盖所选预设的动画画风。
3. 同一角色的后续视图沿用相同预设及版本，保留已确认身份。五份模板仍分别决定肖像、头部四视、半身、全身三视、宫格的构图与画幅。
4. 用户明确要求优先于预设；年龄、性别、族裔、肤色、脸型、体型、发型、发色、服装和配饰属于角色设计。正常人体比例允许角色自身的合理差异，不按固定头身数重塑所有人。产品原样保留或产品写实材质按实际任务补充，不自动附加到所有角色。
5. 默认一次采用一个完整风格预设。跨模式或组合预设时先核对兼容性；通用3D预设不静默覆盖真人摄影或AAA固定写实目标。预设名称和内部管理标识不作为画面文字生成。

调用示例：“用正常人体比例3D动画预设，为下述角色生成通用3D正面肖像。”如用户只要求提示词，则只组装文字，不自动生图。

## 持续新增

每种风格新增一个小写英文短横线命名的 `.md` 文件，再在上表登记中文名称、唯一标识、适用模式与链接。新增内容至少包括：

- **名称与版本**：保留用户指定名称；独立记录预设版本，便于复用。
- **适用范围**：声明支持的模式/模板，以及它控制的建模、比例、皮肤、眼睛、头发材质、渲染等内容。
- **风格提示词**：一段可直接填入模板的完整文字，不依赖项目图片、临时路径或某个人物。
- **边界与来源**：记录用户授权的来源、实测范围和必要限制；首次提炼或改写不能冒充新一轮生图验证。

可复制现有文件的结构后替换风格内容；保留独立的人物与模板字段，不把某个示例的发型、服装、品牌产品、场景、固定年龄或性别写成所有人的要求。除非用户另有要求，预设只保存文字，不附确认图。更新主入口的预设导航及拥有索引；自研开发与本机安装同步遵循项目约定。
