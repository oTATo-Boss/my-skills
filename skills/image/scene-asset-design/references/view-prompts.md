# 机位推导与提示词模板

规划具体机位、编写提示词或修改方向图时读取。先确定空间事实和可见范围，再组织生成文本。

## 方向约定

以 X 向东、Y 向北、Z 向上，画面保持水平、不旋转相机横滚为例：

| 机位标注 | 摄影机所在侧 | 摄影机看向 | 画面左侧对应 | 画面右侧对应 | 四宫格位置 |
|---|---|---|---|---|---|
| 南侧机位 → 朝北 | 南 | 北 | 西 | 东 | 左上 |
| 西侧机位 → 朝东 | 西 | 东 | 北 | 南 | 右上 |
| 北侧机位 → 朝南 | 北 | 南 | 东 | 西 | 左下 |
| 东侧机位 → 朝西 | 东 | 西 | 南 | 北 | 右下 |

完整场景资产默认每个独立空间都覆盖上述四向，各自保留独立原图和提示词；只有用户明确另定视图数量时才可缩减。各空间共用同一项目北。四宫格按表中位置固定排版，图外标签同时写清机位侧与看向。建筑“北立面”描述立面朝向，与相机“朝北拍”含义不同，分别记录。

例如主光来自东侧窗：在“南侧 → 北”中，东侧光位于画面右方；在“北侧 → 南”中，位于画面左方。固定的是窗与世界光源，随相机变化的是画面表达。

对斜向、俯仰或环绕机位，依据摄影机位置、目标点和场景几何重新推导画面左右与遮挡，不直接套用正向表。四向按镜头的实际水平朝向归类，斜向属于补充机位，不能改标签后计入四向；主视、反打按各自实际朝向计数。优先调机位和焦段满足构图，保持固定物件的世界位置。

狭窄空间的侧向允许只呈现合理的局部墙面、门窗或陈设，不强求全景。保持目标正向和可成立的机位，不穿墙、扩大空间或移动固定物件；若仍不可实现，把对应方向记为缺口，不以斜向或另一空间的图替代。

## 参考绑定

按实际提交的图片顺序或文件标识写明职责：

- 结构图负责布局、数量、尺度、门窗与核心元素位置。
- 垂直俯视母版负责空间对应、材质分布、地面状态与全场照明。
- 已验收方向图负责可见立面、装饰、材质身份和成像连续性。
- 元素与氛围参考只继承指定内容。

每次复用辅助方向图都保留其场景版本和机位信息。前次生成的缺陷不能成为下一张图的设计依据。结构与视觉参考冲突时，先纠正参考或缩小其用途。

输入图片不能替代当前机位的完整文字描述；文字也不能冒充实际未提供的图片。没有图片时，移除对应绑定句，写明已知的完整空间与视觉约束，并在提示词外说明视觉验证状态。

## 平面与俯视的表达

平面与俯视按结构覆盖需要确定画幅，不强制 16:9。精确平面优先使用可核对的几何表达。向绘图或建模工具传递边界、坐标、尺寸、方向、门窗开口、元素 ID 与位置，之后检查图与记录。需要生成式草图时，标为设计示意并另外保留数值依据。

俯视生成文本可采用以下结构，将占位内容全部替换为项目事实：

```txt
参考绑定：[结构参考的实际编号或文件]确定场景边界、区域、门窗和核心元素位置；[相关材料]提供已选定的材质与光线信息。
画面：生成[画幅、用途与风格]的场景垂直俯视母版。相机位于场景正上方，光轴垂直向下，采用[正交或极弱透视]，完整呈现[场景范围]；图上方对应[项目北或指定方向]。
结构：[依次描述区域、墙体或地形、出入口、动线、关键元素的世界方位、数量和尺度]。[室内去顶观察方式及需要保留的可见结构]。
材料与环境：[材料分布、接缝、干湿、新旧、地面与空气状态]。
光线与影调：[时间、天气、固定光源的世界方位或位置、软硬、色温、阴影逻辑、亮暗层级与主辅色]，让关键空间与物件边界清楚可读。
成像：[项目要求的透视、材料反射、高光过渡、暗部细节与质感]。
```

## 单视角生成提示词

按“空间 × 方向”矩阵逐格输出完整独立文本；完整资产默认每空间四条，特定机位请求按用户指定范围。方向场景单图未明确另定时采用 16:9 横版；任何参考图的原始画幅不得覆盖交付画幅。按项目保留必要模块；字段是提醒，不要求冗长填空。参考绑定与正文放在同一个 txt 代码框，提示词中只保留实际控制信息。

```txt
参考绑定：[实际图片编号或文件]负责[结构职责]；[实际图片编号或文件]负责[材质与光线职责]；[有效方向图]是[机位侧→看向]的已验收视图，继承其中[可见细节]；[相关元素参考]仅提供[指定元素特征]。
画面与用途：[交付画幅，未明确另定时为16:9横版]，[场景类型、图像用途、目标风格]。
机位与构图：相机位于[所属独立空间内的确切或稳定相对位置]，高度[数值]，以统一项目北为准，朝向[明确世界方向与目标点]，[水平/俯仰角]，使用[焦段及口径基准或视场角]；[景别、构图重心、透视、景深]。
可见空间：前景为[对应元素、画面位置及遮挡]，中景为[主体、数量、尺度与相互距离]，远景为[可推导的墙面、建筑或环境]。[门窗、通道、地标与边界在本视角的位置关系]。
材质与状态：[实际可见的关键材料、粗糙度、反射、接缝、干湿、新旧与必要细节]。
光线与影调：[时间与天气]，[固定主光源]从[世界方位及本视角投影方位]照入；[环境光、实景光、阴影、反射和曝光层级]。色彩以[主辅色及冷暖关系]组织，[饱和度、黑位与高光处理]。
成像：[符合项目风格的光学表现、材料反射、自然细节与空间层次]。
```

在实际输出中完成以下处理：

1. 把占位符替换为已定义事实，删去不适用模块。
2. 确保所有需要的参考已真实可用，编号和顺序与提交一致。
3. 把固定世界位置转换为本视角的前中后景、画面左右与遮挡。
4. 只写会影响当前画面的元素；被遮挡的结构保留在场景记录中。
5. 合并重复的风格、材质与光线描述，优先用可见的具体事实表达质感。
6. 用户要求修改时，直接输出完整改好的提示词；正文描述新状态，变更原因与历史只记在场景档案。检查末尾排除项，删去正文已用正向描述表达的同义限制。
7. 核对每条提示词对应的空间与方向；完整资产所需四向全部覆盖，局部构图仍须满足该方向，不以斜向或重复主反图填补。

## 把写实标准落实到画面

写实场景用材料与施工逻辑说明细节，例如石板拼缝、潮湿区域的局部反光、木材方向性纹理、金属磨损或墙面接缝。光线说明来源、覆盖、软硬与遮挡；用明暗分区、冷暖层级、景深和空间纵深组织美术效果。

检查实际成图中的重复门窗、融化构件、漂移道具、反射不一致、错误阴影和破损细节。风格化项目保留其指定表现方式，继续检查世界内的几何、元素和光线一致性。

局部编辑时明确编辑目标、关联元素 ID、可改变区域与本次要呈现的正确结果；把其余有效场景作为继续继承的基准。编辑后复核整个画面，防止局部调整影响相关结构或照明。
