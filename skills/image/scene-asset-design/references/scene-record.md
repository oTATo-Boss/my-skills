# 场景记录与交付字段

在场景解析、锁定、续做或修改时读取。为一个场景维护一份当前记录；下面是字段提示，按项目保留有用内容，不要求每次填写空泛长表。

## 最小记录模板

### 项目与状态

| 字段 | 记录内容 |
|---|---|
| 场景 | 稳定 ID、名称、用途、故事功能 |
| 独立空间 | 本次范围内的空间 ID、名称与边界；逐空间列全，不用整体总览代替 |
| 当前版本 | 场景版本，例如 v01；机位局部修订可单独记 C01-r02 |
| 执行范围 | 设计 / 提示词 / 完整资产，目标交付清单 |
| 当前阶段 | 已完成阶段、下一阶段、实际阻碍 |
| 交付规格 | 风格、交付画幅、所需像素尺寸、每空间所需方向、总图数与用途；记录用户明确指定的数量例外 |
| 验收方式 | 用户指定审核点、已有执行授权、已发生的验收者与结论 |
| 基准文件 | 有效平面、俯视图、补充剖面、已验收方向图的路径或可用标识 |
| 设计假设 | 缺失事实、采用的推断、影响范围 |

完整场景资产默认每个独立空间交付朝东、朝南、朝西、朝北四张独立原图，总图数为独立空间数 × 4，例如 6 个空间为 24 张；只有用户明确另定视图数量时才可缩减。斜向或其他补充图另计，主视、反打按实际看向归入对应方向。

方向场景单图未明确另定时，交付画幅记录为 16:9 横版；任何参考图的原始画幅不得覆盖该规格。平面与俯视按结构覆盖需要确定画幅，不强制 16:9。

“已验收”必须有实际对象与检查结果。把方案、生成结果和用户确认分开记录；Agent 自检不写成用户批准。

### 参考职责

| 参考 ID / 文件 | 主要用途 | 继承内容 | 重新设计或不适用内容 | 对应区域 / 元素 |
|---|---|---|---|---|
| R01 | 结构 / 元素 / 光线 / 材质 / 质感 / 氛围 | 可操作的事实 | 与本场景无关或冲突的部分 | 稳定 ID |

一份参考可以有多个用途，但分别说明继承范围。只有相关、当前有效的参考才进入具体机位输入。

### 空间与元素

记录坐标原点、单位、方向、场景边界、区域、通行关系、相邻空间、门窗、表演区、摄影机可用区和高低差。真实北未知时使用项目北，所有独立空间共用该方向基准。

| ID | 元素与数量 | 位置或占地 | 尺寸与高度 | 朝向 | 材质与状态 | 可移动性 |
|---|---|---|---|---|---|---|
| E01 | 一个明确元素 | 坐标 / 所属墙面 / 相对锚点 | 长宽高；标明依据 | 世界朝向 | 可辨认特征 | 固定 / 随场次变化 |

门窗记录所在墙面、开口范围、窗台或门槛高度；必要时记录开启方向。楼梯与夹层记录上下标高及连通关系。相对描述应绑定稳定锚点，例如“北墙中部”，而非某张图的“左边”。

### 视觉锁定

| 类别 | 必要内容 |
|---|---|
| 环境 | 时间、季节、天气、湿度与温度感、风、地面、空气介质、远景环境 |
| 主光 | 光源类型、世界方向或位置、高度、软硬、色温、主要覆盖区 |
| 其他光 | 环境光、实景灯位置、反射光与负补光的合理来源 |
| 影调 | 主辅色、冷暖、亮暗重点、曝光层级、黑位、高光过渡与饱和度 |
| 材质 | 材料、粗糙度、反射、干湿、新旧、接缝、磨损或污渍分布 |
| 摄影 | 约定的焦段体系或传感器基准、透视、相机高度范围、景深与构图原则 |

把光源固定在场景中。区分光来自哪个方向和光传播的方向，例如“主光来自东侧窗，照向西侧”；阴影方向随遮挡与光源推导。镜头曝光可合理调整，光源位置变化应更新视觉版本。

### 机位表

| 空间 ID / 机位 ID / 修订 | 用途 | 位置与高度 | 看向 | 焦段或视场角 | 画幅与景别 | 可见元素与遮挡 | 依据版本 |
|---|---|---|---|---|---|---|---|
| S01 / C01-r01 | 主视图等 | 世界坐标或稳定相对位置 | 明确世界方向与目标点、俯仰 | 明确传感器基准或等效口径 | 项目要求 | 前中后景与关键 ID | 场景 v01 |

只给焦段无法独立确定视域；需要准确取景时说明传感器基准或视场角。只需要设计示意时可采用已声明的统一等效口径。机位标签同时包含所在侧与看向，例如“西侧机位 → 朝东”。狭窄空间的侧向可记录为局部构图；不可成立的方向记录缺口，不用穿墙机位或斜向图补数。

### 资产与验收表

| 资产 ID / 文件 | 类型 | 场景依据 / 机位修订 | 状态 | 验收者与实际结论 | 来源与复现信息 |
|---|---|---|---|---|---|
| A01 | 平面 / 俯视 / 方向图 / 拼板 / 提示词 | 对应版本 | 见下列状态 | 用户 / Agent；检查了什么 | 参考映射、工具与可取得参数 |

采用少量明确状态：

- **设计完成：**文字或几何方案已完成，相应图像尚未制作。
- **待验收：**实际产物已生成，需要检查。
- **已验收：**已查看并满足该阶段要求，记录验收者。
- **待更新：**依据发生变化，尚未重新核对或制作。

读取并记录实际输出的像素宽高，核对交付尺寸与宽高比；宽高比仅允许单像素取整误差，不匹配不得验收。不把提示词中写的分辨率当作已达到的参数。若做了放大或编辑，记录原图及处理后的版本。工具未提供的 seed、权重、参数等留空或省略。

### 空间 × 方向完整性矩阵

每个独立空间一行，四个正向分别占一格。每格记录或引用资产表中的独立原图文件、实际像素宽高、实际水平朝向、空间/元素/光线连续性检查、验收状态及验收者。

| 独立空间 | 朝北 | 朝东 | 朝南 | 朝西 |
|---|---|---|---|---|
| S01 / 空间名称 | 文件与检查记录 | 文件与检查记录 | 文件与检查记录 | 文件与检查记录 |

实际查看图片并对照结构基准后才判定方向和连续性；文件名、数量或拼板不能代替检查。所有必需格逐格通过，才可将完整资产标为完成；缺图、方向不符或检查未通过均记录具体缺口。只有用户明确缩减的格可标为“不在本次范围”，同时记录其要求依据。

## 版本与恢复规则

场景结构或视觉状态修改时递增场景版本，机位独立修改时递增该机位修订。资产记录始终指出实际依据；未受影响的旧文件可以复用，但记下已对当前版本复核。

把依赖关系记成简明字段或表：平面影响俯视和机位，视觉状态影响俯视及相关方向，机位提示词影响对应图片，单图变化影响拼板。按影响范围标记待更新，不为无关资产增加无效返工。

恢复时先核对当前需求、有效版本、文件是否可用、最早失效步骤。若某张原图缺失或无法查看，明确其可用性，不把文件名或旧文字描述当作完成验收的证据。

## 完整资产的交付组织

文件名至少包含场景、类型或机位、版本；例如 `scene01_C01_S-to-N_v01.png`。优先使用已有项目目录约定，未指定时采用易读的场景目录即可。

完整交付保留：

1. 当前场景记录及参考映射。
2. 有效平面图、必要剖面和垂直俯视母版。
3. 每个独立空间的四向独立、合格原图，或用户明确另定的方向范围。
4. 每个空间一张 2×2 四宫格，固定左上朝北、右上朝东、左下朝南、右下朝西；每格图外标清所属空间及“机位侧 → 看向”。用户明确缩减方向时按实际覆盖排版。
5. 每个机位完整提示词、可取得的生成信息与验收结论。

四宫格使用同一空间的四张已验收原图，保持统一顺序并保留各原图完整构图，不用拼板替代独立原图或掩盖矩阵缺格。标注、留白和排列由排版工具完成。按用户请求交付必要文件；用户仅要提示词时在聊天的 txt 代码框交付。
