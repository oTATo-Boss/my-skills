# 控件细节配方

先按问题选择 [surfaces.md](surfaces.md)、[animations.md](animations.md) 或 [performance.md](performance.md)。
嵌套圆角可从外圆角约等于内圆角加内边距开始，再按真实边界和裁切校准。图标做视觉对齐，不只依赖几何中心。
选择与项目材质匹配的边框或阴影。图片可用低透明边缘帮助区分背景，但不能把一种 outline 色值当作所有项目要求。
状态动画应可中断。图标交叉淡入淡出、轻微缩放和按钮按压反馈是可选做法；幅度、时长和弹性按尺寸与操作频率调整。
鼠标、键盘和触屏需要对应的焦点、悬停或触控反馈。扩大点击区域时避免与相邻控件重叠。
指定需要变化的 transition 属性；will-change 只有实际测量表明有帮助时加入，持续模糊需检查渲染成本。
相关状态用真实文字验证，避免加载、选中或图标替换造成布局跳动。评价与反馈格式由任务决定。
