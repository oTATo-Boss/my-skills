# 组件与交互精修

判断动效是否说明状态与空间关系。高频操作优先响应速度，展示动作可以更有节奏。
弹出层的 transform-origin 靠近触发点；进出支持中断，不从 scale(0) 让文字失真。
首次 tooltip 可有短延迟，同组连续访问可更快。拖拽保持 pointer capture，处理取消、边界阻尼和释放速度。
进出时长可不对称；新状态从当前位置开始，避免抢回初始状态造成跳变。
用语义块安排 stagger，不能让用户等待所有动画完成才能操作。颜色切换与几何运动分别处理。
检查真实组件的 open/close、连续触发、路由销毁、触屏与 reduced motion。
