# 对比度测量

测量最终前景与实际背景，考虑 alpha 合成、图片、渐变和玻璃面板。用可靠的对比度计算工具验证，不能用 OKLCH L 差值直接替代。

WCAG 2.x 的常用目标：普通文字 AA 为 4.5:1，足够大的文字 AA 为 3:1；大文字约为 24 CSS px，或约 18.67 CSS px 且加粗。相关非文本控件边界与图形按适用条件检查 3:1。AAA 的文字目标另行核对。

APCA 可作为补充的感知分析，结合具体字号、字重与对应查表；它的 Lc 值不等同于 WCAG 的对比度比例，也不能直接用来宣称 WCAG 合规。

优先调整文字或背景的明度，同时保留语义角色。色度、色相和色域变化也可能影响最终 RGB 与对比度，调整后重新计算。

深浅主题逐一检查；透明表面应有可预期的背景。色阶、状态色和叠加媒体必须在实际使用处测量。

文字对比度定义参见 [W3C Contrast Minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。
