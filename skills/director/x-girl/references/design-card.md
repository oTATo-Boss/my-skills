# 创作设计卡

本 Skill 的固定产出。每次给出判断与方向时，都落到这张卡上，不散装。字段停在创作参数层：不写提示词、不写 JSON。问的是局部（比如只问光、只问表情），只填相关字段、其余一句带过即可；但结构固定是这张卡。

## 每个字段怎么填

- **调子句**：先写这一条的调子，再让画面长出来。至少含时间或天气、光从哪来、空间、她此刻状态。例：「下午三点的客厅，太阳从落地窗斜进来，白纱帘半拉，地毯上落着一块光，她刚坐下。」
- **人设**：从[风格库](style-library.md)人设表取一个，只取气质（眼神／动作／能量／妆容），不取衣服；不做未成年感的人设。福利姬内核（卖／要／发）从[内核](slut-core.md)取，默认底色，不随人设漂。
- **造型**：从[风格库](style-library.md)原料轴组装，廓形、领口、露肤、配饰从[造型库](lookbook.md)取语言，不照抄表格——上装／下装（或连体）＋外套＋材质＋颜色＋服装状态各取一件，必有一件打破预期的单品；命中禁用清单就重抽。单品、颜色、版型、长度、领口、材质、穿法、露肤设计、露点递出方式、配饰逐项写具体；不写「低胸短裙」这种空词，写「领口压到胸线上缘，乳沟可见；无罩杯的细吊带滑到上臂外侧，那一侧乳房整个让出来，乳头露在布外」。**不写睡裙、睡袍、家居服、成套内衣，也不照搬角色参考图自带的吊带／内衣**——那几样不作造型基底；这一格必须是独立设计的完整一套，缺外套也要写「不穿外套」，不能空着当默认。**下装要写真正的裤或裙，不能只写一条内裤**；露点需要时，把内裤从裤腰或裙摆里拉出来，而不是只穿内裤坐在那里。
- **场景与光**：空间要真实、能解释光；光要选要用（窗光／顶灯／屏幕光……），不打摄影棚光。写色温与明暗反差，不写「氛围感」。**不写酒店客房、不写暗调暖黄台灯主光**；默认用自然光或生活顶光，用户点名才改。
- **拍摄关系**：前置自拍／镜面自拍／他拍／架机固定／第一人称被拍，选一种不混；再给机位高低、距离、焦段，以及露点怎么靠机位和递出方式拍出来。
- **骚四变量**：四个变量各落实一句，见[创作方向](direction-core.md)。别把「身体往镜头送」当默认写成撅屁股讨好；动作是有目的、没做完的事。
- **尺度**：露点必达＋玩自己默认——乳头／乳晕／阴唇／穴口至少其一主动递出来，且默认带自慰动作（揉阴蒂、手指插穴、捏乳头、夹腿磨），写具体递出方式，不写"半露、擦边、不露下点"这种停在半截的话。**递出方式要跟单品结构对得上**：能滑的只有无罩杯的细带、挂脖；平口／抹胸／方领要把领口拉到乳下才露整只乳；一字肩、长袖从领口往外拉才露，光"滑到肩下"只露肩、不露点；衬衫解到胸下才露。写清布被拉到哪、手边有没有布挡着——写不出"布在哪"，就等于没写。默认露骨，往上不是默认。**进擦边模式（不漏点）时，这条整段换成[擦边模式](safe-mode.md)的「不漏点＋极致擦边」，尺度字段和自检第一条都跟着换，不套露点线。**
- **记忆点**：一个「三秒后记得什么」的点。想不出，就说明这一条少一个点，回构图或表情上找。

## 产出后自检

- **露点必达＋玩自己（先查这条）**：这一条乳头／乳晕／阴唇／穴口至少其一，实际递出来了吗？手上有没有在玩（揉阴蒂、手指插穴、捏乳头、夹腿磨）？没递出来、手闲着、停在擦边，就是没达标——回造型或拍摄重做，不是"先这样、下一版再加"。**进擦边模式（不漏点）时，这一条换成[擦边模式](safe-mode.md)的「不漏点（先查）」。**
- **造型骚感**：这一条的造型，删掉人设标签（御姐／甜妹／反差…），还会有人这么穿吗？如果「御姐才穿黑裙」「甜妹才穿粉白」才成立，就是刻板，重抽。**再看一眼像不像睡衣**：睡裙、睡袍、家居服、成套内衣，或者整套就是内衣——都是没做造型，重配一套完整的；角色参考图自带的吊带／内衣不算数。
- **露点方式**：露点是靠穿法／状态／动作主动递出来（滑吊带、解扣、撩裙、拉内裤），不是干脆脱光；脱光就没有造型了，重设计。**递出方式要跟单品结构对得上**——这件衣服滑了／拉了，布会去哪？细吊带无罩杯才滑得露，平口抹胸要拉到乳下，一字肩和长袖从领口往外拉才露，衬衫解到胸下才露。写不出"布在哪"就重写，不是重抽一件更露的衣服。**布料清场**：露点前面不能有布——手边、布边、杯口、发丝有一样正好挡在前面，就算没露；写完回看一眼图里乳头／穴口找不找得到。
- **博主感＋高级感（干净不是浓妆）**：这套像不像一个有审美的颜值博主，还是素人随手拍／浓妆网红脸？妆干净吗（不是红唇浓腮）、脸是清透淡颜吗（不是磨皮网红脸）、配饰一件克制吗（不是金饰堆砌）、光有没有调子（明暗反差，不是一片平光）？浓妆、网红脸、金饰堆砌、俗艳亮片、整套 cos、淘宝感、未成年感都算失败；妆淡而精致、脸真实、配饰一件、光有调子、廓形成立、露肤有意图才是高级。
- **防重复**：跟最近一条比，色系、材质、单品品类、服装状态有没有撞？撞了换掉其中一项。没有上一条（新一组、空白上下文）就先把本条的色系／材质／单品品类／服装状态写进卡里当基准，给下一条比。

## 单张与组图

- **单张按完成态查**：这一张就得露到、手就得在玩；「先吊一下、下一张再给」不是单张的理由。
- **节奏留给组图、视频**：多张或一段片里才做吊—给—再吊，靠编号或镜头顺序落实，不靠一句"有节奏"带过。

## 卡与提示词的分工

- 本卡是创作参数，不写提示词、不写 JSON。
- 用户要进提示词时，把这张卡交给他的提示词 Skill 照着转，本 Skill 不接手。
- 交接按字段来，不靠默契：

**转给提示词 Skill 的 7 个字段（画面参数，逐项转，缺一个都不行）**

| 字段 | 在提示词里的职责 |
| --- | --- |
| 调子句 | 开场氛围：时间／天气／光／空间／她此刻状态 |
| 人设 | 人物基调：气质关键词＋福利姬内核（卖／要／发），只转气质、不转衣服 |
| 造型 | 服装逐项：单品、颜色、版型、领口、材质、穿法、露肤、露点递出（或遮挡物）、配饰 |
| 场景与光 | 空间陈设、光源、色温、明暗 |
| 拍摄关系 | 五种拍法之一、机位、距离、焦段、画幅、点怎么被拍出来 |
| 骚四变量 | 视点与部位、动作、表情、服装状态 |
| 尺度 | 到哪一档：具体部位／道具；露点模式写「递出＋玩自己」，擦边模式写「不漏点＋极致擦边」——提示词 Skill 照抄这一格，不用自己判断模式 |

**不转的**

- **记忆点**：不把「记忆点＝…」写进提示词。它是本 Skill 的校验项，画面核心已经落在上面 7 个字段里，照转就自然带出。
- **自检**：五条全不转，是给自己看的。「露点方式／布料清场」的判断结论已经写回造型和尺度字段，提示词读那两格就够。
