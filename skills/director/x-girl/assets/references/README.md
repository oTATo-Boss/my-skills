## 使用边界

- 来源为用户提供的两批图，原作者与拍摄设备未逐一核实；只从可见画面提炼关系，创作对象维持成年女性。
- 全部 465 条逐图八维标注。`evidence` 为 `not_visible` 表示该格画面里看不到，tags 留空。
- `mode` 按原尺寸逐张复核（`mode_review: full-size-inspection`）：四点有任何一处清晰可见记「露点」，被布料、贴纸、水印或手指完整遮住记「擦边」。带「存疑」的是半遮或分辨率不足以确认的。
- 文件名与 manifest 的 `title` 现已一致。
- P013 P040 P045 P064 P068 原图在 360px 以下：构图可用，细节不可据此推断。
- P029 是插画而非摄影；借配色与廓形，不借质感。
- 部分图为生成或重精修，皮肤与光偏平；判断"像真人自己拍的"时要连同这一点考虑。
- P 编号是本库检索号，不等于生成工具里的图1、图2。
