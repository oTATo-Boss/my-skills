# 妆容、发型与上镜效果

先决定观众会从多近看她，画面里最值得留下的是眼神、唇色、肤感，还是发型与肩颈的轮廓。沿人物自己的眉形、眼形、唇形和肤色设计浓淡。近距离可看清睫毛根部和腮红边缘，全身照更容易读到眉眼、唇与头发形成的色块。

| 部位 | 设计时的具体选择 | 放进画面如何判断 |
|---|---|---|
| 底妆与肤感 | 清透薄底适合保留雀斑和自然肤色；半哑面能让金属耳饰或亮唇成为重点。把光泽留在想强调的颧骨或唇峰。 | 看脸颊到颈肩的肤色与明暗是否连贯。直闪下若额头比双眼更抢眼，先判断是受光角度、油亮还是局部高光。窗边阴影里也应留有皮肤的层次。 |
| 眉眼与睫毛 | 柔和眉峰、细眼尾能保留清淡感；眉尾更利落、眼线上扬会把表情带向自信或俏皮。睫毛根部的清晰度和眼尾的拉长各有作用。 | 顺着她的视线看。低头时睫毛能形成轮廓，抬眼后要仍看得到瞳孔与眼神。近景里眼线、假睫毛和刘海叠成一团时，先决定最想留哪一层。 |
| 腮红与脸型 | 颜色靠面中显集中和亲近，扫向颧侧会延长脸部线条。选色时把肤色、唇色和靠脸的衣服一起看。 | 脸转向窗外时，受光侧与背光侧要仍像同一张脸。红招牌或粉色墙面的反光也可能改变脸色，看清现场再提改妆意见。 |
| 唇色与质地 | 水润唇能接住小高光，柔雾唇让形状更清楚。暖针织可试杏玫瑰或豆沙，冷灰造型也可让莓果唇成为唯一鲜色。 | 自然闭唇、说话、笑起来分别看。夜间亮唇与亮耳环同时跳出来时，按当次重点保留更能衬眼神的一处。 |
| 发型与碎发 | 松盘发显颈线，单侧别耳让出耳饰和领口，披发能柔化贴身衣服的直线。按脸形选分缝、刘海开口、两侧发量与头顶蓬松度。 | 看发尾停在领口哪一边，深发与深背景是否仍有分界。侧转时发丝可短暂扫过脸，下一刻让眼神显出来，这段变化本身就值得留。 |

**同一造型的日夜对照（设计示例）。** 奶白方领衫靠窗，眉睫纤细、玫瑰色薄唇和脸颊很浅的暖色，能把注意力留在视线与针织纹理之间。入夜仍穿这件衣服，朋友近距离拍她，耳侧收发让脸部轮廓干净，唇色可略深，让受直闪照亮的脸仍有气色。若两张的眼神都好，优先看哪张光线与妆面配合得好，再决定是否真的要改妆。

视频另看从正脸转到侧脸时，鼻翼和颧侧的高光怎样移动；说笑前后唇形是否自然；拨开头发后露出耳饰的那一刻值不值得停留。只看到单帧时，把判断限制在那一帧。
