# 穿搭偏好与具体款式

先想这套衣服穿在这个人身上，最想让人看见哪条线、哪种质地、哪一处穿法。把领型和深度、肩带宽度、腰位、衣摆落点、面料垂坠、配色和配饰连起来看。款式可以大胆，表情与整体造型仍要有存在感。

| 想突出的地方 | 可以怎样设计 | 看画面时注意 |
|---|---|---|
| 低胸与自然露沟 | 窄深 V 把视线带向中间，宽低方领同时展开锁骨与肩颈；细吊带让肩部更轻，较宽肩带能呼应方领的横线。 | 领口是否顺着真实胸型贴合？转身或微微前倾后，开口与衣料张力是否说得通？手机、头发、外搭会遮掉哪一侧？避免靠生硬暗线模拟体积。 |
| 露肩或露背 | 斜肩针织露一侧锁骨，另一侧保留衣料重量；露背上衣可用后侧角度让肩带与背部剪裁一起可见。 | 头发落在哪边，肩颈是否放松？若亮点在背后，把人物回看的眼神和背部结构放进同一画面。 |
| 露腰与腰臀曲线 | 短款贴身上衣配低腰裙，留出腰腹；高腰直筒短裙搭利落短外套，腰线由衣摆与裙腰的交界显出来。 | 坐下后衣摆、腰头和褶皱会移动。侧一点身可以显轮廓，肩胯扭转仍要符合她怎么站、怎么坐。 |
| 超短露腿 | 百褶迷你裙靠起褶位置和裙摆动势显轻盈；修身窄裙靠干净的边缘和腿线；热裤配略松上衣能留出清楚的上下比例。 | 保留可辨认的裙摆或裤脚。跨步、倚靠、屈膝都可显腿部形态；看近腿与远腿的透视是否自然。鞋口、袜口会改变小腿被分成几段的观感。 |
| 贴身与宽松的层次 | 罗纹针织有纹理也有弹性，垂软缎面会沿身体落下，短皮衣和挺括牛仔能在贴身内搭外撑出轮廓。 | 看高光、衣褶和身体朝向是否一致。上身与下装都紧时，可由领口、面料光泽或外搭建立层次。 |

配色先看靠脸的一圈。米白针织可以衬出玫瑰色唇，樱桃红上衣已经很醒目时，小耳钉就足以接住眼边的光。包带、项链、发尾都是构图中的线，试着顺着它们看一遍，判断它们把视线带回脸和穿搭，还是切碎了两者。

选鞋时同时看裙摆到鞋口之间的比例。来源项目明确偏好避免长靴，可优先考虑低口鞋、运动鞋、玛丽珍或短靴；人物或主题另有偏好时从其设定。十一种气质的不同组合见[风格灵感](styles.md)。
