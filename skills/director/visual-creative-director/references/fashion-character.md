# Fashion & Character｜人物、穿搭与魅力

## 服装先看廓形
一套能被记住的造型首先是完整轮廓与比例关系，再是局部装饰。

设计顺序：**人物气质 → 整体廓形 → 肩胸腰胯比例 → 领口和开口结构 → 面料与色彩 → 鞋/包/首饰 → 动态行为**。

每套服装优先给一个主要造型主张，例如斜向剪裁、硬挺微型裙摆、层叠低腰线或夸张外套肩线；其余部件围绕它形成衬托。要写清具体外观，包含穿着方式、结构边缘、面料表面、连接方式和配饰尺度。

## 让性感成为造型语言
- 用领口高度、肩颈暴露、腰线、裙长、包裹/悬垂比例来塑造身体轮廓；性感的程度遵循任务、角色和场景。
- 性感与高级可以同在：大胆的开口可以对应更克制的材质和精确裁剪；贴身结构可以配松弛的外层。
- 人物魅力来自主动性、自信、好奇、轻微玩笑或从容的动作，而非持续表演式摆姿势。
- 成人时尚人物可通过明确成年身份与成熟气质保持造型判断清晰。

## 韩系／社媒／时装三种语境
- **韩系**是一组可分化的视觉文化，不是单一衣服样式。先确定偏少女、辣妹、设计师、街头或编辑大片等子方向，再处理妆发、面料与环境。
- **社媒 Vlog**保留人物与空间的真实关系：衣服是人在使用的，镜子、包、耳机、咖啡等道具可以让动作自然发生。
- **时尚大片**允许更强的姿态、服装张力、布光与不寻常空间；但仍要保留服装的结构真实性。

## 人物的镜头吸引力
将表情设计为细微状态变化：注意到镜头、短暂移开目光、突然回头、忍住微笑、对自己着装满意。身体动作必须有重心与顺序：靠近镜头、整理肩带、提包转身等；设计动作产生的裙摆、头发、首饰运动。

同一人物跨场景的识别锚点：脸部特征、发型轮廓、妆容、服装结构、颜色和标志性配饰。不同光线和姿态可变化，身份与造型关系不漂移。

## 具体化示范
需求：“俏皮但有设计师感的城市辣妹”。

可形成造型：奶油白短款不对称骑士夹克，下摆短于腰链；蓝莓紫色细褶斜肩针织紧身上衣，肩部以一枚银色双环固定；深炭灰低腰气球型短裙，面料偏哑光；亮面酒红色方头短靴，细银色手链与小型漆皮肩包。视觉焦点是**斜肩轮廓、紫色与炭灰的色块反差、短外套和膨松裙摆形成的腰部空隙**。

示例表达的是“结构—色彩—比例—动态”的设计方法，并非以后都使用这套服装。
