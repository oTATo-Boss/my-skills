# 摄影设计卡

先写一句分享重点，再填整张图。每项都描述看得见的结果，近似距离和占幅只用于辅助理解。新建单张时，可复制 examples 中最近的完整 JSON 再替换本次内容。JSON 契约是 `摄影设计` 根键、版本 `1.0`，十项设计连同参考分工见[交接](../references/prompt-handoff.md)。

| 项目 | 必须决定 | 唱片店完整例子的决定 |
|---|---|---|
| 分享重点 | 当事人想分享、观众能看见的内容 | 找到喜欢的唱片，抬眼看朋友的轻快状态 |
| 摄影者位置 | 谁拍、站坐位置、相对头肩高度与左右方位 | 朋友在店内隔木柜站着，略高于她眼睛 |
| 距离与透视 | 人物哪一部分更近，近远尺度关系 | 约一臂到一步距离，脸与封套相近深度，货架在后 |
| 四边界 | 上下左右收到哪里，哪个边缘可以切 | 发顶少量空隙，下到上胸与柜上唱片边；左留手肘一部分，右切在封套外 |
| 人物与物件 | 头肩朝向、手部接触、视线和嘴部 | 左肘靠柜、手托颊，右手拿封套下角；头轻偏、看镜头、轻抬嘴角 |
| 空间层次 | 前、人物、后各承担什么 | 唱片格边在前，脸和封套在中，深色货架退后 |
| 光线 | 来源方向、亮到哪里、阴影在哪 | 入口侧光照近眼颊与封套，远侧发留暗 |
| 明暗颜色 | 第一眼如何读到重点 | 脸和橙封套对深货架，藏蓝领口在下方稳定颜色 |
| 成像质感 | 焦点、柔化、锐度、材料表面 | 双眼清楚，皮肤柔和，发束与纸面小亮点，货架稍松 |
| 成功条件 | 两三项真正决定成败的条件 | 隔柜近拍，眼神清楚，封套与脸同框 |

## 从模特到拍法的推导记录

记录“可见特征 → 本次选定的分享重点 → 妆造怎样配合 → 为什么用这个拍摄位置”。例如深直发能提供深色轮廓，搭配莓唇和橙封套后，选择近拍让唇色和纸面在小图中仍可辨。只观察到椭圆脸不能推出本人喜欢某种风格。

## 图号与职责

`参考分工`按实际上传顺序逐一写图号、负责、保留、调整。未上传的案例只用于构思，不写成模型见过的图1。每图可承担多项职责，冲突按用户明确的优先关系处理。新方案无图时留空数组，身份依据写本次原创设定或实际人物档案。
