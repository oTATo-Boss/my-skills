# V2 验证与覆盖

本目录记录真实已执行的验证。摄影设计、结构检查、调用模型行为与最终图像分别报告。默认继承模型不能冒充低能力模型，人工视觉判断不能冒充用户认可。

## 升级前证据

用户提交的六屏参考已做30张裁图、屏号和原截图哈希定位。六张旧片已逐张审看，见[失败对照](../references/failure-comparisons.md)。旧 JSON 固定正文与高位俯拍的冲突已通过读取实际模板和拼装代码核实。

writing-skills 独立基线测试在改动前运行，模型为默认继承，未生图。任务为 A 身份文字+唱片店、B 蓝袖俯拍迁移到书店、C 暖格窗暗调低头。现版 xhs-girl 已能形成具体设计，A选柜边半身，B高位坐垫，C暗调侧脸。不存在“旧版每次必失败”的证据。

基线原话包括 A“朋友站她左前方、接近眼高，从发顶收到胯下”、B“手机举至胸口以上，从高于坐姿头顶的位置向下倾斜”、C“远侧脸和衣料保持深色但仍有层次”。读取下游后发现 B 与 fixed.md 的“平视或轻微低机位为主”相竞争。C 低头没有被任何固定直视规则强制纠正，动态抓拍和自动测光只是与静态暗调的软张力。旧规则中还存在原创服装前禁后补的矛盾，新摄影入口独立使用摄影契约。

JSON 回归测试先运行失败，确认旧 CLI 不识别 `--photography`。实现后测试通过，覆盖关系模式、真实分辨率文字、字段缺失、类型、图号、纯 JSON、字面占位符和旧正文兼容。具体命令和最终结果在发布记录补充。

## 复核命令

从技能开发项目根运行 `python3 skills/director/xhs-girl/scripts/check_package.py`。安装副本从任意位置运行 `python3 /absolute/path/xhs-girl/scripts/check_package.py`，它按同一分类结构定位JSON Skill。JSON Skill 的回归命令为 `python3 -m unittest discover -s /absolute/path/json-prompt-system/tests -v`。
