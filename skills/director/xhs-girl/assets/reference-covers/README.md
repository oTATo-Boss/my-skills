## 来源与裁切

[manifest.json](manifest.json)是元数据维护源，保存源截图 SHA-256、屏号、原始尺寸、左上右下裁框和包内路径。新增批次还记录源文件名、batch、tags、partial；新截图均为 2000×1299，裁图不放大。旧批次保持原有记录结构，R04、R07、R10、R25、R27 等本就被页面边缘截断。原帖是否完整未知。

新增 `partial: true` 表示截图边缘截断或为避开播放控件而局部裁取；不能据此推测缺失的衣服与动作。R42 的小段内嵌文字、R93 的车内多图拼接、R30/R39/R84 等的贴纸属于原封面，不默认复制到单张成片。原截图外层浏览器导航、状态栏访问令牌、账号卡片及链接查询参数不进入资源包。

不根据截图搜索词推断人物年龄、身份或设备；本 Skill 的创作对象为成年女性。公开传播或另行分发原照须遵守原作者权利及相应用途条件。R 编号仅用于库内检索，生图时只有确实上传的图片才分配工具参考图号。
