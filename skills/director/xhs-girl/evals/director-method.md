# 导演方法行为检查

只读模拟选择与推理；打开所需参考，不生成图片，不改变用户已确认项。以下检查内部方法，不定义新的对外输出格式，也不替代真实成片验收。

| 请求 | 应出现的行为 | 应避免的行为 |
|---|---|---|
| 已确认人物和黑色长裤，设计同地点三张，地点未定，近期刚拍过唱片店 | 保持裤装。先从场景、背景、光影和质感索引找几组互补原图，比较空间支撑、人物受光和组图变化，再定地点与氛围并回填图号 | 先把唱片店定为地点，再用参考补道具和光色；只换店名；随机衣服覆盖锁定项 |
| 已确认继续在唱片店的试听角拍三张 | 用锁定的试听角筛参考，补足窗光、背景和不同机位；保留已确认的场地与造型 | 启动开放选景并擅自替换地点 |
| 冷蓝室内、近距离交流、不要咖啡馆 | 分别找受光、表情和空间证据，逐图说明取舍，统一一套主光；闭眼图不能自动当直视参考 | 整套照搬一个蓝光人物；为空场景添咖啡馆；拼入另一图的暖光 |
| 从一张图借表情，另一张借穿法，再找背景和质感 | 给每个入选来源限定维度、舍弃项和适配；人物身份独立；检查景别能否展示穿法 | 把身份图加单一整图照抄称为多图设计；把所有优点写成矛盾拼贴 |
| 用户明确只允许 R125，要求忠实复拍 | 尊重单图边界，保留用户身份与锁定造型，未知处不补造事实 | 为凑多图擅自加入别的来源或运行随机 |
| 用户明确“随机探索三种候选” | 可使用 plan_set.py；随后看图取舍、明确候选与最终方案的区别 | 把随机组合或类型卡顺序当成质量结论 |
| 检索库内不存在的特征 | 返回无命中，尝试相关可见特征或明确原创判断，保留未知 | 伪造命中；返回默认咖啡馆；把文件名当视觉证据 |
| 仅裁脸衣服图，却需要表情参考 | 表情不足标 not_visible，另找表情证据；局部只贡献可见穿法 | 编造微笑、视线、完整下装或鞋袜 |
| 一个来源侧光、另一个正面亮脸，欲借后者动作 | 选定整体照明，迁移动作后重算受光；统一背景与人物空间 | 同时保留相反主光、同一组随镜头旋转光源 |
| P02 取材时选了地毯侧坐图，初稿只写「室内镜自拍」，放进提交版后又重试了一次 | 记录原图可见的支撑与腿线、P02 改变的决定；发现初稿漏写时补齐；按实际提交版本逐字引用并绑定对应结果 | 仅列图号和姿态标签；用初稿、计划发送的句子或另一轮的 Prompt 作为提交证据 |
| P02 的实际 Prompt 写了斜向伸腿，照片里身体支撑成立但两腿仍折叠 | 记录部分兑现和可见偏差；提交原句清楚时把腿线偏差定位到实现 | 只因同样是侧坐就判全部兑现；原文不可得时断言属于生成错误 |

2026-11-17 的旧版基线显示：默认三张任务先运行抽签；只找参考时可以人工拆分多图用途；用户指定单图时没有必要强制多图。新版应纠正默认入口并明确贡献边界，同时保留用户明确单图／随机的例外。
