## 深化一个完整画面

检查一个方案的画面关系、取材落点和可拍性。

| 请求／压力 | 检查 |
|---|---|
| 台球厅新设计，时间紧，只要最终 Prompt | 直接深化一个画面。台面支撑、腰线、服装、机位和光色相互成立，八维依据对应同一份 Prompt，只附实际授权的身份图 |
| 三张全新照片，要求画面好看，参考库取材 | 一份企划统筹三张，各张有独立画面任务和不同身体／观看／空间关系，覆盖八维依据，分析库图按原授权边界处理 |
| 仅看脸部妆容、头肩自拍，只要 Prompt | 深化表情、肩线、发饰和光色，保持头肩裁切及真实前置观看关系 |
| 忠实复拍，正面站姿、机位、衣服和背景全部锁定，只换用户身份 | 按锁定关系复现，保留姿态和道具 |
| 只设计造型板，不生图 | 深化一套搭配的剪裁、材质、配饰和比例关系，按造型板阶段交付 |
| 成片有漂亮脸、露腰、对视和干净场景，但斜靠屈腿设计退成正坐并腿，已有生成授权 | 据实际画面判断中心收益是否丢失，指出首要差距并作针对性返修，不能只因技术合格、已耗成本而通过；无生图授权仅交诊断 |
| 原本简洁站姿已整体成立且用户认可，细小配饰或姿态差异未逐字实现 | 保留成功设计、说明局部边界并停止，不为新奇强制坐躺跪或无限生成 |

这些检查用于审核设计决策与交付边界。
