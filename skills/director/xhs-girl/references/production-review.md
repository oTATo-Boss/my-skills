# 生成、选片与返修

## 提交前

核对实际身份与上传图分工。每张只设两三项成功条件，再看以下关系能否一起成立。

- 摄影者位置与高度可达，近远透视与画幅相符，四边界留得下计划展示的部位。
- 手、肘、脚和身体有合理接触或支撑。画外身体只按可见部分需要补全。
- 发、帽、物件与手不会同时挡住需要展示的双眼、领口或剪裁。
- 光源方向能照到本张重点。最亮背景、招牌和硬线与头颈的位置经过选择。
- 深发与深衣可以有轮廓，哑光与亮面区别清楚，局部锐度与柔化相容。
- 一组的衣物、唱片、包、首饰和光线连续；新图确实增加观看信息。

用户指定 Flow 时按 flow-image Skill 使用现有登录态与任务恢复方式；用户指定1K则核实原图，无需默认上采样。未指定工具时遵守当前环境默认生图工具。提示词中的设备和分辨率描述不能冒充真实生成规格。

## 两种观看尺度

**信息流小图**可缩到约 240–360 像素宽，与匹配的参考并排看。指出第一眼落在哪里、还能读清什么，人物是否只是场景中的一条窄影。全身照不能只用头脚占高度证明人物足够大。背景更亮可以成立，但必须能解释人物怎样仍被看见。

**大图**检查同一身份、双眼与嘴部状态、物件和手的接触、衣服结构、支撑、毛绒/织物/纸面/金属表面，以及想要的焦点和暗部是否保留。肤色、柔化和颗粒按本张效果评价。

逐张记录“成功条件 → 实际看到的证据 → 通过/待修”。允许一处成功而整张暂不能做首图。工具 ok 或下载成功只证明文件到手。

## 针对性返修

| 看到的问题 | 优先检查与改动 | 验证变化 |
|---|---|---|
| 脸小、表情读不清 | 移近相机、缩小景别或把本图作为全身配图 | 小图是否看见目标眼神 |
| 透视不对 | 核对相机真实高度和距离，移动摄影者 | 头臂膝的近远关系是否改变 |
| 墙、招牌、窗框更抢眼 | 横移拍摄方向、减占幅、调整人物与背景的明暗/颜色 | 主体边缘和第一眼是否集中 |
| 阴影全灰、光线平 | 让人走到光边、改变脸向，保留暗部 | 近脸与远脸是否有选定区别 |
| 过于塑料或全图太锐 | 皮肤过渡柔，眼唇局部清楚，材料各有高光 | 身份、眼睫、布料能同时保留 |
| 手像摆件、身体僵 | 改支撑、重心、手接触和头肩角度 | 是否能直接看出受力与意图 |
| 多图近乎重复 | 改观看距离、展示部位或摄影关系 | 新图是否提供不同信息 |
| 与参考偏离 | 先比机位、裁切、透视、曝光，再比衣服细节 | 决定参考吸引力的关系是否回来了 |

每次选最影响成片的一两处修改，明确保留成功部分。结构错误与大方向偏离可重生成，局部问题可按实际工具能力编辑。连续修同一处无明显变化时，检查是否提示矛盾、参考冲突或模型无法实现，改用更清楚的摄影参考、简化动作或重新设计。保留已生成结果与诊断，按实际预算和工具状态决定下一次。

## 测试与证据

创作 Skill 验证分别记录调用模型、生成模型与工具、输入参考、完整提示词、运行次数、全部结果、尺寸和审片意见。相同输入比较新旧方案；留出未写进案例的任务测试迁移；只有身份的任务测试原创。可以固定种子时记录种子，不能固定时记录随机性。

评价身份、摄影关系、整体吸引力、首轮可用情况和返修次数。各项分开报告，人工选片标注评价者。不要把结构检查、一次好图或默认模型的表现报告成弱模型成功率。弱调用模型测试需要实际可指定的较弱模型，生图能力测试需要真实生成，缺项保留为待验证。

## 边界与透视的自检例子

“下缘收到大腿中段，同时让弯膝完整入画”只有膝实际抬到大腿范围时才相容。先明确膝在身体前方还是身侧，再决定下缘。若用头臂膝近远关系做重点，下缘应收在需要看见的膝下或腿的转折之外。书本并非书店的必需道具，手已绕头、另手需要撑地时，可让书留在背景。

“约一臂远的高位相机”和“膝比头更接近镜头”会改变原来的头近膝远。先定头、手、膝哪一个最近，再写摄影者站在哪里，最后选择近似焦距感。逐句读最终提示词，删去已经被新位置替代的旧要求。
