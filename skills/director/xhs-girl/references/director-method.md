# 导演判断与多图分工

本页规定内部创作方法。对外输出按[输出格式](output-format.md)，根据用户请求选择企划、Prompt 或成片交付。

## 1. 明确这次画面为什么值得拍

当前任务先达到主入口的美感目标：脸与妆造有吸引力，曲线与比例被拍漂亮，人物和环境的配色、明暗、材质互相衬托。在这个整张画面中确定主动被拍、镜头交流与手机自然感，再分析实现它的姿态、构图和光源。借鉴写真方法只改变分析和表达方式，不自动接管拍法、服装、背景与成像审美。用户明确在本次任务要求棚拍时才按棚拍设计；历史上另一 Skill 的题目不能替代当前任务。

先复用用户已经确认的人物、妆发、服装、地点、数量与拍法，区分锁定项和允许创作的部分。决定这次主要让观众看到什么：人物状态、服装轮廓、亲近距离、空间关系、特定光影，或它们之间有主次的组合。不同任务可以有不同中心，不统一从浓妆、甜酷或换地点开始。

先用参考解释整张图为何吸引人，再拆维度。例如蕾丝领口、发丝、耳饰和柔亮面部共同形成精致感；不能只保留“贴身上衣”而丢掉这些联系。构思至少明确本张美感中心、所选曲线如何显得漂亮、取景如何突出人物、背景如何衬托，内部用简短画面描述即可，不增加一套审批表。

把表达目标写成可以选图和验收的画面条件。比如“她主动展示腰臀线条，同时和观众对视”，要落实为真实镜头位置、眼睛的目标、肩胯错位与承重、腰侧空隙和服装边界，再安排可辨的现场背景。人物只是被朋友叫住、随手撩发或抬眼听话，尚未说明主动展示了什么。

## 2. 按维度寻找互补证据

读取[视觉索引](visual-index.md)，分别查妆造、场景、背景、表情、动作、构图、光影与质感的相关候选，再打开原图。先确定要找什么，不能先随机抽出衣服、店铺和动作，再给组合寻找理由。空结果应调整检索词或明确采用原创判断，不回退到默认地点。

常规原创设计从多张参考分维度取材；人物身份参考单独计算，不能把“身份图＋一张整图照抄”当成多维设计。选图数量由需要的互补证据决定，不设每个维度一张的配额。可由某张参考贡献连贯的妆造、服装、配饰与色彩关系，其他图补所需的轮廓、取景或环境；多图分工应保住整体吸引力。一个来源可以贡献多个相容维度，每个入选来源都必须有实际用途。

用户明确只允许一张参考并要求忠实复拍时，按该明确任务执行；不悄悄掺入其他方案。对来源不足的维度保留未知或作明确的原创设计。

## 3. 给每张图限定贡献范围

在内部给来源记录图号、值得保留的吸引关系、贡献与迁移方式；只对实际身份／锁定项／光源等冲突说明不继承内容。这是内部工作依据；完整企划将其中的贡献、舍弃与适配压缩成参考分工表，并展示入选图片。只要 Prompt 时仍做内部分析，对外直接交付 Prompt。

人物是谁由用户身份图或已确认角色设定决定。库内人物只提供被选定的妆造、表情、姿态等视觉证据，不默认贡献脸、身材或身份。R 编号不是工具上传序号；仅用于分析的库图不写成“图2”等生成输入；实际附图或导出时明确列为需附附件的图，按真实输入顺序另编序号，不声称待附图片已经上传。

本次模型输入单独决定。若造型、材质、妆感或光色的关键关系难以仅靠文字准确传达，使用可用的必要视觉参考，并明确它负责哪些内容、身份仍由用户原图保持；工具不支持或用户只允许身份图时，将观察写成具体视觉描述并说明边界。只做分析的图不冒称已上传；不把“多图分析”误写成“所有任务只传身份图”。

例如，一个冷蓝室内近照的候选组合可以是：

- R125 研究蓝色受光和人物／背景明暗关系，不继承白吊带、人物五官及原手势。
- R166 研究掌侧贴脸的位置与脸部遮挡，不继承短发、黑色字母上衣及原有光色。
- R143 研究灰枕与近距离支撑形成的背景层次，不另引入第二套光源。
- R156 研究灰白领口叠穿；只有服装允许设计时才使用，已确认服装优先。
- R192 研究笑脸、肩部倾向与镜头的交流，不继承车内、粉吊带或暖色环境。

这些图号只说明分工，不是默认参考套餐。实际使用仍需打开图片，选择本次真正需要的来源；主题不同就换参考。

## 4. 整合成一个可以拍出来的方案

多图取材先记录每张参考最值得保留的穿法、观看关系或环境关系，再整合。限制来源职责是区分贡献，不是要求每张都删掉一组特征。“舍弃”必须对应用户锁定冲突、现场资源／支撑不相容或未选择的来源内容；没有冲突可直接保留并解释迁移方式。低腰露腹、字母、饰品、街景、镜自拍与手机他拍不因“更原创”或“更时尚”被默认删除。为了构图简洁也不能把真实环境换成无缝灰棚。

多图取材完成后重新设计整体关系，不能拼贴所有优点：

- **光影：** 先让脸、发丝和所选轮廓得到好看的亮暗与色彩层次，再选定一套主照明关系和曝光系统。借某图的构图或服装不等于带入它的光源；换机位后重建脸、手、服装和环境的受光，光源不随镜头旋转。
- **妆造：** 服装剪裁、纹理、配饰、妆感和发丝组成连贯的视觉中心，不能只剩颜色加贴身款式。用户锁定项不被参考覆盖，裁脸与局部图不提供看不见的穿搭。
- **动作：** 以主动拍照为事件，先明确哪一两项曲线／比例怎样呈现才漂亮，再以肩颈舒展、腰胯连贯、臀腿转折与腿线延伸决定侧转、侧倾或重心变化。手臂、衣服与背景共同留出轮廓边界，表情与眼神主动回应真实镜头；支撑和持机关系成立。具体设计按[身材展示](silhouette-studies.md)。用户明确要无意识抓拍时，转为该事件所需状态。
- **空间：** 先选好看、衬衣服肤色、线条不干扰人物的拍摄位置，再让环境、机位与取景成立。日常手机感支持干净通透、布置精致或鲜明配色；旧墙、粗水泥、污迹与杂物不是默认真实感。丰富背景可通过拍摄方向、局部裁切、明暗和颜色建立主次，无需每处同样锐利。
- **质感：** 色彩、反差、锐度和皮肤反射服从同一成像方向。需要更换某来源的光色、材质或动作时，记录适配理由。

整合前比较备选方向；优先保留整体最有吸引力且符合用户目标的关系，再处理重复或冲突。近中景应让脸与目标轮廓清楚突出；头到鞋的完整取景、远距离交代场所和多物件背景都要有展示理由。人物占画面高度八九成，仍可能让脸和腰胯很小，不能只凭这个比例判断。

用户提供的头肩身份图，只能据可见部分锁定；不可见的身体比例保留未知，不推测原三围，不加入“保持原身材比例”。已确认体型、服装或完整身形参考优先；未锁定的妆造与所需体态按本次目标设计。没有依据的细节来自明确的原创判断，不伪称参考所见。

## 5. 组图与跨任务变化

同一组默认保持人物、确认的造型、地点、时间、主光和后期，差异由机位、观看距离、动作事件和信息展开产生。每张说明自己的展示任务；通过正面对视、侧身回看镜头、坐姿侧倾等不同主动姿态展开，不靠换地点制造差异。画外视线可以作为组内变化，默认组图应有明确对视镜头的画面。

跨任务参考已知的近期方案，比较场景、服装轮廓、观看关系、表情动作和光色；新鲜感服从美感，不能为换地点而选不衬人的环境。换店名而仍是同一套隔桌托腮暖窗光，不算新构思；咖啡馆、面包店或针织不是禁用项，但必须由本次目标和所选证据支持。没有历史记录时不声称已经避免所有重复。

用户要求“独立、全新测试”时重新构思，不沿用旧造型／地点作局部替换，也不默认交付前后对照；明确要求对照才保持相应变量。

抽签脚本只在用户明确要求随机、抽卡或候选探索时调用。它负责产生可评估的备选，不能替代看图、选图、分工和整合；未被选中的随机结果不进入方案。

## 6. 从方案反推提示词并验收

先确认整体吸引力、漂亮轮廓、突出人物的取景、衬人的光色与背景，再核对支撑和空间关系。提示词用可见视觉结果组织这些关系，必要时简写实现动作，不用冗长动作证明挤掉妆造和光色设计。完整企划用共用设定和分张设计展示结果，内部推理不逐项外显。每张实际 Prompt 自包含，写清本张真实输入职责与摄影关系；详细版、单张和仅 Prompt 按[输出格式](output-format.md)交付。

成片用本次实际选中的相关参考对照：每个借用维度是否兑现、整体是否协调、人物与锁定项是否保持。分别评价光影、背景、表情、妆造和构图，不能只凭衣服像或“比上次好”判定通过。原图仅用于诊断的重做，回到用户原始输入与选定参考重新构思；用户明确要求局部编辑时才按编辑任务处理。
