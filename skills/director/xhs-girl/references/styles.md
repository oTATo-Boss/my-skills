# 十一种可组合的风格灵感

沿用来源灵感库的十一种气质与穿搭方向。下表前两列提炼原有款式、配色和配饰，第三列是本指南新增的妆发或观看建议，供构思时试选。可以拆用一件单品、一个色彩关系，或从这十一种以外另想造型。

| 气质 | 款式、颜色与配饰 | 可怎样表现 |
|---|---|---|
| 韩系甜辣 | 低领吊带、露肩针织、超短百褶裙或热裤，粉白黑里点樱桃红，配银饰或蝴蝶结。 | 鲜色唇呼应红色小件，露一侧耳朵，把轻快的眼神和利落肩线一起留下。 |
| 甜酷少女 | 短皮衣搭蕾丝抹胸、不对称短裙或工装热裤；黑粉或酒红配金属链、铆钉。 | 柔软内搭和硬皮边缘形成差别。短发或高束发能显外套肩部结构，表情可以带一点戏谑。 |
| 多巴胺甜心 | 糖果色吊带、泡泡短裤、拼接迷你裙；柠檬黄、草绿或湖蓝配果冻饰品。 | 大面积鲜色选一个最值得看的，唇或腮红小面积呼应，保住眼神在亮背景前的存在感。 |
| 清冷猫系 | 一字肩针织、细肩带、修身短上衣或露背装；冷蓝黑白灰配银细链、窄框镜。 | 干净眉尾和薄唇色适合近看。轻抬眼、短暂停住，足以让克制的表情有变化。 |
| 度假甜辣 | 印花抹胸、绑带吊带、亚麻热裤或钩织短裙，珊瑚橘、海水蓝配贝壳饰或草编包。 | 肩颈见光，发丝受风有明确方向。画面里能读到涂色、织纹或风动其中一项就有看点。 |
| 都市 It Girl | 短西装、背心、皮质迷你裙、廓形夹克，灰黑或牛仔蓝配酒红、金属耳环或短靴。 | 利落发缝露出眉线，走到街角停下时，用建筑的直线衬肩线与停步的姿态。 |
| 运动甜辣 | 修身背心、短 Polo、百褶网球裙或运动热裤，白、草绿、亮蓝配长袜、发带或球鞋。 | 束发位置要能跟着真实活动起伏。接住东西后的呼吸或重心变化，能让造型显轻快。 |
| 法式甜欲 | 方领、蕾丝吊带、收腰碎花短裙或轻开衫；奶油白、复古红配珍珠、丝巾或玛丽珍。 | 露出锁骨与一侧耳饰，松开的发丝和柔雾玫瑰唇可呼应衣料的轻柔。 |
| 派对甜心 | 亮片吊带、金属抹胸、闪钻迷你裙或不规则露肩；亮银、香槟金配水钻耳饰、细带鞋。 | 看金属面、耳坠和眼妆谁先闪。转身时让其中一处先亮，使脸仍有轮廓。 |
| Clean Fit 微辣 | 白短 T、纯色修身背心、细肩带、高腰热裤或极简短裙，奶白燕麦配浅灰、银饰、小肩包。 | 看简单剪裁是否合身。保留皮肤的细微明暗，清楚的眉睫就能让纯色衣服旁的脸有神。 |
| 韩系软萌 | 短针织开衫、蕾丝吊带、花边泡泡袖、蓬蓬短裙，奶油黄、樱花粉、浅紫配珍珠发夹。 | 用柔软面料和浅色层次表达亲和。表情可以很放松，一下自然的侧目比连续摆出甜笑更鲜活。 |
