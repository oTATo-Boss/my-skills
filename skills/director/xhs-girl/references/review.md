# 审片与返修

先从[参考导航](reference-library.md)选择与任务相关的图，运行 `scripts/compare_sheet.py 成片 --refs R编号 ...` 做并排对照。随机六图只适合探索。先看信息流大小是否吸引注意，再打开原图检查身份、手指、服装结构和背景；对照图的容错加载不代表原文件完整。

## 参考兑现与整合

先回看本次各参考的贡献范围：借光影的检查受光与曝光，借表情的检查视线和嘴角，借背景的检查空间层次，借穿法的检查剪裁与轮廓；不因衣服相似就认定全部通过。不要求成片复制来源的身份、场景或未选择的维度。

再看整体：动作与情绪是否响应同一事件，手和身体是否有支撑，各来源是否统一到同一套空间、主光与后期，用户锁定项是否保留。留白背景可以成立；丰富环境也不要求所有细节同样锐利。跨任务比较已知方案的组合，不能靠店名不同掩盖相同托腮暖窗光。

## 逐项检查

| 项目 | 合格 | 偏差与修正 |
|---|---|---|
| 景别与展示重点 | 画幅真的容纳想展示的部位 | 近脸却要求长腿：改重点；穿搭只剩脸：改取景 |
| 机位与持机 | 俯仰角可见，自拍持机与手势相容 | 双手入镜仍写手持自拍：改由朋友拍或固定手机 |
| 造型 | 具体剪裁、配色、松紧有主次 | 简单不自动判失败；先看贴合与比例，不机械补三件饰品 |
| 妆发与身份 | 五官、肤色和用户锁定项保持 | 只有获准换造型时才改发色刘海；删除统一“大眼小脸、冷白皮”的句子 |
| 动作 | 支撑可信，视线和表情符合所选参考 | 无支撑跪姿、机械微笑、每张托腮：改一处支撑或动作关系 |
| 背景 | 选定的环境锚点和明暗层次成立，人物处于现场 | 背景与目标不符或空间虚假：修正相对位置与受光；有意留白不机械添道具 |
| 光色与后期 | post 整组时间、光源和调色一致 | 某张突然直闪或黄昏：统一整组照明，或改该张拍法 |
| 同一地点 | 墙、窗、桌椅等锚点及相对位置连贯 | 同款但不同房间：逐张复用环境描述，必要时使用已有现场参考 |
| 组内差异 | 同环境中机位、景别、姿态确有变化 | 只差一点远近：换兼容的类型；不要靠换地点制造变化 |
| 图像文件 | 完整解码，输出尺寸符合任务 | 截断或破损先恢复完整文件；只见局部不能评完整成片 |

## 返修

- 每轮改最差的一两项，保留已成立的造型、身份、地点和光线。
- 局部错误可编辑；整体构图失败可重生成，按用户任务和工具能力选择。
- 同一拍法反复不成立时换同场景兼容类型，保留用户锁定项。
- 参考图自身的贴纸、水印、嵌入文字或多格拼接不自动复制。

## 交付

按[输出格式](output-format.md)绑定 P 编号交付实际图片、实际完整 Prompt 与简短审片结论。写清已兑现的参考维度、仍有的问题及建议；有实际失败就记录无图或错误，不以占位图充当成片。明确区分“初审可用”“需调整”“生成失败”与用户已经给出的认可，不代用户确认最终采用。

整组可推荐首图：face 优先最有吸引力的近脸，outfit 优先服装或轮廓最清楚的一张，不固定所有任务以近景开头。只在实际看过成片后评价审美；方案阶段只写预期与检查重点，脚本及资源检查不表述为出图效果通过。用户只要图片或指定精简交付时服从该要求，必要问题仍如实说明。
