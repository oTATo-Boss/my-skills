# 审片与返修

先从[参考导航](reference-library.md)选择与任务相关的图，运行 `scripts/compare_sheet.py 成片 --refs R编号 ...` 做并排对照。随机六图只适合探索。先看信息流大小是否吸引注意，再打开原图检查身份、手指、服装结构和背景；对照图的容错加载不代表原文件完整。

## 先审美，再核对实现

先把成片与本次实际取材参考按信息流大小观看，再打开原尺寸。第一轮判断整张画面是否符合用户要的美感：

- **人物吸引力：** 脸、眼神、妆感、发丝、服装与饰品有清楚的中心和连贯关系，精致程度符合本次参考。
- **曲线与比例：** 肩颈舒展，所选腰胯或臀腿轮廓连贯，腿线与躯干比例协调，姿态看起来漂亮；抬手、推胯、露腰与对视只证明动作存在。
- **取景与环境：** 脸和目标轮廓足够醒目，裁切与观看距离服务展示；背景悦目、衬人，色彩与明暗有主次，没有无意抢画面的污迹、杂物、车挡或大块地面。
- **现场氛围：** 手机观看关系、人物受光与环境成立，允许精致妆容、修饰和调色；真实感没有把人物降成随便直出、把背景降成破旧记录照。

若这一轮美感未成立，即使镜头对视、动作支撑、字段和文件都正确，也记录为“需调整”。按最影响画面的原因改一两项；用户明确要求粗粝旧街、全身、无意识抓拍、背影或锁定衣服时按本次目标验收，不把默认偏好当成禁令。未要求时偏离成商业空棚同样属于方向失败。

**对照选定设计验收。** 回看设计时决定的画面中心：身体方向和空间线条是否形成预期关系，衣服边界是否让目标曲线漂亮，表情和视线是否配合，配色与受光是否共同衬人。把背景换成别处仍毫无影响、三张都退回扶物撩发、或原定侧靠屈腿变成正坐并腿，都需要判断是否失去了本次设计收益；不因画面整洁漂亮、动作存在或已经付出生成成本就直接判通过。

未兑现中心关系或仍与已知近期方案实质雷同时，明确哪一两项导致“合格但常规”，在已有生成／返修授权内调整最关键的姿态—空间—机位关系，再审结果。仅要方案／Prompt时在文字设计阶段解决；只要审阅时交付诊断，不自行生图。用户指定忠实复拍或简洁正面照时按该目标判断，不强行换姿势。整体已成立且剩余差异不影响目标时停止，说明局部限制，不无限刷图追求新奇。

第二轮再核对身份、参考兑现、手指与支撑、服装结构、空间光源和文件完整性。文字应用测试只能验证指令理解，包检查只能验证资源与结构；两者都不能证明真实出片漂亮或用户已经认可。

## 参考兑现与整合

用[逐图核对](director-method.md#逐图核对)里的 P 编号、设计决定和实际提交的 Prompt 原句，逐行对照同一次生成的图片。借光影的查受光与曝光，借表情的查视线与嘴角，借穿法的查剪裁与轮廓。每行给出「兑现／部分兑现／未兑现／无法判断」加具体画面证据。成片没有给出相应画幅、细节不可辨或未拿到图时，写明限制。成片细节可以独立检查；缺提交原文时保留偏差归因。

八图原创组图要覆盖本组八张实际主来源，参考过多可分几张对照图查看，不能只挑最像成片的一两张作比较。先看八个主维度是否各有独立可见的贡献，再暂时忽略换成用户人物造成的身份差异，将成片与每张来源比较：若服装、地点、背景、光影及整体气质仍主要沿用其中一张，其他来源只留下一点手势或道具，即使表格有八行也判为**来源主导失败，需重新选图和设计**。八维具体细节已兑现但整图吸引力仍弱，另记审美问题，不把流程齐全当作出片通过。

区分断在何处。来源的关系未进入设计，回选图或设计。设计关系明确但实际 Prompt 漏写，回转写。提交原句已写清、成片仍偏离，按实现偏差处理。单项兑现和整体美感分别判断。

再看整体：动作与情绪是否响应同一事件，手和身体是否有支撑，各来源是否统一到同一套空间、主光与后期，用户锁定项是否保留。留白背景可以成立；丰富环境也不要求所有细节同样锐利。跨任务比较已知方案的组合，不能靠店名不同掩盖相同托腮暖窗光。

## 逐项检查

| 项目 | 合格 | 偏差与修正 |
|---|---|---|
| 景别与展示重点 | 脸与目标轮廓足够醒目，容纳重点且裁切得当 | 为鞋和场所拉远导致腰胯很小：按重点收紧；明确全身任务保持完整；近脸不硬塞腿 |
| 机位与持机 | 俯仰角可见，自拍持机与手势相容 | 双手入镜仍写手持自拍：改由朋友拍或固定手机 |
| 造型 | 具体剪裁、配色、松紧有主次 | 简单不自动判失败；先看贴合与比例，不机械补三件饰品 |
| 妆发与身份 | 五官、肤色和用户锁定项保持 | 只有获准换造型时才改发色刘海；删除统一“大眼小脸、冷白皮”的句子 |
| 镜头意识与视线 | 默认明确知道被拍，露脸他拍／前置自拍与真实镜头对视，表情有主动交流 | 只写看朋友、眼神游离或整组回避镜头：锁定真实视线目标；用户明确另定视线时按该目标 |
| 主动造型与展示 | 一到两项曲线／比例实际拍得漂亮，轮廓连贯，衣服和光影配合 | 有推胯却显僵硬、坐姿挤短腰、手或发遮住弧线：改姿态／机位；不以加露肤或捏造未知身材代替 |
| 动作支撑 | 姿态主动且支撑可信，手、物件和持机关系相容 | 无支撑跪姿、强扭腰、机械微笑或每张同样推胯：保留展示目标，换相容的支撑与姿态 |
| 背景 | 环境真实且悦目，颜色材质衬人，边线与亮部不抢主体 | 只因新鲜而选粗糙环境、深景深拍满杂物：换位置／方向／取景与光色；明确旧街风格按其意图整合 |
| 光色与后期 | post 整组时间、光源和调色一致 | 某张突然直闪或黄昏：统一整组照明，或改该张拍法 |
| 同一地点 | 墙、窗、桌椅等锚点及相对位置连贯 | 同款但不同房间：逐张复用环境描述，必要时使用已有现场参考 |
| 组内差异 | 同环境中机位、景别、姿态确有变化 | 只差一点远近：换兼容的类型；不要靠换地点制造变化 |
| 图像文件 | 完整解码，输出尺寸符合任务 | 截断或破损先恢复完整文件；只见局部不能评完整成片 |

## 返修

- 每轮改最差的一两项，保留已成立的造型、身份、地点和光线。
- 局部错误可编辑；整体构图失败可重生成，按用户任务和工具能力选择。
- 同一拍法反复不成立时换同场景兼容类型，保留用户锁定项。
- 参考图自身的贴纸、水印、嵌入文字或多格拼接不自动复制。

## 交付

按[输出格式](output-format.md)绑定 P 编号交付实际图片、实际完整 Prompt 与简短审片结论。写清已兑现的参考维度、仍有的问题及建议；有实际失败就记录无图或错误，不以占位图充当成片。明确区分“初审可用”“需调整”“生成失败”与用户已经给出的认可，不代用户确认最终采用。

整组可推荐首图：face 优先最有吸引力的近脸，outfit 优先服装或轮廓最清楚的一张，不固定所有任务以近景开头。只在实际看过成片后评价审美；方案阶段只写预期与检查重点，脚本及资源检查不表述为出图效果通过。用户只要图片或指定精简交付时服从该要求，必要问题仍如实说明。
