# 视频表现与镜头节奏

先找片里最想回看的一刻。它可以是眼神的变化、肩膀转向朋友、衣摆或发梢随后才落下来。再看前一镜给了什么期待，后一镜是否接到了这一下。多镜头可以让人物与穿搭在不同距离下各有表现；连续一镜也可以靠动作、空间或两个人的关系撑起一段。按实际可看内容决定长短。

| 看哪一段 | 判断依据 |
|---|---|
| 开场 | 第一眼能读出人物状态、服装线条或她与拍摄者的关系吗？已经进入动作的半拍、安静但有指向的一眼、清晰有力的穿搭轮廓，都可能成为开场。 |
| 动作与表情 | 从动作发生前看至落稳。是她真的换了重心、注意力转移、衣料受力跟着变化，还是只有镜头绕着相同的表情走？肩颈、手、物件和视线应有连续的空间关系。 |
| 换镜与停留 | 新的一镜是否给出了上一个位置看不到的信息？从对方的近距离表情转到看见两人隔桌的位置，能补观看关系。让观众读清造型和神情再切，时长由内容决定。 |
| 声音与现场 | 实听一句招呼、衣料声、脚步、环境底声或音乐如何与动作相遇。呼唤可以带出抬眼，停顿能留下对视；用音乐推动变化时也要留出看清动作的时间。 |
| 全片 | 看同一个人的妆发、体态和造型在动作与光线中是否连贯，变化有没有缘由。分开评价服装、人物表现及镜头连接，再说明它们最终形成什么观看体验。 |

**审片示例。** 片里她拉好外套、正对镜头、再从另一个距离正对镜头。值得留的是拉好衣襟后眼神移回朋友的瞬间。若后两镜情绪和观看内容重复，可把时间留给她看见朋友点头后的反应。现场若没有这个反应，就建议缩短重复段，把新增动作列为另一种构思；审片时按已经看到的画面下判断。
