# 八维视觉索引

`assets/reference-covers/manifest.json` 是唯一逐图维护源。原来源、裁框、哈希、图号和图片保留；每条新增 `visual`，供检索候选与回看证据。索引不能代替打开图片，也不自动决定创作方案。场景、材质或姿态标签只帮助定位候选；命中不代表该环境好看、轮廓漂亮或适合这套人物穿搭。选图需回看整体吸引关系，再按导演方法取舍，不机械选择“旧墙／水泥”等词作为真实感。

| 字段 | 观察范围 | 不由该字段决定 |
|---|---|---|
| `styling` | 可见妆发、衣服剪裁、颜色、材质、饰品 | 人物身份、看不见的整套穿搭 |
| `scene` | 室内外、车内、可辨地点类型、天气或时间线索 | 未出现的店名、城市和拍摄地点 |
| `background` | 墙窗桌椅的位置、材质、大形、远近层次、留白与信息密度 | 为了丰富场景虚构的道具 |
| `expression` | 视线、眉眼、嘴角及嘴唇可见状态 | 人物性格或不可见的心理活动 |
| `pose` | 头肩与肩胯方向、重心、手的位置、身体支撑 | 被裁掉部分的姿态和身材 |
| `composition` | 景别、机位、占幅、裁切、遮挡、重心、原拼接形式 | 仅据画面猜测的精确焦距或设备 |
| `lighting` | 可见亮暗分布、阴影、高光、边缘光、光色和曝光关系 | 无证据的灯具型号、精确灯位 |
| `finish` | 色彩、反差、锐度、颗粒、柔化、压缩、皮肤纹理与反射 | 未核实的滤镜名和修图软件 |

每个维度保存 `tags`、`observation`、`evidence`。`observed` 表示直接可见，`inferred` 表示需保留限定的解释，`not_visible` 表示没有足够画面信息；最后一种的 tags 为空，并说明为何看不见。未知值不能为了填满索引而补写。

`transferable_mechanism` 是解释“画面为什么成立、什么关系值得迁移”的分析句，不冒充摄影事实。`limitations` 保存裁切、贴纸、光源或环境等具体边界。`review` 记录观察日期和被观察图片的 SHA-256；图片发生变化时必须复核，不能沿用旧观察。

旧 `tags` 保留兼容检索，但新流程按八个维度使用 `visual.facets`。不要从文件名、旧标题、推广文案或标签反推不存在的视觉信息。

## 检索方式

从 Skill 根目录运行：

```bash
python3 scripts/reference_index.py --vocabulary lighting
python3 scripts/reference_index.py --facet scene=室外 --limit 12
python3 scripts/reference_index.py --facet lighting=蓝 --limit 8
python3 scripts/reference_index.py --facet expression=直视 --limit 8
python3 scripts/reference_index.py --query '雪' --limit 8
python3 scripts/reference_index.py --show R125 R143 R166
```

这是对已审阅文字的关键词检索，不是图像向量搜索或审美评分。不同维度分别检索，才能找到“这张借光、另一张借表情”的候选；不要把所有条件绑在一次查询上，最后只剩一张整图可照抄。

- 同次 `--facet` 条件取交集；查询中的多个词都需有文字支持。`scene=室内`、`室外`、`车内`、`场景不明` 四种大类只按明确标签匹配，避免“不明室内外”的说明被当作已知室内。其他条件按标签和观察文字匹配，宽泛的“蓝”也可能找到蓝衣或蓝天，需按真实亮区进一步检索和看图取舍。没有结果时返回空，不自动补咖啡馆或其他默认地点。
- 没有填写意图时拒绝检索，不按最早图号给出一个默认方案。同分只按图号稳定排序，排序不是导演优先级。
- 用 `--vocabulary` 查看真实词汇，或改用相近的可见特征；不伪造检索命中。可按目标分别搜索场景、动作、表情和光影，再实际看图取舍。
- `--exclude R编号` 只排除具体候选，不证明构思具有新意。跨任务的重复仍需比较场景、妆造、观看关系、人物事件与光色组合。
- 选中的 R 编号只是库内来源；实际生图时按真实提交顺序另编图号。默认参考库用于 Agent 的视觉分析，不把候选全部上传模型。
