# 输出格式

先按用户这次要的交付物选择内容。形式借鉴写真 Skill 的系列母版、分张差异与完整 Prompt；创作仍按本包的小红书手机自然感、导演方法、多图贡献及用户锁定项完成。“拍摄企划”可由自拍、镜自拍或朋友拿手机拍完成；采用写真组织方法不等于采用商业影棚审美。

## 按请求交付

| 用户请求 | 对外内容 |
|---|---|
| 完整摄影企划，含提示词 | ①拍摄企划 → ②参考分工 → ③分张设计 → ④每张完整 Prompt |
| 只看方案、先看设计 | ①②③；停在方案层，不自动生成或追加整套 Prompt |
| 只要 Prompt | 给④的独立 Prompt，再附逐图简表，标明「未提交」 |
| 详细拆解版提示词 | ④采用下方八模块；每个 P 编号各自完整 |
| 单张设计 | 企划压成一小段，参考分工简洁呈现，分张设计为一张画面卡；需要 Prompt 时附一条完整 Prompt |
| 明确生图 | 按已有授权执行，交付简短企划、实际图片、实际完整 Prompt 和逐图兑现结果 |
| 只要造型方案或造型板 | 给造型目标、参考贡献、完整搭配及必要板式／Prompt；不硬填照片分镜与摄影机位 |

用户指定数量、结构、精简程度及联用 Skill 的完整格式优先。用户只要图片时精简文字；失败与必要问题仍如实说明。指定 json-prompt-system 时读取并使用它的完整格式，不把本页当作削减字段的理由。

## 视频交付

- **方案。** 一份短片企划给出关键一刻、拍摄关系、共同画面锚点，以及[镜头表](video.md#镜头表)。完整原创按下文交代八维参考落点，视频参考用实际看过的时间段，标明对应镜头。只问局部时，给对应段落或判断。
- **提示词。** 按目标模型的实际输入职责与能力，把镜头表转成能直接用的时序描述。图生视频从已确认首帧的构图和姿态写起，写清从哪里动、先后关系、表情／视线变化、谁带动镜头及哪里停住。多镜按工具能力用镜头区块或独立 Prompt；独立生成时随镜附上必要的身份、造型、空间和光线锚点。画幅、声音和时长按本次用途填写。
- **有成片。** 按镜号或时间点回查关键一刻、动作和视线有无动机、受光与造型是否连贯、运镜或切换是否带来需要的信息。依照本次实际提交文本核对参考贡献；文字方案或提示词按实际阶段记为待审片。

## ① 拍摄企划

用一个主题名和一小段说明整张画面为什么漂亮。写清人物怎样利用具体空间，姿态、衣服、机位与光色怎样共同突出人物／妆造中心和想拍好的曲线或比例，再交代拍法。共同设定只集中讲一次：

- **人物与锁定项：**身份、已确认妆发服装、地点及允许变化的部分。身份来自用户确认人物；默认明确知道被拍，主动对镜头展示，用户另定抓拍或视线时写明。
- **妆造与服装：**保留所选参考连贯的妆感、衣料、配饰与配色关系，写出出片细节；只改允许部分。头肩身份图不提供完整体型，不虚构原比例或三围。
- **场景与背景：**先说明这处环境如何好看、如何衬肤色与衣服，再按空间三层落入前景使用中物件、中景互动与背景真实纵深（公共空间可带自然招牌陈列与路人，私密空间保留居住痕迹）；用明暗与色温建立主次，丰富但不抢脸、不切断人物轮廓。
- **光影与成像：**面部、发丝与所选轮廓的漂亮亮暗，人物／背景曝光关系、配色与修饰程度，再说明光源方向和落点。观察到的成像与原创布光方案分别说明，不鉴定未知设备。
- **组内变化：**本组通过什么事件、距离、视线或机位展开；共同空间和主光保持。

只写对本次有作用的设定。单张省略组图变化。

## ② 参考分工

完整企划展示实际用到的参考，标图号并提供单图入口。用[逐图核对](director-method.md#逐图核对)写短表，放在独立 Prompt 之外。完整原创可从简表查到八个维度各自的证据与设计决定，缺口及原创补足如实标记。一行可涵盖一张图支撑的多个维度。同一维度若用多张图，写出各自贡献如何合成一个可执行的画面决定。人物身份图单列。

| 涉及维度＋参考／成片编号 | 实际看到 | 改变或保留的设计决定 | 最终 Prompt 原句 | 成片兑现证据 |
|---|---|---|---|---|
| 填真实 R 编号或文件名及对应 P 编号 | 具体可见关系 | 本张因此怎么拍 | 逐字摘录，结构化 Prompt 加字段路径 | 状态加可见细节 |

未写 Prompt 标「待写」，只交付 Prompt 标「未提交」并照录交付稿。实际生图引用最终提交文本，平台未提供原文时标明。尚未出图标「待审片」。用户明确只要纯 Prompt 或纯图片时，将简表留在本次任务记录，交付保持用户指定格式。

从 manifest 的真实 file 路径定位图片；对话中引用本地图片用当前环境可访问的绝对路径。展示不了时给可访问的单图链接并说明限制，不以别图替代。库内图片在方案中被展示，不代表已经提交给生图工具。

参考分工写实际发生的设计决定。原创补足的内容写在拍摄企划或分张设计里。将借用的可见关系写成可执行文字，默认生成时只附用户人物身份图。仅当用户明确指定额外生成参考时，才列其实际附件与贡献。

适配写在设计决定一栏。先写保留什么、怎样迁移；确有冲突再说明舍弃理由。原图里成立的露腰、低腰、字母和街头背景可以继续保留，不把它们自动换成高腰素色、机车外套与空棚。

表中写具体可见关系及迁移方法：例如借某图的肩手支撑，舍弃它的服装和光色，再在本次主光下重新处理受光。借用理由压在这几句话里，不展开全部内部推理。裁切、光源不明等影响选择的限制随对应参考写清。

## ③ 分张设计

完整组图用四列表：**编号｜画面任务（美感与展示重点）｜机位与构图｜主动姿态、表情与视线**。P 编号贯穿后续 Prompt 和成片；张数跟随用户任务，不设固定景别配额。“画面任务”写清已选的整体吸引关系，其他列落实空间、衣服与姿态怎样配合，不能只填地点和动作名称。

每张围绕一个主动展示的瞬间，写清哪一两项曲线／比例要怎样拍漂亮、姿态与服装如何形成好看的轮廓、支撑与持机关系、眼睛看向的真实目标，以及该张如何推进整组。可以标“推荐首图”，此时表示企划建议，实际首图在看到成片后再判断。同组发生不同受光结果时，说明新位置和朝向如何响应同一主光。

单张将表格压成一张画面卡或几句话。这里的共同设定可引用企划，下一部分的可执行 Prompt 必须完整展开。

## ④ 每张完整 Prompt

每个 P 编号下面放一条可独立复制的完整 Prompt，默认单独文本代码块、连续自然语言，不带内部分析标题。**不设机械字数上限**，以完整写透妆发、衣料受力、动作微表情、前景使用中生活物件、背景纵深层次、真实光学与参考职责为准（不因控短删减生活细节）。每条都重新写入必要的人物、妆造、场景、主光和质感；“同上”“保持前一张设置”不能代替这些内容。

完整Prompt突出人物、妆造、漂亮轮廓与衬人的光色环境；必要动作和支撑用可见关系简写，避免用大量左右手／承重证明替代美感设计。取景默认先考虑近中景，不为交代鞋或背景自动头到脚。

内容覆盖主入口要点，按以下顺序编译：实际输入职责 → 本张拍摄关系 → 身份与妆造 → 服装与展示重点 → 动作表情与支撑 → 空间层次 → 光影、曝光与质感 → 本张必要约束。具体衣料、镜头数值或设备没有依据时不补事实；需要原创设定时明确作为设计。

输入职责按真实提交方案编写：默认只有用户人物身份图作为图1，库内取材写成文字；用户明确指定的额外生成参考才按真实顺序编图2等。R 编号留在来源说明，未随 Prompt 提供的库图要把所借特征转为可执行描述；不写“照 R125 的光”让模型猜。作为导出材料尚待用户附图时，清楚标“需附：身份图”等真实附件要求，不声称已经上传。

用户要求**详细拆解版**时，每个编号改用以下八模块，内容仍逐条自包含：

1. 【参考职责】真实附件顺序与每张职责；纯文生图写人物设定。
2. 【人物与妆发】稳定身份锚点、可见妆发与锁定项。
3. 【服装】可见剪裁、颜色、材质、穿法与展示重点。
4. 【场景与道具】空间锚点、层次、具体所需物件及用途。
5. 【机位与构图】持机关系、景别、观看高度、占幅与裁切。
6. 【动作与表情】主动展示目标、肩胯／承重、支撑、手、真实视线目标和可见表情变化。
7. 【光线、曝光与质感】来源方向与落点、环境明暗、皮肤纹理和反射、色彩及清晰度层次。
8. 【必要约束】本张最需要避免的偏差，简短、具体，不堆通用禁词。

## 生图后的交付

按 P 编号绑定**实际图片＋实际使用的完整 Prompt＋逐图兑现结果＋简短审片结论**。结论先说明整体吸引力、曲线／比例和环境美感，再说明主要问题与建议，可用“初审可用／需调整／生成失败”；用户是否认可仅据真实反馈记录。无图片时写失败或无图及已知原因，不伪造占位成片、请求编号或通过项。整组推荐首图并说明一项具体理由。

只做方案或提示词时，结尾至多写本次预期与检查重点，不写成片质量状态。分析和交付格式不扩大生图、重试、归档或发送的授权。

## 示例：单张 Prompt 的完整写法

以下内容演示自包含写法，人物妆造与空间均为此例的设计设定；不是默认参考组合或默认拍摄模板。此例导出时需附一张人物身份图，无其他生成输入。

**P01｜窗边近距对视，妆造与腰胯共同突出**

```text
3:4竖幅，图1保持已确认成年女生的五官、脸型、原肤色和发型，其他造型按本次设计。朋友拿手机近距拍头顶至大腿中部，脸、领口与腰胯占画面主要部分，保留自然手机透视。她穿莓粉色细肩带修身短上衣，领口有窄蕾丝边和小蝴蝶结，搭深灰低腰牛仔裤、细银腰链和小银耳坠；眼尾轻扬，蜜桃色腮红提亮面中，玫瑰豆沙唇中间有水亮反光，脸侧几缕发丝与耳坠分开。她主动把腰胯斜向镜头，肩颈舒展、上身轻延展，衣摆到裤腰之间形成清楚柔和的腰侧弧线；一手扶身侧窗沿，另一手轻收发丝让手臂与腰线分开，脸转回手机，双眼直视镜头，唇轻分带一点玩味笑意。她位于整洁明亮的窗边转角，后方淡蓝墙面与通透玻璃衬粉色衣服，窗外只留一小片绿意，没有杂物横穿身体。侧前方天光柔亮脸与衣料，发丝有光泽，腰侧有浅浅明暗，人物比背景更醒目；保留适度皮肤修饰、衣料细节与真实环境层次，粉、灰、浅蓝的色彩清爽协调，远处随距离自然减弱。
```

该例只有真正需附的人物图被称为图1。多张 Prompt 时，每张都像这样展开本张必要设定，不能让后一条依赖前一条才能理解。
