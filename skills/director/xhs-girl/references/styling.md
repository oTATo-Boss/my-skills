# 造型设计

用于成年女性博主的穿搭、造型板和出片。目标是好看、有辨识度、能展示人物与身材；既包括甜辣、性感和强设计感，也包括简洁贴身、都市长裤、复古居家。身份、妆发及已确认衣服按用户设定保持，只重新设计获准改变的部分。

## 从部件到完整造型

未定造型时运行 `python3 scripts/plan_set.py --look-only [--direction 风格方向]`；出片用完整抽签。部件是候选，不是必须全部照抄的清单。检查剪裁、季节、场景、发型和风格是否相容，只替换冲突项并说明。

1. **定视觉中心。** 选主单品的领口、收腰、背部剪裁、材质或一件醒目饰品作中心。R31 的修身裙、R43 的背心短裤、R60 的绑带上衣长裤各有成立方式。
2. **定配色与材质。** 主色、辅色与少量点缀要有主次。材质对比是可选手段，纯针织或单色套装也能成立；不为了凑两种材质加无关外套。
3. **写具体剪裁。** 收省在哪里、领口多宽、绑带如何连接、蕾丝在哪里停止。简洁款也需描述贴合与长度，不必添加无意义装饰。
4. **定松紧与长度。** 贴身上衣可配宽松长裤，也可用修身连衣裙建立连续轮廓。根据想展示的部位选择腰线，不强制低腰、露脐或露腿。
5. **选饰品。** 通常一到三个不同功能类别，写清位置与大小；主衣服繁复时减少饰品，简洁服装可用一副耳环提亮。头饰、颈饰、发型不能互相挤占，不要求每张戴帽子。
6. **核对妆发与鞋袜。** 遵守人物锁定项。短发不同时写长发盘发；长裤下袜子可以不可见，鞋按裤脚和场合选。延续来源项目少用长靴的偏好，用户指定优先。

## 完成后检查

| 维度 | 看什么 |
|---|---|
| 主次 | 小图里能看出一个明确中心，其余细节在服务它 |
| 剪裁 | 具体到领口、肩线、腰线、裙摆或裤型；简洁不等于笼统 |
| 身材 | 至少一个适合本任务的展示重点；可以是贴合曲线或比例，无需两处露肤 |
| 搭配 | 色彩、材质、长度与季节相容；没有仅为凑数量出现的饰品或叠穿 |
| 人物 | 五官、肤色与用户锁定的发型妆容保持；未经允许不改变身份特征 |
| 出片适配 | 所选景别能看见设计重点；近脸不用写一大段鞋裤，穿搭图不能只剩脸 |

R45 的灰裙、R77 的居家坐姿、R85 的黑短T长裤说明：克制的衣服可以靠比例和姿态好看。R46 的金属饰品、R69 的粉色帽包说明：强配饰也需要明确主次。迁移这些关系，不把参考整套固定成新模板。

## 造型板与出片的衔接

xhs-girl 指导穿搭，character-design 组织角色多视图，这条使用路径有效。先确认造型板，再按[画面类型](shot-types.md)设计同地点照片；保持确认的妆发、服装和饰品，不重复抽出一套新衣服。造型板展示服装，成片再加入支撑、视线、表情和环境关系。
