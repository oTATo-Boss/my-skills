# 造型设计

用 xhs-girl 设计穿搭、出造型板或给抽签方案补细节时读这一页。目标是当代年轻成年女性博主的私服：韩系或美式甜辣，合体、性感、有设计感，敢露肤。人物参考只决定是谁；衣服、饰品和妆发按本页重新设计。

## 一套好看的造型由这六样组成

逐项写满，缺一项就会退回网店基础款。

1. **一件有设计感的主单品。** 隔着手机屏幕也看得出剪裁的那一件：斜肩或一字肩、绑带、镂空、蕾丝边、毛领、不对称下摆、交叉露背、只扣一颗的短开衫。用户提到的 Zara 是这种设计感的参照。
2. **至少两处露肤，其中一处是腿。** 下装默认超短：迷你裙、热裤、低腰短裙。上身再选一处：露腰、露肩、锁骨、露背或低领。冬天把外套敞开或滑到手肘，露肤照样成立。
3. **层次。** 外套和内搭是两种长度、两种材质：毛绒外套配蕾丝吊带，皮衣配紧身打底，羽绒服配小抹胸。内搭贴身，外层松。
4. **材质对比。** 同一身里至少两种质感：毛绒、皮革、蕾丝、罗纹针织、牛仔、缎面。全身一种面料会显得平。
5. **饰品三件以上。** 从耳饰、项链或 choker、腰链、手链戒指、包挂、发夹或帽子、美甲里选。近景能看清的饰品最值钱：大圈耳环、星星发夹、毛绒包挂。
6. **腿和鞋。** 腿袜、过膝袜、堆堆袜或光腿，配玛丽珍、乐福、厚底板鞋、短靴、复古跑鞋。来源项目偏好少用长靴。

配色：一个主色 + 一个点缀色 + 黑白灰。点缀色放在离脸近的地方（帽子、发夹、唇色）或主单品上。

## 同样是"性感"，年轻和不年轻的区别

| 想要的方向 | 写成这样 | 不要退回到 |
|---|---|---|
| 美式辣妹 | 黑色交叉绑带露背短上衣，低腰牛仔超短裙，银色腰链，大圈耳环，厚底短靴，高马尾 | 红色基础吊带 + 牛仔裙 + 白球鞋，没有饰品（网店基础款） |
| 韩系甜辣 | 粉色斜肩毛绒短毛衣露一侧肩，白色百褶迷你裙，粉色堆堆袜，星星发夹，毛绒包挂 | 纯色针织 + 灰色 A 字裙 + 低跟鞋（通勤 lookbook） |
| 冷感性感 | 黑色一字肩紧身短上衣露腰，低腰灰色包臀迷你裙，黑色腿袜，choker | 露肩小黑裙 + 黑丝 + 尖头高跟（熟女晚装） |
| 冬季性感 | 浅灰长毛绒短外套滑到手肘，黑色蕾丝抹胸，低腰牛仔热裤，灰色堆堆袜，玛丽珍 | 毛绒外套 + 吊带 + 长牛仔裤（露肤只剩锁骨，太保守） |

右列三种是模型自己设计时最常落入的默认款。写完造型后对照一下，像右列就重写主单品和下装。

## 出造型板时

造型板（角色多视图）只用来确认这套衣服。写造型提示词时同样列满上面六样，正面图选能看清主单品和露肤点的角度。之后出小红书照片，仍按 SKILL.md 的抽签和画面类型库走，不要按造型板的正面全身站姿去拍。
