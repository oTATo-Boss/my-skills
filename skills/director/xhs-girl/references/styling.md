# 造型设计

用 xhs-girl 设计穿搭、出造型板，或把抽签方案写成提示词时读这一页。目标是当代年轻成年女性博主的私服：合体、性感、有设计感，敢露肤。人物参考只决定是谁；衣服、饰品和妆发每次重新设计。

## 先抽签，再设计

每次都从 `python3 scripts/plan_set.py --look-only` 开始（出片时用不带 `--look-only` 的完整抽签）。抽签给出风格方向、主单品、下装、外层、腿和鞋、饰品、头饰、妆容、发型、美甲。用户指定的项直接替换，其余照抽签结果设计。

抽签结果是部件，你的工作是把它们写成一套具体的衣服：

1. **按风格方向的配色给每件定颜色。** 一个主色 + 一个点缀色 + 黑白灰。点缀色放在离脸近的地方（帽子、发夹、唇色）或主单品上。
2. **给主单品补一个细节。** 写清剪裁或装饰在哪：绑带交叉在背后、蕾丝只在领口一圈、镂空在腰侧。
3. **定材质，保证至少两种质感。** 毛绒、皮革、蕾丝、罗纹针织、牛仔、缎面、网纱里选，外层和内搭不要同一种。
4. **定长度关系。** 内搭贴身，外层松；上衣停在腰上方，下装低腰，中间露一段腰。
5. **饰品写到能在近景里看清的大小和位置。** 例如"左耳一只大圈银耳环""包带上挂一只粉色毛绒小熊"。

抽到的部件放在一起明显冲突时（比如芭蕾风配机车皮衣），只换掉冲突的那一件，换成同一类里最接近风格方向的选项。

## 写完对照一遍

一套合格的造型六样都有：

| 要素 | 合格标准 |
|---|---|
| 主单品 | 隔着手机屏幕看得出剪裁或装饰 |
| 露肤 | 至少两处，其中一处是腿 |
| 层次 | 外层和内搭两种长度、两种材质（夏天无外套时用叠穿或饰品补） |
| 材质 | 至少两种质感 |
| 饰品 | 三件以上，至少一件在脸附近 |
| 腿和鞋 | 袜子和鞋写明颜色和款式；来源项目偏好少用长靴 |

写完后读一遍：如果去掉颜色词，这套衣服还能被认出是这次抽签的结果，说明细节写够了。如果读起来像"一件纯色上衣 + 一条裙子 + 一双鞋"，回到第 2 步补细节。

## 出造型板时

造型板（角色多视图）只用来确认这套衣服。写完造型后，出小红书照片时运行完整抽签，在方案里把穿搭各项替换成这套造型，再按画面类型库写提示词。
