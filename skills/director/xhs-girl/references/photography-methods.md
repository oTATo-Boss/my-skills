# 摄影方法与成像选择

每次先选完整的观看关系，再把造型、姿势、现场和成像放进去。距离决定透视，焦距与裁切共同决定收到的范围。站在同一个位置换焦距或裁图，近远部位的比例关系基本保留；改变位置才会改变它们。以下距离是构思范围，原参考的精确设备未知。

## 镜头、位置和四边界

| 方法与图例 | 一起安排的条件 | 容易失去的东西与调整 |
|---|---|---|
| 高位近拍 [R03](photography-cases/r03.md)、[R22](photography-cases/r22.md) | 相机高于头顶，人物坐低或摄影者举高；抬眼，近臂绕脸；头近身远，地面成背景 | 近鼻和手可能变大。先改变左右距离与手的位置，找双眼清楚的一侧；想展示完整长腿应另留全身 |
| 隔桌近景 [R26](photography-cases/r26.md) | 摄影者坐对面，桌沿和杯盘进下缘，肘支撑托腮，脸与后景拉开 | 从远处站拍会失去桌前关系；先坐下来再确定裁切，允许杯盘被下边切去一部分 |
| 日光发色 [R11](photography-cases/r11.md) | 发顶与发束接光，衣色安静；近到能读发丝，手可以围脸 | 直顶光眼窝太黑时轻转头或改变拍摄方向，保留光带；过度保护所有高光会使发色变灰 |
| 平视半身 [R21](photography-cases/r21.md) | 镜头和眼睛接近，脸与物件同深度，肩腰轻错位，浅墙衬深发 | 用近肩、饰物或手创造明确关系；端正也可成立，眼神与物件需有吸引力 |
| 低至腰高全身（原创方法） | 退到脚尖可留落点，身体横向有展开，地平线避开脸；支点和腿线完整 | 靠近脚的超广角会放大鞋；先退开、调相机高度，再考虑裁切，竖线是否倾倒按画面决定 |
| 暗调侧脸 [R08](photography-cases/r08.md) | 明亮窗格在后，黑衣和发在前，颈与近脸有光；低头弯肘形成空隙 | 全部提亮会失去深浅层次。先让一小处脸接光，其他部位允许暗 |
| 镜前穿搭 [R15](photography-cases/r15.md) | 镜子、可见手机、持机手和遮挡一致，角度让出衣服结构 | 图号锁脸时仍按镜面关系生成，反射前后与左右需在成片复核 |
| 前置自拍/近脸 [R06](photography-cases/r06.md)、[R17](photography-cases/r17.md) | 持机在可达位置，脸、手和发占主要面积，适度歪头或旋转 | 旋转画面不能替代靠近。只有脸时检查可见关系，支撑和腿可在画外 |

焦距只在有用途时写近似等效范围。例如 24–28mm 感的近距俯拍、35–50mm 感的半身、退开后收窄视野的全身。脸落到超广角画面边缘时更易拉伸；眼睛和嘴附近尽量留在畸变较小区域。实际工具按可执行参数操作，提示中的“感”不等于可读取的相机 EXIF。

[R14](photography-cases/r14.md)提供栏杆支撑和旅行空间参考，但其承重脚在截图外，不能用它验证完整全身的鞋尖落点。

四边界逐边决定。上缘留多少发顶，下缘是否切过衣摆、胯或膝，左右是否保留手肘与物件。关节裁切可能打断姿势，具体看轮廓能否读清；有意局部构图可保留清楚的切口。负空间可以给目光、风、招牌或天空，说明其用途。

## 前后景与观看顺序

前景可用杯盘、柜上唱片、手、袖或栏杆。它应交代摄影者的位置、提供近大远小或把视线带向人物。背景选与头发、衣缘有区别的局部颜色，再看它的窗框、字和灯是否穿过头颈。浅背景并非必然失败，深背景也不会自动高级。

对焦和清晰度有层级。人物双眼或当次重点较清楚，后景可以略松、明显虚化或仍保留细节，由现场和摄影效果决定。需要环境时用位置、尺度和色块降低竞争，不能仅靠一句“背景虚化”。头肩人像的背景字可只留下形状，全身旅行照则可能需要可辨场景。

## 光线与曝光

| 光线方法 | 先写可见结果 | 处理方式 |
|---|---|---|
| 窗口/门口侧柔光 | 近眼、颊和衣褶受光，远发或远脸稍暗，眼里一处小反光 | 让人靠近光边，转脸与相机一起试；柔和仍需要方向 |
| 强日光 | 发束、肩、纸袋有明确亮面，鼻下/发下阴影有边界 | 选择光落在展示重点的一刻；脸过暗时转头或补反光，而非全图均匀抬亮 |
| 夜街正面补光/直闪效果 | 脸比街亮，鼻颊下有短阴影，皮革和首饰有小硬亮点，招牌保色 | 人物与背景留距离，按背景所需曝光保住灯牌，再决定人物亮度 |
| 逆光/暮色 | 背景天空保色，头发边缘亮，脸依然可辨 | 按现场选补光或反射，让人物与天空各有可读信息；想剪影时另定成功条件 |
| 暖窗暗调 | 亮格窗、暗衣发，侧脸/颈线留一条亮 | 允许暗部和局部高光失细节，控制脸旁亮块，不把所有阴影恢复成灰 |
| 开阔阴天 | 皮肤柔、影边软，颜色与轮廓承担主体区分 | 可用深帽浅脸、深衣浅墙、物件色，按需要增加一点侧向反射 |

“人物最亮”并非统一要求。[R26](photography-cases/r26.md)的秋叶更亮，脸仍被帽沿、发与袖集中。[R08](photography-cases/r08.md)的窗格亮于脸，姿态靠轮廓成立。必须写清本张的观看顺序怎样由明暗、尺度、颜色共同得到。

## 质感与局部处理

| 表面或成像 | 可见描述 | 应核对 |
|---|---|---|
| 皮肤柔化 | 颊部过渡柔，眉睫、鼻翼与唇线保留，肤色有细微起伏 | 面孔是否仍像身份参考，局部是否被糊成同一色块 |
| 发丝 | 深发有成束深浅，受光侧有细亮边，散发数量适中 | 方向与风、身体动作一致，发后背景能读出边缘 |
| 针织/毛绒 | 针织组织沿身体走，绒边软且有短细丝 | 亮部不成为整块白，接触位置有压痕或褶皱 |
| 皮革/金属 | 皮革沿弯曲面有窄亮带，金属有小而较硬的反光 | 不把哑光布也画成镜面，眼睛不被饰物完全抢走 |
| 纸面/玻璃 | 纸有折面和局部反光，透明杯有边和透射 | 封套图案可读，杯子不会像不透明实心块 |
| 锐度/颗粒 | 眼唇局部清楚，背景细节较弱，暗部细小颗粒 | 缩略图仍看得出主次；1K 无需靠毛孔支撑吸引力 |
| 动态 | 眼睛和关键手势可辨，发尾或衣缘轻微运动 | 真正的运动方向与支撑成立，静态摆拍可以完全清楚 |

精修、直出、直闪、胶片感都要落实到这些可见处理。选择与画面一致的一组处理，避免让所有区域同时极锐、极软或同亮。实际分辨率由工具文件证明，手机型号或“原生4K”不能替代它。
