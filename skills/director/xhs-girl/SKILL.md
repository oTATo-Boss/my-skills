# xhs-girl

目标画面是用户小红书点赞流里的颜值、氛围照。先打开[总览图](assets/reference-covers/contact-sheet.jpg)看一眼，它就是验收标准：近景为主，妆造和头饰很满，表情和手势贴着脸，道具举到脸旁，有明确的调色和精修。

画成"人站在店门口，平视一两米外拍全身，淡妆直发，礼貌微笑，自然光直出"的，是网店 lookbook，不合格。

## 流程

1. **定模式。** 默认颜值氛围，`--focus face`。用户要看穿搭、身材或全身时用 `--focus outfit`，并读[身材展示与穿法](references/silhouette-studies.md)。一篇笔记的组图用默认 `--mode post`（共用妆发和衣服）；互不相关的多张用 `--mode mixed`。
2. **抽签。** 在本目录运行 `python3 scripts/plan_set.py --count 张数 [--focus …] [--mode …]`。用户指定了画面类型或地点时加 `--type 类型名`、`--scene 地点`；指定了人物、单品或风格时，直接替换方案里的对应项。其余项照抽签结果用，这一步保证每次的衣服、场景和画面类型都不同。
3. **写提示词。** 每张查[画面类型库](references/shot-types.md)里对应的卡片，按下方模板写。
4. **出图。** 用 flow-image，比例 3:4。身份参考只上传面部图；outfit 模式再加一张基础身形图。
5. **审片。** 运行 `python3 scripts/compare_sheet.py 成片1 成片2 …`，把成片和真实样本缩成同样大小并排看，按[审片与返修](references/review.md)逐项判断，返修最差的一两处。

只要构思或只要提示词时，停在第 3 步交付。

## 提示词模板

每张一段，200–350 字，按以下顺序写，每句都是画面里看得见的东西：

1. **画面类型句。** "一张小红书爆款〈类型〉照片，3:4 竖图"，接类型卡里的机位景别句。
2. **身份句。** 有参考图时固定写："图1是人物身份参考：只保留她的五官、脸型和肤色；妆容、发色、刘海和衣服按下文改变；画面里只有她一个人，不复制参考图的白底和排版。"
3. **妆发。** 抽签的妆容、发型、头饰、美甲，逐项写部位和颜色。抽到的妆容没写腮红时补一句"面中淡粉腮红"，小图里脸才有气色。
4. **穿搭。** 一句话写清款式、颜色和露出的部位。outfit 模式再加一句体态，比如"身材纤细，胸型饱满，腰细腿长"。
5. **动作。** 表情 + 手势或道具，写清手或道具在脸的哪一侧、多近。
6. **场景。** 地点 + 一处能看出时间或季节的细节。
7. **质感。** 固定开头"韩系网红精修图，皮肤白皙通透、柔焦磨皮、大眼小脸、五官精致"，接抽签的后期风格。

人物档案里的气质形容词、身高三围不要贴进提示词，它们会把画面推回"端正的模特照"。距离、角度和占幅用"贴得很近""脸占满画面大半"这类视觉说法写，不写厘米和度数。

## 完整例子

> 一张小红书爆款怼脸自拍，3:4 竖图。手机前置镜头贴得很近、略高于眼睛，脸占满画面大半，画面微微歪斜，头顶被上边切掉一点。图1是人物身份参考：只保留她的五官、脸型和肤色；妆容、发色、刘海和衣服按下文改变；画面里只有她一个人，不复制参考图的白底和排版。妆发：面中大面积粉色腮红，亮片卧蚕，浅棕美瞳，水光嘟嘟唇；奶茶棕空气刘海，大波浪卷发，戴一顶猫耳毛线帽；裸粉猫眼长甲。穿搭：敞开的白色短款羽绒服，里面是黑色小吊带，露出锁骨。动作：歪头嘟嘴看镜头，一只手比耶贴在脸颊旁。场景：冬天傍晚的便利店门口，身后货架的灯光虚成暖色光斑。质感：韩系网红精修图，皮肤白皙通透、柔焦磨皮、大眼小脸、五官精致，冷白皮低对比，整体偏粉白干净。

## 与 json-prompt-system 联用

用户明确要求结合 json-prompt-system 时，按它自己的模式填动作卡，把抽签方案和类型卡的内容写进对应字段，用它原有的 `compose.py` 拼装，不改动那个 Skill。它的固定正文规定了"原相机直出、无滤镜、不磨皮"，会削弱精修和调色效果；交付时把这一点告诉用户。用户没有要求时，用本 Skill 的模板。
