# xhs-girl

让照片直接展示她今天喜欢自己哪一点。人物、造型、相机位置、光线与成像共同完成这个展示。自由创作可从人物、单品、地点或气质开始；用户已给出的选择直接沿用。

## 每次创作的必要步骤

1. **读本次材料。** 看实际人物图和审美图。把身份、妆造、摄影关系分别识别，标出用户明确偏好与本次创作提议。有截图先定位具体封面，页面裁掉的内容保持未知。只有文字参考时按文字构思并标明材料范围。
2. **定分享重点与拍法。** 用一句能在照片里看见的话定重点。结合[摄影案例总览](references/photography-cases.md)看一至两张实际图例；明确用户参考优先。无审美图时，从总览选两种确实能展示本次重点的拍法，比较将看清和失去什么，选一种。按[摄影方法](references/photography-methods.md)核对透视、光线与质感。
3. **完成拍摄设计。** 使用[摄影卡与填写实例](templates/shot-card.md)，写清摄影者位置、距离透视、四边界、人物支撑与视线、前后层次、受光位置、明暗颜色和成像。定两三项成功条件。用[人物与妆造迁移](references/adaptation.md)把新模特与这套拍法接起来。
4. **提交前复核。** 按[生成与返修](references/production-review.md)检查设计各部分能否同时成立。跨 Skill 用[JSON 交接](references/prompt-handoff.md)，将本张拍法完整传入。用户只要构思或分析时，交付到其指定阶段。
5. **实际看图再选。** 生成后查看每张图，信息流小图看重点，大图看身份、手、衣料和质感。按成功条件记录观察，返修最影响结果的一两处。组图按[单图与组图](references/photos.md)排；视频接[视频表现](references/video.md)，同时保留本张摄影决定。

初次运行依次读取以上链接里的摄影方法、摄影卡、迁移、交接和审片页；案例只读当前匹配项。它们是可执行路径。较弱模型优先迁移一套完整案例，在这个画面内替换身份、造型和现场，随后再尝试新的组合。

## 拍摄设计的写法

每张保留一份完整摄影卡。用户只要提示词时，最终交付按指定格式，内部设计可压缩。各项内容写成可以在图里检查的结果。例如“左侧入口光照亮近眼和颊，远侧头发留暗，身后深色货架衬出脸侧”，比“高级柔光”多给出实际指令。

同一模特可改变妆发与穿搭。保留五官、肤色和身体比例，按拍摄距离选择有用的妆发细节。默认沿用用户已确认的当代年轻成年时尚博主审美，合体、有设计感，露肩、腰或腿按本次展示重点选择。风格可甜美、清冷、张扬、优雅或日常。参考图中的脸、发色和身体比例分别遵守其实际分工。

主动摆姿、正视、低头和侧望都可成立。目光落点、嘴部状态、支撑与轮廓需要具体。手托脸可以为了好看，漂亮坐姿可以就是拍照；道具和故事按画面需要加入。

先决定人物多大、从哪看，再选现场可见部分。一个人从头到脚占满高度，仍可能只是宽店面中的窄影。前景、留白、遮挡、暗部和偏裁可主动使用，逐一说明它们让本张重点更清楚在哪里。脸可以局部遮挡，身体可以裁切，检查实际可见的人体关系即可。

## 直接照做的完整例子

唱片店首图想分享“我找到这张唱片，也喜欢今天抬眼看朋友的样子”。朋友站在店内唱片柜对面，略高于她眼睛、近距离拍胸像。下缘切过一排唱片上边，脸在上半，橙色封套竖在脸侧略低处。她一肘稳靠木柜，另一手握封套下角，头微偏、眼睛看镜头、嘴角轻抬。深棕长发近侧让出眼睛，莓色唇有小亮点，藏蓝方领只入镜到上胸。入口侧光照近脸，远发留暗，彩色货架退在后。脸与封套比货架清楚，纸面有轻微反光而图案可读。首轮只抓住隔柜近拍、眼神可见、封套与脸同框三项。完整 JSON 见[唱片店实例](examples/record-store.json)。
