# xhs-girl

目标画面是用户小红书点赞流里的颜值、氛围照。先打开[总览图](assets/reference-covers/contact-sheet.jpg)看一眼，它就是验收标准：近景为主，妆造和头饰很满，表情和手势贴着脸，道具举到脸旁，有明确的调色和精修。

画成"人站在店门口，平视一两米外拍全身，淡妆直发，礼貌微笑，自然光直出"的，是网店 lookbook，不合格。造型设计好但还是出这种图，说明画面类型和机位没换——抽签和提示词模板是关键。

## 流程

**出片：**
1. 运行 `python3 scripts/plan_set.py --count 张数 [--focus face|outfit]`，得到画面类型、造型和场景方案。
2. 用户指定了任何项（人物、造型、地点、风格方向）时，直接替换方案对应项，其余照用。
3. 每张查[画面类型库](references/shot-types.md)对应的卡片，按提示词模板写。outfit 模式查[身材展示](references/silhouette-studies.md)的展示重点行补机位和穿搭句。
4. 用 flow-image 生成，比例 3:4，只上传面部参考图；outfit 模式再加一张基础身形图。
5. 运行 `python3 scripts/compare_sheet.py 成片1 成片2 …` 和真实封面并排，按[审片与返修](references/review.md)判断。

**只出造型板（不出片）：**
1. 运行 `python3 scripts/plan_set.py --look-only [--direction 风格方向]`，得到按部件分开的造型抽签。
2. 读[造型设计](references/styling.md)，把抽签结果写成一套具体衣服（配色、剪裁细节、材质、饰品位置）。
3. 写造型板提示词；生成后如需出片，回到出片流程第 1 步运行完整抽签，把穿搭项替换成这套造型。**不要把造型板的正面全身站姿直接当小红书出片用。**

只要构思或提示词时，停在出片流程第 3 步交付。

## 提示词模板

每张一段，200–350 字，按以下顺序写，每句都是画面里看得见的东西：

1. **画面类型句。** "一张小红书爆款〈类型〉照片，3:4 竖图"，接类型卡里的机位景别句。
2. **身份句。** 有参考图时固定写："图1是人物身份参考：只保留她的五官、脸型和肤色；妆容、发色、刘海和衣服按下文改变；画面里只有她一个人，不复制参考图的白底和排版。"
3. **妆发。** 抽签的妆容、发型、头饰、美甲，逐项写部位和颜色。抽到的妆容没写腮红时补一句"面中淡粉腮红"，小图里脸才有气色。
4. **穿搭。** 把抽签的主单品、下装、外层、腿和鞋、饰品按[造型设计](references/styling.md)写成具体颜色和细节，写清露出的部位。outfit 模式按展示重点加一句姿势或机位，比如"镜头放到膝盖高度，从超短裙下摆到鞋尖的整段腿线修长"。
5. **动作。** 表情 + 手势或道具，写清手或道具在脸的哪一侧、多近。
6. **场景。** 地点 + 一处能看出时间或季节的细节。
7. **质感。** 固定开头"韩系网红精修图，皮肤白皙通透、柔焦磨皮、大眼小脸、五官精致"，接抽签的后期风格。

人物档案里的气质形容词、身高三围不要贴进提示词，它们会把画面推回"端正的模特照"。距离和占幅用"贴得很近""脸占满画面大半"这类视觉说法，不写厘米和度数。

## 完整例子（face 模式）

> 一张小红书爆款怼脸自拍，3:4 竖图。手机前置镜头贴得很近、略高于眼睛，脸占满画面大半，画面微微歪斜，头顶被上边切掉一点。图1是人物身份参考：只保留她的五官、脸型和肤色；妆容、发色、刘海和衣服按下文改变；画面里只有她一个人，不复制参考图的白底和排版。妆发：面中大面积粉色腮红，亮片卧蚕，浅棕美瞳，水光嘟嘟唇；奶茶棕空气刘海，大波浪卷发，戴一顶猫耳毛线帽；裸粉猫眼长甲。穿搭：敞开的白色短款羽绒服，里面是黑色小吊带，露出锁骨。动作：歪头嘟嘴看镜头，一只手比耶贴在脸颊旁。场景：冬天傍晚的便利店门口，身后货架的灯光虚成暖色光斑。质感：韩系网红精修图，皮肤白皙通透、柔焦磨皮、大眼小脸、五官精致，冷白皮低对比，整体偏粉白干净。

## 与 json-prompt-system 联用

用户明确要求结合 json-prompt-system 时，按它的模式填动作卡，不改动那个 Skill。它的固定正文规定了"原相机直出、无滤镜、不磨皮"，会削弱精修和调色效果；交付时告知用户。用户没有要求时，直接用本 Skill 的模板，不走 json-prompt-system。
