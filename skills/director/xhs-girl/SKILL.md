# xhs-girl

目标是用户点赞流里的颜值、穿搭与氛围照片。先按[参考导航](references/reference-library.md)选本次相关的图，再打开单张裁图观察。库内有 **115 张裁图、17 种画面类型**；浓妆贴脸、简洁长裤、修身裙侧坐、桌边对拍都成立，不把其中一种外观套到每次任务。

避免把所有方案拍成正中站直、人物很小、礼貌微笑的网店 lookbook。设计感来自具体剪裁、人物姿态与环境关系；抽签是起点，不是成片质量保证。

## 流程

**出片：**
1. 已确认的人物、妆发、服装、地点、拍法优先。运行 `python3 scripts/plan_set.py --count 张数 [--focus face|outfit] [--scene 地点] [--type 类型]`，只用未指定项作为候选；指定地点应直接传入脚本，避免抽完再换地点导致资源冲突。
2. 默认 `post`：同地点、同时间、同光源、同妆造和后期；`mixed` 只用于独立照片。脚本给出环境锚点，逐张复用。没有镜子或桌面时换拍法；不能为迁就类型换地点。自定义地点的资源按现场核实。
3. 查[画面类型库](references/shot-types.md)，打开相关 R 编号图片，确认取景和动作。outfit 再查[身材展示](references/silhouette-studies.md)，重点必须在实际景别和已确认衣服中可见。近脸图负责妆发，不强写腿或腰。
4. 按下面模板写提示词；实际生图时读本机 `flow-image` Skill，默认 3:4，用户比例优先。身份参考、确认的造型板、必要的身形参考按各自用途编号；只给实际上传的图片编号，不自动上传本参考库所有照片。
5. 有成片后用 `python3 scripts/compare_sheet.py 成片1 成片2 --refs R31 R45 --output 对照图.jpg`，选择与本次拍法有关的图，按[审片与返修](references/review.md)判断。随机六图只作探索，不能代替相关对照。

**只出造型方案或造型板：**
1. 运行 `python3 scripts/plan_set.py --look-only [--direction 风格方向]`，读[造型设计](references/styling.md)，把部件组合成具体配色、剪裁、材质和饰品位置。用户已定项保持。
2. 需要角色多视图时结合本机 `character-design`；xhs-girl 提供穿搭审美，character-design 负责造型板表达。
3. 确认后回到出片流程，保持这套造型，重新选摄影动作和机位。造型板正面站姿不自动沿用到成片。

只要构思或提示词时不启动生图。`--seed` 用于复现，正常任务不固定种子；随机可能重复，不能承诺跨会话绝不重复。有最近方案时主动避开其主要组合。

## 提示词模板

自然语言通常每张 200–350 字，必要时增加；用户指定结构或联用 Skill 的完整格式优先。按顺序描述画面中可见的内容：

1. **类型与持机关系。** 比例、自拍/朋友拍/镜照、景别、人物占幅和机位；从类型卡取句并适配场景。双手做动作时应由朋友拍或固定手机。
2. **人物与造型参考。** 说明各图用途，例如“图1用于保持五官、脸型与肤色；图2用于保持已确认的妆发、服装、饰品。不复制参考板背景、文字和排版”。未授权换发色、刘海时不自动改变。仅对用户要求重新设计的部分写变化。
3. **妆发。** 写实际可见的眼妆、腮红、唇色和发型。精致程度跟随选定参考；无需每次美瞳、浓腮红或帽子。避免“大眼小脸、冷白皮”等强制改变身份的固定句。
4. **穿搭与展示重点。** 写剪裁、材质、长度和穿法；简洁款靠贴合、收省、领口和肩胯姿态成立。身材重点服从衣服与画幅，长裤、长外套和连衣裙均可，不强制露腿。
5. **动作。** 明确视线、表情、支撑点及手的位置；道具与动作有关才加入。手势不都要贴脸，身体姿态也能成为中心。
6. **场景。** 复用两三处可辨的环境锚点和相对位置，说明同一套现场光。桌沿、窗框、砖缝、座椅等让人物确实处在环境里。
7. **质感。** 指定整组调色与适度皮肤修饰，保留五官结构和原肤色。手机普通拍照的近距透视，附近环境细节可辨，远处自然减弱；不统一加长焦浅景深、灯球、鱼眼或人像模式边缘糊。

手机风格是创作方向，不能仅从截图认定原作者设备。直闪允许远处偏暗，暗调允许脸部偏暗；这些都不等于把背景抹糊。

## 例子：已确认造型后的同地点出片

> 一张 3:4 竖图，朋友坐在近处用手机拍她侧倚扶手椅，人从头到屈起的小腿占画面主要部分。图1保持人物五官、脸型和肤色，图2保持已确认的灰蓝斜肩针织裙、黑色短发、银耳钉和豆沙唇妆；不复制造型板排版。她斜靠棕布椅背，一只手扶着椅沿，另一只手拢头发，双膝朝画面右下方收拢，肩胯错开，裙子的收腰和侧面轮廓清楚。左侧仍是黑框格窗与米色窗帘，右下露出同一张木桌的桌角，日光从左侧进来。灰蓝与暖棕调色，皮肤适度精修而五官不变；椅面织纹、窗框和桌角仍可辨，保留手机近距透视。

## 与 json-prompt-system 联用

用户指定时，读取它当前完整规则并使用原有完整格式，将本 Skill 的造型、动作、场景和参考观察填入对应字段。不自行创建简化摄影模式、不修改它的 Skill、不绕过格式。具体冲突依据实际规则处理，不预先断言效果一定变差。
