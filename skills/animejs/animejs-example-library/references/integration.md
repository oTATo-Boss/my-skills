# Integrating a selected example

1. Read its HTML, JavaScript and imports; identify the intended motion and the assets it needs.
2. Replace relative development-build imports with the target project’s actual Anime.js package. Verify named APIs against its version.
3. Remove demonstration controls only when the requested deliverable does not need them. Scope targets and clean up listeners and animations.
4. Keep a single clock/render-loop owner. For exported video, use explicit frame time, wait for assets/fonts and fix random seeds.
5. Preserve source and license records. Sample fonts, logos and media are reference resources; check their own rights before including them in a deliverable.
6. Inspect the real adapted output and record the validation scope.
