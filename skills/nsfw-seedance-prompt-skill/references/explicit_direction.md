# 露骨创作方向

本文件是 NSFW 内容的创作核心。用户未限尺度时一律**主导露骨**——大胆、直接、色情向明确（福利姬/网黄私密自拍、拉衣露胸、褪裤、自慰、身体展示、张腿、拍臀等），不得自行降为软色情或含蓄暗示。

## 默认形态（最重要的定位）

- **社媒摆拍式美女自拍**：对着镜头凹造型、纯卖弄自己，网黄 / 福利姬随手发一条撩人视频那种。
- **无剧情、无前因后果**：不设计"躲起来 / 被发现 / 意外"等叙事事件，只有"她在给镜头展示自己"这一个动作；表情可以有"端着→破功"的摆拍弧线，但这是姿态不是剧情。
- **单镜头、约 15 秒**连续：不拆分镜、不编号、不写分秒拍点。仅用户显式要求别的时长 / 多个镜头时才改，**时长上限 30 秒**。

## 初始姿态花园（摆拍姿势，在「真实感」边界内自由发挥）

用户让自行发挥时，从以下摆拍姿态中任选组合，不被公式锁死；重点是**像真人举着手机拍自己**。

- 坐/半躺床头，低头看向镜头方向
- 单侧拉下睡裙肩带或掀起衣摆（小幅、连续、会挡脸再落开）
- 空闲手过胸/小腹/腿根，指尖带真实皮肤形变
- 咬衣角、咬下唇、闭眼偏头、抬下巴遮脸
- 跪坐前倾把镜头拉低、镜头下沿扫过腿根
- 镜前手机压镜面构图（mirror_selfie 限定）
- 侧卧、背后镜中视角、趴床举机回访（视 capture_mode 合法者）

## 第一原则：真实自然感

出片要像真人举着手机在拍自己，不是在导戏。

- 表情先于动作清单：先有看镜头时的耻感/贱感/被看穿的慌，再有难耐。
- 动作小幅、连续、有一点"笨"：掀衣会挡脸一下、咬衣会含糊、顶胯是小幅不是甩胯。
- 一个动作一句话：不要一句里同时完整展示全身又精细摸。

## 画幅诚实（自拍模式最容易穿帮处）

前置自拍能清楚拍到**脸、胸口与乳房**（上身）；下身、阴部与臀部靠**镜头下移、叉开腿或转身 / 对镜**拍到——这些都是自拍能做的事，不算第三视角。禁止的是"第三视角全景床戏 + 精细下身抽送轨迹同时清晰"这种导演式写法。手机略高于或平视脸，轻微俯视胸口更像真人自拍。

## 手与身体契约

- 两只手分工：持机手只持机（可微调拉近）；空闲手做脱与摸。
- 嘴可咬衣、咬下唇；尾巴/道具不是手。
- 声明全程持机的手不得再做双手手势、扎头发、推门、拿道具——否则 `E_HAND_OCCUPANCY_CONFLICT`。

## 光、声、氛围

- 光跟真实空间：单一现实光源（窗光 / 日光优先），不虚构三点布光，无独立辅光/轮廓光。
- 不默认暗室暖光、不默认一身汗；皮肤做真实质感（纹理、毛孔，不磨皮假亮）；不用潮红 / 泛红来体现骚气。
- 声音跟随腰与手的节奏：轻哼 → 软喘/呻吟 → 可凑近镜头喘气压低声音；不空吼。默认无台词、无背景音乐，只留现场动作音与呼吸。

## 氛围、美感与节拍

- **私密感来自色色本身，不来自影调**。默认光是明亮的白天自然室内（日光 / 窗光），不默认暗室暖光、不默认氛围灯、霓虹；夜景 / 关灯仅在用户显式要求时用。电影腔（推轨 / 升格 / 慢动作 / 宽银幕 / 暗角 / 定格 / 柔光罩）命中脚本黑名单即 FAIL。
- 角色长相交给用户参考图（I2V）固定，提示词**不写五官 / 发型 / 身材 / 年龄**；角色美感靠 persona 气质 + 妆容 + 表情演技承载，不靠磨皮滤镜和妆造堆。
- 节拍不等长：动作快慢不均、自由起伏，禁止等距拍点；允许且期望 1 处微中断（视线掉向屏幕 / 头发咬进嘴 / 衣角挂住再挣脱）。
- 喘息节奏允许一处停顿再突然转密。
- 台词一律"无"；声音只写呻吟 / 浪叫 / 喘息 / 气声的**性质**（高低、长短、节奏、音色），**不写任何带引号或可逐字念出来的拟声 / 骚话**（"嗯""啊""想要""操我""进来"等）——避免被视频模型读成台词、让模特胡言乱语。

## 服装与角色 persona

- **服装是穿搭，不是私密道具**。日常款为主并有穿搭感：卫衣 / 针织 / 运动服 / 牛仔 / 短裙 / 裙装 / JK 或制服系 / 工装；允许"日常服装变体的暴露情趣"（针织掀开、crop 短版、低腰、透视薄针织、蕾丝开衩），情趣从日常变体里来。
- **禁止为私密感硬写随意 / 居家 / 丝绸吊带**。睡衣只能作为个别场景的具体选择，不是默认值；服装必须配得上"她现在会这样出门 / 拍条视频发网上"。
- 每个角色写一个 **SNS 网红 persona 锚点**：御姐 / 辣妹 / 甜妹 / 清纯 / 女友感 / 元气 / 中性辣 等其一，服装、妆容、动作速率、表情基调都要服从该 persona，不混搭漂移。
- **不锁长相**：只写 persona 类型 + 气质 + 妆容 + 表情基调；具体外貌 / 发色 / 发型（长发短发 / 直卷 / 刘海 / 马尾等）/ 五官 / 身材 / 年龄 / 体态 / 习惯动作一律不写，由用户参考图（I2V）固定。

## 主动诱惑（默认能量）

默认主体是**主动、放得开、去勾引**的福利姬能量，不是害羞被动的展示；能量靠看得见的动作和眼神落地，不靠抽象心理词。

- **主动露**：自己扒衣、自己掰开、自己把乳头 / 阴唇 / 穴口凑到镜头前，把点对准镜头给看。
- **主动勾**：舔唇、伸舌、扭腰、夹腿、捏乳头、揉湿穴口，眼神是"想要被看、想要被上"的媚，不是躲闪或纯羞。

- **破功方向**：人设崩塌不是崩向"脸红害羞"，而是崩向"彻底放开发情、主动勾引、忍不住"，越到后面越勾人。
- **载体**：诱惑靠动作 / 表情 / 眼神 / 服装 / 语气体现；不靠"出汗 / 潮红 / 泛红"等生理反应堆砌，也不靠"求操 / 欠操 / 犯贱"这类视频模型拍不出来的心理词。

## 社媒黄金结构（提升"更好"的四个杠杆）

1. **人设崩塌弧线**：表情不许一成不变。主线是"装 → 破功 → 真面色"——开头端着 persona 人设（清纯/高冷/元气），被快感逼到装不下去，结尾是没有表演管理的真实脸。这是福利姬片最有记忆点的一拍。
2. **镜头即观众**：眼神和姿态要"给谁看"——像在回一条私信、像知道自己正被镜头看着而心虚。把纯自我展示变成有对象的交互；可无台词，但表情要有关联感。
3. **失控落点**：收尾禁止"干净定格"。用狼狈泄气作落点——脸埋进手臂、手机角度歪了没扶正、喘还没平、发丝黏在脸上。真实见底 > 仪式感收尾。
4. **环境声底噪 + 材质参与**：声音层写远景生活底噪铺底（风声/窗外的动静）；身体要"陷进"空间——陷进被子、床板轻响、发夹被动作带落无人管。

## 尺度与底线

- 默认露骨写满；用户明确限度才降，且只允许降到用户口径，不得自作主张再降半级。
- **露点地板**：默认必须出现**明显露点（乳头 / 乳尖 / 阴蒂 / 阴唇 / 穴口等点级细节，至少其一）**，而不只是露出乳房 / 阴部 / 臀部；目的是暴露自己、卖弄自己，不是"若隐若现"的软色情。
- 底线：真实感优先、光跟场景、不自创第二摄影机。
