# 提示词模板（单段公式）

完整提示词 = 一个 `txt` 代码块，按下面 **12 栏固定顺序**各写一行，合成一段交付。非空白字符数逐栏受限（由 scripts/prompt_tools.py 计量）。每栏只回答一个问题，不跨栏、不复述；所有栏目名、顺序、`栏目名：` 键值格式必须与模板一致，脚本才能定位。

```txt
默认设定：[摄影机身份：front_camera_selfie / mirror_selfie / third_party_capture 其一；单镜头约15秒；主导露骨（明显露点 + 主动诱惑），用户未限尺度不降；不锁长相，由参考图固定]
人物：[网红 persona 类型（御姐 / 辣妹 / 甜妹 / 清纯 / 女友感 / 元气 / 中性辣 其一）+ 气质 + 妆容 + 表情基调；不写五官 / 发色 / 发型 / 身材 / 年龄 / 体态 / 习惯动作]
服装：[日常穿搭 + 穿搭感，或日常款变体的暴露情趣；不硬写随意 / 居家 / 丝绸吊带]
场景：[固定地点 + 空间拓扑 + 方向 + 环境物件]
完整连续动作：[一段连贯的卖弄 / 自慰动作，含明显露点（乳头 / 乳尖 / 阴蒂 / 阴唇 / 穴口 至少其一）+ 主动诱惑（自己扒 / 掰 / 凑镜头 / 勾眼）；不拆镜、不编号、不写秒数]
表情与视线：[人设崩塌弧线（装 → 破功 → 真面色）+ 镜头即观众的对象感]
机位与构图：[手机略高于 / 平视脸、轻微俯视胸口；前置广角轻微畸变；前置只清楚拍到脸和胸，下身靠镜头下移 / 叉腿 / 转身]
运镜：[画面运动只来自持机手腕、呼吸、身体重心；无外部推进 / 跟拍 / 重新取景]
动作节奏：[快慢不等、自由起伏，保留 1 处犹豫 / 停顿 / 看屏幕的瞬间]
光线与画质：[单一现实光源（默认白天自然室内）；手机实拍画质：轻微噪点、过曝漂移、边缘涂抹、动作模糊]
声音：[远景生活底噪 + 呻吟 / 喘息节奏跟随动作；无台词、不写可念的拟声字]
抖音真人感：[像随手点开相机录的，松弛、笨拙、有停顿，不是摆拍导戏]
```

## 说明

- 12 栏顺序固定，`栏目名：` 在行首、冒号为中文 `：`，供脚本定位；顺序错、漏栏、栏目名不一致都会 FAIL。
- `摄影机身份：` 只在默认设定写一次，全片唯一；机位与构图、运镜两栏服从它，不引入第二视点、不写外部摄影机。
- 露骨落地靠动作 / 表情 / 眼神（主动诱惑），不靠「求操 / 欠操 / 犯贱」等心理词，不靠出汗 / 潮红 / 泛红堆砌。
- 长相交给参考图固定；声音不写带引号的拟声 / 骚话。
