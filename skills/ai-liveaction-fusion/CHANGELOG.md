## 4.1.0 — 2026-08-22

### 镜头—场景投影门禁
- 新增强制投影分析：摄影机高度 / 俯仰、人物屏幕空间姿态与接触拓扑、主导可见表面、地墙交界 / 地平线、资产表面重投影。
- 静态阶段不得只看单帧，至少核验精确关键帧与同镜头前后邻帧；高影响角度不确定时停止生成并等待确认。
- 明显俯拍必须由地面主导，明显仰拍必须由上部墙面 / 天花 / 天空主导；反转关系视为硬失败。

### 场景资产三维理解
- 场景资产先拆成地面、墙面、天花 / 天空、门窗、锚点与邻接关系。
- 新增场景图视角证据级别：同方向权威 / 仅拓扑 / 仅材质 / 当前方向排除。
- 禁止把场景资产原构图直接贴到原摄影机后方。

### 静态与视频 QC
- 静态候选新增姿态关键点、主导表面、表面占比、地墙交界和资产重投影核验。
- 视频新增首 / 中 / 尾帧投影连续性、背景角度漂移及运动中表面占比变化核验。
- 已批准分镜图若投影错误，必须退回静态阶段，不得继续绑定视频。

## 3.0.0 — 2026-08-20

### Breaking：逐镜合同重构
- 标准逐镜由 3 栏升级为 6 栏：**构图与景别 → 背景与空间 → 空间透视与镜头匹配 → 光源与融合 → 最终画面 → VFX**。
- 正式废弃 `视频内容` 与 `画面内容` 栏目，统一改为 `最终画面`。
- 新增独立 `VFX` 栏，所有换装、清理、补画、特殊特效和后期操作从结果画面描述中分离。

### 背景贴图感专项升级
- 新增 `spatial_lens_matching_rules.md`。
- 强制逐镜判断前中后景层、透视消失关系、真实尺度、焦平面、景深递进、焦外、摄影运动视差和低幅度环境动态。
- 明确禁止整张背景统一模糊、所有层同锐度、摄影机移动时背景同步平移。
- 强调“背景适配当前原摄影机”，而不是让人物适配参考背景。

### 景别 / 空间锚点冲突修复
- 新增硬规则：空间锚点不得覆盖原视频可靠景别。
- 角色处于塔楼顶部、屋顶、教堂门口等位置时，若原视频是近景，必须用局部结构交代位置，禁止自动拉成建立远景。

### 光源栏目升级
- `光源与融合` 必须写当前镜头可见受光结果，不再接受“人物与环境真实融合”“按参考重光”等空话。
- 光比正式归入光源栏目；数值只在项目明确时使用。
- 人物面光、背景降饱和等继续保持项目级变量，不写进 Skill 默认审美。

### 最终画面 / VFX 职责隔离
- `最终画面` 只写观众最终看到什么，不机械复述原视频，不写后期操作。
- `VFX` 只写如何从原素材实现最终结果。
- 发光类 VFX：VFX 栏写效果本身，光源栏写其照明反馈。

### 平台兼容
- 新增 `platform_wording_rules.md`，仅在平台实际文本审核失败时启用；以中性影视运动和视觉反馈表达替代高风险伤害机制词，不改变最终镜头结果。

### QA
- validator 升级到 v3 六栏合同。
- package audit 新增旧栏目扫描、六栏模板检查、新 references 完整性检查。
- 更新夜街、塔楼近景、月亮转场、眼睛反光与纯 AI 示例。
