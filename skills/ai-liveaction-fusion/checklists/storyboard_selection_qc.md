# `/分镜图` 发布与绑定 QC

- 用户是否明确说明筛选完成，或明确指定要发布的具体文件？
- 是否只读取 `/分镜图` 中实际存在的文件？
- 每个文件是否能唯一映射到分镜 ID 与关键帧状态？
- 同一分镜是否存在多个未裁决的权威版本？
- 画幅、方向和分辨率是否适配目标视频？
- 平台要求精确像素时，实际像素、色彩模式、透明通道和编码是否通过技术预检，而不是只看画幅标签？
- 是否已清除时间码、水印、技术字和错误元素？
- 是否与镜头事实卡的场景方向、人物、服装、光线和 VFX 状态一致？
- 是否与镜头—场景投影卡的摄影机角度、人物姿态 / 接触拓扑、主导可见表面、地墙交界 / 地平线和资产重投影一致？
- 若分镜图投影错误，是否退回静态阶段，而不是把错误图绑定给视频阶段？
- 是否已建立“分镜 ID → 文件 → @句柄”绑定清单？
- 所有标记“需分镜图”的镜头是否都有已绑定文件？
- 候选目录中的未入选图是否保持非权威状态？
- 候选状态清单中的 `current_best` 是否仅作为推荐，且与用户最终发布选择一致或已明确被用户覆盖？
