# 六栏逐镜分解 QC

## 分镜判定
- 最终镜头数量是否经过用户 / 最终剪辑意图确认？
- 是否区分最终硬切、制作拼接点和源文件边界？
- 是否检查首帧 / 中段 / 尾帧？
- 是否核验同镜头前后邻帧，并建立摄影机角度、人物姿态 / 接触拓扑和场景表面投影？
- 是否读取了画面批注的制作语义？
- 时间码是否来自实际核验？

## 六栏结构
每镜是否都有且仅按顺序使用：
1. 构图与景别
2. 背景与空间
3. 空间透视与镜头匹配
4. 光源与融合
5. 最终画面
6. VFX

## 构图与景别
- 是否锁定原视频可靠景别 / 机位 / 人物占比？
- 是否记录人物关键关节、轮廓、接触点、受力点和前后遮挡的屏幕空间轨迹？
- 空间锚点是否错误诱导镜头拉远或改变构图？

## 背景与空间
- 是否具体描述当前摄影机实际看到什么？
- 是否明确人物后方、两侧、地面、远景、场景方向？
- 是否写清地面 / 墙面 / 天花或天空的主次、上中下分区，以及首 / 中 / 尾帧占比变化？
- 明显俯拍是否由地面主导，明显仰拍是否由上部空间主导？
- 是否避免只写 `使用 @场景`？

## 空间透视与镜头匹配
- 是否有真实前中后景层？
- 透视 / 消失点 / 尺度关系是否可信？
- 地墙交界 / 地平线是否与摄影机高度和俯仰一致？
- 场景资产是否按原摄影机重投影，而不是复制资产原视角？
- 是否明确焦平面和景深递进？
- 摄影机有运动时是否明确视差？
- 环境是否有合理低幅度动态？
- 是否避免整张背景统一模糊？

## 光源与融合
- 是否写清光从哪里来、人物哪侧亮？
- 是否正确注入当前项目光影要求？
- 是否写人物与背景视觉光比 / 材质受光 / 接触阴影 / 反射？
- 是否避免空话“真实融合”？

## 最终画面
- 是否能直接脑补最终成片？
- 是否写的是结果而不是后期操作？
- 是否没有机械复述全部原视频动作？
- 是否没有虚构原视频不存在的表演？

## VFX
- 是否只写后期操作？
- 角色 / 服装 / 配饰替换是否正确？
- 清除 / 补全 / 特效 / 转场是否具体？
- 无额外 VFX 时是否避免强行添加？

## 连续性
- 跨镜动作是否按镜头阶段拆分？
- 第一帧已有状态是否被错误重新生成？
- 多素材连续 VFX 是否被错误拆散？
- 摄影机静止时背景角度与表面占比是否稳定？摄影机运动时交界线、表面占比和视差是否连续变化？
