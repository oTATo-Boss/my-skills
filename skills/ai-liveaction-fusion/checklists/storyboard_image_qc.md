# 静态分镜候选图 QC

- 原演员身份、五官、体型和身体比例是否保持？
- 当前关键帧的构图、景别、人物占比、裁切、表情、口型、姿态和接触是否保持？
- 是否逐点核对头、肩、肘、手、髋、膝、脚的屏幕位置、关节方向、人物轮廓、接触点和前后遮挡，而不是只判断“姿势大致相似”？
- 摄影机高度与俯拍 / 平视 / 仰拍类别是否与原图及同镜头前后邻帧一致？是否把人物仰头 / 低头误当成摄影机角度？
- 背景方向、承托面和近中远空间是否与镜头事实卡一致？
- 地面 / 墙面 / 天花或天空的主次、上中下分区、近似占比、地墙交界 / 地平线是否与投影卡一致？
- 明显俯拍是否由地面主导、墙面压缩到上沿 / 侧边？明显仰拍是否避免无依据大面积地面？
- 是否误用了场景资产的另一方向或不可见结构？
- 若画面存在门、门槛、拱洞或其他空间边界：摄影机侧、逐人物所在侧、越界状态、门框遮挡和人物背后空间是否全部正确？
- 是否把场景资产原视角直接当背景板，而没有按原摄影机重投影？
- 服装是否完成几何结构替换，而不是只改色 / 材质？
- 所有可见人物，包括越肩、前景局部、背景和非本轮修改目标，是否保持其已确认身份、服装、妆造、配饰和剧情状态？
- 人物、服装、背景、地面、空气和 VFX 是否共享同一光源？
- 是否出现门框、祭坛、石地、完整建筑等被明确排除的元素？
- 是否出现时间码、文件名、技术字、水印或额外人物？
- 本轮失败变量是什么？其他已正确内容是否可以锁定？
- 投影角度、主导表面或人物姿态拓扑错误时，是否作为硬失败而非审美差异？
- 输出是否只保存在候选目录，而非 `/分镜图`？
- 实际宽高比、精确像素、方向、色彩模式和透明通道是否符合当次平台要求？
- 候选状态清单是否登记本版本；若设为 `current_best`，是否已有真实审查证据且未被误当成正式分镜图？
