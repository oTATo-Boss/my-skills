# 项目接入 QC

- 是否明确基础视频？
- 是否明确场景、人物、服装、固定配饰 / 妆造附件、剧情道具和分镜图？
- 场景资产是否覆盖正向、反向、俯视 / 仰视或至少足以建立地面、墙面、天花 / 天空与门窗的拓扑？
- 是否区分场景资产的世界身份权威与资产图片自身视角，避免把参考图当通用背景板？
- 哪些参考素材当前可实际分析，哪些只是生成阶段的运行时句柄？
- 若有剧本 / Shot List / 镜头说明，是否明确其只负责叙事语义，不覆盖视频动作？
- 是否明确必须保留与必须替换边界？
- 是否记录当前项目专属光影 / 色彩要求？
- 是否明确这些项目级要求不得自动迁移到其他项目？
- 是否明确当前要输出完整提示词、单模块、审片还是返修？
