# 平台真实 @ 素材绑定规则

本规则只在把已编译提示词落地到生成平台时启用。它约束平台侧素材引用与提交边界，不改变两阶段生产、镜头事实、素材权威或提示词结构。

## 1. 四种状态必须分开

以下状态互不等价，不得互相冒充：

1. **语义句柄已编译**：本地 Markdown 或提示词正文已写入预期 `@句柄`；
2. **素材已上传 / 可选**：目标素材真实存在于当前平台、项目或会话的素材选择器中，并可被唯一识别；
3. **正文真实 mention 已绑定**：正文中的每次语义引用已通过平台支持的素材选择 / 绑定机制，解析为指向正确素材的真实 mention、token、attachment ID 或等价结构；
4. **任务已提交生成**：平台已经接收生成任务，可能开始消耗积分、配额或计算资源。

本地文件映射、上传成功、纯文本句柄出现、真实 mention 绑定和生成提交都只能证明各自状态。`/分镜图` 绑定清单证明的是正式文件到语义句柄的本地映射，不证明平台正文 mention 已建立。

## 2. 纯文本 `@句柄` 的默认含义

本地 Markdown、剪贴板文本或普通输入框中的纯文本 `@xxx` 默认只是**待绑定的语义句柄**。直接粘贴或键入后，不得仅凭文字长得像 `@句柄` 就报告“素材已绑定”。

只有目标系统本身把该文本解析成可观察、可验证且指向唯一正确素材的结构化引用时，才可将对应出现位置记为已绑定；验证方式和平台绑定模型必须记录。

## 3. 绑定前清单

平台操作前，从最终提示词建立逐次引用清单：

- 每个预期句柄及其目标素材；
- 该句柄在正文中的语义出现次数与位置；
- 素材在平台中的唯一可识别名称、ID 或其他稳定标识；
- 素材是否已上传、可选，是否存在同名冲突或意外重复；
- 平台使用逐次 mention、全局 attachment、素材槽位映射或其他绑定模型。

目标素材不存在、不可选、存在无法消解的同名冲突，或绑定模型尚未核验时，不进入提交阶段。

## 4. 富文本 mention / token 平台的执行门禁

当平台编辑器支持由 `@` 联想、素材选择器或等价交互产生的富文本 mention / token 时：

1. 先确认每个目标素材真实存在且可唯一选择；
2. 在正文中逐个处理每一次语义素材引用；
3. 在该引用的原始语义位置调用平台真实的 `@` 选择 / 绑定机制，并选择唯一正确素材；
4. 确认插入结果成为结构化 mention / token，而非仍是普通字符；
5. 同一素材在正文重复出现时，每次语义引用都建立有效 mention。

不得：

- 用粘贴或键入的纯文本 `@文件名` 替代平台真实 mention；
- 只在提示词末尾额外堆放一组素材标签，冒充正文各语义位置已引用；
- 因素材已上传或在侧栏可见，就声称正文已经绑定；
- 只绑定同一素材的第一次出现，遗漏后续语义引用。

若平台采用经验证的不同模型，例如一次全局 attachment 或素材槽位即可供正文中的多个结构化引用解析，允许遵循该模型；但必须记录模型、实际素材 ID / 槽位、作用域、正文解析方式与验证证据，不能把未经验证的猜测当作例外。

## 5. 提交前的可观察验证

优先检查平台可访问的结构、元数据和交互行为；颜色、底纹、字体或其他视觉样式只能作为辅助证据。可用证据包括但不限于：

- 编辑器结构中存在 mention / token 节点及其素材 ID；
- 交互检查能打开或定位到唯一正确素材；
- 平台序列化值、可访问性信息、请求数据或预览映射显示正确引用；
- 平台针对未解析文本与有效素材引用表现出不同的可验证行为。

提交前必须确认：

- 所有期望句柄都解析到唯一正确素材；
- 未解析句柄数为 0，误解析句柄数为 0；
- 素材列表没有本次操作造成的意外重复；
- 正文有效 mention 的总数、逐句柄计数和位置映射与语义引用清单一致；
- 若使用非逐次 mention 模型，其已记录映射能覆盖全部语义引用；
- 提交按钮未被触发，任务历史尚无本次新增任务。

若任何真实 mention 无法建立或验证，将状态标为`未绑定 / 阻塞`，列出具体句柄、出现位置、预期素材和失败原因；不得提交，也不得声称完成。

## 6. 授权与提交边界

上传素材、填入提示词、绑定正文素材引用、点击生成是四种不同外部动作。用户授权其中一项，不自动授权后续动作。

除非用户明确要求提交生成，否则完成绑定后必须停在**未提交**状态。按实际情况报告：

- 素材：已上传并可选 / 原已存在且可选 / 阻塞；
- 提示词：已填词 / 未填词；
- 正文真实 mention：已绑定 / 未绑定 / 阻塞；
- 生成：未提交。

绑定完成且未明确授权提交时，标准摘要必须为：`已上传、已填词、已绑定、未提交`。其中“已上传”表示全部目标素材已确认存在于平台且可选，并不虚构为本轮刚执行了上传；详细状态仍须注明“本轮上传”或“原已存在”。不得把“绑定完成”解释为允许点击生成或消耗积分。

## 7. 防误提交复核与异常处置

设置修改或素材绑定后，在结束外部操作前复核：

- 提交 / 生成按钮没有被触发；
- 任务历史、队列或生成记录没有新增；
- 可观察的积分、额度或配额没有异常变化；
- 当前页面仍处于可编辑、未提交状态。

若发现意外提交，立即停止进一步外部操作，如实记录可见的任务标识、时间与积分 / 配额变化。不得擅自再次生成、删除、取消或重试任何可能继续影响积分的任务；等待用户决定后续处置。
