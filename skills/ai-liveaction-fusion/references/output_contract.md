# 输出合同（v4.2.2）

## 0. 两阶段产物

静态分镜阶段可输出：
- 镜头事实卡；
- 镜头—场景投影字段；
- 静态分镜提示词；
- 参考图清单；
- 候选 Take 审查 / 单变量返修；
- `/分镜图` 本地映射清单。

视频阶段继续使用本文件后续四模块合同。

### 静态分镜提示词固定结构

严格按顺序：
1. `# 图像编辑指令`
2. `# 当前素材锁定`
3. `# 画面质感`
4. `# 单帧画面`
5. `## 构图与景别`
6. `## 背景与空间`
7. `## 空间透视与镜头匹配`
8. `## 光源与融合`
9. `## 最终画面`
10. `## VFX`

候选图不进入 `/分镜图`；本地映射清单只允许引用用户发布目录中的真实文件，且不代表平台正文真实 mention 已绑定。

## 1. 完整提示词
默认输出 **一个** `markdown` 代码框，模块顺序固定：
1. `# 视频编辑指令`
2. `# 素材锁定`
3. `# 影片质感`
4. `# 逐镜分解`

## 2. 单模块输出
用户只要求某一部分时，只输出对应模块的一个 `markdown` 代码框。

## 3. 代码框外文本
默认模板化交付物代码框外不加前言、解释、摘要、建议或结语。用户明确要求“先分析再输出”时例外。

## 4. 代码框内部
- 正文以 `---` 开始
- 正文以 `---` 结束
- 一级模块标题位于代码框内部

## 5. 视频编辑指令
必须包含：
- `@视频`
- 项目编号角色映射（女1 / 女2 / 男1 / 男2……）
- 对应人物妆造、服装与固定配饰（存在时）
- 场景映射
- `@分镜图`
- `@分镜图` 必须可映射到 `/分镜图` 中已批准文件，不允许空句柄或候选图
- 常规镜头完全保留项
- 逐镜摄影例外覆盖关系
- 完全去除项
- 重光照
- 后续逐镜执行声明

## 6. 素材锁定
固定：
- `## 场景锁定`
- `## 角色视觉锁定`
- `## 道具视觉锁定`

## 7. 影片质感
固定：
- `## 风格类型`
- `## 摄影偏好`
- `## 整体质感与氛围`
- `## 光影与色彩`

## 8. 逐镜分解
每个标准实拍融合分镜固定六栏，顺序不可改变：
1. `### 构图与景别`
2. `### 背景与空间`
3. `### 空间透视与镜头匹配`
4. `### 光源与融合`
5. `### 最终画面`
6. `### VFX`

旧栏目：
- `### 视频内容`
- `### 画面内容`

均视为旧合同，不得继续用于 v4.2.2 标准逐镜。

相邻分镜使用 `---` 分隔。

## 9. 内容质量硬约束
以下文本不能单独作为合格逐镜内容：
- `场景固定为 @xxx`
- `保持原视频空间关系`
- `按照 @场景 重光`
- `人物与环境真实融合`
- `电影级融合`

`背景与空间`、`空间透视与镜头匹配`、`光源与融合` 必须包含当前镜头具体最终结果。

明显俯拍 / 仰拍还必须包含主导可见表面、画面分区、地墙交界 / 地平线与资产重投影结果；只写“保持俯拍 / 透视正确”不合格。

## 10. 命名与句柄
- 使用用户实际 `@句柄`
- 保持原始拼写、空格、下划线、大小写
- 不自行标准化 / 改名
- 不使用 `{{Mixed X}}` 作为 canonical 句柄，除非用户明确要求
- 不允许空 `@`、未解析 `@[占位符]`、残缺引用

## 11. 纯 AI 镜头
纯 AI 镜头可独立输出 `# 纯 AI 镜头提示词`，但镜头结果仍需覆盖：
- 镜头定位
- 素材使用
- 构图与景别
- 背景与空间
- 空间透视与镜头匹配
- 光源与融合
- 最终画面
- VFX

## 12. 成片审查 / 单变量返修
不强制四主模块，但仍使用一个 `markdown` 代码框。

## 13. 平台执行状态报告

平台上传、填词、绑定或提交任务不受“提示词只能有一个代码框”限制；使用 `templates/execution_manifest_template.md` 分开报告：

- 语义句柄：已编译 / 未编译；
- 素材：已上传并可选 / 原已存在且可选 / 阻塞；
- 提示词：已填词 / 未填词；
- 正文真实 mention：已绑定 / 未绑定 / 阻塞；
- 生成：未提交 / 已提交（仅限明确授权）。

不得把本地纯文本 `@句柄`、`/分镜图` 本地映射、素材上传或资产列表可见性报告为平台正文绑定完成。无法验证时列出具体句柄与出现位置并标为阻塞；没有明确提交授权时必须报告未提交。

完成平台正文绑定且未获提交授权时，标准摘要为：`已上传、已填词、已绑定、未提交`；详细状态另行区分素材是本轮上传还是原已存在。
