# 素材权威规则

## 1. 实拍编辑模式
当基础素材为 `@视频` 且任务是 AI 后期融合时：
- `@视频`：演员身份、五官、脸型、肤色、体型与身体比例；摄影、动作、表演、接触、受力、时长、口型和节奏
- `@分镜图`：只指用户已筛选并保存在 `/分镜图`、且已进入绑定清单的正式关键帧；负责该关键帧的场景方向、可见空间、人物最终妆造 / 服装呈现、影调、色彩、光影、材质与 VFX 状态校准；不覆盖动作、表演、接触、受力、摄影机运动和时序
- `@场景`：场景身份、建筑体系、地面 / 墙面 / 天花或天空等可用表面、空间拓扑、锚点与环境材质；资产图片自身机位只对该图片视角有效，不自动决定当前镜头机位或背景表面占比
- `@角色`：目标发型、妆容、角色妆造与项目明确要求的角色视觉元素；默认不替换原演员身份 / 五官，除非用户明确要求身份替换
- `@角色服装`：服装结构、版型、材质、层次与穿着方式
- `@固定配饰 / 妆造附件`：耳环、项链、眼镜、头饰、假牙、妆造附件等固定人物视觉元素及其佩戴关系
- `@道具`：剧情道具的结构、材质、颜色和持有 / 放置关系
- `影片质感`：当前项目已确认的影调、色彩、电影感、空气感和融合结果

## 2. 纯 AI 镜头模式
当镜头不再使用原视频人物身份与摄影时：
- `@角色` 负责角色身份、五官、脸型、肤色、体型、发型与妆造
- `@角色服装`、`@固定配饰 / 妆造附件`、`@道具` 分别继续负责自己的职责域
- `/分镜图` 中已绑定的 `@分镜图` 负责当前镜头关键帧视觉校准；候选图不具备此权威
- 前后实拍镜头负责连续性边界，不要求纯 AI 镜头机械复制无效原摄影

## 3. 剧本 / Shot List
剧本、Shot List 和镜头说明负责：
- 人物关系
- 剧情语义
- 行为对象
- VFX 触发的剧情目的

它们不覆盖已经清楚存在的实拍动作与身体接触。具体规则见 `script_interpretation_rules.md`。

## 4. 冲突裁决
1. 先判断冲突发生在哪个职责域
2. 优先使用负责该职责域的素材
3. 实拍编辑模式下，`@分镜图` 和角色参考不得无故改变 `@视频` 的演员身份、动作、表演与时序
4. 用户明确要求身份替换或摄影重构时，按用户要求和逐镜例外执行
5. 不得把一个参考素材扩张到它未被授权的职责域
6. 静态提示词和视频提示词均为编译产物，不进入素材权威顺序；发生冲突时回到镜头事实卡和原始来源裁决
7. `/分镜图` 文件与原视频冲突时，视觉状态域服从用户批准的分镜图，动态 / 摄影域继续服从原视频，除非用户明确要求重构
8. `@场景` 视角与原摄影机冲突时，保留原摄影机，重投影场景几何；禁止让人物和机位迁就场景参考图
9. 已批准 `/分镜图` 若被后续证据证明摄影机角度、人物姿态或场景投影错误，必须退回静态阶段重新发布，不得将错误继续传递到视频

## 5. 片场批注
画面中的中文批注、时间码、黑底说明最终必须删除；但如果批注包含制作语义，必须先读取其含义并转译为逐镜要求，再删除像素层。
