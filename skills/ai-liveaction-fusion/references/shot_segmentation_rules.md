# 最终执行分镜判定规则

## 核心区别
不要机械认为“每次源素材变化就是一个最终分镜”。必须区分：

### 最终可见硬切
观众在最终成片中应当真正看到的剪辑切点。

### 制作拼接 / VFX 接力点
临时素材、黑边、画中画、旋转卡片、占位镜头、反光接入等制作结构。它们可能来自多个源素材，但最终应成为一个连续镜头。

### 源文件边界
只说明素材来源变化，本身没有分镜权威。

## 分镜数量权威顺序
1. 用户明确确认的最终镜头数量 / 最终剪辑意图
2. 最终应当可见的硬切
3. VFX 连续运动与画面批注所表达的无缝镜头意图
4. 源文件边界
5. 剧本段落

## 工作要求
在正式写逐镜前：
- 先记录所有可见切点
- 再逐个判断这是“最终硬切”还是“制作接力点”
- 必须看首帧、中段、尾帧
- 复杂 VFX 镜头额外检查整个运动链条，不只抽单帧
- 同一个源文件名可以在剪辑中被多次使用，不能据此合并成一个镜头
- 不同源文件也可能只是一个无缝 VFX 镜头的制作接力，不能据此强行拆镜

## 时间码规则
- 只有实际测量 / 用户提供的时间码才可写成精确值
- 未核验时不要伪造精确帧号
- 如需表达但只能粗估，应明确标注“约”或直接省略时间码
