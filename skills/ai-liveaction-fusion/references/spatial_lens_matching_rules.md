# 空间透视与镜头匹配规则

该模块解决 AI+实拍环境替换中最常见的“背景贴图感”。

摄影机角度、人物姿态拓扑、可见表面占比和场景资产重投影的完整门禁见 `camera_scene_projection_rules.md`；本文件负责投影确定后的空间、镜头与运动匹配。

## 核心目标
新环境必须像真实三维场景被原摄影机拍到，而不是把人物抠到一张漂亮背景图前。

## 一、空间分层
按镜头实际需要建立：
- 前景：靠近摄影机的墙角、门框、地面、建筑边缘、人物局部等
- 主体 / 人物层
- 中景：人物附近空间、建筑、道路
- 后景：远街、远建筑、天空、雾气、灯光

不是每镜都必须人为塞满四层，但不能让所有背景结构堆在人物后方同一平面。

## 二、透视与尺度
检查：
- 摄影机高度与俯仰类别是否由关键帧和相邻帧证据核验，而非从人物仰头 / 低头猜测
- 地平线 / 摄影机高度是否合理
- 地面 / 墙面 / 天花或天空的主次、上中下分区和近似占比是否符合机位
- 地墙交界是否处在合理位置；俯拍是否由地面主导、仰拍是否由上部空间主导
- 道路、建筑边缘是否沿真实消失关系收窄
- 近处结构尺度是否明显大于远处
- 人物与门、窗、墙、道路宽度是否比例可信

## 三、焦平面与景深
- 明确主要焦平面
- 景深随空间距离连续递进
- 近焦外 / 远焦外强度不同
- 点状灯源的散景必须符合距离与原镜头成像观感
- 禁止“整张背景统一模糊”

## 四、光圈 / 镜头结果
优先写结果：
- 大光圈浅景深
- 中等景深
- 深景深
- 焦外柔和 / 圆润
- 边缘不过锐

只有用户 / 元数据明确给出真实参数时，才需要写具体焦距、F / T 值。

## 五、摄影机运动与视差
### 推进
近景边缘更快向两侧扩张 / 退出，远景变化较慢。

### 后拉
新的近景结构可逐渐进入，近层相对位移明显，远层变化较慢。

### 横移 / 跟拍
近景横向位移大，中景次之，远景最小。

### Tilt / Pan
必须体现真实取景方向变化、地平线 / 地墙交界移动和可见表面占比变化，而不是整张背景位置动画。

## 六、环境动态
背景不能完全冻结。按场景实际选择低幅度自然动态：
- 薄雾 / 湿气缓慢流动
- 烛火 / 壁灯光晕轻微波动
- 远处布料 / 植物轻风运动
- 雨雪 / 粒子
- 地面反射随摄影机角度与遮挡自然变化

动态必须克制，不得为了“真实”让背景喧宾夺主。

## 七、空间锚点与景别冲突
“角色在塔楼顶部 / 教堂门口 / 屋顶边缘”等是空间事实，不等于建立镜头要求。

如果原视频是近景：
- 保持近景
- 用局部塔顶 / 门框 / 屋檐结构证明位置
- 不要为了完整展示地标而拉远摄影机

## 八、失败特征
以下任一出现时视为镜头匹配失败：
- 背景像二维海报
- 人物移动而背景无视差
- 所有背景同一清晰度 / 同一模糊度
- 人物与建筑比例不可信
- 地面没有透视收缩
- 摄影机移动时环境整体同步平移
- 背景完全静止、灯光与雾气没有任何自然呼吸
- 俯拍镜头仍由高墙、高窗或立柱正面主导，地面占比明显不足
- 仰拍镜头出现无依据的大面积地面
- 场景资产原视角覆盖原摄影机角度
- 人物关键关节、接触点或前后遮挡被重新安排
