# 静态分镜提示词规则

## 1. 目标

静态分镜不是概念图，而是后续视频阶段的候选关键帧。它必须最大限度继承原实拍的身份、摄影、构图、表演瞬间和空间关系，只替换目标世界。

## 2. 编译输入

只从以下输入编译：
- 镜头事实卡的静态视觉字段；
- 镜头事实卡中的镜头—场景投影字段；
- 当前关键帧原图；
- 素材职责地图；
- 用户已确认的项目影片质感；
- 已核验的连续性状态。

视频提示词此时尚未产生；静态提示词直接从镜头事实卡编译。任何已存在的提示词都视为下游产物，不参与新项目事实建立。

## 3. 固定结构

严格使用：
1. `# 图像编辑指令`
2. `# 当前素材锁定`
3. `# 画面质感`
4. `# 单帧画面`
5. `## 构图与景别`
6. `## 背景与空间`
7. `## 空间透视与镜头匹配`
8. `## 光源与融合`
9. `## 最终画面`
10. `## VFX`

不新增同级栏目，不把动态过程写进单帧画面。

## 4. 原图权威

原图默认唯一负责：
- 原演员身份、五官、脸型、肤色、体型与比例；
- 当前帧构图、景别、机位、透视、人物占比与裁切；
- 当前表情、口型、视线、姿态、接触和遮挡。

参考人物图不得替换原演员脸；服装图不得改变原姿态；场景图不得反推机位。

原图姿态不只用自然语言概括：记录头、肩、肘、手、髋、膝、脚的屏幕空间位置，主要关节弯曲、人物轮廓、接触点、受力点和前后遮挡。人物仰头 / 低头不等于摄影机仰拍 / 俯拍。

## 5. 参考图最少充分原则

每张参考图写明“负责 / 不负责”。只选择当前帧真正需要的素材：
- 单人近景通常只需要原图、人物妆造、服装结构、当前可见场景方向；
- 不可见的长外套下摆、完整建筑或后续 VFX 状态不必绑定；
- 同一职责只保留一个最高权威；
- 与当前镜头方向冲突的场景图必须明确排除；
- 场景图必须标记其视角职责：同方向权威、仅拓扑、仅材质或当前方向排除；
- 风格试生图、旧 Take 或未经用户确认的图片不得自动成为权威。

生成前读取当前工具的参考图数量、格式和尺寸上限。超过上限时不得静默删图；先保留唯一编辑底图，再按当前可见画面的场景方向、主角完整状态、其他可见人物状态、关键道具 / VFX 排序。若仍不能覆盖关键职责，使用经过核验的同职责拼图、分步编辑或标记阻塞，不得让模型自行补猜。

## 6. 静态化规则

从动态镜头选择关键帧时：
- 固定一个可见瞬间，不描述“随后、逐渐、最终、继续”等时间过程；
- 动态运镜只用于解释当前帧为何是该景别，不要求在单图中表现整段运镜；
- VFX 只写当前帧已经成立的状态；
- 后续状态不提前生成，之前状态只保留仍应连续存在的残留。

## 7. 背景与空间

先根据精确关键帧和同镜头前后邻帧判断摄影机高度、俯仰和朝向，再判断人物位于场景哪一层、镜头射线主要落到哪类表面。必须写：
- 当前可见背景；
- 承托面 / 地面；
- 近中远层；
- 地面 / 墙面 / 天花或天空的主次、上中下分区和近似占比；
- 地墙交界 / 地平线是否入画及位置；
- 必须排除的错误方向和结构。

若素材不能直接提供当前方向，可使用原视频相邻帧、画中参考或项目空间拓扑作为证据，并标记来源；不得用最相似的场景图硬套。

明显俯拍时，背景通常应由地面主导，竖直墙面压缩到画面上沿或侧边；明显仰拍时，上部墙面、天花 / 天空主导。候选图若反转该关系，直接判定为投影失败。

## 8. 服装结构

换装必须写三维几何结构、领口、翻领、肩线、层次、扣件与穿着关系。不得只写材质替换或改色。服装结构服从原演员身体、姿态和当前裁切。

每个可见人物都必须有状态锁定，即使只是越肩、前景局部、背景人物或不是本轮修改目标。返修某个角色、背景或 VFX 时，提示词须列出其他可见人物已经正确且必须保持不变的身份、服装几何、妆造、配饰与剧情状态。

## 9. 用户确认门禁

默认先交付：
- 完整静态提示词；
- 参考图文件列表；
- 每张图的职责；
- 明确排除项。

用户确认后才调用生图工具。用户已经明确要求“直接生图”时可视为当次确认。

## 10. 候选图审查与返修

审查真实结果：身份、构图、口型 / 表情、人物姿态 / 接触拓扑、摄影机角度、主导可见表面、地墙交界、空间方向、承托面、服装结构、光源、材质、VFX 和文字清除。

单变量返修时，可把正确 Take 作为编辑底图，只改失败域。例如背景错误但人物和服装正确，则锁死主体，只替换背景。返修图仍是候选图，不自动发布到 `/分镜图`。
