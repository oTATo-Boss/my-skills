# 镜头事实与提示词血缘规则

## 1. 唯一中间真相

镜头事实卡是静态分镜提示词和视频提示词的共同上游。提示词是编译产物，不是事实数据库。

## 2. 来源优先级

按职责域裁决：
1. 用户最新明确反馈；
2. 原视频的可见摄影、表演、动作、接触、受力、口型和时序；
3. 用户确认的剧本 / Shot List / 镜头说明；
4. 场景、人物、服装、道具与特效资产各自职责；
5. 用户批准的 `/分镜图`，只负责关键帧视觉状态；
6. 合理推断。

静态提示词和视频提示词都是镜头事实卡的下游编译产物，不进入来源优先级，也不得反向充当事实证据。

## 3. 事实状态

每条关键事实标记一种状态：
- `已核验`：已从原视频 / 文件直接确认；
- `用户确认`：用户明确纠正或批准；
- `推断`：为完成画面而做的可解释推断；
- `待确认`：缺失信息会显著改变结果。

同时记录来源文件、时间码、帧、资产文件或用户确认记录。

## 4. 静态与时间字段

### 静态视觉字段
- 关键帧时间码与选择理由；
- 构图、景别、机位方向、人物占比、表情 / 口型瞬间；
- 当前可见背景、承托面、空间方向与必须排除项；
- 前中后景、焦平面、景深与尺度；
- 角色、妆造、服装、配饰、道具当前状态；
- 当前光源、材质和 VFX 状态。
- 镜头—场景投影：证据帧、摄影机高度 / 俯仰 / 朝向 / roll、人物屏幕空间姿态与接触拓扑、主导可见表面、上中下分区、地墙交界 / 地平线、资产表面映射与排除项。

### 时间运动字段
- 镜头时长与帧率；
- 摄影机运动；
- 人物动作轨迹与节奏；
- 接触、受力与动作相位；
- 开始、中段、结束状态；
- VFX 触发、峰值、残留与跨镜连续性。
- 首 / 中 / 尾帧的摄影机角度、主导表面、地平线 / 地墙交界和场景投影变化。

静态分镜提示词不得把时间字段改写成新的动作；视频提示词不得遗漏时间字段。

## 5. 新项目事实建立算法

1. 读取剧本 / Shot List，提取剧情目的、人物关系、场景需求、行为对象与 VFX 意图。
2. 分析原视频及原声，按硬切和叙事单元划分镜头，核验每镜首帧、中间帧、尾帧、动作、口型、接触、运镜与可见批注。
3. 建立资产职责地图与场景拓扑，分别确认场景各表面、原视角、邻接关系，以及人物妆造、服装、配饰、道具和 VFX / 质感资产负责什么、不负责什么。
4. 为每镜建立镜头—场景投影：区分摄影机角度与人物姿态，记录人物屏幕骨架 / 接触、地面 / 墙面 / 天花或天空占比、地平线 / 地墙交界和资产重投影。
5. 按职责域协调剧本、原视频、资产和用户确认的项目要求，冲突项回到来源权威规则裁决。
6. 为每个镜头建立事实卡，记录静态视觉字段、时间运动字段、投影字段、来源和状态。
7. 只从镜头事实卡的静态视觉字段与投影字段编译静态分镜提示词。
8. 用户筛选候选图并发布到 `/分镜图` 后，从镜头事实卡的静态、投影与时间运动字段加已批准分镜图编译视频提示词。
9. 用户纠正任何事实后先更新镜头事实卡，再使受影响的静态提示词、绑定与视频提示词失效并重新编译。

## 6. 血缘失效规则

以下变化必须使下游静态提示词、候选图绑定或视频提示词回到待更新状态：
- 用户修改场景方向、承托面、人物身份、服装结构或关键 VFX 状态；
- 用户修正摄影机俯仰、人物姿态 / 接触拓扑、主导可见表面、地墙交界或场景资产视角映射；
- 关键帧改变；
- `/分镜图` 中权威文件被替换；
- 原视频时间码映射被修正；
- 素材职责地图发生冲突修正。

不得只改一份下游提示词而保持镜头事实卡错误。
