# 镜头—场景投影分析规则

该规则位于镜头事实卡与静态 / 视频提示词之前，解决“场景身份正确，但背景角度、可见表面和人物姿态错误”的问题。

## 1. 强制门禁

每个实拍编辑镜头先建立镜头—场景投影字段，再编译静态或视频提示词。以下任一未确定时，不得直接生图或编译最终视频提示词：

- 摄影机高度与俯仰类别；
- 人物屏幕空间姿态、遮挡与接触拓扑；
- 当前机位主要看到地面、墙面、天花 / 天空中的哪一类表面；
- 场景资产中的几何表面如何映射到当前机位；
- 会改变主导背景表面的高影响不确定项。

## 2. 分析证据

### 静态分镜

不得只看一张关键帧。至少核验：

- 精确关键帧；
- 同一硬切镜头内的前邻帧与后邻帧；
- 若关键帧缺少地面 / 墙线证据，再查看同机位或同布景的更宽镜头。

相邻帧只用于判断摄影机、遮挡、人物姿态和场景方向；最终静态图仍锁定精确关键帧。

### 视频镜头

至少核验首帧、中段帧、尾帧及摄影机运动段。记录：

- 摄影机高度、pitch / yaw / roll 是否变化；
- 地平线、地墙交界、消失点和可见表面占比如何随时间变化；
- 人物骨架、接触点、遮挡与画面占比如何变化；
- 近中远层视差是否证明摄影机在移动，而非人物单独移动。

## 3. 摄影机与人物姿态必须分开判断

人物仰头、低头、弯腰或倒地不等于摄影机仰拍、俯拍。摄影机角度必须综合以下证据：

- 是否看见头顶、肩顶、道具顶面、家具顶面或地面大面积展开；
- 垂直线与水平线的收敛方向；
- 地墙交界和地面纹理的透视压缩；
- 前景人物对后景人物的遮挡高度；
- 同镜头相邻帧中的视差与背景揭露；
- 同机位宽镜头或现场几何证据。

同时建立人物屏幕空间姿态拓扑：头、肩、肘、手、髋、膝、脚在画面九宫格中的位置；主要关节弯曲方向；身体轮廓；人物间接触点、受力点与前后遮挡。生成结果不得用“更自然”的新姿势替换这些事实。

## 4. 场景资产先拆成三维世界，不直接当背景板

逐个场景资产记录：

- 可确认表面：地面、墙面、天花 / 天空、门窗、柱、楼梯、家具与固定道具；
- 邻接关系：哪面墙连哪段地面，门窗位于哪一侧，正反向如何衔接；
- 材质与尺度：石板、木地、墙高、门宽、窗高等；
- 固定光源及方向；
- 资产自身视角：只作为“该图片看见了什么”的证据，不自动成为当前镜头视角；
- 视角置信度：同方向权威 / 拓扑证据 / 材质参考 / 不可用于当前方向。

场景图定义世界身份与拓扑。只有它与原摄影机方向、机位高度和俯仰一致时，才可作为直接视角参考；否则必须把几何表面重新投影到原摄影机。

## 5. 门、窗与空间边界拓扑

当镜头包含门口、门槛、拱洞、车门、窗洞或其他连接两个空间的边界时，不能只写“人物在门口”。逐镜必须记录：

- 边界平面：门框 / 门槛在画面中的位置、朝向、厚度与开启方向；
- 摄影机侧：摄影机位于室内、室外、边界线上或哪个相邻空间；
- 人物侧：每个可见人物的双脚、躯干和头部分别属于哪一侧；
- 越界状态：尚未进入、部分跨过、完全进入、正在离开；
- 背景归属：每个人物轮廓后方的射线应落到室内、室外还是门洞侧壁；
- 遮挡证据：门框应遮挡身体哪一部分，人物是否遮挡门槛或门扇；
- 正反打关系：反打时摄影机侧和背景方向必须随真实机位翻转，建筑和道具不能只做左右镜像。

“站在门外”意味着人物空间归属仍在室外；即使头肩出现在门洞中央，也不能默认人物已经进入。若原图只证明上半身位置而看不到脚，须结合相邻帧、接触阴影、门框遮挡和剧情连续性判断，并记录置信度。

## 6. 可见表面占比与画面分区

只对人物未遮挡的背景区域估算，可使用定性描述或近似区间：

- 极端俯拍 / 顶视：地面通常占背景约 70%–100%，墙体只可能出现在边缘或画面顶部窄带；
- 明显俯拍：地面通常为主导表面，约 50%–85%，竖直墙面被压缩到上沿或侧边；
- 平视：竖直墙面 / 门窗通常占主导，地面多位于下部窄带；
- 明显仰拍：上部墙面、天花、屋檐或天空主导，地面极少或不可见。

这些区间是检查启发式，不替代实际画面证据。每镜必须写明：

- 上 / 中 / 下三区分别主要是什么表面；
- 主导背景表面及大致占比；
- 地墙交界或地平线是否入画、位于哪里；
- 允许出现的场景锚点；
- 因机位不可能出现的结构。

例如：高机位明显向下俯拍时，人物背后大部分射线应落到地面；若候选图仍在人物头后铺满高墙、立柱和高窗，而原图没有对应证据，视为投影硬错误。

## 7. 镜头—场景投影字段

镜头事实卡至少记录：

- 证据帧：关键帧、前邻帧、后邻帧、辅助宽镜头；
- 摄影机：高度、俯仰类别、yaw / roll、是否运动、置信度；
- 人物姿态拓扑：关键关节屏幕位置、轮廓、接触、受力、遮挡；
- 表面分布：地面 / 墙面 / 天花或天空的主次、近似占比、九宫格位置；
- 透视：地平线 / 地墙交界、消失方向、地面纹理收缩；
- 场景映射：使用哪些资产表面，如何重投影，哪些资产视角明确排除；
- 空间边界：摄影机侧、人物侧、门槛平面、越界状态、门框遮挡与各人物背后空间；无边界时写“无”；
- 静态时刻：当前关键帧的固定投影结果；
- 视频时序：首 / 中 / 尾帧表面分布与摄影机运动响应；
- 不确定项：来源、影响和是否必须用户确认。

## 8. 静态提示词编译

- `构图与景别`：写摄影机高度、俯仰类别和人物屏幕空间姿态拓扑。
- `背景与空间`：写主导可见表面、上中下分布、近似占比、允许与禁止结构。
- `空间透视与镜头匹配`：写地平线 / 地墙交界、消失关系、地面纹理收缩、尺度、遮挡与景深。
- 存在空间边界时：写清摄影机侧、人物侧、门框遮挡、人物是否越过门槛以及人物轮廓后方应出现的空间。
- `VFX`：只写替换和清理操作，不在此补救错误机位。

若场景资产是平视图而原图为俯拍，提示词必须明确“只借用资产的材质与拓扑，禁止复制资产原视角”。

## 9. 视频提示词编译

视频阶段从原视频恢复时间运动字段：

- 静止摄影机：主导表面和地平线位置应稳定，只随人物遮挡变化；
- tilt / pan：记录取景方向变化以及地面、墙面、天花在画面中的占比变化；
- 推进 / 后拉 / 横移：不同距离表面产生真实视差，地面纹理收缩连续；
- 手持 / 稳定器：允许低幅微动，不允许背景角度漂移或墙地关系跳变；
- 已批准 `@分镜图` 若与投影卡冲突，必须退回静态阶段，不得用视频提示词强行补救。
- 门槛动作：逐时段保持脚、躯干、头部与边界的空间归属连续；只有原视频或用户要求明确发生跨越时，人物才能从一侧进入另一侧。

## 10. QC 硬失败

以下任一出现即判定失败，不作为审美差异放行：

- 俯拍镜头被生成成平视 / 仰视背景，或背景仍由高墙主导；
- 仰拍镜头出现无依据的大面积地面；
- 地墙交界、地平线或消失方向与原摄影机矛盾；
- 场景资产原视角覆盖了原图机位；
- 人物关键关节、轮廓、接触点或前后遮挡被重排；
- 视频中背景表面占比、地平线或场景方向无原因漂移；
- 正反打使用同一背景方向或场景锚点左右翻转。
- 门外人物被生成成已经进入室内，门内人物被放到室外，或门框 / 门槛遮挡与人物空间归属矛盾；
- 修正主角或背景时，其他可见人物的身份、服装、妆造、配饰或剧情状态发生无依据回退。

返修时先修投影或姿态中的一个主变量，并锁定其余已正确域。
