# 参考素材可用性规则

## 运行时句柄
`@场景`、`@角色`、`@服装` 等可以是用户实际生视频时才绑定的运行时句柄。

这里的“运行时句柄”是提示词中的语义引用，不代表生成平台已经建立真实 mention / token。纯文本 `@句柄`、素材已上传 / 可选、正文真实 mention 已绑定、任务已提交生成必须分开记录；平台落地时读取 `platform_asset_binding_rules.md`。

`@分镜图` 必须对应用户已经筛选并保存在 `/分镜图` 的真实文件。候选图目录、聊天中出现过的图片、旧 Take 和只存在于文字中的句柄都不得自动视为正式分镜图。

## 当前对话中没有实际素材时
Agent 可以：
- 保留准确的 `@句柄`
- 使用用户此前已经确认的描述
- 对场景 / 角色等未上传素材写职责型约束
- 对 `@分镜图` 只能在绑定清单已存在时引用实际句柄；否则把镜头标为 `待补分镜图`

Agent 不可以：
- 声称已经看过未提供的素材
- 猜测其颜色、结构、构图、服装细节或光影
- 为了填满模板而虚构素材内容

## 何时需要追问
只有当缺失的视觉信息会直接改变：
- 角色 / 服装映射
- 场景身份
- 当前镜头空间关系
- 项目光影标准
- 关键 VFX 设计

才需要向用户确认；否则保留句柄并继续执行。

## 句柄原样保留
用户提供的句柄必须保持原始拼写、空格、下划线与大小写，不得自行重命名或标准化。

## `/分镜图` 发布与本地映射门禁
- Agent 默认只读 `/分镜图`；
- 不得自行把候选图复制 / 移入该目录；
- 用户明确指定文件并要求发布时，才可执行对应文件操作；
- 视频提示词编译前必须建立“分镜 ID → 文件 → @句柄”本地映射清单；该清单不证明平台正文 mention 已绑定。
