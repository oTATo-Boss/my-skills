# 按需方案比较

仅在用户要求比较方案，或关键方向确有不确定性时使用。普通精修直接修改。
明确一个待决定问题、真实内容、现有 token 与评价标准。先完成少量实质不同的方案；数量按不确定性和预算决定。
把每个方案放在相同内容、尺寸和状态下比较，保留截图与简短差异说明。动效用实际播放或帧序列比较。
以任务完成、设计一致性、可读性和实现成本逐项判断；避免用方案名字、作者或生成顺序作为偏好依据。
选定后在实际代码中实现并验证，不把静态 mock 的优胜等同于生产代码完成。
现有单代理可顺序完成。不需要作者的私有运行器、指定模型、付费网关、十方案循环或每个圆角单独竞赛。
如果用户明确授权多人并行，才选择当前可用子代理机制；提交、合并、部署沿用本次实际授权。
