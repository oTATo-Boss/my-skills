# 从目标推导视觉方向

用受众、内容、品牌、使用频率和参考建立方向。可分别调整布局表达强度、动效强度与信息密度，不要求固定数值。
产品工具优先扫描、操作与状态；品牌展示可强化图片、字形与构图。已有设计系统或明确参考优先于个人偏好。
选择一个可辨识的主视觉组织方式：编辑式不对称、严格网格、媒体主导、密集操作面板、纸感阅读或简洁产品展示。
统一字体角色、内容宽度、间距、颜色语义、表面层次与图标语言。避免只靠更换颜色重复同一套版式。
首屏重点、标题长度与媒体尺寸一起规划，用真实文案测量，不强制两行标题或某种 hero 高度。
对后续区块安排内容密度和媒体节奏，避免所有内容都包装成相同卡片；确有同类比较时可以采用规则网格。
已有项目采用渐进调整：优先信息层级、排版、间距、素材质量和状态，只有明确授权时改变导航或整体结构。
字体、主题、渐变、侧栏、圆角与某个前端框架都不是普遍禁令。用与用户目标相关的证据决定。
