# Asset Generation

以当前简报为依据补齐真正缺少的素材。已有素材足够时直接使用，用户只要提示词时交付提示词并停止。

## 独立使用的输入契约

需要目标/简报、所需素材或片段、已有文件位置。执行生成还需要实际服务能力、规格、素材权利和当前费用/上传等授权；缺其中一项时先完成离线计划，暂停依赖它的动作。

可读取用户提供的项目配置中的身份、素材、生成、视频、声音和工具字段。没有共享配置也可用请求中的对应信息；不得借用其他项目凭据或固定环境路径。配置里的预算不是授权。

## 工作方法

1. **盘点并查看。** 核实真实素材、身份特征、参考职责和使用权；把身份与风格分开。见 [身份与来源](references/identity-and-sources.md)
2. **补最小缺口。** 用实际可用的工具生成/编辑需要的图片，保留原文件；先检查图片能否支持关键动作，再投入视频生成
3. **写可执行提示词。** 说明事件、变化、参考职责、段内时间、衔接与声音；名称和真实文件/上传槽位对应。规格不硬编码，见 [生成与可靠执行](references/generation-and-execution.md)
4. **按授权执行。** 核实当前官方接口与能力，先离线验证，再提交一次并保存任务 ID。未知提交状态不能盲目重试或追加付费批次
5. **验收源素材。** 核实文件与实际规格，按可用能力检查画面、运动、声音及关键动作。生成成功不等于素材合格，也不等于完整作品完成

## 输出与停止条件

交付实际文件、来源/权利记录、参考映射、提示词、真实任务状态和已知用量，以及可用范围和缺陷。把秘密与含访问凭据的 URL 排除出交付和日志。

达到请求的素材数量与范围后停止；不自动新增批次。执行受阻时交付可用部分并准确标注“未生成”“状态未知”或“未视听验证”，不制造假文件或把等待超时当任务已取消。需剪辑和完整成片时交接制作阶段，不以若干原片冒充成片。
