# Asset Generation

以当前简报为依据补齐真正缺少的素材。已有素材足够时直接使用，用户只要提示词时交付提示词并停止。

## 独立使用的输入契约

需要目标/简报、所需素材或片段、已有文件位置。执行生成还需要实际服务能力、规格、素材权利和当前费用/上传等授权；缺其中一项时先完成离线计划，暂停依赖它的动作。

可读取用户提供的项目配置中的身份、素材、生成、视频、声音和工具字段。没有共享配置也可用请求中的对应信息；不得借用其他项目凭据或固定环境路径。配置里的预算不是授权。

## 角色资产交接

角色长相建立、面部与全身综合参考板、服装提取/设计、换装妆造和剧情状态裂变使用 `character-design`；本技能负责简报、其他素材及生成交接，不另建角色流程。完整角色资产必须同时具备清晰面部、半身与全身信息；具体镜头是否只取部分输入由R2V决定。复用已有确认结论，按character-design所选路径执行：快速整板不强制中间肖像/样衣；分阶段制作遵守肖像和新造型两处确认节点。

## 视频资产与镜头画面的边界

已有角色、场景、道具足够且当前入口支持对应参考时，直接交接参考资产与视频提示词；不为了进入视频阶段而先生成双人构图、分镜图或完整镜头首帧。多角色、眼神关系、站位和连续表演本身不是补图理由，优先用文字明确角色绑定、动作先后与相机要求；需要选型时使用 `r2v`。

补图只解决明确的资产信息缺口，例如面部参考补必要全身/侧背视角、角色换装、场景延伸或重要道具。每项写清“缺少什么 → 影响什么 → 最小补充 → 验收标准”，继承原身份、结构与质感；三视图和场景扩展均按实际需要制作。

完整镜头图仅在用户要求锁定具体画面/端点、所选入口必须使用端点，或已有参考与文字不足以解决具体控制问题时制作，并说明必要性及其将作首帧、尾帧还是普通参考。入口限制与目标路线冲突时先评估可用替代入口，不把先合成静帧作为默认补救。讨论用分镜图不自动上传作视频输入。

## 工作方法

1. **盘点并查看。** 核实真实素材、身份特征、参考职责和使用权；把身份与风格分开。见 [身份与来源](references/identity-and-sources.md)
2. **补最小缺口。** 先确定视频生成方式与参考职责；无缺口则跳过生图。有缺口才用可用工具生成/编辑必要资产，保留原文件，检查身份、可见结构、材质和相关视角；不要求把关键动作先画成完整镜头
3. **写可执行提示词。** 说明事件、变化、参考职责、段内时间、衔接与声音；名称和真实文件/上传槽位对应。规格不硬编码，见 [生成与可靠执行](references/generation-and-execution.md)
4. **按授权执行。** 核实当前官方接口与能力，先离线验证，再提交一次并保存任务 ID。未知提交状态不能盲目重试或追加付费批次
5. **验收源素材。** 核实文件与实际规格，按可用能力检查画面、运动、声音及关键动作。生成成功不等于素材合格，也不等于完整作品完成

## 输出与停止条件

交付实际文件、来源/权利记录、参考映射、提示词、真实任务状态和已知用量，以及可用范围和缺陷。把秘密与含访问凭据的 URL 排除出交付和日志。

达到请求的素材数量与范围后停止；不自动新增批次。执行受阻时交付可用部分并准确标注“未生成”“状态未知”或“未视听验证”，不制造假文件或把等待超时当任务已取消。需剪辑和完整成片时交接制作阶段，不以若干原片冒充成片。
