# Social Media

一个 Skill 管理社交内容从策划到交付与分析。先识别当前目标、真实输入与交付终点，只加载必要阶段。以下为包内方法文档，不是独立 Skill，不需要发现、安装或调用旧六个入口。

## 阶段选择与执行

| 用户目标 | 按需读取 | 交付 |
|---|---|---|
| 参考研究、创意、脚本分镜 | [策划](references/content-planning/workflow.md) | 创作简报与素材需求 |
| 整理资产、补图、提示词、生成原片 | [素材](references/asset-generation/workflow.md) | 素材、来源与检查记录 |
| 剪辑、声音、完整成片、封面 | [制作](references/content-production/workflow.md) | 成片、封面与验收限制 |
| 标题正文标签、待发布文件夹 | [发布交付](references/publishing-delivery/workflow.md) | 文案与逐篇待发布材料 |
| 后台导出、表现比较、实验建议 | [数据分析](references/performance-analysis/workflow.md) | 同口径分析与可检验建议 |

读取选中阶段的完整方法，再按需读取其相邻参考文档。多个阶段时在本 Skill 内顺序推进，交接目标、锁定规格、真实文件、来源和检查结果。

## 共通规则

- 最小输入是当前目标、已有材料的位置和交付终点；已知内容不重复询问。可选配置见 [配置说明](shared/config-guide.md) 和 [模板](shared/project-config.template.yaml)，项目取值不写回本包。
- 新内容通常策划、补必要素材、制作、整理发布材料；资产足够就跳过生成。只要提示词、剪辑、封面、文案或分析时，停在对应结果。
- 已定稿视频仅补发布材料时保留视频字节及原音轨；缺封面才进入制作阶段。不自动重剪或重生。
- 人物建立、服装妆造及状态裂变按需使用 character-design；视频参考方式按需使用 r2v。核实工具能力和入口，不能声称调用了不可用技能。
- 阶段串联和项目配置不额外授权付费、上传、登录、发布、运营或持续监测；依照当前用户授权与环境权限执行。受阻时继续不依赖该动作的工作。
- 不浏览用户个人点赞、收藏的作品列表。后台聚合点赞和收藏数可按当前分析范围使用。
- 证据、推断与创作选择分开；技术检测、实际看画面和实际试听分开报告。未运行、未生成、未试听不写通过。
- 默认交付普通文件夹，压缩按实际传输需要。达到用户的数量与范围后停止，不追加批次。
