# 后台数据契约

## 采集前确定边界

明确账号/平台、分析问题、日期范围和最小所需字段。优先已授权连接、官方导出或用户提供的截图/文件；能力不足时说明哪部分缺失，不以抓取其他私有数据或更改账号设置补足。

保留原始导出不覆盖；转换后的工作表与原始来源可对应。截图记录页面、筛选条件、截取时间及可见范围，模糊字段标未读清。分页、筛选、时区和指标延迟可能改变总数，采集后检查是否遗漏或重复。

只收聚合数据和分析所需内容信息；没有任务需要就不收个人观众身份、联系方式或完整评论者名单。不浏览用户的点赞/收藏作品列表。

## 最小数据字典

按任务实际可得字段记录，缺项标为未知，不为了完整模板制造数据：

- 平台、非秘密账号引用、内容 ID/可用链接、标题或简短内容类型
- 发布时间及平台时区，数据提取/截图时间及其时区
- 指标对应区间起止、区间边界定义、发布后经过时长
- 每个指标原名、定义、单位、来源位置、是否延迟或估计
- 累计值、滚动窗口值、固定日期区间值或某次快照，四者明确区分
- 唯一人数/次数、曝光/播放/有效播放、总时长/平均时长、完成数/完成率等具体定义
- 每个比率的分子、分母与适用样本；平台已给的比率保留其定义
- 置顶、付费推广/投放、审核/违规/可见性提示、修改/重发/删除等可见状态和时间
- 片长、形式、主题、封面/标题版本及分析所需创作特征；事实与人工标注分开

看不到定义就写“平台展示指标，详细口径未核实”，不能自行补成熟悉平台的定义。不同平台同名指标也可能不同，不能只凭列名合并。

## 时间与增量

报告明确使用的数据时间，不把发布日期、报表筛选日期和提取时刻混为一谈。“本周表现”应说明是本周发布内容的累计表现，还是所有内容本周获得的新增表现。

对同内容、同指标定义且无口径切换/重置的两次累计快照，可以用后值减前值得到两次提取间的观察增量。它不自动等于完整自然日或发布后固定窗口的增量；负值可能来自校正/删除，先核对，不能静默归零。

滚动窗口的差值不是这段时间新增量：旧数据退出窗口、新数据进入窗口会同时发生。只有最新累计值时不能反推出昨天、首日或固定发布后窗口的表现。

发布日期只有“日”而无精确时刻时，不制造精确发布后小时数。时间范围跨时区先统一或明确保留原区间；夏令时和平台日界线有影响时核实。指标可能尚在更新，注明提取时刻和成熟程度。

## 比率与缺值

- 互动率、关注转化率等先声明分子和分母；分母未知或为零时不计算有效比率
- 点赞/收藏/评论等动作计数不一定代表去重人数；相加得到“动作率”不能叫“参与用户占比”
- 平台显示的完成率可能不是可见完成数除以可见播放数；无定义不强行重算
- 比较平均观看时长需考虑片长；平均观看占片长比例也不是平台定义的完成率
- 汇总比率通常从适配的总分子/总分母重算，不能未经说明直接平均每条百分比
- 缺失、不可用、延迟、被隐藏和零是不同状态。百分比变动与百分点变化也分开表示
- 发现重复内容 ID、截断、不同单位或异常数值，先核对来源，不直接当业务事实

## 审核与曝光状态

照录平台可见的具体提示及对应帖子/时间范围；将提示事实与推测影响分开。一条审核中、违规或低曝光内容不能证明整个账号被限流/封禁，也不能证明其他内容都受影响。

有账号级明确通知才报告通知所述状态；没有则写证据不足。也不要反向保证“没有影响”。指出仍需的状态页面或对照数据，保持只读，不擅自申诉、删除或修改帖子。
