# 封面与系列设计

是否需要独立封面、画幅比例、尺寸和安全区根据内容类型与目标平台的当前显示要求确定。视频画幅与封面比例分开判断；图文首图可承担封面职责，无需额外生成重复图片。没有指定账号设计系统时先建立适合本次内容的层级，不预设固定坐标、字体、颜色或品牌署名。

## 统一设计语言，保留每篇美术

系列可共用信息层级、署名方式、视觉重点、文字与图像关系以及缩略图可读性，不必所有内容采用同一布局。用户锁定具体模板时按批准模板；自由创作时先根据本篇决定构图，再按需与历史成品校准设计逻辑，不让旧片美术替换新片。

查看真实成品，从实际帧、图片、动作、关系或信息中选择观看理由；不使用脚本里未实现的情节。封面文字与发布标题互补，也可以采用符合内容的无字封面，不强制所有作品加大字钩子。

素材不足时按需求选择抽帧、摄影、绘制、排版、生成或其他适合的方法。可以重组构图、突出真实主体与关键物件，但不新增未发生的重大剧情、不偷换产品与人物，也不提前泄露需要保留的关键回报。

制作后逐字核对文字、真实格式与目标尺寸，检查主体、重要细节和安全区。按实际平台卡片或手机缩略图大小预览，判断主信息与视觉重点能否辨认；系列并排检查共同语言与变化。透明通道不代表背景一定透明，改扩展名不代表完成格式转换。

无所需制作能力时用已有工具做诚实替代并说明差别，不声称生成了不存在的图。
