# 执行与恢复

用于异步、付费或远程制作。工具、模型、节点、规格、价格和限额从当前环境能力及官方文档核对，不内置某个提供商、应用 ID、凭据路径或固定参数。优先用户指定路线及适用的 CLI、MCP、插件，必要时再使用应用界面；已有可靠实现可复用。

提交前检查真实素材、输入映射、完整配置、输出规格、预计用量与当前授权。只提交目标所需任务，困难试验采用足以判断的规模，凭据以环境支持的安全方式使用，不进入技能、日志、提示词和交付文件。

每项任务保存输入摘要与状态，提交后立即保存任务 ID。按已保存 ID 查询到明确终态；短暂查询失败可重查，不能触发重复提交。支持幂等键时为同一提交保留并复用该键。

结果未知且没有 ID 时先核查历史或恢复接口，不凭连接错误推断未执行、未扣费。重启从已有记录恢复；超时不等于取消，取消请求不等于服务端终止，要核对实际终态。

并发由依赖、限额、预算和授权决定，不默认占满额度。失败先诊断输入、配置或服务原因，达到任务约定的质量、费用或尝试边界后停止并说明。完成后及时保存输出，核对实际媒体与规格；放大不等于原生高清，缺失用量不等于零，墙钟等待不等于计费用时，本地超时不能宣称是服务端费用硬上限。
