# 复盘与复用

没有内置旧作品、固定成功题材、封面样例或标签模板。新方向先独立选定，确需去重、校准系列语言或用户要求回看时，再按需读取当前项目实际历史材料，不为遵循技能预加载所有旧作。

把证据分开：技术检查说明文件行为；用户反馈说明该用户对当前作品的判断；实际平台数据说明某个账号、时期和发布条件下的表现。没有真实播放、互动或转化数据，不能称已证实爆款或宣称某风格能稳定增长。

有数据时先核对时间窗口、指标定义、统计单位、平台与作品范围；不同口径不直接混排。一篇表现变化不足以证明某个标签、工具或画风的因果效果，说明其他可能影响后再决定小范围试验。

记录可迁移规律，例如观看重点、动作可读性、信息发展、切点、声音和自然互动的关系，附来源和适用边界。保留成功条件，也记失效条件；不把一次认可变成以后必须重复的故事、句式、材质或声音偏好。

更新本次项目中的创意记录、素材与验收日志。修改全局技能、安排周期任务、发布或互动只按用户明确要求进行；复盘本身不授权额外制作和账号动作。
