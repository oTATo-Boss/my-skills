# 账号、素材与视觉约定

先阅读当前项目要求和实际资产。只记录影响本次决策的定位、受众、说话者、表达目标、产品事实与视觉约束；没有固定账号或品牌时使用内容目标即可，不补造创作者身份、产品或个人经历。涉及产品现状、价格或平台规则时核对当前来源，不拿旧案例当事实。

## 稳定层与自由层

稳定层来自当前批准内容，例如人物或角色的识别特征、真实产品结构、Logo与名称、事实和文案口吻。自由层可以是材质、绘画方法、渲染、维度表现、灯光、配色、摄影、节奏和叙事形式。参考图片的白底、拼图、多视图和标注通常是参考排版，不是作品必须继承的布局。

每个参考明确承担身份、构图、场景、美术、物件或动作职责。有冲突时按职责和用户指定优先级处理；风格化不等于可以偷偷改变产品或角色识别特征。用户明确要重新设计时更新当前约束，而非继续锁定旧设计。

## 素材设计与记录

只准备本篇需要的场景、对象、图片、镜头与角度。已有素材足够时直接使用；缺失部分按目标选择许可素材、图像生成、绘制、摄影或三维工具，不强制某种生图方法。查看实际文件，保留原文件，衍生版本另存。

检查主体与数量、透视、关键细节、裁切安全区和跨图或跨镜头连续性；图文还核对顺序、文字和信息准确性。素材漂亮但无法支持所需动作或表达时先调整方案，不能靠占位文件完成交付。

记录真实文件及用途。调用远程工具时再核对文件与输入槽位映射，按该接口语法转换；文件名本身不完成上传。只使用当前必要素材，不把认证、私聊或不相关文件混入生成和交付。
