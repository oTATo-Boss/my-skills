# Social Media Router

把请求送到最短必要路径，保持用户要的终点。讨论不自动变执行，补发布材料不自动重做视频，复盘数据不自动变成新一批生成。

## 最小输入

需要当前目标、已有输入的位置以及希望交付到哪一步。已在请求中明确则不重复询问。项目配置可由用户提供路径；缺配置时按被选技能的本地输入契约处理，不依赖共享目录存在。

## 路由

| 当前需要 | 使用技能 | 交接结果 |
|---|---|---|
| 找参考、定方向、写脚本/分镜 | `content-planning` | 选定简报、结构、素材需求 |
| 整理身份素材、补图、写生成提示词、生成原片 | `asset-generation` | 实际素材、来源、规格和检查结果 |
| 剪辑、声音、成片检查、制作封面 | `content-production` | 完整成片、封面、检查边界 |
| 标题正文标签、整理待发布文件夹 | `publishing-delivery` | 逐篇文件夹，无自动发布 |
| 采集/解释账号后台数据、比较内容表现 | `performance-analysis` | 同口径观察、限制、下一次测试 |

先检查环境中是否能发现对应技能，再加载其 `SKILL.md`。技能名不是工具调用，也不证明它已安装。只有完整套件存在时可定位同级目录；独立复制本路由器且技能缺失时，按上表整理清晰的阶段简报，说明缺少的能力，或用实际可用工具完成用户允许的工作；不声称执行过缺失技能。

## 串联规则

- 全新内容通常先策划，再生成必要素材、制作成片、整理发布材料；现有资产足够就跳过生成
- 已有定稿视频补材料：直接交给发布交付；缺封面才按需要进入制作技能的封面模式。保留视频字节及原声音，除非明确要求编辑
- 只做提示词、只剪辑、只做封面或只做复盘：停在对应成果，不要求跑完整流水线
- 每阶段交接目标、已锁定规格、实际文件、来源与检查结果；不把暂定方案或未验证内容升级成事实
- 受阻动作单独暂停，继续不依赖它的工作。付费、上传、登录、发布、额外重生或监测不因技能串联而自动获得授权
- 数据建议可以回到策划简报；生成新内容或持续采集需处于当前任务授权范围

最后报告实际交付、关键限制和需要用户决定的事项。普通文件夹是内容交付单位；是否压缩取决于当前传输请求，不是流程必选步骤。
