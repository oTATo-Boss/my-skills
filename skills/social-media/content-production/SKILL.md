# Content Production

依据真实素材重新组织观看体验。生成段只是原料；时长拼够、文件可播、运动流畅都不是内容完成的充分条件。

## 独立使用的输入契约

需要实际素材位置、目标/简报、允许编辑的范围和预期成果。时长、宽高、画幅、帧率、声音政策、封面要求有则读取；对会改变成片的缺项询问或先给可撤回的编辑方案，不默认为特定平台或无声片。

配置可由用户提供；无共享目录时使用上述输入。使用现场实际可用的剪辑、媒体检测及视听能力，不要求特定软件。已有定稿视频只补封面时保留视频字节与原音轨，不把制作默认值当修改授权。

## 工作方法

1. **检查来源和范围。** 核实输入及使用权，保存原始版本；完整观察可用素材，标记好动作、缺陷、信息和声音边界
2. **按真实结果剪辑。** 去掉无效等待与重复，保留必要信息、因果、反应和回报。接点服务动作、视线、节奏或明确跳跃。见 [剪辑、声音与验收](references/edit-sound-and-qa.md)
3. **单独处理声音。** 对照本项目策略、实际动作点与许可音源；既检查来源和流映射，也实际试听。没有试听能力就明确未验证
4. **核验完整成片。** 技术检测与完整视觉/声音检查分开记录；问题优先在已授权编辑范围内修复，不因缺陷自动重生付费素材
5. **按请求做封面。** 从实际成片选内容，适度海报化，继承本片视觉语言并适配项目比例。见 [封面设计](references/cover-design.md)。只要视频则不强行加封面

## 输出

用户要完整作品时交可播放的完整文件；原片、工程和分段可作附件但不能替代主成片。说明真实时长/尺寸、封面规格、关键编辑及实质限制。工作目录保存源文件对应、编辑决定、许可和检查记录；待发布文件只保留需要的成品。

只有已执行的检查才能写“通过”。未播放、未试听、只抽帧、只探测各自明确；技术通过但关键内容仍失败时不能称为完成品。需要标题文案和逐篇文件夹时交接发布交付，不自动上传或发布。
