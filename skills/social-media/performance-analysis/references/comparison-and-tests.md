# 可比分析与下一次实验

## 先选对照口径

最先回答“这些数字能不能回答当前问题”。例如同一天截取的累计播放数，发布几小时的新内容与发布几周的旧内容不能直接排名评判创意。优先同平台、同口径、相近发布后年龄或同长度观察窗，并说明剩余差异。

可比性检查包括发布时间段、片长、题材/形式、受众、投放、置顶、分发入口、账号阶段、封面/标题版本和审核状态。可用分层、匹配或明确列为例外，不默认把所有例外删掉；保留全量概览，说明过滤对结果的影响。

只有异龄累计快照时可以展示事实，但把排名标为“截至该时刻的累计规模”，不将其解释为相同机会下的质量排名。“累计播放÷上线天数”隐含稳定增长，通常只能作粗略描述，不能替代对齐发布后窗口。

## 指标沿目标解释

- 曝光/触达与播放先区分；可用时再看进入观看的比例
- 平均观看、留存曲线、完成率分别说明定义和片长影响
- 互动动作、去重参与人数、关注和点击/转化分别对应不同目标，不混成一个无定义的“效果分”
- 高比例但分母极小，和大规模下稳定的比例意义不同；始终给关键计数/分母
- 只比较有数据的环节；缺曝光、留存或转化时，不推断这些未测环节发生了什么

从原始数据到结论的计算应可复现；使用工具时保留转换与过滤说明。人工截图少量数据可手工核对，复杂表格用可靠计算并检查，不要求某个固定软件。

## 事实、解释、建议三层

**事实**：限定来源和观察窗，指出哪组在什么指标上不同，以及样本量/计数。

**可能解释**：列真正有证据支撑的机制和竞争解释。标题、题材、开头、发布时间和投放同时变了，就不能声称某一项造成结果。审核标记也只是可见状态，不是所有差异的已证实原因。

**建议**：选择成本合理、信息收益高的一个或少量变化，说明为什么值得试，而不是宣称算法必然奖励某种形式。数据不足也可给创作质量建议，但明确它来自作品观察或专业判断，并非后台因果证据。

小样本以描述和不确定性为主，不套任意“达到多少条就可信”的通用门槛。需要统计结论时，交代样本选择、独立性、模型假设、误差和多重比较问题；不凭几个成功例子使用“显著提升”“证明因果”。

## 可证伪的测试卡

为建议写下够用的字段：

- 问题和假设：哪个可观察变化预计影响哪项结果
- 只改什么、尽量保持什么；如果多项同时改，说明只能评估整组改动
- 主指标、分子/分母、必要的质量/成本等保护指标
- 对照组或匹配方式、目标平台与受众、发布后观察窗、数据提取时刻
- 足够信息的判定方法及实际可执行的观察周期；没有样本量依据时采用明确的探索性结论
- 支持、削弱或无法判断假设的条件，以及对应下一步
- 投放、置顶、审核或数据缺失出现时如何单独标记和解释

同一账号的顺序发帖通常不是随机实验，会受时间、受众和分发波动影响。把它写成有限的探索性比较；可以随机化且已授权时再考虑更强设计。不要为试验自动发布、改账号或购买流量。

## 报告与停止条件

先给最有用且可靠的发现，再给口径、数据质量限制和下一次测试。报告可以短，但必须保留会改变结论的时间/分母/样本信息。

当前数据不足时明确最小补充项，例如同一内容两次可比快照、同发布后窗口数据或指标定义。用户只要当前报告就结束；已明确要求追踪某个结果时，仅在授权范围内跟踪到约定观察窗/结果。不要借复盘名义自动开启无期限采集、发帖或生成新素材。
