# 可选深色进度面板

当用户选择这种风格时，使用 [template.html](assets/template.html) 作为静态页面起点。
视觉特点：近黑底、细分隔线、紧凑单列、等宽标签、橙色进行中、绿色完成、红色失败。
字号、密度和主题按实际用户与设备调整；标签不是强制 9px，也不覆盖项目已有设计系统。
组织概览、当前工作、进度、决定、任务队列与风险。每个状态和数字都必须来自可验证的数据。
模板只提供视觉结构。需要实时状态时明确数据来源、刷新机制和失败表现；localStorage 反馈不等于服务器持久化。
不要凭空画正在工作的 agent 或宣称自动更新。用户没有要求进度面板时，不因普通设计任务附带创建。
