# 视觉参考到前端

先检查用户选定图片和已有项目。记录页面网格、宽度、间距、字体角色、颜色、媒体比例和可见控件。
保留明确可读的真实文案；对图片未显示的信息与交互做必要推断并标明。已有参考足够时直接实现，不先重新生图。
用现有组件与样式映射参考。先建立布局和响应式结构，再校准排版、素材、表面与细节。
整体图过小可读取高分辨率原图、裁切放大或请求缺失来源；只在用户需要探索新方向时生成概念图。
检查桌面与窄屏，处理文本长度、固定媒体框、可操作状态和焦点。页面真实性不能依赖一张 UI 截图代替整个交互界面。
将实际截图与参考的关键区域比较，优先修复比例、层级和布局漂移，再调微小装饰。
