# 网页概念图

先确定页面目的、真实文案、主视觉方向、主要操作和设备范围。选择布局、字体、色彩、媒体与组件语言，再生成需要的参考。
整体概念图适合比较方向；当细节不可辨认时补充关键区块图。图片数量、横竖比例和区块数量按任务决定。
同一页面共享字体、色彩、图标、按钮与素材语言。区块之间用内容、构图与媒体节奏形成变化。
将 hero 的标题、说明、操作和媒体一起规划；首屏重点清晰，不把文字和按钮压进细小装饰标签。
真实文字应可读；生成图中无法准确表达的文案，用后续实际排版补齐。品牌、数据、评价不能凭空虚构。
用用户提供的参考约束方向，检查桌面和窄屏的构图是否可实现；生成图仅作为设计参考。
