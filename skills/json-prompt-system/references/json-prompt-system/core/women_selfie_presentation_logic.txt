women_selfie_presentation_logic

本文件用于描述女性社媒照片中的自拍呈现心理：把“她为什么会这样拍、为什么这个角度自然好看、为什么像真实会发布的照片”转成可执行动作变量。

一. 呈现心理
- 自我检查：视线像在确认屏幕里的自己，表情有短暂停顿。
- 发布前选择：姿势不是标准摆拍，而是刚调整到满意角度后停住。
- 松弛控制：身体看似随意，但重心、肩线、头偏角和手部停点有秩序。
- 轻微不对称：肩线、嘴角、视线和手指不要完全模板化。
- 镜头意识：知道镜头在，但不把每个动作都演给镜头看。

二. 可写变量
- 头部：轻偏、微低、半转、刚回看、下巴轻收或轻抬。
- 眼神：看屏幕、看镜中自己、看镜头旁边、扫回镜头附近、短暂停住。
- 嘴部：轻抿、浅弧度、微分一点、笑意没完全展开。
- 肩颈：一侧肩线轻落、颈部拉长但不僵、锁骨区域只作为上身姿态参考。
- 手部：整理边界、托腮、拢发、扶住支撑面、停在画面边缘或衣物边界附近。
- 身体：重心偏移、肩胯错位、上身轻前倾、坐姿支撑、靠姿受力。

三. 衣物边界
- 只写中性边界关系：上方边界、腰部边界、袖口边界、下摆边界、遮挡关系、接触点、牵引方向。
- 不写服装款式、颜色、材质、品牌、图案或穿搭评价。
- 当用户要求动作变量层之外的目标时，保留构图重点和手部接触关系，不写入目标本身。

四. 反模板化
- 不要每张图都强行加入扶腰、顶胯、拉边界、回头或夸张表情。
- 不要只写“自然”“好看”“有氛围”，必须落到眼睑、嘴角、头偏角、肩线、手指、支撑点和裁切。
- 不要把女性呈现心理写成抽象目的；重点是形象管理、构图吸引力和真实照片生命力。

五. 一句话标准
- 最终 JSON 应让画面像真实女性会拍、会选、会发布的社媒照片，而不是姿势说明书。
