mode_selector

当前支持的模式：

1. mirror-selfie
- 适用：
- 镜子明确存在
- 镜面关系是构图核心
- 对镜自拍、越肩镜自拍、遮脸镜自拍、镜前近拍
- 识别关键词：
- 镜子
- 对镜
- 镜中
- 越肩自拍
- 镜前

2. front-camera-selfie
- 适用：
- 明确是手持前置自拍
- 前置取景不依赖镜子成立
- 举机自拍、前置近脸自拍、前置半身自拍
- 识别关键词：
- 前置自拍
- 前置自拍
- 前置视角朝向自己
- 前摄

3. third-person
- 适用：
- 明确不是自拍镜面逻辑
- 镜头来自人物外部
- 他拍、第三视角、仿自拍姿态、被拍感画面
- 真实美女图、生活直出感、ins 感、抓拍感、封面感
- 识别关键词：
- 第三视角
- 他拍
- 非自拍
- 仿自拍姿势
- 抓拍
- 被拍感
- 生活直出
- 生活感
- 封面感
- ins
- 真实美女图

4. ecommerce-tryon
- 适用：
- 明确是电商区的模特上身效果
- 目标是商品展示 + 品牌电商高级感 + 商业成片感
- 不再是生活照动作设计，而是服装展示与镜头设计
- 展示重点、镜头母版、裁切和手部交互比人物姿态本身更重要
- 识别关键词：
- 模特上身
- 电商图
- 商拍
- 品牌感
- 大牌感
- 时尚感
- 上身效果
- 展示上方边界
- 展示肩线
- 展示袖口
- 展示上身线条
- 展示腰线
- 展示参考表面关系

5. ecommerce-clothing
- 适用：
- 明确是电商区的服装渲染效果
- 目标是服装 Ghost Mannequin / 3D 商品细节图
- 不是模特上身，不是真人拍摄，不是生活照
- 识别关键词：
- 服装渲染
- 正面立体
- 反面立体
- 侧面立体
- 45 度立体
- 上方边界特写
- 袖口特写
- 下摆特写
- 参考表面关系
- 参考图案关系特写
- 刺绣特写
- 开合结构特写
- 局部结构特写
- 厚薄感展示
- 内里展示
- 口袋展示

默认优先级：
1. 镜子明确存在且镜面关系成立：`mirror-selfie`
2. 明确是手持前置自拍：`front-camera-selfie`
3. 明确不是自拍镜面逻辑、而是第三视角人物动作：`third-person`
4. `ecommerce-clothing` 与 `ecommerce-tryon` 都不参与 AUTO 判断，只有在管理员显式选择对应电商模式时才启用

执行规则：
- 如果站点传入 locked mode / modeHint，直接使用锁定 mode，不再按关键词或图片重新选择。
- 只有 AUTO 可以执行本文件的自主 mode 判断。
- 先选 mode，再读取 mode 文件。
- 不允许在未选 mode 前直接写最终 JSON。
- 如果用户提供图片，先按图中镜头关系判断 mode，再做动作拆解。
- 若 mode 为 `ecommerce-tryon`，优先按“服装展示模式”处理，而不是按人物姿态模式处理。
