pipeline_context

本文件说明 JSON Prompt 在外层提示词与多参考图协议中的职责边界。只供 Agent 内部阅读，不得写入最终 JSON。

1. 外层通常负责：技术规格、人物/身材/手机/背景/服装参考图、完整生成协议、项目 API 字段。
2. JSON Prompt 负责：动作、姿态、镜头关系、构图裁切、表情微动作、支撑关系、衣物边界关系、手机直出质感。
3. `mirror-selfie`：外层使用固定场景参考图时，场景、环境、灯光在参考图侧已锁定；JSON 内只写镜面自拍成立所需的姿势、持机、表情、构图与物理逻辑。
4. `front-camera-selfie`、`third-person`：当无单独场景参考绑定时，可按 mode 允许范围写场景、支撑、空间与光线氛围，以辅助照片成立；仍不写人物外形、服装款式、服装颜色、服装材质、服装图案或配饰具体名。
5. 产品域边界：不属于动作变量层的目标只可转为安全的构图、边界、姿态和表情变量；不属于动作变量层的部分不写入 JSON。
6. 目标质感：普通人用生活原相机随手拍到的画面。景深按手机常见深景深理解，不写单反焦外、bokeh、HDR 光效或专业修背景。
