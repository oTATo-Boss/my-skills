detail_control_logic

这份文件用于控制人物在出图时最容易失真的细节层。
目标不是增加文学描述，而是通过可执行的细节参数，减少：
- 表情发呆
- 五官僵硬
- 手部像摆件
- 身体像 mannequin
- 过度对称
- 没有生活感的 AI 感

一. 核心原则
- 真实感来自小误差、小停顿、小缓冲，不来自大动作。
- 好看的自拍通常不是“动作完美定格”，而是“动作刚停住的一瞬间”。
- 微表情、微动作、局部细节必须互相一致，不能各写各的。
- 细节必须服务于整体画面，不单独抢主体。

二. 表情控制细则

1. 面部状态
- 默认不要写成完全静止的标准脸。
- 面部状态要有轻微流动感：
- 放松
- 轻收
- 轻提
- 轻偏
- 轻停顿
- 避免：
- 冻住
- 空白
- 完全对称
- 过满笑容
- 过强冷脸

2. 眼神控制
- 眼神默认不写成“死锁镜头”。
- 更自然的写法优先：
- 看屏幕画面
- 轻停在镜头附近
- 半聚焦
- 轻回落
- 有一点点游离
- 眼神不要同时满足：
- 过强
- 过满
- 过直
- 过空
- 避免：
- 双眼完全瞪大
- 双眼完全无神
- 机械直视
- 像证件照一样的固定眼神

3. 嘴部控制
- 嘴部默认写成轻放松，不写成模板化微笑。
- 更自然的范围：
- 轻抿
- 微松
- 很浅笑意
- 微微分开一点点
- 唇角一侧比另一侧略有差异会更自然。
- 避免：
- 完全水平僵直
- 过于标准的“AI微笑”
- 张口过大

4. 微表情控制
- 微表情不是额外表演，而是对当前动作和自拍状态的即时反馈。
- 微表情可以是自然流露，也可以是女生主动摆出来的表情管理。
- 识图时必须读懂原图里的具体微表情动作，而不是统一改写成“刚看到屏幕里自己不错”。
- 常见安全微表情来源：
- 看见自己当前角度比较顺眼
- 动作刚停稳
- 正在确认屏幕画面
- 刚整理好一个小动作
- 主动压住嘴角
- 轻垂眼或半抬眼
- 侧眼看向屏幕或镜头附近
- 下巴轻收、头部轻偏，配合当前气质
- 微表情要短、轻、收着写。
- 避免：
- 明显戏剧化
- 情绪拉满
- 多种表情信号同时出现

三. 微动作控制细则

1. 头部
- 头部默认保留很小的偏转、歪斜、轻抬或轻收。
- 不要完全摆正。
- 更自然的是：
- 角度不大
- 有一点未完全锁死
- 顺着动作方向轻微跟随

2. 肩部
- 双肩默认不要绝对对称。
- 一侧轻收、一侧略后、一侧略高，通常都会更自然。
- 肩线变化必须和动作来源一致：
- 抬手
- 偏头
- 倚靠
- 曲腿
- 支撑

3. 手部
- 手是最容易出 AI 感的位置，必须写小。
- 手部默认优先：
- 轻搭
- 轻停
- 轻托
- 轻碰
- 轻扶
- 手指默认：
- 微弯
- 松
- 不完全展开
- 不完全并死
- 避免：
- 五指完全标准打开
- 僵直兰花指
- 抓握感过重
- 手像悬空摆件

4. 身体
- 身体默认保留轻微不对称和小幅呼吸感。
- 不写成“完美中轴”。
- 微动作来源可以是：
- 重心偏移
- 倚靠
- 曲腿
- 前伸举机
- 刚停住的动作余势

四. 对称性控制
- AI 图容易过分对称。
- 默认要主动打破：
- 头部左右完全等量
- 肩线左右完全平
- 嘴角左右完全一致
- 手指左右完全一样
- 身体中轴完全笔直
- 自然好看的图通常有小偏差，但仍然稳定。

五. 局部细节控制

1. 发丝
- 发丝默认不要完美服帖。
- 可以有：
- 少量碎发
- 边缘轻贴脸侧
- 顺着动作方向微偏
- 不要写成大面积凌乱。

2. 脸侧边缘
- 脸侧、下颌线、嘴角边缘适合写成“柔和清楚”，不要写成过锐。
- 轻微压贴、轻微收放、轻微转折，通常会更像真实自拍。

3. 接触点
- 任何接触点都要写小：
- 指尖停留点
- 脸侧轻压
- 肩颈轻搭
- 腿前轻贴
- 不要写成用力按压，除非动作本身就是支撑点。

六. 好看与自然的统一标准
- 细节控制不是为了“乱”，而是为了：
- 更像真实人
- 更像真实自拍
- 更像会被保留的好看照片
- 如果一条提示词已经动作成立，但人物仍像 AI，优先补：
- 眼神停顿方式
- 嘴部细小不对称
- 头部小偏差
- 肩线不对称
- 手指松弯
- 动作未完全停死的缓冲感

七. 反向避坑
- 不要把“自然”写成“没有表情”
- 不要把“克制”写成“发呆”
- 不要把“精致”写成“过度对称”
- 不要把“好看”写成“模板化微笑”
- 不要把“吸引力”写成“情绪过满”

八. 写法原则：叙事触发优先于参数校准

生图模型是从海量真实照片中学习的。它对“一个瞬间的故事”的理解能力，远强于对“肌肉控制参数”的精确拼装能力。
因此，写提示词时必须遵循一个原则：先写瞬间感和情绪，再用参数辅助。

1. 眼神：先写“她在看什么、为什么看”，再写参数

坏写法（参数校准式）：
- “视线方向：迎向镜头方向，落在镜头附近区域”
- “眼神强度：中度偏轻，半聚焦，不做证件式死锁”
- “眼部状态：眼睑自然，略带沉静，不瞪不空”

为什么不好：
- 模型读到的是一组约束条件，它会尝试同时满足所有参数，结果就是“哪个都沾一点但什么都不像”的 AI 脸

好写法（叙事触发式）：
- “像刚从屏幕抬起眼，还没完全对焦到镜头上的那半秒”
- “像发现有人在拍自己，没慌但也没完全准备好”
- “像刚确认了这个角度不错，眼里有一点满意但嘴上不说”

为什么好：
- 模型训练数据里有大量这类瞬间的真实照片，一句叙事就能触发整套自然的面部状态
- 不需要手动指定每个肌肉参数，模型自己知道“刚抬眼”时眼睑、聚焦、视线应该是什么样

实际执行时两者结合：先写触发叙事（占主导），再用 1-2 条参数做防护栏（防止跑偏）。

2. 嘴部：先写“嘴在传递什么情绪”，再写形状

坏写法：
- “嘴唇状态：自然微松，唇缝可极轻分开一点点”
- “嘴角状态：左右嘴角略有细微不对称更自然”

好写法：
- “像刚含着一口气慢慢吐出来，嘴唇自然分开了一点”
- “像刚想笑但忍住了，嘴角只有一侧微微动了一下”
- “像在心里轻轻哼了一声，嘴角不自觉带了很浅的弧度”

关键：嘴部和眼神必须讲同一个微故事，不能眼睛在“刚抬头”而嘴在“忍住笑”。

3. 微表情：写“这个瞬间刚发生了什么”

坏写法：
- “微表情优化：像刚意识到被拍、情绪还来不及完全整理的一瞬”（方向对，但太抽象）

好写法：
- “刚把头发别到耳后，手指还没完全离开脸侧，发现镜头在拍”
- “刚调整完姿势准备按快门，身体放松的一瞬比刻意摆的那一瞬好看”
- “刚看完屏幕里的自己，觉得这个角度可以，眼神里有一点小得意”

关键：微表情的触发力来自具体的“刚刚发生了什么”，而不是来自抽象的情绪标签。
但这不等于所有微表情都必须是抓拍瞬间。女生自拍里很多微表情是主动摆出来的气质管理，写法要同时交代气质和具体表情动作。

主动表情管理的好写法：
- “眼睑轻垂，视线压在屏幕边缘，嘴角故意不笑开，形成一点冷淡的自持感”
- “下巴轻收，眼神从镜头旁边侧过来，嘴唇轻抿，像知道自己这个角度很有攻击性但不明说”
- “嘴角压着一点很浅的弧度，头轻偏，眼神更近，整体像主动摆出的娇俏感”
- “眼神不热烈，嘴部收住，肩颈线条干净，像清冷气质照里故意保持距离”

坏写法：
- 不看图像气质，统一写“刚看到屏幕里这个角度不错”
- 把冷淡脸写成甜笑，把慵懒感写成强锁镜，把清冷感写成夸张表演
- 只写“冷淡、慵懒、娇俏、自信”，不写眼睑、视线、嘴角、下巴和头部角度

4. 氛围关键词：写情绪锚点，不写摄影课笔记

坏写法：
- “第三视角私密感”“低机位轻张力”“手势前景层次”

为什么不好：
- 这是构图技术描述，不是情绪描述
- 模型训练数据中不存在“低机位轻张力”这个标签

好写法：
- “像被男朋友偷拍到的一个好看的瞬间”
- “slightly seductive, candid, effortlessly pretty”
- “安静的、克制的、让人想多看两眼的”
- “像深夜发给很亲近的人的一张自拍”

关键：氛围词要贴近真实社交媒体照片会被打的标签，而不是影评人的分析术语。

5. 心理暗示 / 成片目标：写微叙事，不写旁白评论

坏写法：
- “人物状态：放松、自我关注、带一点轻微羞怯和玩笑感”

为什么不好：
- 这是对人物状态的第三方总结，模型无法直接执行“自我关注”

好写法：
- “她刚确认完这个角度还不错，手指还停在刚拨完头发的位置，嘴角不自觉带了一点得意”
- “她不是在摆pose，是在镜子前整理自己的时候顺手拍了一张”
- “她知道自己现在很好看，但不会直说，只是多看了屏幕一眼”

关键：写一个 2 秒内发生的极短微故事，让模型自己去“拍”这个瞬间。

6. 信息权重分配原则

一条成品 JSON 中，各层信息的实际占比应该接近：
- 瞬间叙事 + 情绪方向 + 氛围锚点：约 30%
- 表情 / 眼神 / 嘴部（叙事式 + 少量参数防护）：约 25%
- 身体骨架 / 力学 / 物理逻辑：约 30%
- 构图 / 镜头关系：约 15%

当前系统的常见问题是身体力学占 70% 以上，而情绪和叙事不到 10%。
身体力学写得再精确，如果表情和氛围没写好，出来的就是“骨架正确但没有灵魂的 AI 人偶”。

九. 一句话标准
- 细节控制的目标，是让人物看起来像真实女生在某个瞬间顺手拍到的一张好看自拍，而不是被 AI 摆好的标准人像。
- 写法上，叙事触发（“她刚怎么样”）永远优先于参数校准（“眼神中度偏轻”）。
- 整体光线、色调、生活直出质感等由外层 Technical Specifications 与参考图承担，本 JSON 侧重用叙事式写法让表情和氛围活起来。
- 向「普通人生活原相机随拍」对齐：不写专业式虚化与修背景；若需压 AI 腻感，可在 `core/rule.txt` §9 允许的质感槽位**极轻**点噪点/颗粒，不抢动作与叙事。
