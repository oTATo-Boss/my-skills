original_pose_invention_logic

本文件用于无图原创任务。
目标是让 agent 根据用户意图发明一个可拍、好看、有动作母题的瞬间，而不是只写“站着自拍”。

一. 核心原则
- 无图原创必须先选一个主动作母题。
- 主动作母题只能有一个，其他动作只能辅助它成立。
- 每次原创至少确定：展示目的、主动作、曲线策略、表情策略、取景/镜头关系。
- 用户给的是气质词时，agent 要把气质词转成具体动作和表情，不要只重复气质词。
- 共享的是主动作发明能力，不共享某个 mode 的视图语义；当前 mode 已锁定时，所有动作母题必须按当前 mode 翻译。
- 同一个“轻松镜头感/慵懒/可爱反差”母题，在 mirror-selfie 下可写镜面关系，在 front-camera-selfie 下必须写画外前置视角关系，在 third-person 下必须写外部拍摄者关系。
- 禁止因为示例里出现过“对镜/镜边/持机”就把 FRONT 或 PORTRAIT 写成镜面自拍。

二. 五步发明法
1. 展示目的
- 判断用户主要想要脸部气质、肩颈、上身轮廓、腰线、髋线、腿长、整体氛围中的哪一个。

2. 主动作母题
- 选择一个最能承载用户意图的动作。
- 生活图通用母题：侧身低头确认画面、指尖停唇、单手压腰侧、整理衣物上方边界、刚转身停住、靠近画面边缘停住、遮挡停顿、拢发停住。
- mirror-selfie 翻译：把母题落到镜中手机位置、持机手路径、镜边距离和镜面回看。
- 前置自拍常见母题：靠近屏幕低头看、托脸停住、拨发停住、抱膝靠近、侧躺抬眼、手指停在下巴边。
- 他拍常见母题：刚回头、刚靠住、刚走近、刚把手从脸侧放下、刚转身停住、被叫住抬眼。

3. 曲线策略
- 决定曲线来自哪里：肩线高低差、上身结构与骨盆方向差、腰线压缩、胯线偏移、腿部一承一松、构图裁切。
- 曲线必须由主动作自然带出。

4. 表情策略
- 按 `expression_intensity_logic.txt` 选择表情档位。
- 表情必须服务主动作，例如指尖停唇适合轻松镜头感，低头看屏适合慵懒，头轻偏靠近适合娇俏。

5. 取景/镜头关系
- mirror-selfie 写镜中手机位置和持机手路径。
- 前置自拍写画外前置视角、手臂前伸和近距离关系。
- 他拍写外部镜头为什么在这个位置，以及人物为什么刚好被拍到。

三. 防普通站姿
- 如果输出只剩“侧身、重心偏移、看屏幕”，视为失败。
- 必须出现一个具体动作瞬间：指尖停唇、手停腰侧、刚整理边界、刚低头确认、刚转身停住、刚靠近镜边等。
- 不能为了丰富而堆三个以上动作；动作多会变成 AI 摆拍。

四. 职责边界
- 可以写社媒产品域边界的轻松镜头感、社媒呈现、腰胯线、上身轮廓、开放式构图和私密感。
- 不处理不属于动作变量层的目标；只把用户意图翻译成动作、表情、身体角度、构图和衣物边界变量。
- 社媒呈现要通过主动作、表情和构图成立，不通过色情词成立。

五. 一句话标准
- 无图原创必须像“一个女生正在做某个会让她更好看的小动作”，不是“一个女生站在那里被描述”。
