Image Restore Checklist

这份清单只用于“以图还原式创作”。
目标不是复述整张图片，也不是泛化成类似动作，而是尽量完美还原图片里的女性表达、视图关系、身体曲线、微表情和动作变量层信息。

一. 任务判断
- 这是不是自拍图
- 是镜前自拍、他拍感自拍、还是非自拍画面
- 如果不是自拍图，是否还能提取出可用的人物动作骨架
- 如果站点已锁定 mode，图片的原始拍摄方式只作为“需要被翻译的参考信息”，不能推翻锁定 mode。
- 锁定 FRONT：从图中提取姿势、构图、支撑点、曲线和表情，再翻译成画外前置视角或定时自拍成立的 JSON。
- 锁定 PORTRAIT：从图中提取姿势、构图、支撑点、曲线和表情，再翻译成外部拍摄者/第三视角成立的 JSON。

二. 先锁定 5 个不能丢的视觉锚点
- 视图/构图：当前 mode 的视图来源、机位距离、人物画面位置、压迫式裁切或留白关系；只能输出一个视图关系，不能把对镜、前置、他拍并列混写。
- 主体姿态：正身、侧身、半转、背身、靠近、低头、回看、贴近画面边缘或远离镜头。
- 曲线策略：肩胯错位、腰线压缩、上身结构与骨盆方向差、腿部一承一松、构图裁切造成的比例。
- 表情强度：克制、轻松镜头感、甜/娇俏、自信强表达，以及眼睑、视线、嘴部、下巴的具体动作。
- 关键手部动作：持机手位置、非持机手停点、指尖/手腕/手掌是否真实可执行。
- 这 5 个锚点比氛围词更重要；如果它们丢了，就是只剩动作骨架。
- 如果站点锁定 FRONT，视图锚点必须转为画外前置视角、手臂前伸、近距离透视和迎向屏幕的眼神，不得输出镜子、对镜、镜中或拍摄器材入画。
- 如果站点锁定 PORTRAIT，视图锚点必须转为外部拍摄者、第三视角机位、被拍瞬间和人物与镜头的位置关系，不得输出镜子、对镜、前置自拍、持机自拍或自拍拍摄器材入画。
- 如果参考图是局部近景、上半身裁切、上身近景裁切或缺少完整环境，也必须先提取可见动作锚点；不得因为缺下盘、缺完整场景或缺摄影者信息而拒绝生成。
- 对局部图只还原可见链条：裁切边界、主体姿态、上身结构/肩颈/手部/衣物边界、表情或头部边缘；缺失部分只做当前 mode 的最小合理补全。

三. 服饰锚点抽象
- 识别可见服饰/道具如何影响照片：遮挡眼神、露出肩颈、压住腰线、分割腿部比例、制造近距离私密感。
- 最终 JSON 不得写任何具体服装、穿戴、配饰、颜色、材质、图案、品牌或道具款式；包括头部/眼部穿戴、上下装、外层、鞋袜、饰品、包、可见拍摄器材外观等。
- 禁止把服装/配饰写进表情、焦点区域、头部状态、色彩、氛围、核心主色调、点缀色彩、视觉关键词等字段。
- 只能转写为中性动作变量：上方边界遮挡、衣物边界、腰线边界、腿部边界、遮挡关系、画外前置视角关系。
- 如果某个服饰/道具不是动作成立的必要原因，直接舍弃，不要转写。

四. 先读视图关系
- 是对镜、前置、他拍，还是接近哪一类
- 机位高度、拍摄距离、裁切范围、人物画面占比
- 人物是否在主动对着当前视图目标管理自己，还是被外部镜头捕捉
- 视图关系必须先定准，后续动作不得硬改视角
- 非 AUTO 任务不重新选择 mode：图片识别只能服务当前锁定 mode 的动作还原，不能把 FRONT/PORTRAIT 改写成 mirror-selfie。

五. 再读女性表达
- 这张图里的女性气质是什么：冷淡、慵懒、娇俏、自信、自信强表达感、清冷感、漫不经心，还是其他
- 拍照情绪是什么：刻意展示、随意记录、确认自己角度、冷淡自拍、慵懒自拍、轻微炫耀、清冷气质照
- 拍照目的是什么：展示脸部气质、肩颈、上身轮廓、腰线、髋线、腿长、整体氛围，还是动作状态
- 必须思考怎么写才能充分还原该女性在这张照片里的表达，不要只提取骨架

六. 再读身体曲线
- 哪里不是直线
- 有没有 S 曲线、斜线、肩胯错位、腰线拉长、髋线推出、腿部一承一松
- 头、肩、上身结构、腰、骨盆、腿之间是否形成自然错位
- 曲线来自原图已有姿态，不得为了更有曲线硬塞顶胯、扭腰或回头

七. 再读微表情动作
- 眼睛怎么摆：轻垂、半抬、侧眼、看屏幕、看镜中自己、压住眼神、轻挑还是游离
- 嘴怎么摆：轻抿、嘴角压住、单侧微动、微张、浅笑、冷淡收住还是中性
- 头怎么偏：下巴轻收、头轻歪、脸略转开、颈部是否顺着肩线拉出角度
- 这是不是主动摆出来的气质表情，而不是单纯抓拍瞬间
- 微表情必须和气质、身体语言一致

八. 再看自拍逻辑
- 哪只手持机
- 拍摄关系大概如何成立
- 拍摄关系是否和身体朝向成立
- 镜头是正拍、侧拍、越肩拍、遮脸拍还是低头拍
- 当前 mode 为 front-camera-selfie 时，只允许写画外前置视角、手臂延伸、定时自拍和迎向屏幕的视线；如果参考图双手都在做姿势，不要强行生成持机手。
- 当前 mode 为 third-person 时，不写自拍持机逻辑；只写外部镜头、拍摄者位置和被拍者如何被捕捉。

九. 再看动作母题
- 这张图的核心动作是什么
- 是拉衣摆、拢发、托腮、交叉腿、扶腰、顶胯、撑扶、背身回看、遮脸、扎头发还是别的
- 只能提炼一个主动作母题

十. 再看身体朝向
- 正身
- 侧身
- 背身
- 半转身
- 身体与镜面的关系是否清楚

十一. 再看重心与承重
- 重心落在哪条腿
- 哪条腿承力
- 哪条腿放松
- 是否有交叉腿、前后错步、脚尖轻点、微屈膝等细节

十二. 再看上半身结构
- 头部朝向哪里
- 肩线是否有高低差
- 上身结构是打开、收住还是轻微偏转
- 腰线是拉长、压缩还是中性
- 骨盆是否偏向一侧

十三. 再看手部与支撑
- 非持机手放在哪里
- 是在拉衣摆、扶腰、拢发、托脸、撑扶还是自然垂落
- 手掌、手指、手腕是否有清楚停留方式
- 非持机手是否真的只有一只，避免误判多手
- 手部和支撑必须服务原图表达；不能为了补魅力硬塞撑台、扶腰、拉衣

十四. 再看自拍瞬间感
- 这个动作处于哪个阶段
- 是刚抬手
- 刚转头
- 刚停住
- 刚整理衣物边界
- 刚靠住支撑点
- 是否需要补上“未完全停死”的缓冲感

十五. 再看物理逻辑与衣物牵引
- 动作有没有带来身体连锁变化
- 动作有没有带来衣物位置变化
- 衣物变化是否由动作直接造成
- 上方边界、下方边界、腰线边界、腿部边界或衣物边界是否帮助身体线条成立
- 是否存在原图动作僵硬、角度不合理、肢体不成立的问题
- 如果原图有 bug，是否能在不改变母题前提下修正

十六. 必须舍弃的信息
- 模特长相
- 模特年龄和身份
- 服装具体款式、颜色、材质、图案、风格和配饰具体名
- 背景环境
- 光线与色温
- 品牌、颜色、道具；其中颜色只能在允许写环境/背景色时服务空间，不得来自人物服装或配饰
- 皮肤、妆容、材质审美词

十七. 魅力核验
- 是否只剩下侧身、站立、举机等动作骨架
- 是否丢失原图的表情强度、构图压迫感、遮挡边界、身体线条目的
- 是否丢失原图“她想把自己拍成什么感觉”
- 是否把可见服饰、配饰、颜色或图案照抄进动作 JSON，导致服装参考图被污染
- 是否为了魅力硬加了原图没有的动作

十八. 还原优先级
- 视图关系
- 身体曲线
- 表情气质
- 手部与支撑
- 衣物牵引
- 氛围
- 如果这些层级冲突，优先保住前面的层级，不要为了氛围或动作破坏视图和女性表达

十九. 最终转写前确认
- 能不能只用动作变量层解释这张图
- 有没有越界写到参考图控制项
- 有没有保留原图动作母题
- 有没有保留原图女性气质、拍照情绪、目的、身体曲线策略和微表情动作
- 有没有把原图动作修正得更自然
- 有没有避免把原图泛化成一个类似动作
- 有没有避免为了“更有魅力”硬改视图或硬塞动作
- 有没有确保最终结果更适合模型执行，而不是更像对图片的口语描述

二十. 一句话执行原则
- 先读懂图里的女生，再拆图；先完美还原她的视图、气质、拍照情绪、目的、曲线和微表情，再自然化，最后转写成 JSON。
