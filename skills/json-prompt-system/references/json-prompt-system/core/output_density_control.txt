output_density_control

目标：压缩输出但不丢细节。

一. 基本原则
- 压缩不是删细节，而是去重复、去解释腔、提高每句话的信息密度。
- 最终 JSON 要保留可生图执行的信息，不保留规则说明、创作理由、内部判断过程。
- 每个字段只承担一个职责；同一锚点不要在多个字段里反复扩写。
- 允许短句、顿号、逗号组织信息；禁止长段散文式复述。
- 压缩后仍必须保留用户明确要求和图像里的核心动作，不得把细节压没。
- 输出密度控制是生活图共享能力，不是对镜自拍模板；视图词必须按当前锁定 mode 写。
- mirror-selfie 写镜面/镜中/拍摄器材入画关系；front-camera-selfie 写画外前置视角、手臂前伸和近距离透视；third-person 写外部拍摄者、生活直出他拍机位和被拍瞬间。
- FRONT 与 PORTRAIT 不得为了保留“自拍感”而混入镜子、对镜、镜面构图或拍摄器材入画。

二. 5 个高权重短锚点
每条生活图输出必须至少保留以下 5 类锚点，位置按当前 mode 模板自然分配：
- 视图构图：当前 mode 的景别、上下左右裁切、人物占比、镜头或取景关系；不得把三种视图词并列写进最终 JSON。
- 主动作母题：这张图到底在做什么，不只写“自拍”或“站着”。
- 表情强度：克制、轻松镜头感、甜 / 娇俏、自信强表达中的具体档位，并落到眼睑、视线、嘴部、下巴和头角度。
- 身体 / 坐姿结构：头、肩、上身结构、腰、骨盆、腿部或坐姿承重关系；复杂坐姿必须保留骨骼拆解。
- 衣物边界或手部牵引：若用户或图片涉及边界下移、遮挡、轻牵、压住、停唇、扶腰等，必须写清手指、方向、停点和可见范围。

三. 字段职责
- `拍摄参数`：只写视角、景别、上下左右裁切、镜头距离、焦点区域、人物画面位置和镜头相对人物/背景的方位。
- `基础体态`：只写身体方向、重心、头部、肩线、上身结构与骨盆关系。
- `手部细节`：只写持机手 / 非持机手、手腕、手指停点、牵引方向和遮挡关系。
- `肩颈与上身`：只写肩颈、上身结构、前倾 / 侧转、上身曲线和上方身体线条。
- `腰腹与下盘`：只写腰胯、骨盆、腿部、坐姿承重和下盘折角。
- `表情控制`：只写眼睑、视线、嘴角、唇部、下巴、头部角度；不复述身体动作。
- `拍照瞬间感增强`：只写这一秒为什么像真实按下快门的停顿。
- `物理逻辑`：只写动作链条、受力、边界牵引和人体可行性；不复述审美目的。
- `整体视觉目的`：一句话收束画面要达成的效果。
- `心理暗示`：一句短触发，写人物当下的心理状态，不展开成故事。

四. 写法标准
- 优先使用“主句 + 必要参数”的短锚点写法。
- 每个小字段通常 1 句即可；复杂动作可 2 句，但不能把相邻字段的信息搬过来重说。
- 不写“为了体现”“需要注意”“根据规则”“避免出现”等规则解释腔。
- 不写“女性魅力来自于……”这类分析句；直接写动作、表情、构图和物理关系。
- 叙事触发可以保留，但必须短：只写一个瞬间，不写完整段落。

五. 不丢细节硬要求
- 用户明确要求的动作不能被压缩删除：如 M 字鸭子坐、上半身前倾、wink、轻咬舌、边界下移、上身中心线 / 上身轮廓线条、指尖停唇等。
- 以图还原不能压缩成泛化动作；必须保留原图的视图、构图、主体姿态、表情强度和关键手部动作。
- 服饰中立化不能把牵引力度写软；款式、颜色、材质、图案、配饰具体名都不写，但边界方向、手指受力、可见范围必须写。
- 任何字段都不得把服装/配饰纳入主色调、点缀色、焦点区域、头部状态、面部状态或视觉关键词。
- 不得用“安全”“保守”当理由删除动作：服装和露出信息由外部参考/上游链路处理，JSON Prompt 只保留动作、裁切、身体链条和衣物边界牵引。

六. 失败判定
- 字段冗长复述，同一锚点在多个字段重复扩写，FAIL。
- 只剩氛围词、情绪词或审美标签，没有可执行动作细节，FAIL。
- 出现规则解释腔、内部判断语气、文件名或路径痕迹，FAIL。
- 压缩后丢失主动作母题、表情强度、人体结构或关键手部牵引，FAIL。
- 为了变短而删除用户明确要求或图片核心锚点，FAIL。
