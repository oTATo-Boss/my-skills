expression_intensity_logic

本文件用于防止生活图表情过空、过冷、过呆，也防止表情过大导致 AI 假人感。
表情必须有情绪，但不能过载；必须落到脸部动作，而不是只写抽象气质词。

一. 核心原则
- 表情强度必须与用户意图、参考图气质、动作母题一致。
- 不要把“克制”写成面无表情，不要把“有镜头表现力”写成空泛标签，不要把“可爱”写成夸张假笑。
- 每个表情至少落到 4 个点：眼睑、视线、嘴部、头部/下巴。
- 优先写一个表情瞬间，不写多种冲突表情同时出现。

二. 四档表情强度

1. 克制
- 适用：清冷、冷淡、安静、轻熟、距离感。
- 眼睑：轻压或半垂，不瞪大。
- 视线：落在屏幕附近、镜中自己或镜头旁边，不死锁。
- 嘴部：嘴角收住，唇线放松或轻抿，不是完全水平僵住。
- 头部/下巴：下巴轻收，脸略转开，头部小幅偏斜。
- 防呆要求：必须写出“她在控制表情”的目的，不能只写冷淡。

2. 轻松镜头感
- 适用：慵懒有镜头表现力、社媒呈现、暧昧、知道自己好看。
- 眼睑：轻垂、半抬或从遮挡下方看出来。
- 视线：像从屏幕边缘扫过来，停在镜头附近但不直给。
- 嘴部：嘴唇微松、轻微分开、嘴角压住一点笑意。
- 头部/下巴：头轻低或轻偏，下巴轻收，颈部顺着肩线拉出角度。
- 防假要求：不要写强烈锁镜、夸张咬唇或过度张口。

3. 甜 / 娇俏
- 适用：可爱、娇俏、俏皮、想让自拍更亲近。
- 眼睑：更近、更亮，但不瞪圆。
- 视线：看屏幕或镜头附近，像主动把注意力递给镜头。
- 嘴部：嘴角小幅上扬，单侧微动或浅浅压住笑。
- 头部/下巴：头轻偏，脸略靠近设备或镜面，动作带一点轻快。
- 防假要求：不要写大笑、标准甜笑、过度嘟嘴。

4. 自信强表达
- 适用：自信强表达感、强吸引力、社媒表达强度、曲线展示明确。
- 眼睑：眼神更有方向，眼睑压住但不空。
- 视线：知道自己在被看见，视线可以更近，但仍避免死锁。
- 嘴部：嘴角和唇部有控制感，轻抿、微松或一侧微动。
- 头部/下巴：下巴、肩线、上身结构和腰胯线一起服务画面张力。
- 防假要求：不要把表达强度写成挤眉弄眼、过度张口或僵硬表演。

三. 默认映射
- “慵懒有镜头表现力”“社媒呈现”“近距离社媒呈现”：默认轻松镜头感，允许接近自信强表达，但必须落到具体表情动作。
- “可爱”“甜”“乖”“娇”：默认甜 / 娇俏。
- “自信强表达”“表达强度”“攻击性强”：默认自信强表达。
- “清冷”“冷淡”“高级冷感”：默认克制，但必须避免无表情。
- 有图还原优先读原图表情强度，不用用户词强行覆盖原图。

四. 最终检查
- 有没有眼睑、视线、嘴部、头部/下巴四个落点。
- 有没有明确表情目的：确认自己、靠近镜头、收住笑意、压住情绪、主动摆出气质。
- 有没有避免面无表情、过强假笑、张口过大、AI 挤眉弄眼。
- 表情是否和身体动作讲同一个瞬间。
