expressive_pose_translation

本文件用于把“更有表现力、更有镜头感、更有社媒呈现”的需求转成具体、可执行的动作变量。目标是保留姿势、表情、构图和边界控制的颗粒度。

一. 核心原则
- 表达强度来自重心、肩线、头部角度、眼神停顿、嘴部微动作、手部停点、裁切和空间压近。
- 衣物只作为边界和遮挡关系处理，不承载动作变量层之外的目标。
- 用户要求动作变量层之外的意图时，只保留可执行的构图重点、边界接触、遮挡关系和姿态。
- 不用抽象标签代替动作变量；每个增强点都要能被图像模型执行。

二. 先判断表达来源
- 视觉重点：脸部状态、肩颈与上身轮廓、腰线、腿部姿态、坐姿结构、手部动作或整体被拍氛围。
- 情绪策略：克制、松弛、自信、甜感、冷静、漫不经心、发布前确认。
- 身体策略：前倾、侧转、坐姿、靠姿、裁切压近、肩胯错位、手部边界接触或局部近景。
- 视图策略：对镜、前置、他拍分别用自己的镜头关系承载表现力，不互相污染。

三. 表达意图翻译表
- 更有镜头感：眼神停在镜头附近但不死锁，头部角度有轻微偏差，表情像刚确认好角度。
- 更有存在感：上身或手部成为前景，裁切更明确，身体轴线不完全居中。
- 更有社媒感：表情和动作像随手拍到的好看瞬间，而不是商业摆拍。
- 更有自信：肩颈打开，重心稳定，视线不躲闪，嘴角控制在小幅度。
- 更有亲近感：镜头距离更近，屏幕意识更强，手臂透视或前景支撑清楚。

四. 手部与边界写法
推荐：
- “手指停在上方边界附近，形成轻微接触和遮挡关系，手腕放松，动作像刚整理完后停住。”
- “指尖沿衣物边界轻停，牵引方向很小，只服务于上身构图重点。”
- “局部近景只写当前裁切内可见的手指、边界、肩颈和上身轮廓关系，不强行补完整下盘。”

不推荐：
- “更会面对镜头。”
- “把边界动作写成不属于照片动作变量的目标。”
- “用抽象目的代替可执行动作。”

五. 表情与动作同向
- wink、轻咬舌、浅笑可以作为小幅表情微动作，但必须服务于社媒照片的调皮感或发布感，不绑定额外目的。
- 冷静表情适合更稳定的肩线和视线；甜感表情适合更近的眼神、轻偏头和小嘴角。
- 表情必须服务主动作，不要夸张到 AI 假人感。

六. 一句话标准
- 先看懂画面想表达的社媒状态，再把判断压缩成视线、嘴角、头部、肩线、手部、边界、裁切和支撑关系。
