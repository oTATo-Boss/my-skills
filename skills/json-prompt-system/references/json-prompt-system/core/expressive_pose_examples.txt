Expressive Pose Examples

这份文件用于校准“表达强度”和“社媒呈现”的动作变量写法。它不是风险清单，也不是不属于动作变量层的目标清单；它只帮助 Agent 把抽象拍照意图转成安全、具体、可执行的姿势、表情、构图和边界变量。

总原则
- 表达强度不是夸张表演，而是视线、嘴角、头偏角、肩线、手部停点、裁切和动作缓冲之间的配合。
- 图示是什么就先还原什么；用户额外要求只在当前 mode 和产品域边界内扩展。
- 不写服装款式、品牌、颜色、材质、图案或配饰；只写衣物边界、遮挡、接触点和裁切关系。
- 不要为了“更有表现力”强塞原图没有的扶腰、回头、边界动作或夸张表情。

一. 先判断表达来源
- 视觉重点：脸部气质、肩颈与上身轮廓、腰线、腿部姿态、坐姿结构或整体社媒氛围。
- 状态方向：松弛、克制、自信、甜感、冷静、漫不经心、发布前确认。
- 视图关系：对镜、前置、他拍分别用自己的镜头关系承载表现力，不互相污染。
- 主动作母题：刚前倾停住、手刚整理边界、侧身回看、坐姿压近镜头、靠住后抬眼。
- 模型抓手：眼睑、视线、嘴角、下巴、肩线、腰胯、手指、边界接触、裁切。

二. 抽象词改成参数
低质量写法：
- 很有感觉。
- 很抓人。
- 很有镜头感。

高质量写法：
- 眼睑轻垂，视线停在镜头附近但不死锁，像刚确认这个角度可以保留。
- 嘴角只保留一点浅弧度，下巴轻收，头部有轻微偏角。
- 手指停在衣物边界附近，手腕微弯，边界接触只作为构图和动作停点。
- 上身轻前倾，肩线和腰线不完全对称，动作像刚调整完后停住。

三. 眼神
低质量写法：
- 眼神自然看向镜头。
- 眼神很有表现力。

高质量写法：
- 眼神先从画面边缘扫回来，停在镜头旁边一瞬，带一点漫不经心的确认感。
- 前置自拍中，视线像落在屏幕里的自己，而不是死盯镜头。
- 对镜自拍中，视线在镜中自己和手机屏幕之间停顿。

四. 嘴部
低质量写法：
- 嘴唇自然闭合。
- 嘴巴很好看。

高质量写法：
- 嘴唇自然分开一点，嘴角压住不笑开，像动作停住时呼吸也停了一瞬。
- 轻咬舌或轻咬唇只作为调皮微动作，幅度小，和眼神/头偏角同向。
- 甜感时嘴角有浅弧度；冷静状态时嘴角更收，靠眼神和身体线条制造画面重点。

五. 手部与衣物边界
低质量写法：
- 手放在胸前。
- 衣物边界参与动作。

高质量写法：
- 指尖停在上方边界附近，形成轻微接触和遮挡关系，手腕放松，动作像刚整理完后停住。
- 指尖沿边界轻停，牵引方向很小，只服务上身构图重点。
- 如果参考图是局部近景，只写当前裁切内能看见的手指、边界、肩颈和上身轮廓关系。

六. 姿态与构图
- 上身轻前倾时，要写上身结构、骨盆和肩线的关系，避免只生成脸部近景。
- 侧身时，要写上身结构、骨盆、肩线、腰胯分别朝哪里，哪一段线条成为视觉中心。
- 坐姿时先锁骨盆和膝腿结构，再写上身前倾、手部停点和表情。
- 对镜：表现力来自镜面裁切、遮挡边界、身体线条和镜中自我确认感。
- 前置：表现力来自屏幕意识、近距离、画外前置视角、身体前景和表情生命力。
- 他拍：表现力来自外部拍摄者捕捉到的一秒、被拍者反应、支撑关系、机位和裁切。

七. 一句话结论
- 先判断照片的社媒呈现意图，再把它压缩成具体动作变量；不要把抽象形容词、不属于动作变量层的目标或审美口号写进 JSON。
