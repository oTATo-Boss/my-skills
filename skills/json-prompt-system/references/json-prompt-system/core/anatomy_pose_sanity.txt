anatomy_pose_sanity

本文件用于减少反人体、手臂错位、手部穿体、侧身扭转过头和多手问题，并建立人体可行性检查。
它不改变动作母题，只负责让动作在真实人体上成立。

一. 核心原则
- 头颈、肩、上身结构、骨盆、手臂、手腕、手指必须连贯。
- 动作越有张力，越要检查人体路径是否真实。
- 有图反推时可以修正原图或模型造成的反人体结构，但不能改变主动作母题。

二. 侧身与半转身
- 上身结构与骨盆可以有方向差，但不能写成极限扭转。
- 头部转向必须顺着颈部和肩线，不要让脸转过去但肩颈完全不动。
- 侧身曲线优先来自重心、腰线、骨盆偏移和构图，不来自硬顶胯。
- 如果人物侧身贴近镜面，持机手必须有真实举机路径，不能穿过上身或脸部。

三. 手臂路径
- 每张图默认只能有一只持机手和一只非持机手。
- 持机手要说明：手机位置、手腕方向、手肘弯曲、与脸/肩/镜面的关系。
- 非持机手要说明：从哪里来、停在哪里、为什么停在那里。
- 禁止手臂穿体、手从不可能方向跨到另一侧、手腕反折、手指数量混乱。

四. 指尖与接触点
- 指尖贴唇、扶腰、压衣物边界、托脸、拢发都必须写清接触点。
- 接触点要轻：轻停、轻贴、轻碰，不要用力按压，除非动作本身是支撑。
- 指尖贴唇不能写成咬手、夸张手势或遮住整张嘴；扶腰不能写成硬掐腰。

五. 承重与支撑
- 每个站姿必须知道哪条腿承力、哪条腿放松。
- 靠近镜子、靠墙、靠桌、坐姿、侧躺都必须有主支撑点。
- 装饰性手势不能替代主支撑点。

六. 坐姿专项检查
- 坐姿必须写清骨盆承重、膝盖方向、小腿折向、脚踝落点、上半身前倾角度。
- M 字鸭子坐必须先锁下盘：骨盆坐地、双膝外开、小腿折向身体两侧、脚踝/脚背落在臀侧附近。
- 上半身前倾 + M 字坐姿必须使用中全身或全身坐姿构图，不能用前置自拍近景半身裁切。
- 复杂动作优先级固定为：先锁下盘坐姿，再写上身前倾，再写手部牵引，再写表情。
- 如果先写脸和上身，模型容易只生成上半身，视为失败风险。

七. 最终检查
- 是否只有一只持机手和一只非持机手。
- 上身结构与骨盆方向差是否中小幅、可执行。
- 手腕和手指是否自然，是否避免手臂穿体。
- 动作链是否能按顺序发生：先站稳，再转身，再抬手，再停住。
