bad_cases

这份文件用于识别不合格输出。重点不是列出禁用词，而是防止四类失败：越界内容、物理错误、审美过度、角色不自然、输出污染。

一. 越界内容
FAIL：
- 把请求写成动作变量层之外的内容。
- 把衣物边界、裁切或手部停点写成不属于动作变量层的目标。
- 把产品域边界当作措辞障碍，通过替换词继续表达不属于动作变量层的意图。

修正：
- 只保留构图重点、遮挡关系、衣物边界接触、姿态、表情停顿和镜头距离。
- 不属于动作变量层的部分不写入 JSON，改为中性社媒照片表达。

二. 物理错误
FAIL：
- 手臂穿体、手指方向不可能、左右手混乱、多手、多关节错位。
- 重心不明，坐姿没有支撑点，靠姿没有受力来源。
- 前置自拍没有画外前置视角、手臂透视、固定设备或屏幕意识。
- 对镜自拍没有镜面关系，第三视角保留自拍持机逻辑。

修正：
- 先写承重点、支撑面、身体朝向、头部方向，再写手部细节。
- 锁定 mode 后只翻译动作，不切换视图语义。

三. 审美过度
FAIL：
- 写单反焦外、bokeh、电影后期、HDR 光晕、强风格调色、作品级修背景。
- 用空泛氛围词代替镜头距离、裁切、支撑和表情动作。
- 把手机直出写成棚拍、商业大片或过度精修。

修正：
- 用普通手机小底深景深、轻颗粒、轻锐化、社交压缩和自然环境光描述真实质感。
- 用人物位置、引导线、前景关系和裁切表达重点。

四. 角色不自然
FAIL：
- 头、肩、嘴角、手指都过于对称，像姿势模板。
- 每个需求都强行加入扶腰、回头、整理边界或夸张表情。
- 表情只剩标签，没有眼睑、视线、嘴角、下巴或头偏角。

修正：
- 加入小幅不对称、动作缓冲、发布前确认感、屏幕意识和真实停顿。
- 每个动作只保留一个主轴，其他细节服务主轴。

五. 输出污染
FAIL：
- 最终 JSON 出现文件路径、规则名、开发说明、读取过程、引用来源或不可执行元信息。
- 混入其他 mode 的模板结构、字段或拍摄语义。
- 写服装款式、颜色、材质、图案、品牌或配饰名，污染外层参考图。

修正：
- 最终 JSON 只保留图像模型可执行内容。
- 服装相关统一抽象为边界、遮挡、接触点、牵引方向和裁切关系。
