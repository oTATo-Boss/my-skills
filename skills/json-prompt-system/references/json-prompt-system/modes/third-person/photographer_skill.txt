third-person Photographer Skill

这份文档是 third-person 的专用摄影师指导层。
目标不是教模型“怎么摆动作”，而是先决定“这张生活直出他拍美女图怎么拍才真实、才好看、才不像 AI”。

一. 总原则
- 先当摄影师，再当动作导演。
- 先决定镜头位置、景别、画面重心、场景关系，再决定人物动作。
- 高级感来自构图、机位、人物停顿、生活直出成像气质，不来自虚化、重滤镜或过度后期。

二. 真实生活直出他拍原则
- 默认小广角直出逻辑：24mm 或 26mm 生活直出广角。
- 默认景深：小底深景深，人物与环境都应大体可辨。
- 默认质感：轻微边缘锐化、极轻颗粒、暗部轻微数码噪点、社交媒体压缩感。
- 禁止单反 / 全画幅 / 大光圈 / bokeh / 奶油焦外 / 前景虚化。
- 不靠虚化托主体，靠机位、构图和环境层次托主体。

三. 构图设计库
1. 三分法偏移主体
- 不把人物钉死在正中央。
- 让人物落在左或右三分区，另一侧交给环境和引导线。

2. 对角线与纵深
- 让地面线、墙线、家具边缘或身体延展方向形成对角线。
- 让人物、背景、远处光点有前后层次。

3. 压迫式裁切
- 允许贴近边缘裁切，但必须服务人物好看和瞬间感。
- 禁止平均留白、平均包裹人物。

4. 低机位 / 轻俯视
- 低机位适合拉出腿部与重心，增强被拍感。
- 轻俯视适合做漂亮的头肩关系和都市抓拍感。
- 无论哪种，都不能做成证件照平视站拍。

四. 人物自然度规则
- 头部不要完全摆正，要有微偏、回看、低头或抬眼差值。
- 肩线不要完全水平，要有一边更松、一边更收。
- 手部不要像摆件，要像刚停在那里。
- 嘴部不要标准微笑，要像瞬间里自然留下来的嘴型。
- 眼神不要死锁镜头，要像刚发现镜头或刚从别处扫回来。

五. 好看但真实的动作方向
- 转身回看
- 走路中被拍到的一瞬
- 扶墙、倚栏、靠桌、坐下前后的小停顿
- 手碰头发、衣角、包带、杯子等生活化交互
- 让动作看起来像正在发生，而不是已经摆好等拍

六. 常见失败图谱
1. 影楼感
- 正中、平视、人物站直、背景像说明板。

2. AI 皮肤感
- 面部过于干净，五官过度工整，对称到假。

3. 站桩
- 动作不带前后关系，没有重量感，没有停顿来源。

4. 虚假抓拍
- 文案写“抓拍”，但人物其实在配合镜头摆 pose。

5. 画面太端正
- 画面过于平均、安全、无层次，一眼像 catalog。

七. 一句话工作标准
- 像有人用外部镜头真的拍到了一个很好看的女生，而不是像 AI 知道什么叫“美女图”。
