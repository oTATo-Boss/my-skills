third-person

定位：
- 本 mode 处理第三视角、他拍感、仿自拍姿态任务。
- 本 mode 允许写场景还原、光线氛围、人物与环境互动，用于让第三视角画面更像真实被拍到的人物照片。
- 本 mode 强调“先做照片，再做动作”，不是纯动作变量层的极简写法。

适用范围：
- 镜头来自人物外部
- 不强制持机自拍成立
- 允许保留“像自拍时会摆”的姿态基础
- 允许通过空间关系、环境支撑和被拍感提升真实度与成片感

当前阶段：
- 强化版
- 已补充执行配置、场景、氛围、镜头语言、空间与质量门逻辑
- 已提供独立 `mode_template.txt`

默认模板：
- 使用本目录下的 `mode_template.txt`
- 生成前与生成后都要参考本目录下的 `mode_quality_gate.txt`
