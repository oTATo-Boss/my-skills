third-person Mode Workflow

一. 总原则
- 先做照片任务，再做人物动作。
- 先做摄影师判断，再写动作字段。
- 先让画面真实成立，再让人物变好看。
- 任何时候都不要靠虚化、滤镜或相机味去“伪造高级感”。

二. 启动步骤

步骤1：先确认这是 third-person
- 镜头来自人物外部
- 没有镜面自拍逻辑
- 没有前置自拍逻辑
- 目标是外部镜头下的真实美女图

步骤2：读取摄影师指导层
- 必须先参考 `modes/third-person/photographer_skill.txt`
- 必须同时参考 `core/third_person_capture_logic.txt`
- 先选摄影方向，再选动作方向
- 先让摄影师决定怎么拍，再让人物决定怎么停

三. 纯原创流程

步骤3：先锁照片任务
- 先判断这张图是：
- 被偷拍感
- 低机位抓拍
- 街头经过感
- 室内生活流
- 封面感生活直出照
- ins 式社交媒体图
- 先写“拍摄者为什么在这里拍”，再写“人物为什么在这一秒被拍到”
- 先从 4 类他拍瞬间里选一个：被叫住回头、走动中停住、靠住 / 坐下时被拍、主动配合镜头的半摆拍

步骤4：写场景基础
- 定地点
- 定时间
- 定天气
- 定季节
- 场景必须具体，不要“室内 / 室外”这类空描述

步骤5：写周边环境与空间
- 定自然或建筑环境
- 定材质
- 定背景物件
- 定空间层次和压迫感
- 这一层负责让人物和镜头真正落地

步骤6：写光影与色彩表现
- 先定主要光源环境
- 再定阴影特征
- 再定核心主色调
- 再定冲突色或点缀色
- 光影必须是环境推出来的，不是摄影棚词汇

步骤7：写整体氛围与情绪传达
- 先定直观视觉情绪
- 再定故事悬念与张力
- 再定美学风格与质感
- 最后定感官通感暗示
- 氛围必须服务真实被拍到的一瞬，不写成海报文案

步骤8：写角色位置与构图模块
- 先定构图法则
- 再定引导线和留白比例
- 再定景别、机位高度、焦距感
- 再定人物在画面中的水平位置、垂直位置、景深位置和占比
- 再定人物朝向、头部转向、视线焦点、姿势动态感
- 构图必须主动避免中轴对称、平视站桩、平均铺开
- 明确外部拍摄者在人物前侧、侧前、低位、轻俯视或斜侧方向中的哪一类，不能只写“第三视角”

步骤9：写动态动作库
- 先写镜头语言
- 再写人物动作骨架
- 最后写人物表情神态
- 动作必须围绕摄影构图服务，而不是动作先行、照片补救
- 人物动作必须保留被拍瞬间：刚回头、刚走近停住、刚靠住、刚坐稳、手刚从脸侧 / 发边 / 衣物边界放下
- 表情必须写视线来向、眼睑、嘴角 / 唇部、下巴和头偏角，体现发现镜头、刚从别处扫回来、知道自己被拍或半摆拍配合

步骤10：写生活直出成像约束
- 只保留生活直出感的轻控制
- 默认景深效果关闭
- 默认无重滤镜、无 强风格调色、无电影感后期
- 只允许轻颗粒、轻锐化、轻亮度或白平衡调整

四. 图片还原流程

步骤1：先拆摄影关系
- 先看场景
- 再看机位
- 再看景别
- 再看人物在画面中的位置
- 再看生活直出感来自哪里
- 如果当前锁定 PORTRAIT，参考图即使是自拍 / 对镜 / 前置，也只作为姿势、构图、曲线、表情和手部动作参考
- 自拍持机、可见取景实体、镜子、看屏幕等信息必须转译为外部拍摄者视角，不得直接保留

步骤2：再拆人物
- 看整体体位
- 看双手停留
- 看头颈和肩线
- 看视线和嘴部
- 看动作是不是被拍到的，而不是摆出来的

步骤3：按新模板转写
- 先写场景基础
- 再写周边环境与空间
- 再写光影与色彩表现
- 再写整体氛围与情绪传达
- 再写动态动作库
- 再写角色位置与构图模块
- 最后写弱化后的生活直出成像约束
- 参考图主姿势、构图、曲线、表情强度和关键手部动作不得被泛化成普通站姿或普通他拍

五. 最终检查
- 是否先处理摄影任务，再处理人物动作
- 是否生活直出感写成了具体参数，不是一句“生活直出拍摄”
- 是否没有单反浅景深、前景虚化、电影级后期
- 是否构图被设计过，但仍像真实生活直出抓拍
- 是否人物更像真实美女图，而不是 AI 漂亮假人
- 是否有外部拍摄者位置、拍摄动机、被拍反应和环境支撑
- 是否没有混入对镜、前置、持机自拍或可见取景实体作为拍摄主体
