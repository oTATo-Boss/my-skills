mirror-selfie Mode Quality Gate

这份文件用于在 mirror-selfie 下做最终质量收口。
目标不是检查“镜子在不在”，而是检查这条提示词是否真的会导向“真实、自然、像女生顺手在镜前拍下来的自拍”。

硬性失败条件（任一命中即 FAIL）
- Schema 不符合当前 mode 模板，或混入其他 mode 的顶层结构。
- mode 判断错误：不是镜面关系，却写成 mirror-selfie。
- 最终 JSON 输出污染：出现 `core/`、`mode_`、文件名、路径、规则名、README 或“参考某文件”等 agent 工作说明。
- 越权写入模特身份、人物外形、具体背景、环境陈设、灯光、皮肤或材质审美。
- 写入背景虚化、浅景深、bokeh、人像模式焦外、单反/全画幅审美、专业后期、HDR 光晕、电影感分层调色或作品级修背景。
- 最终 JSON 出现任何具体服装、穿戴、配饰、鞋包、道具款式、颜色、材质、图案、品牌或商品名，导致服装参考图被污染。
- 在表情、焦点区域、头部状态、视觉关键词、色彩或氛围字段写入服装/配饰信息。
- 表情只剩冷淡、有镜头表现力、可爱等标签，没有眼睑、视线、嘴部、下巴/头部角度；或表情空木、过度假笑。
- 无图原创没有主动作母题，只是侧身站着举手机。
- 侧身/半转身出现极限扭转、手臂穿体、多手、持机路径不成立或非持机手跨越不可能路径。
- 用户要求 M 字鸭子坐但画面被写成半身裁切，或缺少骨盆坐地、双膝外开、小腿折向两侧任一项。
- 用户要求整理边界/牵引/突出上身轮廓，但只写轻牵、轻停、手放胸前，没有明确边界下移、上身中心线/上身轮廓线条可见。
- 因保守化而删除上身边界下移动作，或把上身轮廓线条需求完全弱化为普通上身轮廓。
- 字段冗长复述、重复锚点、只剩氛围词或规则解释腔，导致输出不再是高密度动作 JSON。
- 压缩后丢失主动作母题、表情强度、身体/坐姿结构、镜面构图或关键手部牵引。

一. 核心门槛
- 这张图必须像真实会被保留下来的镜面自拍。
- 不能只是镜子存在。
- 不能只是持机成立。
- 必须同时满足：
- 镜面逻辑成立
- 持机手自然
- 非持机手自然
- 镜中表情有停顿感
- 站姿或动作有生活化微误差

二. 镜面成立检查
- 镜子是否是必要反射元素
- 手机是否与镜中画面关系一致
- 身体朝向是否和镜中主体对应
- 回看、越肩、遮脸等特殊形式是否仍满足镜面自拍成立

三. 持机手自然度检查
- 持机手位置是否符合真实自拍习惯
- 手腕是否不过硬
- 手肘是否不过僵
- 手机与脸部、肩线、镜中构图的关系是否自然
- 是否避免“为了完成自拍而把手机贴上去”的任务感

四. 非持机手自然度检查
- 非持机手是否与动作母题有关
- 是否只是轻搭、轻扶、轻停、轻整理
- 手指是否微弯、放松、不过分展开
- 是否避免“无意义摆 pose”

五. 镜中人物自然度检查
- 头部是否有小偏差，而不是完全标准摆正
- 肩线是否有轻微不对称
- 重心是否真的落在一侧，而不是完美中轴
- 动作是否像“刚停住”，而不是完全定格
- 人物是否不像 mannequin 或示意图

六. 表情与眼神检查
- 眼神是否在镜中自己、手机屏幕和镜头区域之间自然停顿
- 是否避免死锁镜头
- 嘴角是否保留轻微不对称或轻微收放
- 微表情是否像“在镜前确认自己状态”，而不是单独表演
- 是否读懂并还原了原图/任务里的女性气质、拍照情绪、展示目的、身体曲线和微表情动作
- 是否避免为了更有魅力而硬塞撑台、扶腰、拉衣、顶胯、回头或开放式构图
- 是否避免：
- 发呆
- 空洞
- 标准 AI 微笑
- 过满冷脸

七. 常见不合格结果
- 持机手像硬举着完成任务
- 非持机手悬空摆 pose
- 镜中人像太正、太平、太对称
- 回看时头到了但肩线完全锁死
- 遮脸时露出的半张脸仍然是空白模板脸
- 镜自拍成立，但整体像棚拍示意图，不像生活中顺手拍的照片

八. 一句话标准
- mirror-selfie 的最终目标不是“镜子里有个人在自拍”，而是“镜子里的人真的像正在照镜子，并顺手留下了一张自然又好看的自拍”。
