mirror-selfie Mode Rule

1. 模式定位
- 本 mode 只处理镜子明确存在、镜面关系成立的自拍任务。
- 动作、表情、镜头关系都必须围绕“对镜自拍”成立。

2. 核心成立条件
- 镜子必须是必要反射元素。
- 持机逻辑必须成立。
- 身体朝向与镜中画面必须能对应。
- 如果写越肩自拍，镜中脸部或肩背关系必须能成立。
- 如果写遮脸自拍，手机遮挡和镜中身体关系必须统一。

3. 对镜自拍专属关注点
- 持机手位置是否符合真实自拍习惯
- 手机是否需要入镜
- 镜中主体和镜外持机逻辑是否一致
- 回看时头肩方向是否和镜子成立
- 背身动作是否仍然满足镜面自拍逻辑
- 镜中人物是否像“照镜子顺手拍”，而不是专门面对镜子摆造型
- 非持机手是否和动作母题有关，而不是硬摆
- 镜中眼神是否有落点，是否在镜中自己、手机屏幕和镜头区域之间自然停顿

4. 原创时的镜面优先级
- 优先写镜前会自然发生的动作：
- 整理衣摆
- 拢发或扎发
- 回头确认角度
- 扶腰停住
- 单侧支撑靠近镜面
- 遮脸自拍
- 对镜侧站
- 优先写镜前会自然停住的小误差和小缓冲，不优先写完美标准站姿

5. 以图还原时的镜面优先级
- 先确认镜子是否为主视角来源
- 再确认手机是否为自拍设备
- 再判断是正面镜自拍、侧身镜自拍、背身镜自拍还是越肩镜自拍

6. 表达强度与产品域边界
- 镜面自拍中的吸引力以**可执行主干**组织：视线停留与移开、肩胯错位、持机与镜面关系、衣料牵引与受力、动作刚停住的缓冲感、镜中身体轮廓与脸部的反差、镜中确认自己状态时的表情节奏。
- 镜中呈现开放式构图、上身轮廓与肩颈与上身线条时，可与上述主干并行；本层只写它们由哪个动作、角度、裁切或衣物边界带出。
- 手部停留以自拍合理动作为主（整理边界、扶腰、拢发等）；不要写具体服装款式，只写动作停点和受力方向。

6.1 女性自拍呈现还原
- 本 mode 必须参考 `core/women_selfie_presentation_logic.txt`。
- 同时参考 `core/visual_anchor_abstraction.txt`、`core/expression_intensity_logic.txt`、`core/original_pose_invention_logic.txt`、`core/anatomy_pose_sanity.txt`、`core/expressive_pose_translation.txt`、`core/seated_pose_anatomy_library.txt`、`core/output_density_control.txt`。
- 对镜自拍要先读懂镜中女生的自拍目的：她是在展示脸部气质、肩颈、上身轮廓、腰线、髋线，还是整体慵懒/清冷/自信强表达感。
- 曲线感来自镜中身体轴线：头、肩、上身结构、腰、骨盆和腿是否形成自然错位；不得为了曲线硬塞顶胯、撑台、拉衣或回头。
- 微表情必须读懂镜中表情管理：眼睑、视线、嘴角、下巴、头部角度和手机遮挡关系共同决定气质。
- 以图还原时，必须尽量完美还原原图里女性的气质、拍照情绪、目的、身体曲线和微表情，而不是泛化成一个普通镜前动作。

6.2 服饰中立、表情强度、原创动作与人体检查
- 有图还原时，不得把任何具体服装、穿戴、配饰、颜色、材质、图案、品牌或道具款式写进最终 JSON；只能写上方边界、衣物边界、腰线边界、腿部边界、遮挡关系和边界牵引等动作变量。
- 服装/配饰信息不得出现在表情、焦点区域、头部状态、视觉关键词或色彩氛围字段；对镜只写镜面自拍成立所需的姿势、裁切、持机、表情和边界互动。
- 表情必须选择清晰强度档位：克制、轻松镜头感、甜/娇俏、自信强表达；并落到眼睑、视线、嘴部、下巴/头部角度，不得只写“冷淡、有镜头表现力、可爱”。
- 无图原创不能只写侧身站着自拍；必须发明一个主动作母题，例如侧身低头看屏、指尖停唇、单手停腰侧、整理边界后停住、靠近镜边轻贴等，最终只选一个主动作。
- 对镜自拍必须额外检查手机遮挡、镜边距离、人物画面位置、持机手真实路径；侧身/半转身时上身结构与骨盆方向差必须可执行，禁止极限扭转、手臂穿体和多手。
- 用户要求完整坐姿，尤其 M 字鸭子坐时，mirror-selfie 必须使用坐姿构图，画面至少包含腰部、骨盆、双膝、小腿折向；不得写成近景半身或只到大腿上方。
- 用户明确要求整理边界/牵引/突出上身轮廓时，服饰中立化不能削弱动作；必须写非持机手两指钩住上方衣物边界向边界方向轻整理，边界位置被整理得更清楚，上身中心线/上身轮廓线条可见。
- 最终 JSON 必须按输出密度控制压缩：每个字段只写自己的职责，用短锚点保留视图构图、主动作母题、表情强度、身体/坐姿结构、衣物边界或手部牵引；不得用长段复述替代动作细节。

7. 细节自然度要求
- 对镜自拍最容易失败在“动作成立但像 AI 摆拍”。
- mirror-selfie 下必须额外关注：
- 持机手是否自然
- 非持机手是否和动作有关
- 头部是否有小偏差
- 肩线是否轻微不对称
- 表情是否不空不木
- 镜中是否有真实停顿感
- 这些内容最终必须对照 `mode_quality_gate.txt` 做检查

8. 景深、背景与画面处理（全 mode 一致）
- 不得在 JSON 中写背景虚化、浅景深、bokeh、人像焦外等；不得写对背景/画面的专业后期处理（与 `core/rule.txt` §9 一致）。对镜自拍按**普通人手机随拍**景深理解。
- 与固定场景参考图对接时仍**禁止**写具体背景、环境、灯光；若需锚手机质感，**仅**在 `整体视觉目的` 等不涉及场景陈设的槽位用**极轻**噪点/颗粒类短句，不借机描写环境。

9. 与固定场景参考图对接时的边界
- 当外层管线为 mirror-selfie 提供**固定场景参考图**时，背景、环境陈设、灯光由参考图与外层 Prompt 承担。
- 本 mode 的 JSON **禁止**写具体背景、环境与灯光描述，避免与参考图重复或冲突。
- JSON 仍须把对镜自拍成立所需的姿势、持机、镜面关系、表情与构图写清楚。

10. 写法风格要求（叙事触发优先）
- 表情控制、整体视觉目的、心理暗示中的文字描述，必须优先使用叙事触发式写法。
- 叙事触发 = 写一个 2 秒内的微故事或瞬间，让模型自己去“拍”这个瞬间。

好写法示例：
- 眼神：“越过肩线看向镜中的自己——不是在看镜头，是在确认这个角度是不是真的好看”
- 嘴部：“像心里刚冒出一句‘还可以嘛’，笑意只到嘴角还没到眼睛”
- 微表情：“像刚确认好这个背影角度、顺手按下快门前的那一秒”
- 心理：“她知道自己现在很好看，但不会直说，表情里只有一点点藏不住的得意”

坏写法示例（禁止）：
- “人物状态：放松、自我关注、带一点轻微羞怯和玩笑感”
- “情绪浓度：中低强度，偏轻熟、自然”
- “视线方向：看向镜中镜头或手机屏幕，视线柔和”

详细规则见 `core/detail_control_logic.txt` 八.

11. 模式边界
- 不默认扩写前置自拍的近脸透视逻辑
- 不默认扩写第三视角的镜头外关系
- 遇到不明确场景，优先回到 `core/mode_selector.txt` 重新判断
