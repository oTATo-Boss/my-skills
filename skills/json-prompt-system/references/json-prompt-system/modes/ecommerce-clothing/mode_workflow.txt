ecommerce-clothing Mode Workflow

一. 总原则
- 先判任务类型，再锁视角与结构，再写保真细节，最后补环境、技术规格和负面限制。
- 先保证商品成立，再考虑画面整洁。
- 不从情绪词起手，不从风格词起手，不从品牌故事起手。

二. 任务类型判断
- 先判断当前属于哪一类：
- 主视角展示
- 局部特写
- 功能展示
- 一个草稿只服务一个核心任务，不要把主视角和局部特写混写成同一张图。

三. 主视角流程
步骤1：锁视角
- 明确是正面、反面、侧面还是 45 度立体。

步骤2：写任务定义
- 角色固定为电商服装摄影与商品渲染专家。
- 目标明确当前主视角任务。
- 输入保真要求强调结构、颜色、纹理、工艺保真。

步骤3：写主体结构
- 先写当前视角。
- 再写 invisible body / Ghost Mannequin 的撑起逻辑。
- 再写领口、肩线、袖筒、衣身、下摆和厚度如何成立。
- 如果是 45 度视角，要额外写平面过渡与透视控制。

步骤4：写细节保留
- 先写参考来源。
- 再列出必须保住的结构与工艺属性。

步骤5：写环境
- 默认纯白无缝背景。
- 默认商业棚拍柔光。
- 默认只允许内部结构阴影。

步骤6：写技术规格
- 分辨率
- 清晰度
- 输出风格

步骤7：写负面限制
- 优先限制真人写入、塑料假模特、贴图感、错误阴影、透视错乱、颜色材质漂移。

四. 局部特写流程
步骤1：锁定部位
- 明确是领口、袖口、下摆、纹理、印花、刺绣、图案、缝线、拼接、包边、拉链还是纽扣。

步骤2：写任务定义
- 目标明确当前特写图是“工艺放大展示”，不是普通裁切图。

步骤3：写主体结构
- 明确特写部位的局部形状、开口、边缘、厚度、缝合、贴合、层次或开合关系。

步骤4：写细节保留
- 明确当前工艺必须保真的具体细项。

步骤5：写环境与光线
- 保持低干扰白底与柔光。
- 阴影只帮助展示深度，不制造戏剧效果。

步骤6：写负面限制
- 重点限制贴纸感、平面工艺、错误边缘、假材质、脏细节和过度磨皮。

五. 功能展示流程
步骤1：确认功能目标
- 明确是厚薄感、内里夹层还是口袋 / 开合结构。

步骤2：写主体结构
- 先写功能成立方式。
- 再写层次、厚度、深度或开口关系。

步骤3：写细节保留
- 明确哪些结构关系不能错。

步骤4：写环境
- 保持白底和商业光线，避免背景干扰功能理解。

步骤5：写负面限制
- 重点限制假厚度、假层次、假开口、悬浮结构和错误材质关系。

六. 最终检查
- 是否任务类型单一明确。
- 是否当前视角或局部部位写清楚了。
- 是否已经明确输入保真要求。
- 是否环境始终服务商品，不抢主体。
- 是否技术规格简洁稳定。
- 是否负面限制足够针对当前任务。
- 是否整份 JSON 像电商服装渲染协议，而不是时尚大片文案。
