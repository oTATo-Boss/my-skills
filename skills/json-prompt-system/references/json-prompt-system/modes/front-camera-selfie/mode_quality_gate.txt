front-camera-selfie Mode Quality Gate

这份文件用于在 front-camera-selfie 下做最终质量收口。
目标不是检查字段是否齐全，而是检查这条提示词是否真的会导向“真实、自然、合理、好看的前置自拍”。

硬性失败条件（任一命中即 FAIL）
- Schema 不符合当前 mode 模板，或混入其他 mode 的顶层结构。
- mode 判断错误：依赖镜子或第三视角，却写成 front-camera-selfie。
- 在站点锁定 FRONT 时，输出镜子、镜中、对镜、镜面构图或镜前关系。
- 在站点锁定 FRONT 时，输出可见取景实体；本 mode 只能用画外前置视角、屏幕意识和手臂透视成立。
- 最终 JSON 输出污染：出现 `core/`、`mode_`、文件名、路径、规则名、README 或“参考某文件”等 agent 工作说明。
- 越权写入模特身份、人物外形、具体背景、环境陈设、灯光、皮肤或材质审美；除非本 mode 字段明确要求场景/光线服务自拍成立。
- 写入背景虚化、浅景深、bokeh、人像模式焦外、单反/全画幅审美、专业后期、HDR 光晕、电影感分层调色或作品级修背景。
- 最终 JSON 出现任何具体服装、穿戴、配饰、鞋包、道具款式、颜色、材质、图案、品牌或商品名，导致服装参考图被污染。
- 在表情、焦点区域、头部状态、视觉关键词、色彩或氛围字段写入服装/配饰信息。
- 表情只剩冷淡、有镜头表现力、可爱等标签，没有眼睑、视线、嘴部、下巴/头部角度；或表情空木、过度假笑。
- 无图原创没有主动作母题，只是近距离看屏或普通半身自拍。
- 前置自拍取景关系不成立：手臂前伸、固定视角、定时自拍、支撑视角、近距离前方视角没有任何一种成立。
- 固定画外前置视角自拍或定时自拍被误判为不成立，或强行生成持机手导致双手姿势丢失。
- 有图反推时丢失参考图的主姿势、构图比例、支撑点、关键手部动作或表情强度，只剩普通前置半身自拍。
- 卧姿、靠姿、抱膝、侧躺、桌边前倾被写成普通近景半身自拍，没有主支撑点和前景关系。
- 前置自拍取景关系、主支撑点、手腕或手指停留方式不成立，或出现手臂穿体。
- 用户要求 M 字鸭子坐但画面被写成半身裁切，或缺少骨盆坐地、双膝外开、小腿折向两侧任一项。
- 用户要求整理边界/牵引/突出上身轮廓，但只写轻牵、轻停、手放胸前，没有明确边界下移、上身中心线/上身轮廓线条可见。
- 因保守化而删除上身边界下移动作，或把上身轮廓线条需求完全弱化为普通上身轮廓。
- 字段冗长复述、重复锚点、只剩氛围词或规则解释腔，导致输出不再是高密度动作 JSON。
- 压缩后丢失主动作母题、表情强度、身体/坐姿结构、前置构图或关键手部牵引。

一. 核心门槛
- 这张图必须像真实女生会拍、会留、会发的自拍。
- 不能只是动作存在。
- 不能只是结构正确。
- 必须同时满足：
- 自拍成立
- 空间成立
- 表情自然
- 氛围自然
- 构图好看

二. 自拍成立检查
- 画外前置视角是否明确在人物前方
- 是否没有可见取景实体
- 手臂前伸、固定视角、定时自拍、支撑视角或近距离前方视角是否至少一种成立
- 人物是否在迎向画外前置视角，而不是面对镜子或第三视角镜头
- 构图是否符合前置自拍常见距离
- 是否有屏幕意识：视线像落在屏幕里的自己、镜头旁一点、屏幕下沿或略偏离镜头

三. 空间成立检查
- 是否有主支撑点
- 是否有辅助接触点
- 是否区分了“承重接触”和“装饰动作”
- 中距离时是否存在前景部位
- 人物是否看起来真的处在场景中，而不是悬空贴图

四. 人物自然度检查
- 头部是否有小偏差，而不是完全正模板
- 肩线是否有轻微不对称
- 手指是否有停顿感，而不是僵直摆放
- 表情是否不是发呆、木、空
- 微表情是否服务于自拍瞬间，而不是表演
- 是否写出眼睑、视线落点、嘴角/唇部、下巴和头偏角，而不是只写气质标签
- 是否读懂并还原了原图/任务里的女性气质、拍照情绪、展示目的、身体曲线和微表情动作
- 是否避免为了更有魅力而硬塞撑台、扶腰、拉衣、顶胯、回头或开放式构图

五. 美照感检查
- 这条提示词是否让画面更像生活化成片，而不是说明图
- 场景和光线是否帮助人物变好看，而不是只是被提到
- 是否有舒适的构图重心
- 是否有自拍保留感和真实感

六. 常见不合格结果
- 远距离站拍却说是前置自拍
- 中距离没有前景关系
- 可见取景实体出现在画面里
- 参考图双手都参与姿势，却被硬改成一只手持机
- 固定视角/定时自拍关系没有写清，导致画面像普通他拍
- 侧躺却没有主支撑点
- 抱膝却没有坐压关系
- 表情空、眼神直愣、像 AI mannequin
- 场景写了，但和动作毫无关系

七. 一句话标准
- front-camera-selfie 的最终目标不是“前置自拍动作成立”，而是“真实自然、有氛围、空间合理、人物好看、像真正的女孩自拍”。
