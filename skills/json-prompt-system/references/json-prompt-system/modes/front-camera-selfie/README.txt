front-camera-selfie

定位：
- 本 mode 处理前置自拍、举机自拍、前摄近脸自拍。
- 本 mode 允许在动作变量层内补充场景还原、光线氛围、人物与环境互动，用于让前置自拍更接近真实女生自拍成片逻辑。

适用范围：
- 前置视角朝向自己
- 不依赖镜子成立
- 手臂透视和举机角度是主要拍摄逻辑
- 允许通过支撑面、倚靠关系、室内氛围和局部环境互动增强画面成立性

当前阶段：
- 强化版
- 已提供独立 `mode_template.txt`
- 已允许场景、光线、氛围与环境互动字段
- 已加入前置自拍专属质量门槛，目标不只是动作成立，而是生成真实自然、有氛围、像真实女生会保留的自拍成片

默认模板：
- 使用本目录下的 `mode_template.txt`
