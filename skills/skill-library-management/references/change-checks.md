# 变更与校验

## 接入和更新

- 检查来源与当前内容，保留 `SKILL.md` 所需引用、脚本、模板和许可证。示例库保存来源版本、入口、素材、依赖以及适配要求。
- 检查同名目标和本地修改，按实际能力判断重叠；冲突不等于可以自动覆盖或删除。
- 先把候选放在工作目录核对，再接入真实共享目录。更新实际拥有清单的索引和父级数量，接入需要的客户端软链接。
- 把新版源码／引用变化与本地适配一起检查。插件与系统技能通过各自发行渠道管理。

## 移动和归类

保留文件内容及包内资源的相对结构。更新：源目录、拥有索引的路径、受影响入口／引用、父级导航、客户端软链接。不要借索引整理自动改变运行依赖、MCP 权限或发布配置。

外部目录软链接可以是已有的合法来源；核对其目标并在索引中说明实际所有权，不把它当成重复安装。客户端链接只核对这次库内注册的 Skill 名称，不清理其他来源的链接。

## 检查与完成条件

运行只读索引检查：

```bash
python3 scripts/audit_library.py --skills-root /path/to/skills --root-index /path/to/SKILLS_INDEX.md --json
```

按需添加一个或多个 `--link-dir`。检查失败先定位具体拥有索引与真实源；脚本结果是诊断数据，不是删除或自动修复授权。

完成条件：授权范围的资源完整、分级导航可达、分类与子包没有漏项或重复清单、数量真实、受影响链接有效。新／改 Skill 还需通过环境提供的 Skill 格式检查，并验证其引用；新增脚本需运行有代表性的成功与错误路径。

运行与视觉能力另行验收。索引检查通过只证明管理结构，不证明浏览器动效、GPU 渲染、外部应用连接或生产持久化。报告已做的检查和仍未验证的行为。

## 删除和停用

删除按用户明确的名称／路径和影响范围执行。同一操作同步清单和客户端链接。停用只改变约定的可发现／启用状态，不能默认为永久删除。不要自动恢复此前被删除或停用的资源。
