# x-girl

当前版本：4.2.0。成人美女题材的创作指导：图片与视频，前置自拍、镜面自拍、他拍、架机固定与第一人称被拍；基准是"网上随手发的一条"，给判断和方向、也给出随机风格化设计；固定产出八字段「创作设计卡」＋自检，不写提示词。

按问题取用：创作方向、风格库和设计卡是必读，拍摄与画面读一份，图片或视频只读相关的那份。默认值只是起点，用户说了别的就跟用户走。

## 结构

```
skills/x-girl/
├── SKILL.md                      # 入口：定位、讨论方式、判断顺序、边界、路由
├── README.md / package.json / SOURCE.md
├── references/
│   ├── direction-core.md         # 必读① 创作方向（判断内核）
│   ├── style-library.md          # 必读② 风格库（组装器：原料轴＋正反例）
│   ├── design-card.md            # 必读③ 创作设计卡（固定输出＋自检）
│   ├── capture-and-lens.md       # 按需：拍摄与镜头
│   ├── stills.md                 # 按需：图片
│   └── video-motion.md           # 按需：视频
└── checklists/
    └── creative-review.md        # 按需：自查清单
```

三层分工：

- **入口 `SKILL.md`**：只做「怎么接话 + 去哪读」——讨论方式、判断顺序、边界、路由。
- **必读三份（每次都读）**：`direction-core.md`（判断内核：先好看再骚 → 氛围调子 → 骚四变量 → 表演关系／真实感／主动能量 → 不露也骚 → 尺度）＋ `style-library.md`（组装器：人设气质、原料轴、正反例、禁用清单，随机组装新搭配）＋ `design-card.md`（固定输出：八字段创作设计卡＋反套路／防重复自检）。
- **按需（按问题取一份到两份）**：谈拍摄读 `capture-and-lens.md`（五种拍摄方式），谈图读 `stills.md`，谈片读 `video-motion.md`，要判断行不行读 `creative-review.md`。
