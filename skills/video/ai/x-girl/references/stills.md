# 图片创作

图片没有时间轴、没有声音，所以一张图要自己把话说完。判断顺序还是那四层：像不像真的、勾不勾人、成不成立、质感。

## 三种用途，三种做法

- **单张**：一句话说完。第一眼看到什么、三秒后记得什么，这两件事决定它成不成立。
- **一组图（3–9 张）**：不是九张同款，也不是按"穿衣 → 半脱 → 全裸"排步骤。三种组织都成立：
  1. **一段动作**：同一个地方、同一个机位，把一个动作从前到后拆开。
  2. **几个时刻**：不同场景、不同状态，凑成一天或一种情绪，不做动作分解。
  3. **一张加几张**：一张主图，加几张不同视角或局部（近景、全身、背后、事后）。
  判定两条：每张各自成立；放在一起像同一天、同一个调子。
- **封面 / 首图**：要在缩略图里被认出来。主体大、对比强、表情明确，细节可以少。

## 姿势

- **手是构图工具**：一只手给镜头（持机、伸向镜头、挡脸），另一只手做事。两只手都闲着，画面就散。
- **身体不要平行于画面**：转 15–30°、错开肩和胯、一条腿收一条腿伸，轮廓才有起伏。
- 重心要落在一个地方。悬空、绷着、撑不住的姿势，一眼假。
- 姿势要能解释"她为什么这样待着"：跪坐在床上、半躺在床头、趴在床沿、靠着墙、蹲在浴室。
- 越像"随手一拍"的姿势，越要控制细节：脚趾、手指、下巴、肩膀这四处最容易露馅。

## 构图

- **镜头就在人身上**：主体占画面一半以上，胸像贴到锁骨、全身顶天立地，不留大片环境当背景板。
- **竖幅优先**：3:4 或 9:16；横构图只在床上、身体横陈时用。
- 主体放中间偏一侧，往她看的方向留空间；两边对称会显得像证件照。
- 前景遮挡（被角、头发、手臂、镜框、门缝）能增加"随手一拍"的感觉，但别挡住关键部位。
- **露肤与露点要成为视觉重心，不被消解**：写了低胸、露腿、露点，构图就要让那一处读得清——半身收"眼神 + 低胸领口 + 乳沟"，完整取景收腿线；露点靠机位和递出方式给到位（俯拍露胸、下移叉腿露穴、对镜露背），别让手机、手臂、头发无意盖掉。遮挡当层次，不当遮羞。
- 镜面构图：手机、房间、身体一起入画，要先把房间的杂乱收掉。
- 裁切不要正好切在关节上；要切就切得明显，别切一半。
- 留白和满构图是两种语言：留白显疏离、满构图显压迫，按要传达的感觉选。

## 光

- **单一光源最稳**：窗光、落地灯、浴室灯。侧光出轮廓，侧逆光出体积，正面平光最假。
- 光比要留：亮部不过曝、暗部有细节。整张图均匀发亮，是滤镜感的主要来源。
- 皮肤要能看到高光点和阴影过渡；磨掉之后就成塑料。
- 不要三点布光、不要环形灯的眼珠反光，除非场景里真的有一盏环形灯。
- 光的合理性可以现场核对：窗在哪、影子朝哪、脸的哪一侧亮。

## 表情与视线

- **看镜头**：直接、有对象感，像在回一条私信。适合主动、挑衅、邀请。
- **看别处 / 闭眼**：情绪内收，适合"没在表演"的瞬间，也适合破功之后的泄气。
- 一张图里不要同时要"纯"和"骚"，两种信号会互相抵消。要哪个，就只给那个。
- 眼神方向要和头、肩、身体朝向一致；拧着看镜头会像在瞪人。

## 一组图的一致性

- 同一场景、同一套光、同一套衣服（除非设计换装），这是"一段动作"式一组的"同一组"基础；"几个时刻"式的一组则共享调子、不必共享房间。
- 变化维度只选两三个：角度、距离、表情、手的位置、衣物状态。
- 顺序可以有叙事（先完好 → 再乱 → 最后失控），也可以没有；倒着排或完全不打顺序都要有理由，只是别排成"穿衣 → 半脱 → 全裸"的检查清单。
- 相邻两张不要既换角度又换表情又换光，观众会以为不是同一次拍的。

## 质感：直出感 vs 精修感

基准是"网上随手发的一条"，不是作品集。

- **直出感**：手机直出、轻微噪点和压缩、边缘略虚、暗部不死黑。皮肤有纹理，头发有碎发，衣服有褶。
- **精修感**：磨皮到没有毛孔、颜色统一、边缘锐利、光很干净——一旦这样，就变成作品或商品图了。
- 轻微滤镜和手机自带美颜可以有，网黄也开；但别修成塑料，也别统一调成粉色。
- 平台痕迹可以留：水印、账号名、时间戳、截图边框。这些是"真发出来过"的证据。

## 发布形态

- **单张**：像从主页里截出来的一张，主体大、表情明确。
- **一组图**：3–9 张，三种组织都算，只要放一起像同一天、同一个调子；允许有几张构图略歪、对焦略跑，反而真。
- **封面 / 首图**：缩略图里要能认出人；不要做得像海报。

## 常见失败

- **淘宝模特感**：姿势标准、笑容标准、光很平、背景干净得像商品图。
- **滤镜感**：皮肤发光、颜色统一偏粉、对比被拉平。
- **AI 平滑**：手指、发丝、布料边缘糊在一起，皮肤没有毛孔和绒毛。
- **道具堆砌**：花、蜡烛、丝带、羽毛一起上，画面变成布景。
- **身体不可能**：腰的扭转角度、手臂长度、腿的折叠方式对不上。
- **衣服与场景不搭**：西装在浴室、真丝睡衣在办公室、运动装在酒店床。
- **海报感**：留白讲究、字体、色块、构图太完整——那是广告，不是她的主页。
- **敏感位置的手**：手放在胸口、裆部、腿间、按着布料的位置时最容易糊——指节和布料分不清、多一根或少一根、直接融进身体。位置越暧昧，越要把五指、指节、接触面写清楚，或者干脆把那只手挪到安全位置。
- **姿势与 persona 打架**：甜妹做御姐的冷脸、御姐做甜妹的剪刀手。
- **拼图、水印、截图、糊图、重复帧**：这些是来源特征，不是成品要求；不主动制造，也不当风格。
- **只有器官没有关系的特写**：没有构图、没有"谁在看、在看谁"，只是局部轮播。

## 判断一张图

1. 刷到它，会不会以为是真人自己在拍？不像就回到拍摄关系上找原因。
2. 第一眼看到什么？如果不是脸、不是身体、不是她正在做的事，就是构图出了问题。
3. 三秒后还记得什么？记不住，就说明少一个"点"。
4. 哪里不像真的？手指、影子、皮肤、眼神，按顺序看一遍；手在敏感位置时先看手。
5. 修过头没有？皮肤、边缘、颜色三个地方最容易露。
6. 删掉一个元素会不会更好？多数图都能删。
