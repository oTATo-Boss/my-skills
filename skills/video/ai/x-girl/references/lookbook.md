# 造型库（高级名媛／擦边网红级造型语言）

这是**造型语言库，不是配方表**。借高级名媛／穿搭博主／颜值博主／擦边网红的"造型设计"能力——廓形、剪裁、领口、面料、贴合、层次、妆发、配饰作为一个整体来设计，不是挑件漂亮衣服，更不是拍广告大片。判断内核在[创作方向](direction-core.md)，福利姬底色在[内核](slut-core.md)，组装规则在[风格库](style-library.md)，这里给"怎么穿出高级骚"的语言素材。

## 造型设计的核心

完整造型，不只选衣服。看这些关系是否一起成立：

- **廓形**：紧身／宽松／上紧下松／上松下紧，跟身体和动作是什么关系。
- **剪裁**：腰线在哪、下摆到哪、开衩到哪、肩线掉不掉。
- **领口**：方领／深 V／一字肩／细吊带／抹胸／高领，决定露哪条线、露多少。
- **面料**：厚薄、弹性、垂坠与反射如何支持廓形；贴身或反光材料都按实际受光与衣料结构判断。
- **贴合**：贴到哪、松到哪、勒出哪条线。
- **层次**：叠穿怎么搭、外套开不开、里外露哪一层。
- **妆发配饰**：依据人物与景别组织耳饰、项链、戒指或鞋的比例、位置与反光，让细节支持主视觉。

## 博主感的妆发与配饰（按整体关系判断）

博主感来自对具体人物的审美选择：妆发、服装、配饰与摄影共同形成一个完整形象。精致不是浓淡或件数，不是给所有人换成同一张脸。

- **身份**：五官、脸型、肤色与体态沿用户设定和实际参考，不预置眼型、瞳色、唇色或脸型。
- **妆容**：根据脸、衣服、拍摄距离与现场光决定重点。淡妆、红唇、眼妆或派对妆都可成立；看边缘、色块面积、肤色衔接与整体主次，不按浓妆或红唇直接判廉价。
- **发型**：发根、分缝、体积与轮廓可信，头发与肩颈、耳饰和领口相互让位。整齐、湿发或少量散发都由当前处境解释。
- **配饰与美甲**：看位置、比例、颜色和反光如何呼应造型。手部入镜时与皮肤、衣料及拍摄距离协调；没有美甲也不等于没有审美。
- **小心思**：从比例、线条、材质和穿法里选有作用的细节，如短外套与内层下摆错开一点、袖口轻折露出内层、项链落在领口留白处。细节要在当前景别读得清，衣料张力和穿着方式能实现，不为丰富而全部叠加。

## 露肤是设计的一部分

露肤不是"少穿"，是**有意图地选一处／几处露，让身材优势成为视觉重心**：

- 低领／深 V／抹胸／一字肩 → 露胸线、锁骨、肩颈
- 露腰短上衣／短上衣 → 露腰线
- 超短裙／热裤／开衩 → 露腿线
- 露背设计 → 露背线
- 修身单品 → 凸胸腰臀曲线

每次选重点，不要求全露；露肤要和廓形、剪裁、姿态、机位一起设计，让优势"实际可见"，不是写了却看不见。

## 露点怎么从造型里递出来（主动露点）

这是本库和"露肤擦边"的分界：露肤停在"设计感"，露点靠**穿法、服装状态、动作主动递出来**。

递出方式先跟单品结构对得上，写之前先问一句「这件衣服滑了／拉了，布会去哪」：

- **细吊带、挂脖**：没有罩杯，滑到上臂才露一侧；有杯的滑带子只露肩。
- **平口、抹胸、方领**：光滑带子不露，得把杯口／领口拉到乳下，整只乳才出来。
- **一字肩、长袖针织**：整件往下拉，或从领口往外拉才露；滑到肩下只露肩。
- **衬衫、开衫**：解扣到胸下才露；留一颗不动的先写清是哪颗。
- **裙、裤、内裤**：撩到胯、褪到胯、拉到一边，写清布卡在哪、谁压着。

一句话：递出方式里写不出「布在哪」，这一条就没写。

| 递出方式 | 可写落点 |
| --- | --- |
| 吊带滑一边 | 无罩杯的细吊带滑到上臂，那一侧乳房整个让出来，乳头露在布外，没扶 |
| 解开扣子 | 衬衫解开到胸下，乳晕半露；手停在没继续解的扣子上 |
| 裙摆撩起 | 自己把裙摆撩到胯，穴口对准镜头；手指勾着内裤边 |
| 内裤拉到一边 | 短裤／内裤褪到一边，穴口露出来，腿还并着 |
| 裹着但散开 | 浴巾／被子裹一半，腿缝里露出，动一下就开 |
| 湿／透 | 贴身料湿了一块，乳头在薄料下透出来 |

露点是"给"不是"露"：凑到镜头前、对准了给、掰开当邀请，主动递过去，不是被动走光。

写完过一遍图：乳头／穴口在图里找得到吗？布、手、发丝有一样挡在前面，就是没给到——换递出方式，不是换件衣服硬露。

## 反差单品（按画面需要选择）

反差是可选方法，不是每套造型的必需品。先检查廓形、比例、色彩与材质是否协调，再判断一处运动、正式或硬软反差是否增强画面。

连贯统一的穿搭同样成立；需要对比时给它明确作用，例如让肩线更利落、让颜色重心更集中。没改善画面就保留原搭配，不为“意外感”硬塞单品。

## 反套路自检（造型骚感 + 高级感）

- **删掉"时尚"标签，这套还成不成立？** 删掉人设／风格名，仍能解释比例、穿法、材质与人物的关系吗？缺少依据就补实际设计，不按黑裙或粉白配色直接淘汰。
- **露点是不是靠设计递出来，不是靠脱光？** 脱光了就没有造型了；靠穿法／状态／动作递出点，才是"穿出来的骚"。
- **布料清场了吗？** 递出方式写完后，图里的乳头／穴口有没有被布、手、发丝挡住；有就是没递出来，换递出方式。
- **整体有审美吗？** 看廓形与人物比例、材质受光、色彩主次、穿法和配饰位置。未成年感不做；其余不按单品、风格标签、妆容浓淡或配饰数量一票否决。

## 常见不成立

- 造型像 cos／制服整套，不像本人。
- 露肤写了很多处，但没一处"实际可见"（被取景、遮挡、姿态消解）。
- 只靠"不穿"露点，没有造型设计。
- 配饰堆满，像拍广告。
- 只有熟悉标签却没设计具体比例、穿法与画面关系；或为打破预期牺牲整体协调。未成年感仍不做。

## 最终判断

这套造型，穿在一个真正会凹造型的福利姬身上，凭什么让人想保存、想私信、想立刻要她？——让造型自己回答。
