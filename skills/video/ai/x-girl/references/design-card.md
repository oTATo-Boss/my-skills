本 Skill 的固定产出。每次给出判断与方向时，都落到这张卡上，不散装。字段停在创作参数层：不写提示词、不写 JSON。问的是局部（比如只问光、只问表情），只填相关字段、其余一句带过即可；但结构固定是这张卡。

## 每个字段怎么填

- **调子句**：先写这一条的调子，再让画面长出来。至少含时间或天气、光从哪来、空间、她此刻状态。例：「凌晨没开大灯的卧室，只亮床头暖光，被子皱的，她刚醒。」
- **人设**：以实际人物、用户设定与当下情境确定气质，表格只供命名与找方向；身份不由标签补写，不做未成年感的人设。原有内核从[内核](slut-core.md)取，按原模式执行。
- **造型**：从[风格库](style-library.md)原料轴组装，廓形、领口、露肤、配饰从[造型库](lookbook.md)取语言，先决定整体廓形、上下比例与色彩主次，再选择必要单品、材质、穿法和配饰；反差可选，相同单品可复用，用户已定造型不因旧套路表被替换。补充衣料厚薄、贴合与动作受力，让细节真实可见。单品、颜色、版型、长度、领口、材质、穿法、露肤设计、露点递出方式、配饰逐项写具体；不写「低胸短裙」这种空词，写「领口压到胸线上缘，乳沟可见；无罩杯的细吊带滑到上臂外侧，那一侧乳房整个让出来，乳头露在布外」。
- **场景与光**：写明设计或已观察的空间、支撑面、背景关系及可解释的光向与明暗。多处现场光、柔光或较均匀的光按情境可用，保留人物与织物体积；不靠指定强反差、杂乱或暗灯证明氛围。
- **拍摄关系**：单张选定前置自拍／镜面自拍／他拍／架机固定／第一人称被拍之一，内部视点一致；视频有明确切换时交代前后设备与视点。再给机位、距离、裁切、透视，以及原内容要求怎样在该拍法下实际可见。
- **骚四变量**：四个变量各落实一句，见[创作方向](direction-core.md)。身体朝向、手部接触、重心与视线有具体动机；表情强度与动作一致，不把同一眼皮、嘴形或姿势套给所有画面。单张写一个可见瞬间，视频写有支撑和连锁的连续变化。
- **尺度**：露点必达＋玩自己默认——乳头／乳晕／阴唇／穴口至少其一主动递出来，且默认带自慰动作（揉阴蒂、手指插穴、捏乳头、夹腿磨），写具体递出方式，不写"半露、擦边、不露下点"这种停在半截的话。**递出方式要跟单品结构对得上**：能滑的只有无罩杯的细带、挂脖；平口／抹胸／方领要把领口拉到乳下才露整只乳；一字肩、长袖从领口往外拉才露，光"滑到肩下"只露肩、不露点；衬衫解到胸下才露。写清布被拉到哪、手边有没有布挡着——写不出"布在哪"，就等于没写。默认露骨，往上不是默认。**进擦边模式（不漏点）时，这条整段换成[擦边模式](safe-mode.md)的「不漏点＋极致擦边」，尺度字段和自检第一条都跟着换，不套露点线。**
- **记忆点**：一个「三秒后记得什么」的点。想不出，就说明这一条少一个点，回构图或表情上找。

## 产出后自检

- **露点必达＋玩自己（先查这条）**：这一条乳头／乳晕／阴唇／穴口至少其一，实际递出来了吗？手上有没有在玩（揉阴蒂、手指插穴、捏乳头、夹腿磨）？没递出来、手闲着、停在擦边，就是没达标——回造型或拍摄重做，不是"先这样、下一版再加"。**进擦边模式（不漏点）时，这一条换成[擦边模式](safe-mode.md)的「不漏点（先查）」。**
- **造型与动作因果**：删掉风格标签，服装比例、材质和穿法仍然协调吗？人物重心、接触、手与衣料受力是否能实现？只修实际弱点，不因常见单品或没有反差而重抽。
- **露点方式**：露点是靠穿法／状态／动作主动递出来（滑吊带、解扣、撩裙、拉内裤），不是干脆脱光；脱光就没有造型了，重设计。**递出方式要跟单品结构对得上**——这件衣服滑了／拉了，布会去哪？细吊带无罩杯才滑得露，平口抹胸要拉到乳下，一字肩和长袖从领口往外拉才露，衬衫解到胸下才露。写不出"布在哪"就重写，不是重抽一件更露的衣服。**布料清场**：露点前面不能有布——手边、布边、杯口、发丝有一样正好挡在前面，就算没露；写完回看一眼图里乳头／穴口找不找得到。
- **真实、精致与吸引力**：是否仍是参考或设定中的人物？妆发、服装比例、摄影距离、裁切、光色和背景是否共同支持重点？有清楚的体积与材质，不靠噪点、失焦、歪镜头、浓淡妆标签或首饰件数判真伪与审美。
- **连续性与有效变化**：同组该保持的身份、服装与光线是否连续，变化是否带来新的观看内容？没有上一条就按本次画面验收，不编造历史，不要求每项不重复。

## 单张与组图

- **单张按完成态查**：这一张就得露到、手就得在玩；「先吊一下、下一张再给」不是单张的理由。
- **节奏留给组图、视频**：多张或一段片里才做吊—给—再吊，靠编号或镜头顺序落实，不靠一句"有节奏"带过。

## 卡与提示词的分工

- 本卡是创作参数，不写提示词、不写 JSON。
- 用户要进提示词时，把这张卡交给他的提示词 Skill 照着转，本 Skill 不接手。
- 交接按字段来，不靠默契：

**转给提示词 Skill 的 7 个字段（画面参数，逐项转，缺一个都不行）**

| 字段 | 在提示词里的职责 |
| --- | --- |
| 调子句 | 开场氛围：时间／天气／光／空间／她此刻状态 |
| 人设 | 人物基调：气质关键词＋福利姬内核（卖／要／发），只转气质、不转衣服 |
| 造型 | 服装逐项：单品、颜色、版型、领口、材质、穿法、露肤、露点递出（或遮挡物）、配饰 |
| 场景与光 | 空间陈设、光源、色温、明暗 |
| 拍摄关系 | 五种拍法之一、机位、距离、焦段、画幅、点怎么被拍出来 |
| 骚四变量 | 视点与部位、动作、表情、服装状态 |
| 尺度 | 到哪一档：具体部位／道具；露点模式写「递出＋玩自己」，擦边模式写「不漏点＋极致擦边」——提示词 Skill 照抄这一格，不用自己判断模式 |

交接前做一次可见关系核对：本卡不写提示词，也不重新导演已确认方案。

- 身份、体态、服装与场景依据分开说明；只标本次实际存在或实际查看过的参考，不虚构上传、不预设数量与工具。
- 拍摄关系带出设备位置、距离、裁切与透视；动作带出重心、支撑、接触与衣料变化；表情带出视线对象与强度。它们放在原有对应字段，不新增必填表。
- 七个字段中的重复内容统一含义，避免服装、拍法和动作互相覆盖；原模式尺度字段照原文传递，不因通用审美改写。
- 有视频时，把动作的前后关系与应保持的服装、身份、光线一起交接；只有单张时不写无法在一帧看见的时间过程。

**不转的**

- **记忆点**：不转抽象的「记忆点＝…」标签。交接前指出它对应哪一个可见选择，核对该选择已写进造型、拍摄关系、人物动作或场景与光；缺失就先补实质描述，不能假定转了字段就自动存在。
- **自检**：五条全不转，是给自己看的。「露点方式／布料清场」的判断结论已经写回造型和尺度字段，提示词读那两格就够。
