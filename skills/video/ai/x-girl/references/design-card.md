# 创作设计卡

本 Skill 的固定产出。每次给出判断与方向时，都落到这张卡上，不散装。字段停在创作参数层：不写提示词、不写 JSON。问的是局部（比如只问光、只问表情），只填相关字段、其余一句带过即可；但结构固定是这张卡。

## 模板

| 字段 | 内容 |
| --- | --- |
| 调子句 | （一句：时间／天气 ＋ 光从哪来 ＋ 空间 ＋ 她此刻状态） |
| 人设 | （一个 ＋ 气质关键词） |
| 穿搭 | （单品／颜色／版型／长度／领口／材质／穿法／服装状态） |
| 场景与光 | （空间 ＋ 光源 ＋ 色温 ＋ 明暗） |
| 拍摄关系 | （五选一 ＋ 机位／距离／焦段） |
| 骚四变量 | 视点与部位：…／动作：…／表情：…／服装状态：… |
| 尺度 | （到哪一档：具体部位／道具） |
| 记忆点 | （三秒后记得什么） |
| 自检 | 反套路：删掉人设标签，还有人这么穿吗？／防重复：色系、材质、单品品类、服装状态与上一张重复了吗？ |

## 每个字段怎么填

- **调子句**：先写这一条的调子，再让画面长出来。至少含时间或天气、光从哪来、空间、她此刻状态。例：「凌晨没开大灯的卧室，只亮床头暖光，被子皱的，她刚醒。」
- **人设**：从[风格库](style-library.md)人设表取一个，只取气质（眼神／动作／能量／妆容），不取衣服；不做未成年感的人设。
- **穿搭**：从[风格库](style-library.md)原料轴组装，不照抄表格——上装／下装（或连体）＋外套＋材质＋颜色＋服装状态各取一件，必有一件打破预期的单品；命中禁用清单就重抽。单品、颜色、版型、长度、领口、材质、穿法、服装状态逐项写具体；不写「低胸短裙」这种空词，写「领口压到胸线上缘，乳沟可见」。
- **场景与光**：空间要真实、能解释光；光要选要用（窗光／顶灯／床头灯／屏幕光……），不打摄影棚光。写色温与明暗反差，不写「氛围感」。
- **拍摄关系**：前置自拍／镜面自拍／他拍／架机固定／第一人称被拍，选一种不混；再给机位高低、距离、焦段。
- **骚四变量**：四个变量各落实一句，见[创作方向](direction-core.md)。别把「身体往镜头送」当默认写成撅屁股讨好；动作是有目的、没做完的事。
- **尺度**：具体到露到哪、给不给局部特写、有无道具。默认露骨、往上不是默认。
- **记忆点**：一个「三秒后记得什么」的点。想不出，就说明这一条少一个点，回构图或表情上找。

## 产出后自检

- **反套路**：这一条的穿搭，删掉人设标签（御姐／甜妹／反差…），还会有人这么穿吗？如果「御姐才穿黑裙」「甜妹才穿粉白」才成立，就是刻板，重抽。
- **防重复**：跟最近一条比，色系、材质、单品品类、服装状态有没有撞？撞了换掉其中一项。

## 卡与提示词的分工

- 本卡是创作参数，不写提示词、不写 JSON。
- 用户要进提示词时，把这张卡交给他的提示词 Skill 照着转，本 Skill 不接手。
