# 风格库

这是「随机高质量设计」的**组装器，不是查找表**。判断框架见[创作方向](direction-core.md)，福利姬底色见[内核](slut-core.md)，造型语言（廓形／领口／露肤／配饰）见[造型库](lookbook.md)，这里给原料、规则和正反例。

## 怎么组装（不是查表）

原料轴提供可选择的材料，不要求每轴必取一件。先从本次人物与画面出发，再组织衣服，不让随机搭配代替审美判断。

1. **先有画面与气质**：人物状态、拍摄距离、空间和光线影响穿搭；人设只帮助描述，不绑定衣服或脸。
2. **整体选型**：确定廓形与上下比例，再选色彩主次、材质厚薄、贴合和穿法，最后检查妆发与配饰。适合本次的少量元素就够，不强制外套和叠穿。
3. **让细节有作用**：领口与项链留白、肩线与发型、袖口与手、腰线与下摆互相配合；实际画面里看不见的装饰不靠文字堆满。
4. **反差与防重复按需要用**：相同衣服、颜色和材质可以形成同组连续性。只有重复导致观看内容雷同时，才改变有作用的姿态、构图或造型细节，不要求全部换新。
5. **组合后做整体验收**：删掉风格标签仍能解释比例、穿法和材质关系，且适合当前人物与拍法，才展开设计卡。

## 范围与套路检查

- 未成年感（萝莉／学生／校服整套）——不做。
- 旧版列过男友衬衫、小黑裙、运动背心、绸缎等常见套路；这些是提醒检查是否只靠标签，不是对成年造型单品的永久禁令。用户当次指定或有具体设计依据时按本次画面判断。
- 看到熟悉单品，先检查比例、穿法、场景与摄影是否有明确选择；看到新奇单品也要检查协调性，不自动认为新就更好。

## 人设（只给气质，不绑衣服）

| 人设 | 气质关键词（决定眼神／动作／能量／妆容） |
|---|---|
| 御姐 | 成熟、压得住、说话慢、眼神稳 |
| 反差 | 白天正经、晚上骚；外面冷、里面浪 |
| 甜妹 | 软、黏、会撒娇、声音甜 |
| 纯欲 | 看起来乖、动作不乖 |
| 辣妹 | 主动、张扬、敢露 |
| 邻家 | 像住隔壁、没防备 |
| 冷感 | 话少、疏离、不主动 |
| 姐系 | 会照顾人、也会命令人 |
| 夜出 | 出门前、喝了点、妆浓 |
| 居家松弛 | 刚醒、没收拾、懒得穿好 |
| 运动后 | 出汗、喘、脸红 |
| 换个人设 | 今天不是平时的她 |

## 原料轴

### 上装轴

针织开衫、卫衣、紧身背心、短上衣、衬衫（日常款，不是睡裙）、T 恤（洗旧／乐队印花）、吊带、polo、高领针织、毛衣、牛仔外套、西装外套。

设计感单品（露肤／曲线向）：低领吊带、细肩带背心、一字肩针织、方领短上衣、露肩短上衣、蕾丝抹胸、印花抹胸、绑带吊带、修身短上衣、短款 Polo、露腰短上衣、泡泡袖短上衣。

### 下装轴

牛仔裤（低腰／直筒）、短裙、包臀裙、阔腿裤、短裤、工装短裤、瑜伽裤、运动裤、裙裤、单车裤。

设计感单品（露腿／曲线向）：超短百褶裙、修身迷你裙、皮质迷你裙、收腰碎花短裙、拼接短裙、不规则短裙、高腰热裤、亚麻热裤、运动热裤、花边热裤、开衩裙。

### 连体轴

连衣裙（日常款，非小黑裙）、背心裙、衬衫裙、连体裤、背带裤。

设计感单品：修身连衣裙、针织连衣裙、露背裙、吊带裙、方领裙、闪钻迷你裙、钩织短裙。

### 外套轴

牛仔外套、棒球服、针织开衫、长风衣、西装外套、工装外套、皮夹克、羽绒马甲。

### 材质轴

针织、棉（洗旧／汗湿／透）、牛仔、弹力、羊毛、雪纺、局部蕾丝、局部网眼、局部皮、羊绒。
绸缎、亮片与反光料按实际光线和廓形判断，写清厚度、垂坠与亮面，不按材质名称直接淘汰。

设计感材质（跟设计感单品配）：皮革、镜面、钩织、马海毛、闪钻、金属感面料。这些只在对应造型方向用（派对／甜酷／度假），不单独堆成廉价感。

### 颜色轴（色＋适合的材质／场景，不绑人设）

- 酒红／驼 → 针织、羊毛
- 藏蓝／牛仔蓝 → 牛仔、棉
- 橄榄绿／卡其 → 工装、棉
- 黑／灰／白 → 可作基础色，同组按统一概念保留，变化看实际观看内容
- 粉／奶油／浅蓝 → 棉、马海毛，别只给甜妹
- 亮色（红／黄／绿）→ 运动、街头
- 糖果色（柠檬黄／蜜桃粉／果绿／湖蓝）→ 多巴胺、度假
- 金属色（亮银／香槟金）→ 派对、夜出

### 服装状态轴（按本次动作与连续性选择）

贴着、勒着、松脱、滑到一半、解开一颗、湿了一块、透出来、被拉住、卷起、夹住、卡住、褪到一半、翻起、露出边。

露点的递出方式（无罩杯的细吊带滑到上臂露乳头、解开扣子露乳晕、撩起裙摆露穴口、内裤拉到一边等）见[造型库](lookbook.md)，是"给"不是"露"。

## 反差单品（按画面需要选择）

以下只是寻找反差的方向：成熟气质可配运动细节，柔和造型可配利落剪裁，正式与居家元素也可混搭。是否采用看实际比例、材质与色彩关系，不强制错位，不为高级感混入廉价单品。

没有反差但完整协调的造型可以直接采用；反差破坏人物、场合或画面重点时就不用。

## 搭配素材（按本次画面取舍，不作整套配方）

- 御姐：旧棒球服＋低腰牛仔裤，拉链拉到一半，里面是运动内衣。
- 甜妹：藏蓝 polo＋工装短裤，下摆扎歪一边。
- 居家松弛：洗旧乐队 T 恤（有印花）＋男式四角短裤，下摆湿了一块。
- 反差：高领透视针织＋百褶裙，领子被拉下来。
- 冷感：oversize 灰卫衣＋单车裤，袖子长到盖住半只手。

## 坏例子（这是套路，别这么干）

旧版反例包括白衬衫睡裙、亮片小黑裙、黑裙深 V、粉白睡裙和运动套装。需要排查的是：有没有只靠风格名代替比例、穿法与人物状态，有没有衣料受光不真或配饰抢掉重点。

同一单品在不同剪裁、搭配、人物与摄影中结果不同；不因命中旧反例直接重抽，不自动替换用户已确定的衣服。

## 氛围方向（场景与光，不绑服装）

| 方向 | 气质 | 场景与光 | 镜头与尺度 |
|---|---|---|---|
| 🛏 晨起裸感 | 刚醒、迷糊、不设防、软 | 卧室晨光、窗帘缝 | 床上俯拍或侧躺；露肩背、半胸 |
| 🚿 浴室湿身 | 湿、热、雾、真实 | 浴室顶灯、起雾的镜子 | 对镜或前置；半遮半露，水痕在皮肤上 |
| 🖤 黑色 | 冷、艳、压不住 | 床头灯、暗背景 | 半身，胸口到脸；眼神给足 |
| 🎀 甜软 | 软、甜、反差、乖 | 暖光、床、毛毯 | 跪坐、趴着、裙摆撩起 |
| 👔 衬衫 | 偷穿、慵懒、事后 | 窗光、清晨 | 站或坐，下摆遮与不遮之间 |
| 🎓 制服感 | 乖、被拆穿、羞 | 房间、书桌、白墙 | 只取一个元素，不做 cos |
| 🏃 运动湿汗 | 健康、野、喘、有力 | 家里地垫、顶灯 | 镜前、拉伸、跨坐；汗和呼吸 |
| 🪞 镜前 | 自看、展示、挑逗 | 浴室或卧室镜子、镜前灯 | 对镜全身或半身；反射与持机手 |
| 🌃 夜里公寓 | 放纵、不设限 | 落地窗、城市夜景、床头灯 | 床沿低机位、窗边 |
| 🛋 沙发瘫 | 懒、散、随便、不收拾 | 客厅、电视光、夜里 | 瘫坐、腿分开、俯拍 |
| 🌙 窗边逆光 | 轮廓、暧昧、藏一半 | 逆光、窗帘、黄昏 | 侧身轮廓、局部；看剪影不看细节 |
| 📱 第一人称被拍 | 被看着、被按着、服从 | 室内、任何地方 | 俯拍近景；对方的手、呼吸、影子入画 |
| 🌃 街头夜拍 | 出门、被看见、招摇 | 店门口、街边、招牌背景 | 手机直闪，正面站姿全身 |
| 🍳 厨房台面 | 日常里突然越界 | 厨房台面、餐桌、开着的灯 | 站或趴在台面，背后拍 |
| 🛁 浴缸 | 湿、滑、慢 | 浴缸、瓷砖、顶灯 | 半身泡水，腿搭缸沿；俯拍 |

| 状态 | 气质 | 拍什么 |

| 🚿 洗完澡 | 湿、热、松 | 浴室对镜、水汽糊住半边 |
| 🌙 睡前 | 困、软、发骚 | 被窝里、手机屏幕的光 |
| ☀️ 早起 | 迷糊、没穿、懒 | 床上侧躺、头发乱 |

| ⏳ 等对方回 | 撩、吊着、不耐烦 | 坐着、腿交叠、看镜头 |

## 常见不成立

- 一组图像套图：一张穿衣、一张半脱、一张全裸，按步骤走。
- 皮肤、衣料或光影被处理得失去体积与连续性；清晰、精致与认真设计本身不是问题。
- 单张好看、放一起不像同一天、没有一个调子。
- 人设立得太满，像 cos，不像本人。
- 只重复风格标签，没有实际比例、穿法和摄影选择；或为避开旧例子强行换一套不协调的衣服。
- 手数不对、视角混、表情呆。
- 画面好看但没有骚的点，或有骚的点但画面不好看——都不是成品。
- 全程停在半截、把"看不见"当卖点。

## 最终判断

像一个有具体气质与审美的人在本次情境下主动展示自己；造型和画面本身有观看价值，不靠固定时间、地点或标签成立。
