# 风格库

这是「随机高质量设计」的**组装器，不是查找表**。判断框架见[创作方向](direction-core.md)，这里给原料、规则和正反例。

## 怎么组装（不是查表）

人设只给气质，不给衣服。每次从各原料轴各取一件，拼成一个「有意外感的搭配」，再定这一条的服装状态。

1. **人设决定气质**（眼神、动作速率、妆容、能量），**不决定穿什么**。
2. **上装／下装（或连体）＋外套＋材质＋颜色＋服装状态**，各轴各取一件再拼。
3. **必有一件打破预期的单品**（见下文对照）。
4. **相邻产出，色系、材质、单品品类、服装状态不得连用同一种。**
5. 表格是原料不是答案；命中「禁用清单」就重抽。

## 禁用清单（负面，命中即重抽）

- 白衬衫当睡裙／男友衬衫
- 亮片小黑裙＋细带高跟（夜店刻板，且亮片在直闪下反光崩）
- 绸缎睡袍／丝绸透明睡衣
- 黑裙深 V（御姐刻板）
- 粉白软＋大一号睡裙（甜妹刻板）
- 运动背心＋紧身裤的裸搭（运动刻板）
- 蕾丝网袜、整套制服、纯色内衣全套
- 未成年感（萝莉／学生／校服整套）——不做

## 人设（只给气质，不绑衣服）

| 人设 | 气质关键词（决定眼神／动作／能量／妆容） |
|---|---|
| 御姐 | 成熟、压得住、说话慢、眼神稳 |
| 反差 | 白天正经、晚上骚；外面冷、里面浪 |
| 甜妹 | 软、黏、会撒娇、声音甜 |
| 纯欲 | 看起来乖、动作不乖 |
| 辣妹 | 主动、张扬、敢露 |
| 邻家 | 像住隔壁、没防备 |
| 冷感 | 话少、疏离、不主动 |
| 姐系 | 会照顾人、也会命令人 |
| 夜出 | 出门前、喝了点、妆浓 |
| 居家松弛 | 刚醒、没收拾、懒得穿好 |
| 运动后 | 出汗、喘、脸红 |
| 换个人设 | 今天不是平时的她 |

## 原料轴

### 上装轴

针织开衫、卫衣、紧身背心、短上衣、衬衫（日常款，不是睡裙）、T 恤（洗旧／乐队印花）、吊带、polo、高领针织、毛衣、牛仔外套、西装外套。

### 下装轴

牛仔裤（低腰／直筒）、短裙、包臀裙、阔腿裤、短裤、工装短裤、瑜伽裤、运动裤、裙裤、单车裤。

### 连体轴

连衣裙（日常款，非小黑裙）、背心裙、衬衫裙、连体裤、背带裤。

### 外套轴

牛仔外套、棒球服、针织开衫、长风衣、西装外套、工装外套、皮夹克、羽绒马甲。

### 材质轴

针织、棉（洗旧／汗湿／透）、牛仔、弹力、羊毛、雪纺、局部蕾丝、局部网眼、局部皮、羊绒。
不用绸缎；亮片／反光料只在明确夜店场景时用。

### 颜色轴（色＋适合的材质／场景，不绑人设）

- 酒红／驼 → 针织、羊毛
- 藏蓝／牛仔蓝 → 牛仔、棉
- 橄榄绿／卡其 → 工装、棉
- 黑／灰／白 → 基础，但连续产出不连用
- 粉／奶油／浅蓝 → 棉、马海毛，别只给甜妹
- 亮色（红／黄／绿）→ 运动、街头

### 服装状态轴（连续产出不重复同一招）

贴着、勒着、松脱、滑到一半、解开一颗、湿了一块、透出来、被拉住、卷起、夹住、卡住、褪到一半、翻起、露出边。

## 打破预期的单品（必有一件）

气质和单品错位，才出意外感：

- 成熟系（御姐／冷感／姐系）→ 混一件少年感／运动感／廉价感单品：棒球服、旧卫衣、洗旧 T 恤、工装裤、单车裤。
- 软系（甜妹／纯欲／邻家）→ 混一件硬朗／正式／中性单品：西装、皮夹克、polo、工装、直筒西装裤。
- 正式／反差 → 混一件居家／运动单品。
- 居家／松弛 → 混一件出门才穿的正式单品：衬衫、西装外套、高跟。

## 好例子（这才是「日常变体」，照着这个味做）

- 御姐：旧棒球服＋低腰牛仔裤，拉链拉到一半，里面是运动内衣。
- 甜妹：藏蓝 polo＋工装短裤，下摆扎歪一边。
- 居家松弛：洗旧乐队 T 恤（有印花）＋男式四角短裤，下摆湿了一块。
- 反差：高领透视针织＋百褶裙，领子被拉下来。
- 冷感：oversize 灰卫衣＋单车裤，袖子长到盖住半只手。

## 坏例子（这是套路，别这么干）

- 白衬衫当睡裙、下摆遮大腿——最俗套。
- 亮片小黑裙＋细带高跟——夜店刻板＋反光崩。
- 黑裙深 V——御姐刻板。
- 粉白软＋大一号睡裙——甜妹刻板。
- 运动背心＋紧身裤裸搭——运动刻板。

| 方向 | 气质 | 场景与光 | 镜头与尺度 |
|---|---|---|---|

| 🚿 浴室湿身 | 湿、热、雾、真实 | 浴室顶灯、起雾的镜子 | 对镜或前置；半遮半露，水痕在皮肤上 |
| 🖤 黑色 | 冷、艳、压不住 | 床头灯、暗背景 | 半身，胸口到脸；眼神给足 |
| 🎀 甜软 | 软、甜、反差、乖 | 暖光、床、毛毯 | 跪坐、趴着、裙摆撩起 |
| 👔 衬衫 | 偷穿、慵懒、事后 | 窗光、清晨 | 站或坐，下摆遮与不遮之间 |
| 🎓 制服感 | 乖、被拆穿、羞 | 房间、书桌、白墙 | 只取一个元素，不做 cos |
| 🏃 运动湿汗 | 健康、野、喘、有力 | 家里地垫、顶灯 | 镜前、拉伸、跨坐；汗和呼吸 |

| 🛁 浴缸 | 湿、滑、慢 | 浴缸、瓷砖、顶灯 | 半身泡水，腿搭缸沿；俯拍 |

## 常见不成立

- 一组图像套图：一张穿衣、一张半脱、一张全裸，按步骤走。
- 每张都精修，光打得像棚拍，没有随手感。
- 单张好看、放一起不像同一天、没有一个调子。
- 人设立得太满，像 cos，不像本人。
- 命中禁用清单（白衬衫当睡裙、亮片小黑裙、黑裙深 V、粉白睡裙、运动背心裸搭）。
- 手数不对、视角混、表情呆。
- 画面好看但没有骚的点，或有骚的点但画面不好看——都不是成品。
- 全程停在半截、把"看不见"当卖点。
