# 创作方向

用户没提的地方，按这里的默认值起步；用户提了别的，就跟用户走。默认值是省事的起点，不是考核标准。

底子与面子分开看：**底子是高级名媛／穿搭博主／颜值博主／擦边网红的审美（造型、光色、构图、身材优势出片），面子是婊子／骚货／福利姬的内核（卖、要、发、主动露点）**。内核在[福利姬内核](slut-core.md)，造型语言在[造型库](lookbook.md)，这里给判断顺序。

## 先好看，再骚（门槛与顺序）

好看和骚不是一回事，有先后：**先好看，再骚。** 不好看的画面上加尺度，只会更难看；好看的画面上加对的东西，才叫骚。

1. **好看＋氛围（门槛）**：脸读得出来（是清透淡颜真实五官，不是网红脸）、画面有光、构图有重心、比例真、画面干净；**博主感成立（做减法不是加法）**——妆干净（不是浓妆）、配饰一件克制（不堆）、光有调子（明暗反差不是一片平光）、造型是设计过的（廓形、剪裁、领口、面料、层次、配饰整体成立）、构图精致，像有审美的颜值博主，不是素人随手拍、也不是浓妆网红脸。露肤有意图，身材优势**实际可见**，不是写了却看不见。一条有一个统一的调子，光色、空间、生活痕迹都在这个调子里。不过这一层，不加尺度、不写提示词。
2. **真（底线）**：真手机、真房间、真人自己在拍或在被拍、在给具体的人看。不是广告，不是棚拍，不是 AI 展示图。真指拍摄关系可信，不等于糙、不设计、不讲究光。
3. **骚（在好看之上）**：露是结果，不是理由；穿整齐也能骚。骚由四样东西决定，缺一样就只剩露——视角与部位、动作、表情、服装状态，见下文「骚的四个变量」。
4. **露点（硬约束，不是可选项）**：乳头／乳晕／阴唇／穴口至少其一必须主动递出来，靠动作、穿法、服装状态，不是"不小心走光"；递出方式要跟单品结构对得上，写清布被拉到哪。**停在擦边、露点没递出来＝这条不达标，回造型或拍摄重做，不是"下一版再加"。** 高级感是露点的包装，不是露点的替代品；两者冲突时露点优先。规则见[福利姬内核](slut-core.md)。
5. **同一个人（不漂移）**：换的是衣服、状态、尺度、镜头，不是另一个人。同一条／同一组里 persona 不漂移。

## 氛围

氛围不是滤镜，也不是形容词。一条一个调子，先写一句「这条的调子是什么」，再让画面长出来。

- 调子句里至少要有：时间或天气、光从哪来、房间或空间、她此刻的状态。例：「凌晨没开大灯的卧室，只亮床头暖光，被子皱的，她刚醒。」
- 一条里的几张可以换房间、换衣服、换景别，但共享同一个调子；不像几条不相干的帖子拼在一起。
- 光色、明暗反差、空间里的生活痕迹、她身上的状态，都服务这一句。不写「电影感、氛围感、高级感」这种空词。

## 默认形态

- **社媒摆拍式**：她对着镜头展示自己，网黄 / 福利姬随手发一条那种。没有剧情，不设计"躲起来 / 被发现 / 意外"。
- 表情可以有"端着 → 破功"的弧线，但那是姿态，不是故事。
- 默认能量是主动勾引，不是被动展示（见下文"主动能量"）。
- 默认尺度露骨（见文末"尺度"）。

## 人物 persona

- 先定一个 SNS 网红 persona 锚点，只选一个：御姐 / 辣妹 / 甜妹 / 清纯 / 女友感 / 元气 / 中性辣。
- persona 决定四件事：穿搭档次、妆容浓度、动作速率、表情基调。
- **一致性优先于新鲜感**。同一条片、同一套图里不漂移；开头甜妹结尾御姐是最常见的失败。
- 长相、发型、身材、年龄交给用户参考图。讨论时不要替用户改这些，也不要凭想象补一个具体长相。
- 不做未成年感的人设，一律按成年女性写。
- 穿搭的组装方法、原料轴与正反例见[风格库](style-library.md)，人设只给气质不绑衣服；命中禁用清单就重抽。

## 造型设计

- 造型是完整设计，不是挑件衣服：廓形、剪裁、领口、面料、贴合、层次、妆发、配饰作为一个整体成立，语言见[造型库](lookbook.md)。
- 露肤是设计的一部分：低领／抹胸／一字肩／露腰短上衣／超短裙热裤／开衩／露背，有意图地选一处／几处露，让胸腰臀腿的优势成为视觉重心。
- **露点靠穿法递出来，不靠脱光**：无罩杯的细吊带滑到上臂露乳头、解开扣子露乳晕、撩起裙摆露穴口、内裤拉到一边、裹着但散开、湿透。露点是"给"不是"露"，见[福利姬内核](slut-core.md)。
- 服装两条腿：日常款负责真实、松弛、随手拍；设计感单品负责露肤、曲线、辨识度。按当次人设和氛围配比，不默认只走日常裸感。
- 情趣来自**日常变体的暴露**与**设计感单品的露肤**两条路，不再只有"针织掀开、褪到一半"这一种。
- 情趣内衣、丝袜、JK 制服、玩具都可以用，但不是标配。判断标准是"这个人此刻会不会这么穿"，不是"要露了就换上"。
- 别掉进刻板印象：一说诱惑就丝绸透明睡衣、一露就全套蕾丝，那是土，不是骚。设计感不等于俗艳——廓形成立、材质对、露肤有意图、配饰一件够用才是高级。
- 配饰能定人设（耳饰、发夹、项链、戒指、鞋），但别堆；一件就够，多了像在拍广告。
- 材质优先针织、蕾丝、网眼、棉、紧身这类贴身料；不用绸面缎面，反光像道具。皮革、镜面、钩织、马海毛、闪钻只在对的方向用。
- 穿法比单品重要，但"褪到一半"不是唯一解法：也可以穿得好好的、扣子全系、只把下摆拉出来一点，或者脱掉之后裹着被子。穿法跟着这一条的关系走，和"服装状态"一起定。
- 制服只取元素：领结、百褶、过膝袜、制服鞋这类单品可以用，不做整套 cos。重点是穿着有设计感的单品做骚事，不是展示服装。
- 具体单品从[风格库](style-library.md)原料轴组装，不照抄表格；廓形、领口、露肤、配饰从[造型库](lookbook.md)取语言；命中禁用清单就重抽，连续产出不重复色系／材质／单品品类／服装状态。

## 场景

- 真实空间优先：卧室、浴室、客厅、酒店房、出租屋、试衣间。要有生活痕迹——被子是皱的、桌上有点杂物、窗帘半拉、插座和衣架可能在画面里。收得太干净就假。
- 不要摄影棚感：纯色背景、柔光箱、反光板一出现就假。
- 场景要能解释光：窗在哪、灯在哪、门有没有开。光解释不通，画面就假。
- 室内室外都成立；同一件事在浴室、厨房、玄关、走廊、阳台都能发生，不必默认卧室。别把某个方向机械绑到固定房间。

## 网黄质感（本 Skill 的基准）

不是拍作品，是"网上随手发的一条"。通过标准只有一条：**刷到它的人相信这是真人自己在拍，而不是团队做的图或片**。

- **手机直出**：前置或后置、竖屏 9:16、前置默认镜像；允许轻微噪点、压缩、对焦慢半拍、边缘发虚。
- **空间是真的**：床没铺、桌上杂物、窗帘半拉、插座和衣架都可能入画。这不是布景，是她的房间。
- **光就是屋里的光**：白天窗光、夜里顶灯 / 台灯 / 床头灯 / 手机屏幕光 / 自带补光，都成立。不成立的是摄影布光——柔光箱、反光板、轮廓光、两个方向不同的光。
- **不修**：不磨皮、不液化、不统一调色、不加胶片颗粒。轻微滤镜和手机自带美颜可以有（网黄也开），但别修成塑料。
- **不装**：不摆封面、不做杂志构图、不写文案腔的标题。姿态是"给看"，不是"摆艺术"。
- **平台痕迹可以有**：水印、账号名、时间戳、截图边框、相册缩略图。这些是"真发出来过"的证据，不是瑕疵。
- 这些质感痕迹主要由模型和参考图决定：讨论时用来判断像不像真的，但不要指望靠堆形容词在提示里解决。

## 骚的四个变量

骚不是形容词，是四样能写进画面的具体东西。"对象感""往镜头送"只是其中一部分，写成默认会变成撅屁股讨好感。

1. **视角与部位**：先定谁在看、在哪看、看多近，再定画面给哪个部位、故意藏哪个。核心是视点关系，不是特写越多越骚。同一张脸加滑到肩头的吊带，角度选对了比全裸骚。
2. **动作**：她正在做一件有目的、没做完的事——在脱、在等、在藏、在忍；镜头是偷看，不是她在给镜头摆姿势。身体朝向和重心要真。
3. **表情**：不是"骚"，是"她知道被看"的那一下——眼睛先落在别处再抬起来、嘴停在半路、呼吸和脸红。冷和呆差在眼睛有没有在动，骚和媚差在有没有在给他看。
4. **服装状态**：不是穿多少，是衣服和身体之间正在发生什么——贴着、勒着、松脱、滑到一半、解开一颗、湿了一块、透出来、被拉住。

再加一条时间线：把画面挂在**一件正在发生的事**上——消息发出去等回复、刚被叫到名字、衣角刚拉下来一半。比"摆一个姿势"骚得多。

下面「表演与关系」「真实感」「主动能量」是这四个变量在关系、动作、表情上的展开。

## 表演与关系

- 她知道自己被看着，而且是在给**具体的人**看：像在回一条私信、像在应一个付费要求、像知道对面坐着谁。
- 这种关系**不靠台词**。一个眼神、把镜头当人看、动作里带"给你看"的针对性，就够了。说不说话由用户定，默认不出声。
- 直白优先：要露就露，要摸就摸，不靠暗示和留白绕。
- 可以有"卖"的直白感：镜头前展示、把镜头当买家、用姿态和眼神提条件。这类内容本来就是交易性的，不必装成纯粹的自赏。
- 但不设计桥段：不写"被抓到""假装不知道在拍"这类小剧场，除非用户要。

## 真实感（第一原则）

- 出片要像真人举着手机拍自己，不是在导戏。
- **表情先于动作**：先有看镜头时的耻感、被看穿的慌、贱感，再有难耐。
- **动作小幅、连续、有一点笨**：掀衣会挡脸一下、咬衣会含糊、顶胯是小幅不是甩胯。
- 一处"没必要但真实"的细节最值钱：头发黏在脸上、被角挡住半边、手机角度歪了没扶正。
- 静止和自然垂手也须有可信表情、重心与拍摄关系，不把随机小动作当活人感。

## 主动能量

默认主体是主动、放得开、去勾引，不是害羞被动。能量要落在看得见的动作和眼神上，不靠抽象心理词。

- **主动露**：自己扒衣、自己掰开、把乳头 / 阴唇 / 穴口凑到镜头前，对准了给看。
- **主动勾**：舔唇、伸舌、扭腰、夹腿、捏乳头、揉湿穴口；眼神是"想要被看、想要被上"的媚，不是躲闪或纯羞。
- **主动邀请**：屁股朝镜头撅、穴口对着镜头晃、手指掰开当邀请；浪叫和呻吟自己来，越到后面越放得开。
- **破功方向**：人设崩塌不是崩向脸红害羞，是崩向彻底放开发情、主动勾引、忍不住。

## 不露也骚（模型或平台不能露时）

前提一句话：**尺度可以降，关系不能降**。不能露的时候，把力气全放到"她在给谁看"上，而不是靠少露一点、再少露一点，最后变成安静的生活照。

要整套打法，进[擦边模式](safe-mode.md)——那是独立完整模式（边界、七个杠杆、造型、拍摄、设计卡自检都另有一套）。这里先给四条核心杠杆和降级顺序。

四条杠杆，按重要性排：

1. **眼神停住**。不是"看镜头"，是盯住、不眨眼，像在等对方先动。上眼睑半阖、下巴微收。这一下就能把"看"变成"勾"。
2. **嘴停在半路**。微张、下唇被牙轻轻咬住一点、舌尖在唇后；不笑开，也不闭死。笑开是无辜，闭死是冷淡，中间那一档才是骚。
3. **身体往镜头送**。一侧肩前压、腰塌、胸口朝镜头，不是正面坐直。距离也要近：脸占画面三分之一以上。
4. **手做一件没做完的事**。拽着没松、按着没挪、掐着衣角。手一旦"完成"了动作，就变成整理衣服。

降级顺序也要记清：先减露，再减动作幅度，最后才动关系。关系一减，画面就不成立了。

不露不等于保守。不露的张力来自距离、停顿和"她还在等"。

## 美感

- **私密感来自内容本身，不来自影调**。默认用屋里的光：白天窗光、晚上顶灯或床头灯。氛围灯、霓虹、彩色补光只在用户明确要的时候用。
- **皮肤要真实**：纹理、毛孔、小瑕疵、高光点和阴影过渡都要在。不磨皮、不假亮、不塑料。
- 不要用潮红 / 泛红 / 出汗来"演"骚；用眼神和动作。
- 角色美感靠 persona + 妆容 + 表情演技，不靠滤镜和妆造堆。
- 妆容跟 persona：clean skin 加少量色块（比如桃粉眼影），不浓妆、不磨皮滤镜感。
- 露要具体：不是"低胸"，是"领口压到胸线上缘，乳沟可见"；不是"湿"，是"内裤贴在身上，有一块深色"。

## 尺度

- **露肤与露点是两档，别停在擦边**：擦边网红那套停在露肤（低胸、露肩、露腰、露腿、乳沟）；本 Skill 默认往上——**主动露点**。露点是主动给，不是不小心走光；分界与行为落点见[福利姬内核](slut-core.md)。
- **默认直接露骨，按上限讨论**：没被点名降级时，露点、局部特写、自慰、手指或玩具、体液都在可用范围，不必先问"要不要这么露"。**自慰（玩自己）是默认项**：露点默认带揉阴蒂、手指插穴、捏乳头、夹腿磨这些动作，爽感实时发生，不是静止露着给看。
- **点级细节是起点，不是上限**：乳头 / 乳尖 / 阴蒂 / 阴唇 / 穴口至少其一，是这类内容的最低线；内容需要时给全、给近、给过程。
- **遮挡是节奏，不是遮羞**：开头吊一下、中途半褪、被角滑下去再拉开——这些都好看，看情况用。判断标准是"最后给到了没有"；全程停在半截、把"看不见"当卖点，才是问题。节奏只在组图、视频里做，单张按完成态查。
- **露点要写到能指出来**：布被拉到哪、露的是哪一侧、手边有没有布挡着。写「滑到肩下」这类布还在原位的说法，等于没写；单品结构撑不起这个动作，就换递出方式，不硬写。
- **往上不是默认**：一直往上走，最后每组都剩身体局部，越来越像。同一档换个说法、或者退半步，都比加码耐看。
- 用户明确限度才降，且只降到用户口径，不自作主张再降半级；降级降在"露多少"，不降在真实感。
- 前提：角色一律为成年人，只做虚构创作指导。
- 三条底线：真实感优先；光跟场景；不自创第二摄影机。
