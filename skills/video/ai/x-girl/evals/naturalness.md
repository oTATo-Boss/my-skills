# 通用画面方法验收

用于修改摄影、人物表现和造型方法后的针对性检查。只测试普通穿衣成年人物的通用画面判断，不生成媒体、不改变原有内容尺度或模式。本页不是新的创作流程或每次调用的必填清单。

让未参与修改的上下文实际读取入口与相关参考，再给出下面各案的具体画面建议；不能只复述规则。记录建议是否保留输入、有没有新增无依据限制，以及所用依据。可与旧版或无指导的回答对照，单次通过不代表成像或审美提升已验证。

| 场景 | 应体现的判断 |
| --- | --- |
| 普通穿衣半身照，窗光加室内灯，画面清晰、正面、对称，双手自然放松 | 检查光向、肤色、体积、支撑、距离与裁切；不因多灯、对称、垂手或干净直接否定，不强加失焦与歪镜头。 |
| 同一套衣服连续一组图，颜色、材质和背景保持 | 保留造型与空间连续性，用有作用的距离、视线、姿态或构图形成观看变化；不强制每张换色换款。 |
| 给定黑眼、方脸的成年人物设定，红唇派对造型 | 保留输入身份；评价妆容、服装与现场光的比例和主次，不改成预设五官，不以红唇或浓妆一票否决。 |
| 他拍或架机固定的视频，人物自然转头、移重心，动作平顺、结尾自然停留 | 按拍法解释设备与连续动作，观察视线、重心和衣料随动；不强塞持机手、意外、晃动、固定秒数换姿或统一狼狈收尾。 |
| 只有面部参考，要设计精致自然的穿衣半身照；未给服装与房间图 | 将已观察身份与新设计衣服、场景分开，交代服装结构、支撑、光与裁切；不声称看过不存在的参考，不预设上传数量或工具。 |

另做范围核对：默认模式、内容尺度和模式边界沿旧版原条款；没有工具绑定、自动生成、额外确认或生成效果保证。静态资源、版本、权限与副本一致性检查和本页的文字场景应用分别记录。
