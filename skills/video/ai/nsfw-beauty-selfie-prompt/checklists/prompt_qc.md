# 提示词 QC

交付前全部通过；机器项由 `scripts/prompt_tools.py check <文件>` 出具 PASS，模型再补判人工项。

机器检查（脚本覆盖）：

1. 12 栏各恰好出现一次、顺序固定。
2. 逐栏非空白字符数上限（默认设定 ≤150；完整连续动作 ≤700；其余见脚本 LIMITS）。
3. 默认设定含唯一合法 `摄影机身份：front_camera_selfie | mirror_selfie | third_party_capture`。
4. 无电影腔黑名单词（电影感 / 推轨 / 慢动作 / 宽银幕 / 定格 …）。
5. 无设备参数（焦距 / 光圈 / 快门 / ISO / 滤镜参数）。
6. 无引号字符（不写带引号的可念拟声 / 骚话字）。

人工检查（脚本之外，逐条过）：

1. 露骨落地靠动作 / 表情 / 眼神（主动诱惑：自己扒 / 掰 / 凑镜头 / 勾眼），无「求操 / 欠操 / 犯贱」心理词，无出汗 / 潮红 / 泛红。
2. 真实感：像随手点开相机录，动作有犹豫 / 停顿 / 看屏幕的瞬间，收尾失控而非定格。
3. 画幅诚实：前置清楚拍到脸和胸，下身靠镜头下移 / 叉腿 / 转身，不写成第三视角全景床戏。
4. 长相不锁：人物栏只写 persona / 气质 / 妆容 / 表情基调，不写五官 / 身材 / 年龄 / 发型。
5. 两只手：持机手只持机，空闲手单次主任务，物理可达。
6. 光跟场景：单一现实光源，默认白天自然室内，无虚构三点布光。
7. 人设崩塌弧线：装 → 破功 → 真面色，镜头即观众，不全程单一表情。
8. 尺度：与用户口径一致，未被降半级。

输出：全部 PASS → 按原样交付单个 `txt` 代码块（12 栏合成一段）；任一 FAIL → 修后重跑脚本，直至 PASS。
