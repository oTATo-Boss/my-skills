# 阻断输出合同

正常交付只有一个 `txt` 代码块（12 栏单段公式完整提示词）。以下情况**且仅以下情况**允许输出阻断块：

1. 模式矩阵仲裁无法补齐（`references/mode_matrix.md` 判定非法）。
2. 起点截图与指定 capture_mode 冲突。
3. 上游原文缺失（跨对话缺少任一锁定模块）。
4. 用户要求图生视频 / 延长 / 编辑但缺少对应输入（起点图、终点图、参考素材）。

## 规则

- 只输出 `templates/block_output_template.md` 的格式，JSON 必须是合法可解析的单对象，除此之外不得有任何额外文字。
- `code` 取错误码表中的一个值；多码时给触发顺序最早的一个，`missing_fields` 列全部。
- 禁止夹带候选提示词、安慰性解释或"如果你…"的方案。
- 同一轮只阻断一次；用户补齐后按补齐输入继续，不得重复索要。
