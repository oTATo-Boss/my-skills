# NSFW Beauty Selfie Prompt

纯 NSFW 私密自拍提示词生成器。最终产物是**一个** `txt` 代码块，内部固定 **12 栏单段公式**（见 `templates/prompt_template.md`），按顺序合成一段交付。默认是本人手机前置自拍、单镜头约 15 秒的社媒摆拍——不拆镜、不编号、不写秒数。

默认目标：**真实、露骨、像本人随手录的私密自拍**。除非用户明确限尺度，否则按主导露骨写满；用户没给方向时自行发挥。

## 绝对规则

- 中文为默认输出语言。字数单位一律为**非空白字符数**，由 `scripts/prompt_tools.py` 计量，逐栏受限。
- 12 栏顺序固定、各出现一次，`栏目名：` 键值格式；`check` 通过才算交付。
- 长相交给参考图（I2V）固定：人物栏不写五官 / 发色 / 发型 / 身材 / 年龄 / 体态 / 习惯动作，只写 persona 类型、气质、妆容、表情基调。
- 露骨落地靠**动作 / 表情 / 眼神**（主动诱惑：自己扒、自己掰、凑镜头、勾眼），不靠「求操 / 欠操 / 犯贱」等心理词，不靠出汗 / 潮红 / 泛红。
- 默认成片形态：社媒摆拍式美女自拍，纯卖弄自己，无剧情、无前因后果；单镜头约 15 秒，仅显式要求才改时长 / 多镜头，上限 30 秒。
- 不出现设备参数（焦距 / 光圈 / 快门 / ISO / 滤镜参数）。
- `@[语义名]` 是稳定素材句柄；`@图片N / @视频N / @音频N` 只在执行层机械映射。
- 画幅是内部执行参数，不进模板。
- 默认无背景音乐、无台词；环境音、动作音、呻吟喘息只写性质，不写任何带引号的可念字词。

## 摄影机合同（唯一）

每条提示词只有一个成片摄影机，写进默认设定的 `摄影机身份：`，全片唯一：

| 值 | 含义 |
| --- | --- |
| `front_camera_selfie` | 本人手机前置，机身画外，运动只来自手腕 / 呼吸 / 重心 |
| `mirror_selfie` | 手机拍镜面反射 |
| `third_party_capture` | 外部摄影机 / 固定机位，人物手机只是道具 |

机位与构图、运镜两栏必须服从它，不引入第二视点。冲突时阻断，错误码见 `references/capture_modes.md`。

## 阻断输出

正常交付只有一个 `txt` 代码块。门禁不满足（缺起点图、capture 冲突、上游素材缺失）时，只输出 `templates/block_output_template.md` 格式的 JSON 阻断块，见 `references/block_output_contract.md`。禁止夹带候选提示词。

## 创作方向

读取 `references/explicit_direction.md`（真实感与露骨的内核）。要点：像真人举着手机拍自己；动作小幅连续、有点笨；画幅诚实；两只手分工；光跟场景；私密感来自内容不来自影调；人设崩塌弧线；失控落点。

## 渐进加载

- 模板与 12 栏：`templates/prompt_template.md`
- 摄影机合同：`references/capture_modes.md`
- 创作方向：`references/explicit_direction.md`
- 反例校准：`references/anti_examples.md`
- 模式仲裁（起点图 / 生成模式）：`references/mode_matrix.md`

## 最终输出

创建或修改提示词，最终只输出**一个 `txt` 代码块**（12 栏合成一段），代码块之外不追加分析、总结或可选方案。
