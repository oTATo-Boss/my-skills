# 变更记录

## 1.1.1 · 2026-10-19

- 按用户要求，两种模式统一默认 Plus；长视频映射改为 `plus`，客户端为缺少实例字段的旧 jobs 补 `plus`，任务显式指定的实例保持有效。
- 同步说明、来源与版本记录，调整现有离线默认值及提交回归；未提交收费生成。

## 1.1.0 · 2026-10-19

- 新增长视频应用 `2103012816681041921`，独立维护用户提供的 20 个节点；原短视频应用及默认使用方式保留。
- 构造器新增 `--mode long`、`--megapixels`；默认取示例的 35 秒、0.5 MP、16:9、default 实例。时长范围、空图片与可选字段的线上表现保留待核实状态。
- 所选应用 ID 写入 jobs 和提交回执；客户端按任务路由，旧 jobs 缺少 ID 时兼容原应用，拒绝未登记应用。两种模式共用上传、并发限制与查询恢复机制。
- 不继承原示例的提示词、上传素材、启用的 LoRA 强度或文本触发词；未说明用途的数值与开关保留示例值。
- 扩展离线构造、参数隔离、dry-run 与本地假服务路由回归；不提交收费生成，不将假服务视频当成长视频实测。
