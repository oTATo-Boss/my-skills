# 成片审查 QC

## 基础合格
- 身份、服装、固定配饰是否稳定？
- 原动作、表演、接触、受力和时序是否保持？
- 场景方向与关键空间是否连续？
- 摄影机高度 / 俯仰、人物姿态与接触拓扑是否持续匹配原视频，而不是只在首帧相似？
- 地面 / 墙面 / 天花或天空的主次、地墙交界 / 地平线和场景表面占比是否在首中尾帧都符合投影卡？
- 俯拍是否始终由地面主导、仰拍是否始终由上部空间主导；是否出现背景角度漂移或场景资产原视角回弹？
- 绿幕、文字、时间码、黑边、垫子、走位点等非最终元素是否彻底清除？
- 最终视觉是否与 @分镜图 和当前项目影片质感一致？

## 项目要求
- 当前项目明确的光影 / 色彩 / 人物补光要求是否满足？
- 不得用 Skill 自己的审美替代项目要求。

## 特殊镜头
- VFX 是否真实嵌入空间，而不是二维贴片？
- 无缝转场是否真的连续？
- 纯 AI 镜头是否与前后镜头保持时空连续？
- tilt / pan / 推进 / 后拉 / 横移时，地平线、地墙交界、表面占比与近中远层视差是否按摄影机运动连续响应？

## 原因归类
必须区分：
- Skill / 提示词结构性冲突
- 当前项目要求执行偏差
- 源素材先天限制
- 单次模型随机失败 / 抽卡稳定性问题

只有第一类可以直接成为 Skill 升级依据；其他类型需要更多证据，不自动写回通用规则。

## 返修
- 失败必须归类到一个主要变量，优先单变量返修。
