# AI Live-Action Fusion Skill v4.2.2

面向 **AI + 实拍后期融合** 的两阶段生产 Skill：先生成并筛选静态分镜图，再把用户发布到 `/分镜图` 的正式图片绑定为视频阶段 `@分镜图`。

适用于：
- 绿幕 / 棚拍换景
- 人物换装、妆造与固定配饰替换
- 环境重光照
- AI 场景与实拍摄影机匹配
- 背景贴图感修复
- 局部 VFX
- 黑屏补画
- 局部摄影重构
- 纯 AI 单镜补全
- 真实 Take 审片与单变量返修

正式调用名：`$ai-liveaction-fusion`

- 富文本平台必须在正文原位置逐次使用真实 `@` 选择机制，并核验 mention 数量、映射、未解析引用和重复素材；
- 上传、填词、绑定与提交的授权互不包含；没有明确提交授权时停在已绑定、未提交；
- 新增提交按钮、任务历史和积分 / 配额的防误提交复核与异常停止规则。

详细规则：`references/platform_asset_binding_rules.md`。

## v4.1.0 核心流程

v4 解决静态分镜与视频提示词的循环依赖：

- 剧本、原视频、资产和用户确认的项目要求先进入可追溯的镜头事实卡；
- 先建立场景拓扑与镜头—场景投影，强制核验摄影机俯仰、人物姿态 / 接触拓扑、地面 / 墙面 / 天花可见占比和资产重投影；
- 静态分镜提示词只消费静态视觉事实；
- 生图结果先进入候选目录；
- 用户筛选或优化后把正式文件保存到 `/分镜图`；
- 视频提示词从镜头事实卡重新编译，并绑定已批准 `@分镜图`；
- 静态提示词和视频提示词都是镜头事实卡的下游编译产物，不作为新项目输入。

推荐阅读：`references/storyboard_image_workflow.md`、`references/shot_fact_lineage_rules.md`、`references/camera_scene_projection_rules.md`、`references/storyboard_image_prompt_rules.md`。

## v3.0.0 为什么是大版本升级

v2.x 的最大问题是：逐镜虽然解决了“保留原视频”，但后期越来越偏向**操作说明**，没有稳定描述“最终镜头实际长什么样”。

真实生产中又暴露了一个更大的融合问题：

> **AI 背景即使场景内容正确，也可能像贴图：没有真实透视、景深、焦平面、视差和环境动态。**

因此 v3.0.0 对逐镜合同做了破坏性升级。

# v3 六栏逐镜结构

每个标准实拍融合镜头固定为：

1. **构图与景别** —— 摄影机怎么看
2. **背景与空间** —— 当前机位具体看到了什么世界
3. **空间透视与镜头匹配** —— 这个 AI 世界如何真实存在于原摄影机里
4. **光源与融合** —— 当前镜头最终怎么亮
5. **最终画面** —— 观众最终看到什么
6. **VFX** —— 从原素材到最终结果具体做什么

旧的 `画面内容 / 视频内容` 已废弃。

---

## 1. 构图与景别

默认强继承原视频可靠摄影。

重点确认：
- 景别
- 机位高低 / 俯仰
- 人物画面占比
- 前后层级
- 遮挡 / 越肩
- 焦点主体

### 关键生产规则
**空间位置不等于景别要求。**

例如角色在塔楼顶部，但原视频是近距离低机位仰拍：
- 仍然保持近景和人物大占比
- 只用局部塔顶结构证明位置
- 不能自动变成远景塔楼建立镜头

---

## 2. 背景与空间

不再允许只写：

> 场景固定为 @街道-夜晚。

必须描述当前镜头实际看到：
- 人物后方
- 两侧
- 地面 / 承托面
- 近中远景
- 当前场景方向
- 实际可见建筑结构

场景素材负责定义世界，逐镜负责定义当前摄影视角。

---

## 3. 空间透视与镜头匹配

v3.0.0 新增核心模块。

专门解决：
- 背景平
- 背景像海报
- 景深假
- 所有背景同一清晰度
- 摄影机移动但背景没有视差
- AI 环境完全静止

逐镜根据实际情况描述：
- 前景 / 人物层 / 中景 / 后景
- 消失点和透视收缩
- 人物 / 建筑尺度
- 焦平面
- 景深递进
- 焦外灯光和建筑表现
- 摄影机运动时不同距离层的视差
- 薄雾、湿气、灯光、反射等低幅度环境动态

优先描述光圈和镜头造成的**视觉结果**，不无依据乱填具体焦距 / F 值。

---

## 4. 光源与融合

不再接受：

> 人物与环境真实融合。

这种抽象空话。

必须具体写：
- 光从哪里来
- 人物哪边亮
- 当前项目是否要求补光 / 面光
- 人物与背景光比
- 材质如何响应
- 接触阴影
- 地面 / 墙面反射
- 空气、高光扩散
- 发光 VFX 是否参与照明

人物面光、背景降饱和等仍是**项目级要求**，不是 Skill 默认。

---

## 5. 最终画面

旧的 `画面内容` / `视频内容` 正式改为：

> **最终画面**

它只回答：

> 最终成片中，观众具体看到什么？

原视频已有表演默认继承，不机械复述。

这里不写：
- 抠像
- 换装操作
- 清理
- “真实融合”空话
- 文学化心理解释

---

## 6. VFX

所有操作型信息独立放这里：
- 换装 / 妆造 / 固定配饰
- 绿幕 / 时间码 / 黑底 / 片场设备清除
- 垫子 / 走位点删除与补全
- 场景局部重构
- 黑屏补画
- 烟雾 / 天气 / 速度 / 发光效果
- 特殊转场 / 眼球反光 / 画中画

这样“最终画面”和“怎么做”不再互相污染。

# 推荐实际生产流程

1. 分析视频：硬切 + 首中尾帧，并建立镜头事实卡
2. 确认素材职责、项目要求和需分镜图镜头
3. 编译静态分镜提示词并先确认参考图
4. 生成候选图，基于真实结果单变量返修
5. 用户筛选 / 优化并发布到 `/分镜图`
6. 审计 `/分镜图`，建立分镜 ID → 文件 → @句柄绑定
7. 从镜头事实卡 + 已批准分镜图重新编译视频提示词
8. 生成视频并基于真实 Take 单变量返修

旧版：
- 背景与空间
- 光源与融合
- 画面内容

新版：
- 构图与景别
- 背景与空间
- 空间透视与镜头匹配
- 光源与融合
- 最终画面
- VFX

因此建议后续新制作统一切换到 v3.0.0，不再混用旧逐镜格式。
