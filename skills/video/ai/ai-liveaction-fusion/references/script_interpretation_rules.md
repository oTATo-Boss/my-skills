# 剧本 / Shot List 解释规则

## 叙事职责
剧本用于回答：
- 谁与谁是什么关系
- 当前行为针对谁 / 什么
- 这一动作在剧情上意味着什么
- 台词和 VFX 的剧情目的是什么

## 动作职责
剧本不能替代实际视频去决定：
- 动作从哪一帧开始
- 第一帧是否已经建立接触
- 人物具体站位 / 身体距离
- 一个动作是否跨硬切继续
- 演员是否微笑、后退、靠近、转身等

## 权威顺序
用户 / 甲方明确要求改变的部分，以该明确要求为最终目标。对于没有被明确修改的“实际发生了什么”：
1. 实际视频画面
2. 实际音频 / 台词 / 可见口型
3. 用户确认的剧本、Shot List、镜头说明
4. 合理推断

## 禁止
- 根据剧情合理性补写视频里不存在的动作
- 把剧本中的连续动作强行塞进一个已经剪开的单镜
- 未核对音频 / 口型就强行把某句台词绑定到精确时间码
