# 六栏逐镜分解规则

## 编译来源

视频逐镜必须从镜头事实卡重新编译，并读取 `/分镜图` 绑定清单：
- 镜头事实卡提供静态视觉事实与时间运动事实；
- `@视频` 提供实际动作、表演、摄影和时序；
- 已批准 `@分镜图` 提供关键帧视觉状态；
- 静态分镜提示词只可帮助追溯目标，不得机械扩写为动态过程；
- 已编译提示词不作为事实来源；视频逐镜必须从镜头事实卡和当前有效绑定重新生成。
- 镜头—场景投影字段提供摄影机角度、人物姿态拓扑、主导可见表面、地平线 / 地墙交界及首中尾变化；视频逐镜不得只从单张 `@分镜图` 猜测这些动态几何。

## 固定结构
每个标准实拍融合镜头固定六栏：
1. 构图与景别
2. 背景与空间
3. 空间透视与镜头匹配
4. 光源与融合
5. 最终画面
6. VFX

## 1. 构图与景别
只负责“摄影机怎么看”。默认继承原视频可靠摄影：
- 景别
- 摄影机高度与俯仰
- 人物画面占比
- 前中后人物层级
- 遮挡 / 越肩
- 焦点主体
- 人物头肩手髋等关键点的屏幕空间轨迹、接触点、受力点与遮挡关系

### 空间锚点不得覆盖景别
如果角色位于塔楼顶部，但原视频是近距离仰拍：
- 构图必须继续近
- 背景只交代局部塔顶 / 塔身结构
- 禁止为了完整展示塔楼而变成远景

## 2. 背景与空间
只负责“当前镜头看到什么世界”。

必须写清：
- 人物后方、左右、地面 / 承托面
- 近景、中景、远景
- 当前机位对应场景哪一面
- 建筑 / 道路 / 入口 / 屋顶 / 祭坛等实际可见结构
- 空间连续性与必须避免的错误空间
- 地面 / 墙面 / 天花或天空在首、中、尾帧的主次、画面分区和占比变化

禁止只写“场景固定为 @xxx”。

## 3. 空间透视与镜头匹配
负责“这个世界如何被当前摄影机真实拍到”。

按当前镜头需要写：
- 前景 / 人物层 / 中景 / 后景层级
- 消失点、道路与建筑透视收缩
- 真实尺度关系
- 焦平面
- 景深随距离递进
- 焦外灯光 / 建筑的自然柔化
- 推进 / 后拉 / 横移 / 摇摄 / 跟拍时不同距离层的视差
- 背景对摄影机运动的真实响应
- 地平线 / 地墙交界随 tilt、pan、推进、后拉和横移的连续位置变化
- 场景资产表面按原摄影机轨迹重投影，不沿用资产图片自身机位
- 薄雾、湿气、灯光、反射、轻风等低幅度环境动态

### 景深规则
- 不把整张背景统一模糊
- 不让所有景物同一锐度
- 焦外强度必须随空间距离连续变化
- 优先写“大光圈浅景深观感 / 深景深观感”等结果，不无依据写具体 F 值

### 视差规则
摄影机运动时：
- 近景位移通常更明显
- 远景变化较慢
- 不同距离层不能像一张平面贴图一起移动

## 4. 光源与融合
负责“当前镜头最终怎么亮”。

必须结果化描述：
- 环境光来源 / 方向
- 人物哪边亮、哪边衰减
- 当前项目是否要求人物补光 / 面光
- 人物与背景视觉光比
- 白衣、黑衣、皮革、天鹅绒、金属等材质受光
- 接触阴影 / 地面反射 / 色温污染
- 雾气 / 空气 / 高光扩散
- 发光 VFX 对人物 / 环境的实际照明影响

禁止只写“按 @场景 重光”“人物与背景真实融合”。

## 5. 最终画面
负责“观众最后看到什么”。

描述：
- 最终画面主体
- 人物 / 空间结果关系
- 新增视觉状态
- 镜头最终建立的剧情视觉信息
- 若第一帧已有关键状态且模型容易误解，可简短确认

原视频已有动作、表情、视线、口型默认继承，不机械逐项复述。

不得写：
- 抠像 / 换装 / 清理操作
- 空泛“高级感 / 真实融合”
- 文学化心理活动

## 6. VFX
负责“具体后期做什么”。

可写：
- 角色妆造 / 服装 / 固定配饰替换
- 绿幕 / 时间码 / 黑底 / 片场设备 / 垫子 / 走位点清除
- 被遮挡区域补全
- 特殊场景局部重构
- 黑屏补画
- 烟雾、天气、速度、发光、血迹、红眼、尖牙、闪电等
- 特殊转场、眼睛反光、画中画重构

若 VFX 有光照效果：VFX 栏写效果本身，光源与融合栏写它对环境受光的结果。

## 描述强度
### 普通镜头
六栏都可以短，但背景 / 空间透视 / 光影必须足够具体到可脑补最终画面。

### 复杂镜头
以下情况可展开：
- 复杂身体接触 / 受力
- 倒地 / 落地
- 跨镜连续动作
- 极端俯拍 / 仰拍
- 极速后拉
- 真实 Tilt / Pan / Orbit 重构
- 黑屏补画
- 纯 AI 镜头
- 复杂 VFX / 反光 / 转场

极端俯拍 / 仰拍必须具体写主导背景表面：明显俯拍通常由地面主导，墙面压缩到上沿 / 侧边；明显仰拍通常由上部墙面、天花 / 天空主导。不得只写“保持俯拍 / 仰拍”。

## 第一帧状态
如果第一帧已经存在某状态，不重新生成建立过程。例如：
- 已经挽手
- 已经靠肩
- 已经抓住
- 已经躺下
- 已经持有道具

只在 `最终画面` 中简短确认该状态，VFX 不承担动作重写。

## 分镜图状态与动态过程

当本镜绑定 `@分镜图`：
- 写清该图对应首帧、中间状态还是尾帧；
- 视频内容必须说明原动作如何到达或离开该状态；
- 不要求整个镜头冻结成分镜图；
- 分镜图不得覆盖原视频可靠的口型、动作相位、接触、受力和运镜；
- 分镜图若与镜头—场景投影卡的摄影机角度、姿态拓扑或主导表面冲突，必须退回静态阶段，不能把错误背景角度带入视频；
- 多张分镜图必须各自有时间职责，禁止同时作为模糊的全镜风格参考。

## 跨镜动作
一个动作跨两个最终硬切时，每镜只写当前阶段，不提前完成后续动作。

## 剧本使用
剧本只解释人物关系、行为对象和剧情目的。动作阶段与接触时序以实际视频为准。

## 时间码
只写核验过的时间码。不确定时写“约”或省略。

## 片场批注
先读取制作语义，再删除批注像素。批注意图可进入 `最终画面` 或 `VFX`，文字本身绝不进入成片。
