# 平台无关执行说明

本 Skill 输出先保持平台无关的逻辑层：
- 视频编辑指令
- 素材锁定
- 影片质感
- 逐镜分解

落地到具体平台时，仅做机械映射：
- 谁是基础视频
- 哪些是场景参考
- 哪些是人物 / 服装 / 道具参考
- 提示词如何拼接

不在平台映射阶段修改提示词逻辑本体。

平台映射仍须遵守 `platform_asset_binding_rules.md`：提示词中的纯文本 `@句柄` 是语义层，不自动成为平台素材引用。若目标平台使用真实 mention / token、attachment ID、素材槽位或其他结构化绑定，按平台可观察的实际模型逐项建立并验证；没有明确提交授权时只完成映射与绑定，不提交生成。
