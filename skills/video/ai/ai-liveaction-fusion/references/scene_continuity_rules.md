# 场景连续性规则

- 同一场景体系内，建筑年代、材质、道路宽度、环境尺度和固定锚点保持连续
- 正反打应根据视线轴切换到正确反向空间，不复制同一背景
- 场景素材定义世界；逐镜定义当前摄影机看到的部分
- 同一承托面 / 祭坛 / 屋顶 / 门槛在多镜头中保持高度、方向和材质连续
- 空间锚点与景别独立：人物在高塔 / 屋顶，不代表摄影机必须变远
- 背景透视、景深和视差必须跟随当前原摄影机，而不是跟随参考图原视角
- 同一机位内地面 / 墙面 / 天花或天空的主次、地墙交界和地平线保持稳定；只有真实 tilt / pan / 位移才能改变
- 正反打或换机位时按场景拓扑重新投影表面，不把上一镜背景平移、镜像或重复粘贴
- 场景资产只定义世界和可用表面；每镜实际可见表面由镜头—场景投影卡决定
