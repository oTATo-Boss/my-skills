# 光源与融合规则

目标是把抽象“融合”翻译成当前镜头可见的光影结果。

## 通用原则
- 明确废弃需要被替换的棚拍 / 绿幕环境照明
- 根据最终场景、`@分镜图` 和当前项目光影要求重建人物受光
- 环境光、项目补光、VFX 光必须处于同一空间逻辑
- 不把人物单独提亮成与环境无关的图层

## 当前镜头至少判断
- 主要环境光来自哪里
- 人物哪侧亮、哪侧衰减
- 人物与背景视觉亮度 / 光比
- 项目是否要求面光 / 补光
- 衣料、皮革、天鹅绒、金属、皮肤怎样受光
- 人物与地面 / 承托面的接触阴影
- 地面 / 墙面反射是否对应真实光源
- 雾气 / 空气是否参与高光扩散

## 光比
光比属于当前项目 / 当前镜头灯光结果，不属于 `空间透视与镜头匹配`。

可以写：
- 低光比 / 中等光比 / 大光比
- 人物主体比背景高约一档等可视结果
- 项目明确要求时可写近似 1:2、1:3 等

不要在 Skill 中固定任何数值。

## 禁止空话
以下内容不能单独作为合格光源描述：
- 人物与环境真实融合
- 电影级融合
- 光线自然
- 按 @场景 重光

必须说明“亮在哪里、暗在哪里、材质怎样响应、背景怎样退后”。
