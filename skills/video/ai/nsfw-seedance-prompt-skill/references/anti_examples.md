# 反例校准（失败样本对照）

本文件收录一条**质量很差的翻车输出**，用于让生成时刻记住"什么绝不能写"。它不是模板、不是示范，而是一份违规清单：凡命中下列任何一条，都会触发脚本 FAIL 或违背本技能的核心定位。逐字保留原始输出，随后列出违规对照。

> 注意：下方原始反例取自旧「四模块」时代的翻车输出（含旧栏目名、分镜编号、逐镜计时），作为反面样本照旧保留；新模板已改为 12 栏单段公式，结构类错误码已变，内容类错误（电影腔 / 偷拍视角 / 写死长相 / 无露骨 / 三点布光 / 模板残留 / 心理词）依然适用。
