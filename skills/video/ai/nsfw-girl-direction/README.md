# nsfw-girl-direction

当前版本：3.3.0。成人美女题材的创作指导：图片与视频，前置自拍、镜面自拍、他拍与固定机位；基准是"网上随手发的一条"，给判断和方向，不写提示词，无固定交付物。

按问题取用：人物与方向读一份，拍摄与画面读一份，图片或视频只读相关的那份。默认值只是起点，用户说了别的就跟用户走。

## 目录

- `SKILL.md`：定位、讨论方式、判断顺序、路由与边界。
- `references/direction-core.md`：人设、穿搭、场景、网黄质感、表演与关系、真实感、美感、尺度。
- `references/capture-and-lens.md`：三种拍摄方式、手机物理、手部契约、画幅、机位、焦段、手机画质与常见穿帮。
- `references/stills.md`：单张、套图、封面、姿势、构图、光比、皮肤、直出感与发布形态。
- `references/video-motion.md`：时长、镜头运动、表演弧线、节奏、声音、手机视频质感与收尾。
- `checklists/creative-review.md`：通用、图片、视频、尺度四组自查。
- `SOURCE.md`：来源与版本记录。
