# 制作交接：把判断变成具体要求

## 索引
最小交接 → 资产补齐 → 视频制作 → 简单任务示例 → 复刻任务示例 → 返回边界。

沿用项目已有方案、资产编号和交接格式。这里只提供内容组织方法，不新增任务协议。资产已充分时省略补齐部分；已有镜头表用实际位置引用，仅补缺项。

## 最小交接结构
| 内容 | 应回答 |
|---|---|
| 目标 | 做什么、哪些保持、哪些替换、哪些可发挥、目标风格 |
| 参考 | 哪个实际文件控制哪个属性，何时使用，是否作为模型输入 |
| 必要补齐 | 缺什么、影响哪里、做成什么、合格是什么样 |
| 视频制作 | 使用方式、按时间顺序的事件/状态/机位、源质量、可用区间与衔接条件 |
| 核验 | 哪些属性决定可用性、要检查的实际内容、限制或待核验点 |

通常结论与一张表即可。只有复杂镜头才展开空间或时间表。

## 资产补齐要求
写成“指定产物及完成标准”，而非一句“完善素材”。必要内容为：
**用途与镜头 → 继承依据 → 需要的视角/状态/数量 → 关键细节和风格 → 输出形式 → 完成标准。**

例如，转身镜头缺少背面服装资料：明确采用已有角色与目标服装，只补会被镜头看到的背面全身状态；需看清衣摆、后领、鞋和配饰，保持既有体型及穿法；交一张清楚的背面图，另有遮挡细节才追加局部。收到后核对与正面图能否解释为同一人、同一套服装。

新资产“待制作”、已生成“待检查”和当前“可用”分别记录。文件还未产生时使用待交付标识，不伪装成已存在路径。

## 视频制作要求
使用实际输入素材与编号，说明各自用途；由提示词制作方转换成当前入口引用语法。需要的信息包括：
- 对象与状态：角色/产品/场景、造型、数量、起止状态和必要保持项。
- 时序与镜头：已有时间表，或按先后组织的动作、效果、机位、停点与转场；对精确节点注明实际要求。
- 外观：明确风格、艺术类型或指定作品特征，落实光线、色彩、材质与摄影表现。
- 声音：角色、样本、台词及发生时段的语义绑定，或明确本次声音范围。
- 素材用途：生成源质量、需要保留的完整动作/可用区间、相邻镜头连接状态及后期使用条件。
- 核验重点：关键属性及需要实际动态查看/听取的部分。

这些是输入事实与制作规格，不是完整提示词，也不是 API 参数表。

## 示例 A：一张图已经足够
以下文件名与能力条件是示例，不代表本地存在文件。

**目标**：4 秒陶杯展示，固定前侧视角，杯子原位保持，只有少量蒸汽变化；陶釉质感与给定图一致。

| 内容 | 制作依据 |
|---|---|
| 参考 | `示例-陶杯.png` 同时承担杯型、材质、场景和构图；已检查关键内容清楚 |
| 补齐 | 无需新增；背面与内部不进入镜头 |
| 方式 | 已确认入口能使用单图生成；该图作为起始画面依据，事件为蒸汽自然变化 |
| 质量 | 项目已验证的 720P 档满足本次尺寸和细节要求，直接生成；输出适配按既有规格 |
| 核验 | 杯型、釉色和机位稳定，蒸汽变化自然，首尾状态符合展示用途 |

这个例子不增加多视图、白模、音色、试片或额外创意评审。

## 示例 B：换人复刻多套造型展示
这是对用户提供制作经历的条件化示例：只把已报告的结果作为案例依据，未在本包中重新检查原视频或人物资产。下列名称均为示例标识。

**目标范围**：采用自己的角色复刻已给视频的造型展示、版面与事件顺序。身份、卡片布局、服装与质感分别控制；已有时间表直接沿用。

| 输入/依据 | 作用与判断 |
|---|---|
| `示例-人物.png` | 锁定目标身份；实际使用前检查面部可读性、造型版本与目标肤质 |
| `示例-参考视频.mp4`＋已有事件表 | 供导演分析动作、造型顺序、短回闪和机位；是否上传取决于当前入口的参考分工效果 |
| `示例-无人版面.png` | 定义身后三张独立卡片、底部扇形卡片与留白；没有现成文件时列为必要补齐，不当已存在资产 |
| `示例-造型资料` | 逐套对应服装及可见方向；若要求逐件复刻而资料不足，补相关服装或穿搭状态；有充分资料则直接采用 |

**采用方法**：根据当前入口的实际支持，形成身份、布局与事件的独立用途说明。“人物图＋无人版面图＋时序要求”在这次记录中有效，可以优先评估；输入数量或任务条件不同时调整参考形式。

**时间落实**：原表中每套造型的进入、展示、退出和回闪节点，映射为素材必须包含的动作与可用区间。短回闪优先保证它所需的完整短动作；末套需更多展示内容时明确具体表演，而不是只要求增加输出时长。

**质量要求**：正式源片按人物与服装可见细节选择质量策略；自然皮肤与织物、身份、布局和节奏分别检查。源尺寸、清晰度处理、输出尺寸分别记录。

**分工结果**：R2V 形成上述制作依据。导演据此制定具体任务；制作方编写提示词并绑定素材。未有真实源片与动态检查时，保留质量和时序表现待验证。

## 返回范围
准备就绪：采用素材、必要保持项、生成方式与验证重点已足够。
局部可推进：明确哪部分已足够、哪一必要信息仍缺失。
能力不匹配：说明当前入口无法满足的具体要求与已查证依据，交导演裁决。

准备状态只用于参考与制作判断。角色调度、上传调用、后期制作、独立审查与交付放行由项目现有体系负责。
