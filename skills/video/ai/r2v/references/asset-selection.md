# 素材选择与补齐

## 索引
角色与服装 → 道具与产品 → 场景与空间 → 分镜与风格 → 视频与运动 → 声音 → 补齐完成判断。

共同原则：先看当前镜头会展示什么，再选择提供这些信息的最轻素材。资产补齐与完整镜头图分开判断：补视角、换装、延伸场景或重要道具不要求再合成最终构图；当前入口可直接使用已有资产时优先采用。下表的“升级条件”是判断触发点，不是必走阶段。

## 角色与服装
| 情况 | 优先使用 | 升级条件与补齐要求 | 足够的标准 |
|---|---|---|---|
| 已定身份，固定正面近景 | 清楚的面部参考；可见服装信息已有则沿用 | 脸部细节不清、发型过时、目标肤质与参考明显不符时，补相应面部资料 | 本镜头能辨认的五官、发型和服装都有一致依据 |
| 固定造型的全身、侧转或背面展示 | 穿目标服装的角色多视图；脸小则另带面部图 | 镜头揭示的侧背面、鞋、饰品未定义时补对应局部或视角 | 各视角身份、体型、衣长、穿法、鞋和饰品自洽 |
| 只有基础角色多视图 | 用于体型、比例与基础身份 | 目标服装有重要差异时增加服装资料；贴身关系、层叠或穿法难推断时制作穿搭状态 | 基础角色与目标穿搭能组合成明确且一致的可见造型 |
| 多套换装 | 角色身份资料＋各套服装的编号和可见状态 | 每套服装的结构、穿法或背面必要但不明确时补对应图；高度复刻或反复误穿时先做上身造型图 | 每段对应哪套衣服及其关键区别清楚，切换前后身份不变 |
| 面部＋无人服装多视图 | 分别控制身份和服装，适合资料已清楚的组合 | 当前入口组合不稳定，或体型适配本身是卖点时，补穿搭后的角色参考 | 生成用的身份、衣物结构、尺码观感与穿法都有可理解依据 |
| 多角色、相互遮挡或交换道具 | 分别可辨的角色资料＋角色编号 | 容易互换脸/服装/声音时，按可见位置和时间明确每个角色；互动所需手位、尺寸关系无法由现有资料与文字充分表达时，才补必要示意或状态图 | 各角色外观和功能可区分，交互对象及先后关系明确 |

### 角色资料的质感检查
分别看身份与表现：五官/脸型/发型是否一致，光线是否遮掉识别点，磨皮/锐化/镜面高光是否符合目标，服装是否具有所需结构和纹理。风格化的光滑表面可成为有效目标；写实要求下则按写实材质检查。

多视图不是凭名称就合格。检查各格是否真的为同一人和同一套服装；必要时把面部或细节独立保留，避免拼图后主体过小。图像分辨率与主体在图中的占比一起决定信息是否可读。

表情、体态和动作习惯可由表演视频承担，面部身份仍以指定角色资料为依据。明确哪些动作可继承、哪些体态差异会影响迁移。人物、声音与其他素材的来源和使用范围沿用项目授权及当前平台要求。

## 道具与产品
| 情况 | 优先使用 | 升级条件与补齐要求 | 足够的标准 |
|---|---|---|---|
| 简单、静态、单面可见 | 一张主体完整且清楚的参考 | 关键轮廓、材质、标记看不清时补相应图 | 镜头实际可见的形状和表面信息已充分 |
| 旋转、经常复用或需要背面 | 必要方向的多角度图 | 不同视角的结构关系不明时补连接部位或尺寸关系 | 可见方向能解释为同一个物体 |
| 精确包装、标志、细字或材质 | 产品整体＋必要局部细节 | 标签太小、侧面信息重要或不同版本冲突时补局部/版本依据 | 产品版本、比例、主标记与关键细节明确；真实可生成程度另行验证 |
| 开合、拆装、内部展示 | 闭合/打开等必要状态与结构资料 | 机构、铰接、开口位置、内外关系未定义时补状态与连接图 | 起点、运动方式、终点能连成合理过程 |
| 新旧包装变化 | 各版本独立编号与对应关系 | 外形差异、数量、变化区域或中间过程不明确时补关键状态 | 哪个旧对象变成哪个新对象、何时变化、哪些属性保持都有依据 |
| 同一物体兼作产品/车辆/场景 | 一个稳定实体编号，分属性使用参考 | 外观、内部空间和运动功能互相矛盾时补结构关系 | 多种功能属于同一实体，门、内部与外部尺度可理解 |

“剥落露出”“液体冲刷”“滑门开启”与直接外观替换是不同过程。镜头看得到过程时，资产与制作要求一起交代初始状态、关键中间状态和最终状态；是否补中间图取决于现有信息与入口表现。

## 场景与空间
场景图同时承载空间和外观。检查建筑尺度、物体布置、机位高度、光源方向、材料与空气感是否接近目标；其信息有助于定义画面质感，仍需结合实际生成验证。

| 镜头空间需求 | 最小起点 | 何时补充 | 足够的标准 |
|---|---|---|---|
| 固定主方向，轻微运动或不同景别 | 信息充分的主视角 | 镜头边缘或景深层次缺关键信息时局部补充 | 所有拟出现区域已有依据 |
| 正反打或明显换方向 | 主视角＋将被看到的反向/侧向 | 主体相对位置、门窗、灯或背景接不上时补空间示意 | 地标、尺度、朝向和照明能对应同一空间 |
| 四周拍摄、环绕、多入口 | 必要多角度＋俯视布局 | 机位揭露原图外的结构、物体遮挡或通道时补相应方向 | 相邻视角可对齐，路径经过的区域与遮挡明确 |
| 复杂主体走位、跟拍或一镜到底 | 俯视结构图＋分别标注主体/机位路线 | 多条路线交会、穿门、绕柱或高度变化时加入状态点与时间锚点 | 谁在何处、相机何处、朝向什么及先后顺序可执行 |
| 多图仍不能稳定表达复杂空间与运动 | 合理尺度的三维场景和白模预演 | 在现有工具支持或可试验的前提下，预演空间、机位与动作；外观用独立参考 | 预演本身动作与遮挡正确，外观参考能映射到对应对象 |

### 空间图的制作要求
标注统一方向或稳定地标，分别画主体、道具和摄影机路径；机位位置与看向方向分开，楼层/升降另记高度。一个俯视图可包含结构和路线，但标记需要清楚、颜色含义明确。

场景多视图应从同一空间关系推导，补图后复核门窗位置、布置、相对尺寸和光线。多镜头共用场景参考时，逐镜注明当前可见背景、朝向与主要地标，使镜头切换后仍能定位同一空间。镜像翻图要核对标记、左右手、行进方向和结构；把屏幕左右与场景坐标分别说清。

“90°俯视”明确相机垂直向下；车辆等物体同时需明确相对道路的朝向。一张平面示意承担位置和方向，最终材质可由另一份外观参考承担。平面图、文字和箭头仅作控制信息，最终画面中是否出现以作品要求为准。

## 分镜、关键状态与风格
| 参考用途 | 应明确的信息 |
|---|---|
| 构图/版面 | 景别、主体尺度、数量、位置、留白、前后层次及遮挡 |
| 首帧/尾帧 | 帧被用于具体端点还是仅为一般参考；姿态、物体状态与相机位置 |
| 中间关键状态 | 状态发生的条件、前后变化路径、需要保留的对象 |
| 分镜组 | 实际阅读顺序、镜头对应关系、哪些是独立镜头及哪些是连续过程 |
| 风格帧 | 光线方向与软硬、色彩、材质、对比、颗粒、景深及艺术表现 |
| 导演/作品/艺术类型参考 | 指定称谓及任务实际要继承的可观察特征；与已有资产冲突时取舍明确 |

一张分镜图可同时充当风格依据，现成合格静帧优先复用。多格分镜输入前核对当前入口如何理解顺序和构图；需要独立帧时提出拆出原格的要求，保持实际画幅、风格和有效内容。

参考图片定义状态，事件路径由制作要求定义。仅有初末两个状态时，需要检查中间过程是否仍有歧义；关键物理过程不能只用端点关系代替。

## 视频、深度、姿态与白模
先确定视频承担的用途：效果模仿、身份替换、动作迁移、运镜、节奏、场景结构或已有视频编辑。记录准确片段、保留内容与替换内容。

| 已有材料 | 可以提供的信息 | 采用前的关键检查 |
|---|---|---|
| 原始参考视频 | 画面结构、动作、镜头、节奏、外观与声音 | 分析用与模型输入用分开；确认原人物/服装/标志/声音是否会干扰目标 |
| 裁剪片段或代表帧 | 局部事件、构图、服装、关键状态 | 片段保留必要上下文；帧只能证明可见状态，动态关系另看原片 |
| 深度视频 | 深度层次、轮廓及部分运动/机位线索 | 当前入口理解方式、深度稳定性、遮挡边缘、尺度与原片对齐；轮廓仍可能携带原主体特征 |
| 姿态序列 | 关节与肢体动作路径 | 关键点是否准确、遮挡如何处理、目标角色比例与动作是否适配 |
| 绿幕主体 | 可见主体动作、轮廓、表演 | 主体边缘、运动模糊、透明物和接触关系；当前入口支持何种编辑 |
| 白模预演 | 空间、走位、机位、遮挡、时间与关键状态 | 几何与动作本身正确；渲染外观的角色/场景/材质参考对应清楚 |

深度、姿态与白模各保留不同信息。普通视频输入是否能有效利用它们，需要依据当前能力或针对性验证；由执行方将素材绑定为实际支持的输入形式。

## 声音
| 目标 | 素材选择与判断 |
|---|---|
| 固定角色音色 | 干净、单说话人、声音身份明确的样本；3–5 秒是可采用的用户经验起点，实际以入口要求与样本充分性为准 |
| 固定表演语气/语速 | 可辨的情绪、节奏和语言样本；明确保留音色还是也继承表演 |
| 多人对白 | 每个角色单独对应声音、台词和说话时段；重叠说话需明确区间 |
| 已有对白与口型 | 明确使用实际对白波形还是音色参考；台词长度、停顿与画面时长能容纳 |
| 配乐节奏/音效 | 指定音乐版本、片段、关键节拍或音效发生事件；单纯音色样本不承担配乐职责 |

提供语义绑定：角色编号 → 角色图 → 音色样本 → 台词内容/发生时段。执行方转换为当前入口支持的引用标记，文件名与真实上传映射一致。

检查噪声、混响、多说话人、背景音乐与截断。当前入口缺音频输入或无法使用该样本时，输出明确缺口或交接条件，由导演决定声音制作路线。

## 补齐完成判断
每次补齐只回查其用途：关键内容可辨、相关状态/方向覆盖、与原资产一致、当前入口可用。新增素材若引入身份、空间或风格矛盾，先修订相关部分。

资料不全但缺失区域不会被镜头揭示，可有限使用；未知信息会破坏身份、结构、连续性或必要细节，才作为必须补齐项。复杂资产库的完整性与单镜头的可制作性分别判断。
