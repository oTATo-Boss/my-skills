# 参考组合与输入准备

## 索引
属性依据 → 冲突处理 → 输入包 → 不同载体组合 → 提交前交接检查。

## 1. 把控制要求映射到可用资料
对当前生成建立一张小表；只列相关素材。

| 素材 | 简短用途 | 适用范围 | 依据属性/限制 |
|---|---|---|---|
| 实际角色图或资产编号 | 身份、体型与已定服装 | 对应角色和镜头 | 标明哪套造型；面部信息不足时另补 |
| 实际场景图或资产编号 | 空间结构、光线和材质 | 对应场景方向 | 未出现方向另判断 |
| 实际视频及时间区间 | 动作/运镜/效果/节奏 | 明确片段 | 记录分析用、模型输入用或两者兼用 |
| 实际声音文件 | 指定角色音色 | 说话时段 | 明确声音身份与台词绑定 |

同一素材可支持多项属性。每项关键属性指定主要依据，辅助资料只补信息；一个总体优先级不能自动解决所有属性的冲突。

例如，一份视频供动作，一张人物图供身份，一张无人版面供卡片数量与位置。这样的分工先形成清楚意图；其实际分离效果取决于当前输入能力和实测。

风格已有指定时直接采用；未单独指定时，可从已采用且一致的场景/分镜资料归纳光线、材质与色彩，标明这是导演的方案判断。有冲突时只解决影响当前画面的部分。

## 2. 识别并解决冲突
| 冲突 | 判断与处理 |
|---|---|
| 原人物与目标身份 | 明确替换对象、保留动作及外观依据；检查入口的参考或编辑方式是否能实现。必要时针对性提取动作、布局或关键状态，再验证剩余原主体信息 |
| 同一角色不同发型/衣服 | 先确认采用的角色版本与镜头状态，移除本次无关版本或限定时段 |
| 独立服装图与已穿搭角色图不同 | 按该镜头的目标造型确定服装依据；多图无法表达正确穿法时补实际穿搭状态 |
| 场景多角度互相矛盾 | 以已定空间关系为依据重做冲突视图；不把互不连通的空间当多机位输入 |
| 布局正确但风格不符 | 保留位置/比例信息，明确外观依据；高干扰时先重做布局参考的表达形式 |
| 风格参考带入错误身份/产品 | 指定使用的光线、材质、色彩等属性；必要时采用不含冲突主体的风格资料 |
| 首尾状态与动作机制矛盾 | 核对物体位置、相机状态、衣物/道具连续性，修正对应状态或过程要求 |
| 原视频音轨与目标声音冲突 | 确定保留原声、音色参考或单独声音要求，输入音轨按当前可用方式处理 |

处理顺序：明确属性依据 → 去掉当前无用且冲突的信息 → 采用仍保留关键控制信息的素材表达 → 需要时补明确状态 → 验证当前入口效果。

遮脸、裁切、去人物、深度化等处理均是候选信息处理手段。检查被删内容是否正好是动作或遮挡依据，处理后是否还保留原轮廓、服装或机位影响；不能只凭文件形式认定冲突消失。

## 3. 组织最小输入包
优先选择对本镜头贡献最大且信息清楚的素材。去掉完全重复、质量差或仅属其他镜头的资料；保留必要身份、可见状态和空间关系。

输入限制使素材放不下时，先减少无关内容，再考虑组合板、已确定状态图或调整生成单元。参考板适合可清楚并列的资料，但应检查主体大小、文字/格线干扰以及入口对多格画面的理解。单图入口使用整理板或完整场景关键帧，都应依据可理解性选择，必要时验证，不默认二者等价。

原始资产留在项目资产库，预处理副本使用可辨的名称。镜头要求中的素材编号、实际文件和执行方上传映射要对应。复用本次已生效的版本，更新参考后指出受影响镜头。

## 4. 不同载体的组合
### 图片＋图片
身份、服装、场景、道具、构图与风格按属性分工。决定哪些适用于整段，哪些只用于局部或特定角色。涉及空间接触时，检查比例和位置是否能结合。

### 图片＋视频
图片可定义新外观，视频可提供动作或场景/机位。先说明视频是否为被编辑原片、动作参考还是仅供导演分析。当前入口的“参考”与“编辑”若是不同模式，选择与目标相符者。

### 图片＋空间/运动参考
俯视图、深度、姿态或白模承载空间与动作；外观图片承载主体、材质、光线和艺术效果。明确对应实体、相机方向、关键时间与坐标关系。某入口只能看到一张平面图时，把需要连续理解的运动视为待验证项。

### 图片/视频＋声音
为每个说话角色建立外观和声音对应；角色声音、台词内容、语言、语气与时段分开。音乐或音效的节奏绑定到具体事件，而非只写“参考这段音频”。

## 5. 交接时的逻辑检查
核对实体数量、服装版本、产品版本、进出场状态、行进方向、镜头先后与背景关系。多机位时说清屏幕方向与真实场景方向；一镜到底时说明相机停点和后续是否继续运动。

状态变化按照事件发生顺序组织。同一时段中多个动作可并行，但需说清各自主体；互斥的状态按不同时间、镜头或方案处理。所有风格要求与资产采用目标一致。

结果是“每份素材具体做什么、在哪里生效、需要处理什么冲突”的制作依据。具体文件上传、引用语法和提示词组装由执行方完成。
