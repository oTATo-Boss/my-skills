# R2V｜全能参考 Skill

跨模型的参考素材使用判断与视频制作准备方法，主要供导演使用。根据目标、已有资产和当前生成入口，判断用什么参考、如何组合、缺什么、补到什么程度，以及需要向制作方说明什么。

## 使用入口
加载 `SKILL.md`，从当前任务直接进入；其相对链接指向按需读取的方法资料。保留整个 `r2v/` 目录结构，交由现有支持 Agent Skills 的客户端发现和加载。包本身不安装工具或修改项目配置。

适用请求包括：使用自己的角色复刻视频、保持多套服装/多机位场景一致、判断是否需要多视图或白模、设计动作/运镜/音色参考、发现素材缺口、诊断参考冲突和生成偏差。

## 内容组织
主入口给出判断顺序和停止补齐条件。四份方法资料分别处理素材充分性、参考冲突、生成方式与质量/时间策略、制作交接。`evals/` 用于维护检验，正常制作不要求读取。

方法按角色、道具、场景及控制用途组织；模型和平台的差异以当前能力条件输入。不设置默认模型、适配器或参数数据库。

## 产出与边界
通常产出一份并入既有方案的简短制作说明。导演用它制定任务；素材制作、提示词、生成执行、后期、调度、经验持久化和发布审查继续由现有能力承担。

本包不含模型调用、付费生成、上传、自动安装或任务调度脚本。唯一的 Python 文件是离线维护检查工具，不参与内容制作。

## 验证
`python3 evals/validate.py` 在任意工作目录运行都可定位本包，检查本包使用的元数据形式、相对链接、文件完整性、案例资料及内容边界标记；只读，不联网，不安装依赖。`--json` 输出机器可读报告。

结构检查结果在 `evals/validation.json`。`walkthrough.md` 是同一编写者的案例桌面走查，不是独立智能体测试或真实媒体生成。案例覆盖的预期判断不能当作模型画质、速度或成本承诺。

未在本次交付中执行客户端安装、原生加载、多 Agent 运行或真实视频生成。维护来源和经验依据见 `evals/sources.md`。
