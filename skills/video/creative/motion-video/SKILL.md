# Motion Video

## 能力定位

使用本 Skill 理解代码生成、动画化、编辑、合成和渲染画面及声音的能力。以文字、形状、组件、数据、图片、视频、音频、分析结果和三维数据作为可能输入；同一操作的成立条件取决于输入结构与质量，素材可以来自实拍、录屏或 AI 生成。

向调用者提供画面结果、必要输入、可控参数、边界和输出信息。导演依据这些信息决定叙事、镜头组合与制作任务。

## 输入条件的读法

先识别效果作用的对象，再解释该输入结构支持的控制范围。

| 输入结构 | 能力说明的重点 |
| --- | --- |
| 独立文字、路径、组件或规则 | 对象属性、运动和状态可以分别指定；说明内容、几何与时间规则 |
| 分层图片、视频与透明素材 | 说明各层的构图、时间、遮挡与混合关系，以及资产覆盖的范围 |
| 扁平图片或成片 | 直接操作的是像素和时间；对象级修改需要相应定位、分离、重绘或修补信息 |
| 遮罩、alpha、轨迹、光流、深度 | 说明数据代表什么、如何与素材对齐，以及其误差如何影响效果 |
| 三维几何与摄像机 | 说明空间、投影、材质、光照和可见范围；由素材恢复这些信息另有条件 |
| 音频、字幕与事件标记 | 说明来源、时间单位、精度和对应关系；已有标记与自动估计分别成立 |

算法、程序化计算和模型推理都可能由代码执行。分别说明“消费已有分析结果”与“从素材提取分析结果”的输入、输出和质量条件。

## 关键能力区别

- **对象与像素**：独立文字层可以直接改字；压入视频的字需要结合背景和对象信息描述覆盖、修补或重建条件。见 [G01](references/graphics-animation.md#g01)、[A06](references/source-analysis.md#a06)。
- **遮罩、透明度与空间**：区域遮罩、精细 alpha、二维位移、深度和三维几何承担不同信息。按所需结果说明数据类型。见 [C02](references/compositing.md#c02)、[A02–A05](references/source-analysis.md#a02)。
- **平面与空间运动**：平面变换、分层视差、深度辅助视差和真正的摄像机运动有不同成立条件。“点云”“环绕”“立体”等描述需要落实到具体变体。见 [C04](references/compositing.md#c04)、[D01](references/3d-spatial.md#d01)、[D03](references/3d-spatial.md#d03)。
- **已有内容与缺失内容**：采样、裁切、变速或滤镜主要处理现有信息；插值、修补与重建需要说明补充信息的依据及可验证范围。见 [M02](references/media-editing.md#m02)、[A06–A07](references/source-analysis.md#a06)。
- **直接控制与估计质量**：分别列出可指定的文字、坐标、时间和强度，以及依赖识别、跟踪、抠像或推断的结果质量。声音事件位置同样需要正确的时间映射。见 [A02–A05](references/source-analysis.md#a02)、[U02](references/audio-captions.md#u02)。
- **画面与交付结构**：透明合成需要保留 alpha 的输出链路；对象级编辑需要保留相应源码、资产和项目结构。见 [O02–O03](references/rendering-output.md#o02)。

## 能力说明与证据

围绕实际问题组织答案，先说明已给定输入能支持的结果。需要额外数据或运行组件的部分，连同条件一起表述，说明条件满足时可实现的结果；条件尚未核实时，保留结论的条件性。

每个条目包含名称、画面结果、输入、成立条件、可控范围、边界、输出和证据。按问题选取相关信息，保持描述粒度与问题一致。将技术事实连接到对应来源，将跨能力组合或信息范围判断标明为推导。

区分公开文档、可读源码、作品说明和实际运行记录。来源展示的某种实现支持相应条件下的能力；当前环境是否具备所需组件、模型、资产和编码器，应依据该环境的信息说明。对资料尚未覆盖的效果保留待核验状态。

将框架名称作为实现证据理解；时长、画幅、帧率、风格和节奏属于具体内容或实现参数。能力范围以条目列出的输入、操作和条件为依据。
