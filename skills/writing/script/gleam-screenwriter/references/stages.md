# 当前阶段的可解析产物

这些标题对应现有 App 的解析器与 gate。内容服务于用户确认的题材、媒介、时长和语言；标题兼容不意味着要套某个市场的故事。每次只输出指定阶段。

| 阶段 | 稳定标题／结构 | 验收关注 |
|---|---|---|
| 1 梗概 | `## 一句话梗概`、`## 完整大纲`、`## 本剧角色`；角色清单按 `**主角**` 与 `**配角**` 列 `- @名称（中文名） —— 定位` | 核心冲突、推进与结局；角色名单可供后续逐人展开 |
| 2 人物 | `## 核心关系定义`、`## 人物矩阵总览`，每位 `## @名称（中文名）` | 主配角覆盖、欲望／阻力／矛盾与功能、稳定称谓 |
| 3 三幕 | `## 第一幕`、`## 第二幕`、`## 第三幕`、可选 `## 三幕式总检` | 每幕有正文、转折与因果，回扣项目规模 |
| 4 事件 | 每个 `## 核心事件1：标题`；正文明确 `覆盖集数：第1集—第3集` 等范围 | 事件链与计划集数覆盖；未定集数先说明待确认，不假装覆盖完整 |
| 5 设定集 | `## ∆人物`、`## ∆物品`、`## ∆场景`；条目使用 `### @名称（中文名）` | 资产注册与前面名单一致，禁止用“同上”等占位代替可复用设定 |
| 6 分集大纲 | 每集 `## 第1集：标题`；列本集剧情、开头钩子、结尾悬念及 `∆` 资产；集间 `---` | 实际集数、核心事件分配、人物／资产引用、前后衔接 |
| 7 分集剧本 | `## 第1集：《标题》` + 概述字段 + `---` + `正文：` + 单块按时间顺序的动作与对白正文 | 集数完整、正文可解析、引用一致、时长与口吻服从项目 |

需要精确缺项时运行 `check --stage N`，采用返回值，不凭表格猜验收通过。默认 gate 是从 App 复用的工程口径；特殊体量或格式可能不完全符合它。遇到不适配时向用户说明冲突，优先尊重明确交付要求；只有确实获得覆盖授权时，才使用带理由的审批覆盖，不能把覆盖说成结构通过。

STAGE 1 的完整大纲至少说明项目定位／体量、核心卖点、冲突、推进和结局；用户没定的字段标待确认，不自行定案。STAGE 2 的名单来自 STAGE 1；STAGE 5 以后引用注册名。

## 只在选择 BL 短剧时加载

方向入口：`agent/script-agent/directions/bl-short-drama/direction.json`。节奏与商业钩子读取 `agent/script-agent/shared/short-drama/pacing-and-hooks.md`；英语语体读取 `agent/script-agent/shared/locale/english/dialogue-locale.md`。legacy 模板的双男主、约两分钟、情绪与市场假设只属于这个方向，不能回灌成通用默认值。

## 需要模板细节时

- 当前阶段示例模板保留在 `agent/script-agent/legacy/templates/`，按文件名选一份，不整目录加载。
- 通用项目把这些 legacy 模板作为结构参考，仅沿用当前解析需要的标题，去掉不符合用户要求的 BL／短剧默认设定。
- 通用方向的项目级约束见 `agent/script-agent/directions/general-screenplay/templates/stage-brief.md`。
