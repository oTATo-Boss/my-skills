# 移动界面概念图

识别 iOS、Android 或跨平台目标以及核心用户任务。优先设计实际屏幕内容，设备外框按展示需要加入。
从关键流程决定所需屏幕：入口、主要操作、结果和相关状态。屏幕数量由任务覆盖范围决定，不强制整套 onboarding。
共享导航、组件、字体、颜色、图标和媒体比例，同时让各屏适合各自内容。
明确安全区、状态栏、底部导航、返回路径、键盘和触控区域。检查长文案、空态、加载、错误以及成功反馈。
留足主要操作和阅读空间。健康、金融、社交、购物等类别采用符合目标用户的密度和表达，不套固定配色。
参考图可裁切用于比较；只有画质或信息不足时重新生成。逐屏检查流程是否连贯，不能把静态图宣称为可操作产品。
