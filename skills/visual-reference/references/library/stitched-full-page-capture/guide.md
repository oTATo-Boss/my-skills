# 可靠的视口拼接截图

用于懒加载、滚动揭示、canvas 或 fullPage 截图内容缺失的页面。使用当前可用浏览器工具，不依赖特定作者脚本。

1. 打开真实 URL，滚动到页尾预热懒加载，再回顶部。待布局和动画稳定后测量实际页面高度 H 与视口高度 V。
2. 按小于 V 的步长滚动。每次读取实际 scrollY，不用请求坐标假设浏览器已滚到对应位置。
3. 维护已输出的末尾坐标 E。当前视口起点 y，截图只裁取从 max(E-y,0) 开始的未输出部分，长度为 min(V,H-y)-max(E-y,0)。比例按截图像素比换算。
4. 滚动到底时浏览器把 y 限制到 H-V；从该截图顶部直接裁切会重复内容并漏掉页尾。使用实际 y 和重叠裁切，直到 E=H。
5. 页面小于一屏时只保留实际内容高度；页面动态增高时重新测量并继续。检查固定头部是否在每段重复，必要时按来源边界处理。
6. 将区块裁切建立在已验证的完整图上，按实际区块位置划分，不按区块数量平均分割。

检查页尾、相邻拼接点、懒加载媒体和一处滚动揭示区块。保存实际 URL、视口、像素比和采集方法；尺寸正确不足以证明内容完整。
