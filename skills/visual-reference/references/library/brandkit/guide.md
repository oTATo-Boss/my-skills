# 品牌视觉板

明确品牌名称、受众、核心价值、使用场景和已有标识。选择与品牌相关的视觉概念，再决定色彩、字形、图片和材质。
有现成 logo 时保持其身份；明确要求新 logo 时，可探索字母组合、负形、几何构造、产品动作或隐喻融合。
按交付选择品牌板内容：标识、构造、色彩、字体、图片方向、数字应用、实体应用与系统细节。面板数量不固定。
多个面板共享品牌名称、标识、颜色、字体与素材方向，但可用不同应用展示系统延展性。
在提示词中标明准确品牌文案与禁止添加的文字；长文排版优先在实际编辑工具中实现。
检查标识在小尺寸、单色、深浅底的辨识度。品牌效果图不等于可用矢量 logo 或完整品牌资产交付。
