# HTML 到交互提示词

检查给定 HTML、CSS、JS 与实际渲染。提取可见布局、交互触发、动画机制、组件状态与响应式行为。
每个提示词围绕一个可复用机制说明目标、输入、结构、触发条件、运动、性能和降级方式。
来源特定的颜色、尺寸、DOM ID 或库仅在精确复刻时锁定；灵感转译使用可调整参数。
静态截图只支持布局判断，不能证明滚动时间线、鼠标跟随或点击反馈。检查源代码或真实交互后再描述。
按用户交付选择文章、提示词清单或代码实现；不强制每日五项、固定 manifest 或附带视频数量。
