# 当次 UI 灵感采集

明确主题、参考数量和交付位置；数量没有要求时选择足够覆盖方向的少量实例。
对每个来源记录实际页面 URL、访问日期、设计特点、可复用机制和截图或视频证据。
真实页面优先，缩略图只作为入口。检查导航、滚动、关键区块和触屏表现；不可访问的来源如实标记。
按目标组织素材和分析，可以用原项目 manifest 或简单来源表；不要求固定日期目录、五项或二十项。
有滚动驱动或懒加载时采用视口拼接，并核对页尾和区块边界。避免只收首屏而宣称完整采集。
只有用户要求重复采集、提醒或监控时才创建对应自动化；当次采集不隐含定时任务或发布授权。
