# 版本记录

## v1.2.0 — 2026-10-14

- 每个独立 Skill 增加 `SOURCE.md` 约定，覆盖嵌套技能、外部收集、本地编写和二创／整合；保留来源、版本、作者、许可、日期、证据与未知状态。
- 安装、更新、迁移与开发安装同步流程维护来源记录，区分技能来源、参考资源、历史安装版本与本地调整。
- 只读审计新增 `--check-sources`，检查来源记录覆盖和结构，汇总部分确认与未知项；不联网、不自动修改、不把结构通过当作来源真实性或运行验证。

## v1.1.0 — 2026-10-13

- 更新为一级用途分类、可选二级分类与完整嵌套包的管理逻辑；小分类保留直接技能入口。
- 明确项目源码与本机安装沿用同一分类路径、独立实体副本及项目子集索引。
- 增加整包迁移、目录同名冲突、真实相对路径基准和客户端引用的校验要求。
- 默认以一行一个分类的表格展示完整分组清单，保留文件夹原名。
- 扩展只读审计到任意深度分类、子级导航数量、资源排除、开发安装映射与副本一致性，并增加回归用例。
- 当前开发与安装位置为 `Rules/skill-library-management/`，历史导入路径保留在原记录中。

## v1.0.0 — 2026-10-13

- 将已在本机使用的技能库管理工作流纳入 `my-skills` 开发仓库。
- 包含分级索引契约、变更与校验指南、只读审计脚本及 Agent 配置。
- 登记项目索引、安装映射、安装命令与来源；本机实体副本继续安装在 `meta/skill-library-management/`。
