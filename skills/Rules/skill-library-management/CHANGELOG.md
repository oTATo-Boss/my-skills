# 版本记录

## v1.6.0 — 2026-10-30

- 简化日常评估：逐项内容审阅形成参考分，质量70与社区／本人偏好各15分开展示；仍保留严格实测总分和原选择器证据门槛。
- 同一唯一档案增量保存任务验收、具体扣分、已读文件及历史运行边界；元信息不足显示区间，包内容变化使参考分失效，不把未知、估评或空档案计为实测完成。
- 展示表折叠子项，突出用途、参考分、质量、Star及日期、本人偏好与短板；相关查询保持离线复用。增加参考分、未知区间、贡献、过期事实及包更新隔离回归测试。

## v1.5.0 — 2026-10-30

- 管理范围限定为共享库及本项目对应源码映射，不再发现其他项目、系统、插件或客户端独立安装项。
- 固定唯一质量 JSON 与同位置派生展示表；复用历史结果，离线查询、按仓库去重和缓存复用、有限重试与失败保留。
- 明确共享根、统一管理资料、运行工具与外部回滚备份的目录分工；回执和有效报告迁移时修复来源引用，不重建过时汇总。
- 新增独立质量存储工具：带修订与锁保护的增量更新、历史保留、包修订核对、父包折叠及完成状态验收；原评分与结构工具继续复用。
- 明确未知不计完成，先补授权内可获得的证据，逐项交付真实阻塞；不以临时表、模板或 Star 分代替完整评分。
- 增加隔离行为测试；修复包内越界链接读取、gh 后备限流与两次传输预算、既有运行记录无理由改写；真实共享质量数据不纳入分发源码。

## v1.4.1 — 2026-10-30

- 增加真实新会话的原生隐式调用验收，记录评分互换、明确指定、依赖阻塞／项目根依赖满足和无关任务的实际工具轨迹；提供按需运行的 macOS 隔离夹具和离线证据反例测试。
- 实测发现旧接入可让模型读取档案后直接选择，未保证经过确定性选择器；明确有完整同类档案时须运行 select，细化候选事实与相对依赖路径基准。
- select 新增 `--request -`，只读会话可从标准输入传递候选事实，不必写项目文件。
- 修复实测环境中的嵌套 Seatbelt 冲突和父 App 桥接干扰，保留外层真实目录隔离；区分环境失败、旧规则观察与加固后的完整路由证据。
- 修复策略中文路径转义未命中开发目录的问题，新增全保护根及中文路径读写预检；探针失败时禁止模型运行，最终结果使用修复后重新创建的临时项目。

- 为新增、更新、已有运行证据、到期复核和更优候选建立相关范围内的重评与吸收升级流程，沿用原有来源、索引、安装、迁移及备份回滚机制。

## v1.3.0 — 2026-10-30
