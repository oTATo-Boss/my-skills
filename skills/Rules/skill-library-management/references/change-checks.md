# 变更、同步与校验

## 接入和更新

读取相关索引及来源文件，核实版本、作者／许可声明、依赖和资源闭包。在每个独立 Skill 根目录维护 `SOURCE.md`；字段、证据与未知状态见 [来源记录](source-records.md)。保留原始源码、参考、模板、素材与许可证；不替上游授予许可或声明原创。先检查同名目录、独立修改和客户端入口，再按授权接入；冲突不能静默覆盖。

普通共享技能修改真实来源。自研及明确纳入开发仓库的套件在开发目录修改，按项目规定的提交／推送顺序同步本机独立副本。系统、插件资源通过其发行渠道更新。仅做方案、审查或暂不推送的请求停在相应边界。

## 整包迁移

1. 从当前索引和真实入口生成旧路径到新路径的映射，标明保持现状的分类；确认目标不冲突。目录名和 Skill 名可能不同，以实际入口为准。
2. 记录受影响文件内容、执行权限、客户端链接以及原来有效的引用。修改前检查开发与安装的独立变动，已有差异先保留。
3. Skill 连同资源整包移动；嵌套包和套件共享目录保持闭包。若新分类名与现有 Skill 目录名相同，例如 `video/hyperframes`，先在临时位置保留整包，再建立分类目录；不移动目录到自身内部。
4. 同步拥有索引、父级导航和各层数量，重算跨 Skill 的绝对／相对引用。脚本里的相对路径要按真实基准解析，例如文件目录、`SKILL_DIR` 或项目目录；动态路径保留模板变量。不要全局替换所有 `../`。
5. 更新逐技能客户端链接和必要的指令引用，客户端仍指向安装目录；更新项目 `INSTALL_MAP.json`。项目同步自身维护的分类子集和源码路径，不引入整个共享库。
6. 核对资源没有丢失，内容变化只覆盖本次路径／代码调整，执行权限保留，原来有效的引用仍可达。改动可执行路径时运行相关行为检查。

索引、目录和软链接一起完成迁移。合法的外部源软链接保留实际所有权，不强制改成副本；开发仓库的安装副本则保持独立实体。只核对本次库内登记的客户端名称，不清理其他来源的入口。

## 完整维护库检查

脚本使用 Python 标准库，只读检查，不联网、不安装、不删除、不自动修复。

```bash
python3 scripts/audit_library.py \
  --skills-root /path/to/skills \
  --root-index /path/to/SKILLS_INDEX.md \
  --link-dir /path/to/client/skills \
  --check-sources \
  --json
```

`--link-dir` 可传多个，也可省略。检查任意深度的拥有索引、各层数量、导航行的子级数量、实际分类索引、漏项、重复归属、重名、失效入口和客户端目标。资源、缓存及索引代码示例不计入技能数量；返回导航不形成拥有循环。

安装、更新和来源补录后加 `--check-sources`：检查每个独立技能的记录、必需字段、技能身份、类型、确认状态与记录日期。缺失或无效记录失败；明确标记为部分确认或未知的记录计入覆盖，并汇总提醒。结构检查不证明上游链接有效、安装版本相同或许可已完整核实。

此命令用于完整共享库或技能开发仓库。普通项目的选型清单按需核对所选入口，不要求覆盖外部库。实际资源目录若采用特殊约定，先确认维护范围，再调整检查规则；不把检查报错当迁移或删除授权。

## 开发／安装映射

映射值是相对于开发仓库 `skills/` 与安装根目录的同一分类路径：

```json
{
  "installed_root": "~/.agents/skills",
  "mode": "independent-copy",
  "skills": {
    "ai-video-prompt": "video/ai/ai-video-prompt",
    "fashion-picture": "image/fashion-picture"
  }
}
```

检查映射覆盖、名称、源码路径、安装入口和独立副本：

```bash
python3 scripts/audit_library.py \
  --skills-root /path/to/project/skills \
  --root-index /path/to/project/SKILLS_INDEX.md \
  --install-map /path/to/project/INSTALL_MAP.json
```

安装位置可用 `--installed-root /path/to/installed/skills` 覆盖。完成同步后加 `--compare-installed` 核对包内文件内容与权限；比较跳过常见缓存、版本控制目录、`.env*` 和本机私有目录。它不证明脚本已运行或外部服务可用。

源码更新后、安装同步前出现副本差异是待同步状态；保留并报告差异，按当前授权和项目顺序处理，不直接以源码覆盖未知独立修改。

## 删除、停用与完成标准

删除只按用户明确的名称和路径执行，同时移除源码／安装副本、拥有索引登记、安装映射和客户端入口中的相应项。空分类按当前范围处理，相关品牌工作流和其他来源资源保留。停用遵循约定的可发现状态，不默认永久删除；不自动恢复已删除或停用内容。

完成时分别说明：

- **源码与结构**：资源闭包、分级导航、覆盖、数量、引用与权限。
- **安装同步**：安装映射、独立修改处理、副本一致性和客户端入口；未同步要明确说明。
- **实际运行**：本次针对性脚本或应用检查的真实结果；静态通过不代表完整创作、GPU、账号操作或生产功能已验证。

脚本回归验证：`python3 scripts/test_audit_library.py`。检查失败先诊断相关入口与维护源，不重复无效检查，也不借验证扩展任务范围。
